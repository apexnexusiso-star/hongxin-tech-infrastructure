Learning Check: Build the Evidence Chain

Pause after Slide 06 and connect records instead of listing them.

Which evidence route is most useful for this point in the lesson?

Option 1: Connected chain. Connect case comparison grid, audit plan, evidence conflict note with interviews and the sampled decision or review record.
Option 2: One record. Check whether Case Comparison Grid exists and stop there.
Option 3: Verbal assurance. Rely on the process owner's explanation if the answer sounds mature and consistent.

Coaching note: The practical move is to connect records, roles and decisions. In this case, start with three parallel samples: one rejected credit-limit increase, one imaging prompt complaint and one learning-path recommendation dispute, then test whether case comparison grid, audit plan, evidence conflict note support each other.

This is a learning pause, not a formal examination. Use it to test the direction of your audit reasoning before moving on.
