A2 定义与范围界定

本小类是指制造通过叶轮、转子、活塞、螺杆、隔膜、齿轮、滑片、旋涡或其他机构，对液体或气体进行输送、增压、压缩、循环、抽真空或计量的设备及其主要部件的活动。其核心对象包括流体通道、压力边界、旋转或往复运动部件、密封、轴承、润滑冷却、驱动接口和性能试验。

本小类通常包括离心泵、轴流泵、混流泵、旋涡泵、往复泵、柱塞泵、隔膜泵、齿轮泵、螺杆泵、计量泵、磁力泵、屏蔽泵、真空泵、鼓风或气体输送类设备、空气压缩机、螺杆压缩机、活塞压缩机、离心压缩机、滑片压缩机、隔膜压缩机、压缩机主机、泵组和压缩机组装配等制造活动。

本小类不包括以液压传动为目的的液压泵、液压马达和液压站，不包括以流体截断或调节为主的管道阀门，不包括发动机、涡轮机、发电机、电动机、制冷空调整机、管道安装工程、泵阀维修服务和单纯机械加工服务。若企业制造的泵或压缩机已嵌入成套设备，应按合同交付对象、产品铭牌、技术文件和主导功能识别。

B3 关键技术概念说明

泵和压缩机的共同基础是把外部机械功转化为流体能量。泵主要提升液体的压力、速度或位置能，压缩机主要提高气体压力并改变气体热力状态。二者都需要把转子、壳体、密封、轴承、润滑和驱动接口组合成稳定的流体机械。

液体泵与气体压缩机的过程条件不同。液体通常不可压缩，泵关注流量、扬程、效率、汽蚀、密封和过流部件；气体可压缩，压缩机会出现温升、级间冷却、排气脉动、压缩比、气体洁净度和润滑方式等问题。真空泵则关注抽速、极限压力、返油、密封和被抽介质条件。

密封和压力边界是本小类的基本事实。泵体、泵盖、压缩机壳体、气缸、法兰、轴封、机械密封、填料密封和管接头共同形成介质边界。介质可能是清水、污水、油品、化工液体、浆液、空气、天然气、蒸汽混合物或其他气体，不同介质会改变材料、防腐、密封和试验方法。

性能试验是泵压缩机制造的重要环节。泵通常通过流量、扬程、效率、功率、汽蚀、振动和噪声曲线反映状态；压缩机通常通过排气压力、流量、温度、功率、效率、泄漏、振动和噪声反映状态。仅凭零件尺寸无法完整判断设备运行性能。

D. 过程与技术

D1 主要工艺/过程流程

D1.1 离心泵和通用泵典型制造流程

`mermaid flowchart LR A["图纸/性能参数/材料"] --> B["铸锻件和外购件确认"] B --> C["泵体、泵盖、叶轮和轴加工"] C --> D["叶轮平衡、密封面和孔系检查"] D --> E["壳体水压或气密检查"] E --> F["总装、找正和密封装配"] F --> G["性能试验、振动噪声记录"] G --> H["涂装、封堵、包装交付"] `

离心泵制造通常以泵体、叶轮、泵轴、泵盖、轴承箱和密封结构为核心。泵体和泵盖多为铸件或焊接件，需完成流道清理、法兰面、轴承孔、密封腔和安装基准加工。叶轮需要形成叶片通道、轮毂、口环配合面和动平衡状态。泵轴需要控制同轴度、跳动、表面和键槽。

装配时需要确认轴承、叶轮、口环、机械密封、填料、联轴器和底座状态。密封安装、轴向间隙、转子窜量和转动灵活性会影响后续试验。泵性能试验通常围绕流量、扬程、功率、效率、振动、噪声和泄漏展开。

D1.2 压缩机典型制造流程

`mermaid flowchart LR A["压缩参数/气体条件"] --> B["壳体、转子和运动件准备"] B --> C["转子、气缸、曲轴或螺杆加工"] C --> D["热处理、表面和清洁处理"] D --> E["部件装配和间隙调整"] E --> F["润滑、冷却、气阀和控制装配"] F --> G["空载、负载、泄漏和性能试验"] G --> H["封存、标识和发运"] `

压缩机制造需围绕气体压力、温升、密封和机械运动组织。螺杆压缩机关注阴阳转子型线、啮合间隙、轴承、油气分离和冷却；活塞压缩机关注气缸、活塞环、曲轴连杆、气阀、填料和级间冷却；离心压缩机关注高速叶轮、转子动平衡、扩压器、密封和轴承振动。

气体压缩过程中温度和压力升高，零件材料、间隙、润滑、冷却和密封状态会影响运行基础。装配后常需要进行盘车、空载运行、压力泄漏、排气量、排气温度、振动、噪声和控制保护相关项目确认。

D1.3 真空泵和特种泵典型制造流程

`mermaid flowchart LR A["介质/真空/防腐要求"] --> B["材料和密封方案确认"] B --> C["壳体、转子、隔膜或过流件加工"] C --> D["清洗、表面防护和部件装配"] D --> E["气密、抽速或流量试验"] E --> F["防护、封堵和包装"] `

真空泵和特种泵的过程特点来自介质条件。化工泵、磁力泵、屏蔽泵、隔膜泵和真空泵常对材料、密封、隔离、气密、防腐、清洁和泄漏路径更加敏感。磁力泵和屏蔽泵弱化传统轴封，但会增加隔离套、电机或磁传动接口；隔膜泵则通过隔膜隔离介质，对隔膜材料、疲劳和夹持状态更敏感。

E. 产业链与边界

E1 上游供应

上游包括铸件、锻件、板棒材、密封件、轴承、电机、联轴器、机械密封、气阀、仪表、控制柜、涂层材料、无损检测资源、热处理资源和试验台资源。上游材料的耐腐蚀、耐磨、壁厚、组织、表面和标识，会传递到壳体、转子、密封和压力边界。

压缩机和真空设备还依赖气阀、油气分离器、冷却器、过滤器和控制部件；特种泵依赖专用材料、衬里、隔离套和机械密封。上游配套件差异决定产品路线差异。

E2 下游应用/客户

下游包括给排水、市政、水处理、化工、石化、能源、电力、矿山、冶金、食品、医药、造纸、建筑、暖通、压缩空气站、真空系统、实验装备和工业公用工程。下游需求通常以介质、流量、扬程、压力、温度、黏度、含固量、腐蚀性、安装方式、连续运行时间、维护条件和性能曲线体现。

E3 本小类在产业链中的位置

本小类位于材料、铸锻件、密封、轴承、电机和控制元件之后，工艺装置、公用工程和流体系统之前，是把机械功转化为流体压力、流量、压缩或真空能力的设备制造环节。泵和压缩机通常既是独立产品，也是成套设备和工程系统的关键部件。

E4 常见委外/外包环节

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类覆盖范围宽，技术复杂度从小型清水泵到大型离心压缩机、化工特种泵和真空机组差异很大。普通水泵制造相对成熟，核心在铸件、叶轮、密封、装配和性能试验；化工泵和特种泵增加介质材料、密封隔离和防腐要求；压缩机增加气体热力、温升、润滑冷却、振动和噪声控制；大型离心压缩机和工艺气压缩机则具有高速转子和成套机组特征。

自动化程度随产品路线不同而变化。标准泵和小型压缩机可采用批量加工、自动装配和自动试验；大型泵、非标化工泵、工艺压缩机和真空机组具有项目化和小批量特点。人工经验在密封安装、转子找正、异常声音识别、泄漏观察、性能曲线判断和现场接口理解中仍然重要。

敏感点客观影响链
介质条件识别不足温度、腐蚀、黏度、含固或气体成分偏差 → 材料和密封选择偏移 → 泄漏、腐蚀、磨损或性能波动。
叶轮或转子不平衡加工、铸造或装配质量分布偏差 → 旋转不平衡增加 → 振动、轴承载荷和密封磨损路径变化。
过流部件铸造缺陷泵体、叶轮或壳体缩孔、夹渣、裂纹异常 → 承压和流道状态变化 → 泄漏、效率或强度状态波动。
密封安装状态异常机械密封端面、弹簧、冲洗或填料压紧状态偏移 → 介质泄漏或端面发热路径形成。
轴承和润滑状态不稳定润滑、预紧、装配或冷却异常 → 摩擦和温升变化 → 振动、噪声和寿命状态波动。
壳体压力试验条件偏移试验介质、压力、保压或排气条件不稳定 → 微漏和变形信息不充分 → 承压状态判断失准。
泵吸入条件不匹配吸入管路、汽蚀余量或介质温度偏移 → 汽蚀和流量波动 → 叶轮表面和性能状态变化。
压缩机间隙调整偏差转子、活塞、气阀或密封间隙不一致 → 温升、泄漏和效率变化 → 排气状态波动。
性能试验系统不稳定流量、压力、温度、功率或转速测量条件偏移 → 性能曲线可比性下降 → 产品参数信息失真。
涂装封堵和运输防护不足内腔防锈、接口封堵或支撑不足 → 锈蚀、污染、碰伤或异物进入路径形成。

H3 只记录行业中客观存在的敏感点及事实因果链，不对其在任何上层视图中的重要性作判断。
