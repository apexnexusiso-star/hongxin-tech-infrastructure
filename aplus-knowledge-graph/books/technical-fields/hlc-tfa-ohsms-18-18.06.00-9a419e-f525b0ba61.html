A. 标识与定位

A1 小类名称、分类代码、在分类体系中的位置

字段内容

专业小类名称武器和弹药的制造
所属大类18 机械和设备制造相关活动
所属中类18.06 武器和弹药制造
本卡定位描述受严格许可和监管的武器、弹药及相关专用部件制造活动的行业事实，侧重分类边界、受控过程、追溯、检测和资料维护，不展开可操作性制造参数或敏感技术细节。
与上层文件关系本卡只记录底层行业事实、技术边界、过程、设备、投入、检测手段和维护信息，不记录任何上层视图判断。

A2 定义与范围界定

本小类是指在法定许可、专门资质、受控设施和授权技术文件条件下，制造武器、弹药及相关专用部件的活动。其核心对象包括专用金属部件、发射或作用机构、装配单元、专用包装、标识追溯、受控储运接口和经授权的检验试验活动。

本小类通常包括军用或专门用途武器系统的部件和成品制造、弹药及其专用组件制造、武器配套机械部件制造、专用包装和标识，以及与制造直接相关的受控装配、检验和交付活动。不同国家、地区和机构受控分类对武器、弹药、火工品、军警装备和民用许可产品边界可能不同，正式版本应以机构受控分类和有效许可范围为准。

本卡不提供武器弹药的配方、装药、结构尺寸、作战性能、使用方法、改装方法或任何可操作性制造步骤。单纯金属机加工、普通机械零件制造、车辆制造、电子设备制造、化工原料生产、安防器材、体育器材、玩具模型和维修服务，不因外观或用途关联而自动归入本小类。

B3 关键技术概念说明

武器和弹药制造的核心是受控属性，而不是普通机械复杂度。即使某些零件加工方式与一般机械相似，一旦产品具有法定受控属性，其许可、资料、标识、区域、人员和交付边界都会明显不同。 本小类的底层卡只描述行业事实和分类边界，不展开可用于制造、改装、装药、使用或提高效能的技术细节。技术深度应体现在受控制造链条、追溯、检测、包装和接口识别上。 产品状态的形成通常来自材料、零部件、装配、标识、试验和储运条件的连续控制。批次混淆、标识不一致、受控资料变更或包装封识异常，都会改变产品流转和交付状态。

D. 过程与技术

D1 主要工艺/过程流程

`mermaid flowchart LR A["授权文件确认"] B["受控材料和组件接收"] C["专用零件制造"] D["受控装配和标识"] E["检验试验和记录"] F["包装封存"] G["交付资料形成"] A --> B B --> C C --> D D --> E E --> F F --> G `

本小类制造过程以授权文件和许可范围为起点。材料、零部件、装配单元和试验项目需要与受控文件保持一致，任何变更都需在相应授权边界内处理。 专用零件制造可包含精密加工、热处理、表面处理、无损检测、清洗和防护等过程，但本卡不记录可操作性武器弹药制造参数。装配过程强调区域、人员、工装、批次、标识和记录。 包装和交付不是附属环节，而是受控产品流转的一部分。包装封识、标签、批次、随机资料和储运条件共同构成产品交付状态。

E. 产业链与边界

E1 上游供应

上游包括受控材料、精密机械部件、电子控制部件、包装材料、计量检测资源、授权技术资料和许可供应链。上游批次、标识、文件和储运状态会直接传递到成品追溯和交付边界。

E2 下游应用/客户

下游为国防、执法、许可使用单位、受控科研试验单位或其他授权用户。下游需求通常以许可范围、交付资料、序列化追溯、包装储运和授权试验项目体现。

E3 本小类在产业链中的位置

本小类位于受控材料和专用部件供应之后、授权用户和许可使用场景之前，是将专用材料、机械电子组件、装配、检测、标识和包装整合为受控产品的环节。

E4 常见委外/外包环节

委外/外包环节行业常见原因边界提示
专用零件加工部分精密加工或表面处理资源专业化仅在许可和授权边界内作为受控外部接口处理。
材料和检测材料、无损检测和环境类别试验资源专业化作为状态确认信息来源。
包装和储运受控包装和储运资源专业化作为交付边界组成部分。
试验资源授权试验条件和设施专门化仅记录类别，不展开条件细节。

E5 典型接口资料与实物流转补充

F. 适用法规与技术标准

F1 行业准入/资质/许可要求

本小类通常处在国防、武器弹药、危险物品、出口控制、保密、许可生产、储运和专门用户管理等严格监管边界内。具体许可、资质、产品目录、试验、储运和交付要求需由技术管理部门和法规维护人员按现行有效规则核准。本卡只记录类别和检索方向。

标准类别可能覆盖内容本卡处理方式

本小类涉及产品质量、标准化、计量、许可生产、国防科技工业、保密、危险物品、储运、出口控制、市场监管和合同交付等通用类别。环境、能源、职业健康安全等跨主题事项只保留门槛类别指针，具体适用性评价由相应文件处理。

G. 检验、检测与计量手段

G1 行业常用检测/试验/计量方法

方法类别常用手段适用对象
材料检测材料证明、成分验证、硬度、金相和无损检测类别受控材料和关键件。
尺寸和形位检测量具、检具、三坐标和专用检具精密零部件和装配接口。
装配状态检查标识、序列号、批次、装配记录和外观检查组件和成品。
环境和防护检查温湿度、振动、包装、防潮和封识检查类别包装件和交付单元。
授权功能试验按授权文件开展的功能或状态确认成品、组件或样件。

G2 关键检测参数与对应方法

参数/项目常见方法说明
材料状态材料证明、硬度、金相和检测记录确认受控投入状态。
尺寸形位三坐标、专用检具和量具确认装配接口。
标识追溯序列号、批次号、标签和记录核对确认流转链条。
包装封识外观、封识、缓冲和防潮检查确认交付防护状态。
授权试验状态授权项目记录和计量状态确认产品状态信息。

G3 典型检测组合与适用对象

适用对象常见检测组合识别意义
专用机械部件材料、尺寸、形位、表面、无损检测和标识反映部件状态。
弹药组件批次、标识、外观、包装、隔离和授权试验类别记录反映受控组件状态。
成品单元序列化、装配记录、功能类别确认、包装和交付资料反映受控成品状态。
包装单元封识、标签、缓冲、防潮、数量和资料一致性反映储运交付状态。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类技术复杂度和监管复杂度均高。普通机械加工知识不足以完整理解其边界，必须同时理解许可、保密、受控资料、区域、批次、标识、包装、储运和授权试验。自动化程度因产品族不同差异较大，但文件、追溯和隔离管理始终是行业本底特征。

H2 典型组织形态

组织形态典型特征常见资源配置
专用部件企业制造受控机械或电子组件精密加工、检测、标识和受控资料资源。
组件装配企业按授权资料进行组件装配隔离区域、工装、追溯和检测资源。
成品总装企业形成受控成品和交付资料总装、授权试验、包装和资料管理资源。
包装储运配套企业专用包装、防护和标识包装工装、封识、仓储和流转资料资源。

H3 客观存在的易出问题环节/技术敏感点

敏感点客观影响链
受控资料版本不一致图纸、清单或工艺文件版本偏移 → 制造依据变化 → 产品追溯和交付状态受扰动。
批次标识混淆材料、组件或包装批次识别不足 → 追溯链条断裂 → 交付资料状态异常。
区域和隔离状态不足物料、人员或工序隔离不充分 → 混料或非授权接触路径形成 → 产品流转状态受扰动。
装配记录不完整装配、检验或处置记录缺失 → 状态信息无法关联 → 成品交付信息不完整。
包装封识异常封识、标签、防护或数量信息偏移 → 储运识别和交付状态变化。
检测计量状态异常检具、试验设备或记录状态偏移 → 检测结果可追溯性下降。
外部接口控制不足外协加工、检测或储运接口资料不完整 → 受控边界信息断裂。

H3 只记录行业中客观存在的敏感点及事实因果链，不对其在任何上层视图中的重要性作判断。
