A. 标识与定位

A1 小类名称、分类代码、在分类体系中的位置

本卡定位专业小类底层知识卡，用于沉淀冷成型或冷弯的行业事实、技术过程、边界、检测手段和基础信息

17.03.03 冷成型或冷弯，是以钢带、钢板、热轧或冷轧板带、镀层板带、不锈钢带或其他钢材为主要投入，在常温或接近常温条件下通过辊压成形、折弯、冷弯、冲孔、切断、校形、矫直、端部加工和包装等过程，形成开口冷弯型钢、冷成型型材、檩条、槽形件、角形件、帽形件、护栏板、货架型材、门窗型材和其他冷弯钢制型材的生产活动。

本小类的核心是通过连续辊压或折弯，使板带材料发生塑性弯曲并形成目标截面。它不是以厚度减薄为主的冷轧，也不是以穿模拉拔为主的棒材或线材冷拔，更不是闭口焊管和空心型钢制造。冷弯产品通常保持原材料厚度基本不变，重点在截面形状、弯曲角度、孔位、长度、直线度、扭曲、镰刀弯和表面状态。

A2 定义与范围界定

冷成型或冷弯通常指将板材或带材经开卷、校平、送料、辊压成形或折弯成形，使平板或带材转变为具有一定开口截面、折边、加强筋、孔位或边部形态的型材或零件毛坯的活动。典型过程包括开卷、矫平、伺服送料、冲孔、辊压成形、切断、校形、端部加工、去毛刺、标识和包装。

本小类可包括冷弯 C 型钢、Z 型钢、U 型钢、槽钢、角钢、帽型钢、开口异型钢、货架立柱、光伏支架型材、门窗钢衬、轨道和导轨类型材、护栏板、钢结构檩条及其他开口冷弯型材的制造。若企业主导活动是将板带冷弯成型材并以型材或冷弯件交付，可纳入本卡。

本小类不覆盖窄钢带冷轧、闭口焊接钢管和方矩管、钢结构组焊和安装、冲压成具体零件、汽车车身覆盖件冲压、金属家具装配、门窗成品装配、货架总成装配、管道和管件制造。若企业只是使用冷弯型材组焊成构件或装配成系统，应按主导交付物另行识别。

B3 关键技术概念说明

冷成型或冷弯的第一个关键概念是截面成形。板带材料通过多个辊轮道次逐步弯曲，最终形成目标开口截面。与冷轧不同，冷弯通常不以厚度减薄为目标，而以截面形状、角度、边高、孔位和长度尺寸为目标。

第二个关键概念是回弹和残余应力。钢材冷弯后会发生弹性回复，材料强度、厚度、镀层、弯曲半径和辊花设计都会影响回弹。残余应力还可能导致扭曲、镰刀弯和切断后的形状变化。

第三个关键概念是辊轮和模具。辊压成形质量依赖辊花设计、辊轮加工精度、机架对中和设备刚性。多规格冷弯企业经常换辊换模，换型状态会影响首件尺寸和稳定生产。

第四个关键概念是冷弯与下游组装的边界。冷弯型材可以直接用于钢结构、货架、光伏支架、护栏和门窗，但本小类的交付物应仍是型材或型材毛坯。装配成系统或工程构件后，主导活动已经可能变化。

C2 主要功能和性能维度

冷弯型材的功能来自开口截面带来的截面惯性矩、轻量化、可连接性、可定尺生产和可连续成形。与热轧型钢相比，冷弯型钢可用较薄板带形成复杂截面；与冲压件相比，冷弯型材更偏长条连续截面和重复孔位。

客观描述冷弯产品时，常见维度包括材料牌号、基材厚度、镀层或表面状态、截面尺寸、边高、折弯角度、圆角半径、孔径、孔距、孔位、长度、直线度、扭曲、镰刀弯、端面状态、毛刺、表面划伤、锌层损伤、批号和包装状态。

D. 过程与技术

D1 主要工艺或过程流程

`mermaid flowchart LR A["钢带、钢板或镀层板带"] --> B["原料验收、开卷和校平"] B --> C["送料、冲孔或预切"] C --> D["辊压成形或折弯成形"] D --> E["校形、矫直和尺寸调整"] E --> F["切断、端部加工和去毛刺"] F --> G["检测、标识和包装"] G --> H["冷弯型材或冷成型件"] `

冷弯生产从板带原料验收开始。原料的钢号、厚度、宽度、屈服强度、镀层状态、边部、表面划伤和卷形，会影响成形稳定性。开卷和校平用于减少原料卷曲和板形问题，为连续送料和冲孔提供基础。

辊压成形通常通过多道次辊轮逐步折弯板带。每一道次只完成一部分角度或边部变形，最终形成目标截面。冲孔可安排在成形前、成形中或成形后，切断可采用飞锯、飞剪、液压剪或锯切方式。

折弯路线适合较短件、小批量或较厚板材，常使用折弯机和专用模具完成角度成形。无论辊压还是折弯，最终都需要校形、尺寸确认、去毛刺、表面检查、标识和包装。

E3 本小类在产业链中的位置

冷成型或冷弯位于板带钢材和下游结构、支架、货架、护栏、门窗、设备框架之间。它将平板或带材转化为具有截面刚度和连接孔位的型材或毛坯，是钢材从板带形态走向结构形态的重要冷加工环节。

本小类边界应以“开口截面或型材形态形成”为核心。若企业交付仍为型材、打孔型材或定尺冷弯件，可纳入本卡；若交付为装配完成的钢结构、货架、支架系统、门窗或设备外壳，应按相应制品或工程活动识别。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

冷成型或冷弯属于钢材冷态截面成形活动，技术复杂度来自原材料强度和厚度、辊花设计、回弹、孔位同步、模具磨损、设备对中、切断变形和表面保护之间的相互作用。它不像冷轧那样以厚度控制为主，也不像冲压那样以单件模具成形为主，而是以连续截面稳定性为核心。

自动化程度差异明显。标准 C/Z 型钢和货架型材企业可能使用自动开卷、冲孔、辊压、切断一体线；小型折弯企业可能以数控折弯和人工搬运为主。多品种定制型材对换型、首件确认和工装状态依赖较强。

H2 典型组织形态

H3 客观存在的易出问题环节和技术敏感点

环节或敏感点客观事实描述客观影响链
原料强度波动不同批次钢材屈服强度可能不同强度变化 → 回弹量变化 → 截面角度和尺寸变化
原料厚度波动板带厚度影响辊缝和折弯半径厚度偏离 → 成形压力和角度变化 → 截面状态变化
辊轮对中多道次辊轮需保持中心一致对中偏离 → 带材跑偏 → 扭曲或截面偏差
冲孔同步连续线孔位与切断长度关联送料或同步偏差 → 孔距变化 → 定尺产品状态变化
回弹控制冷弯卸载后会发生回弹回弹补偿不足 → 角度偏差 → 装配适配状态变化
切断变形长型材切断时可能产生端部变形刀具或夹持偏离 → 端部塌角或毛刺 → 端部状态变化
镀层损伤镀层板带成形时可能划伤或开裂弯曲半径或摩擦异常 → 镀层损伤 → 表面防护状态变化
换型首件多规格生产需要换辊换模换型设定偏离 → 首件尺寸波动 → 批量状态变化
长件储运长型材易弯曲和磕碰支撑和捆扎不足 → 变形或划伤 → 交付状态变化
边角毛刺冲孔和切断形成毛刺刀具磨损 → 毛刺增大 → 后续装配和搬运状态变化
