A2 定义与范围界定

本小类是指制造机械设备中用于支承、定位、减摩、承载、传递运动、传递扭矩、改变转速、改变运动方向或连接驱动系统的基础机械部件的活动。典型对象包括滚动轴承、滑动轴承、轴承座、齿轮、齿轮轴、蜗轮蜗杆、减速机、齿轮箱、联轴器、离合器、制动或驱动元件、飞轮、皮带轮、链轮、同步带轮、传动轴和类似部件。

本小类的核心技术不是一般金属零件加工，而是几何精度、材料组织、热处理、磨削表面、齿形齿向、轴承游隙、摩擦磨损、润滑、噪声振动和传动效率的组合。轴承关注滚道、滚动体、保持架、游隙、旋转精度和寿命；齿轮关注齿形、齿向、齿距、齿面硬度、接触斑点和传动噪声；传动部件关注扭矩、同轴、平衡、联接和装配运行状态。

本小类不包括发动机和涡轮机整机、泵和压缩机整机、液压设备、汽车变速器整机、整台机床或工程机械、单纯机加工服务、金属热处理和涂覆服务、紧固件和螺杆机械产品、金属链条弹簧等一般金属制品。若企业只为其他单位来图加工轴、齿轮坯或壳体，不形成轴承、齿轮或传动部件成品功能，应按主导活动识别。

B3 关键技术概念说明

轴承、齿轮和传动部件的共同基础是机械运动关系。轴承支承旋转并减少摩擦，齿轮通过啮合传递转速和扭矩，联轴器连接驱动端与被驱动端，减速机或齿轮箱把齿轮、轴、轴承、箱体、密封和润滑组织成可连续运行的传动单元。它们通常不是终端整机，却决定大量机械设备的运动精度、寿命、噪声和传动稳定性。

热处理和表面完整性是本小类的核心概念。轴承套圈、滚动体和齿轮常需要淬火、渗碳、碳氮共渗、氮化、回火或表面强化形成硬度和耐磨层。热处理会带来硬度、组织和变形的共同变化，后续磨削或超精加工需要恢复几何精度并形成稳定表面。磨削烧伤、脱碳、裂纹、残余应力和表面粗糙度都会改变疲劳路径。

几何精度是传动件功能形成的基础。轴承关注圆度、沟道形状、滚动体尺寸分组、游隙和旋转精度；齿轮关注齿形、齿向、齿距、径向跳动、齿面粗糙度和接触斑点；齿轮箱关注轴系同轴、轴承预载、齿轮啮合、箱体孔系和润滑油路。即使材料合格，几何和装配状态不稳定也会引起噪声、振动和磨损。

润滑和清洁是本小类长期运行的基础。轴承和齿轮的接触副在高载荷和重复运动中工作，油脂、润滑油、密封、防尘、清洁度和包装防护都会影响摩擦、磨损和腐蚀路径。小颗粒污染、加工残屑、磨粒或防锈不当，可能在运行中放大为点蚀、剥落或啮合异常。

D. 过程与技术

D1 主要工艺/过程流程

D1.1 滚动轴承典型制造流程

`mermaid flowchart LR A["轴承钢/套圈毛坯/滚动体"] --> B["车加工和热处理"] B --> C["套圈磨削和滚道精加工"] C --> D["滚动体加工、分组和清洗"] D --> E["保持架、密封件和零件准备"] E --> F["装配、游隙调整和注脂"] F --> G["旋转、噪声、振动和外观检测"] G --> H["防锈、包装和标识"] `

滚动轴承制造通常以套圈、滚动体、保持架和密封件为主线。套圈经锻造或管料下料、车加工、热处理、磨削、超精加工和清洗形成滚道和配合面。滚动体经冷镦、热处理、研磨、抛光和分组选配形成尺寸和表面状态。保持架可能采用冲压、机加工、注塑或其他路线。

装配阶段需要控制滚动体分组、保持架、游隙、密封件、润滑脂和清洁度。轴承旋转精度、噪声、振动、摩擦力矩和外观状态，通常在装配后通过专用设备确认。精密和低噪声轴承对清洁、温度、测量和包装防护更敏感。

D1.2 齿轮和齿轮轴典型制造流程

`mermaid flowchart LR A["棒材/锻件/齿坯图纸"] --> B["下料、锻造或粗加工"] B --> C["齿坯车削和基准加工"] C --> D["滚齿、插齿、铣齿或剃齿"] D --> E["热处理和校正"] E --> F["磨齿、珩齿或精加工"] F --> G["齿形、齿向、硬度和表面检测"] G --> H["防锈、包装或转入装配"] `

齿轮制造的主线是齿坯、齿形形成、热处理和精加工。齿坯基准决定后续齿形测量和装配关系。滚齿、插齿、剃齿、铣齿、拉齿、磨齿和珩齿等路线需要根据齿轮类型、精度、材料和批量选择。热处理会提高齿面强度，但也会带来变形，常需后续磨齿或珩齿修正。

齿轮的功能依赖齿面接触和啮合状态。齿形、齿向、齿距、跳动、背隙、硬度、有效硬化层、齿面粗糙度和磨削烧伤，都是理解齿轮制造状态的重要事实。大齿轮、风电齿轮和重载齿轮还涉及大型热处理、探伤、齿面强化和运输防护。

D1.3 减速机、齿轮箱和传动部件典型制造流程

`mermaid flowchart LR A["速比/扭矩/接口参数"] --> B["箱体、轴、齿轮和轴承准备"] B --> C["箱体孔系和安装面加工"] C --> D["齿轮轴承密封和轴系装配"] D --> E["啮合、背隙、预载和润滑调整"] E --> F["空载或负载试运行"] F --> G["噪声、振动、温升和泄漏记录"] G --> H["防护、包装和交付"] `

减速机和齿轮箱制造把齿轮、轴、轴承、箱体、密封和润滑组合为可运行传动单元。箱体孔系位置、轴承座同轴、齿轮中心距、轴向定位、轴承预载、密封件和润滑油路共同决定运行状态。装配后通常需要盘车、空载试运行、噪声、振动、温升、泄漏和接触斑点检查。

联轴器、离合器、皮带轮、链轮和传动轴则更关注扭矩传递、同轴、平衡、连接尺寸、键槽、花键、摩擦面和弹性元件。高速联轴器和大扭矩传动轴对动平衡、材料和表面状态更敏感。

E. 产业链与边界

E1 上游供应

上游包括轴承钢、合金钢、锻件、铸件、粉末件、保持架材料、密封件、润滑脂、润滑油、磨料磨具、刀具、热处理资源、表面处理资源和检测设备。材料纯净度、组织、硬度、热处理变形、磨削表面和清洁度会直接传递到轴承、齿轮和传动件状态。

轴承路线对轴承钢、滚动体、保持架、润滑脂和清洁包装依赖较强；齿轮路线对锻件、齿轮刀具、热处理和齿轮测量依赖较强；减速机路线对箱体、轴承、齿轮、密封和润滑油接口依赖较强。

E2 下游应用/客户

下游包括机械设备、泵阀、发动机和涡轮机、风电、矿山、冶金、机床、机器人、工程机械、农业机械、食品包装、纺织、印刷、物流设备、轨道交通、船舶和工业自动化。下游需求通常以载荷、转速、扭矩、寿命、精度、噪声、安装接口、润滑方式、维护周期和运行环境体现。

E3 本小类在产业链中的位置

本小类位于金属材料、热处理、精密加工和检测资源之后，机械设备运动系统之前，是把材料和几何加工转化为支承、传动、减速、联接和驱动能力的基础环节。轴承和传动件通常作为广泛制造业的通用基础件，也可能作为高端装备中的专用关键部件。

普通齿轮齿形、齿向、齿距、硬度、表面粗糙度、跳动和外观反映啮合几何和材料状态。
重载齿轮材料、无损检测、硬化层、磨削烧伤、齿面接触和尺寸反映承载和疲劳路径。
减速机箱体孔系、齿轮啮合、轴承预载、背隙、跑合、温升、噪声、振动和泄漏反映成套传动运行状态。
联轴器和传动轴尺寸、同轴、动平衡、材料、扭矩和表面反映扭矩传递和旋转连接状态。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类属于机械制造中精密基础件和传动件领域。普通轴承、普通齿轮和通用联轴器可形成标准化批量生产；精密轴承、高速低噪声轴承、风电齿轮、工业齿轮箱、机器人传动和大型重载传动件复杂度较高。其共同特征是材料、热处理、精密加工、磨削、装配、润滑和运行试验高度耦合。

自动化程度随产品族差异明显。标准轴承可采用自动套圈加工、热处理、磨削、装配、注脂和在线检测；齿轮加工可采用数控滚齿、磨齿和齿轮测量；减速机和齿轮箱装配仍依赖人工对轴承预载、齿轮啮合、接触斑点、跑合声音和泄漏状态的判断。精密传动和大型传动件更强调工艺经验和测量解释。

H3 客观存在的易出问题环节/技术敏感点

敏感点客观影响链
材料纯净度和组织波动材料夹杂、偏析或组织异常 → 热处理和疲劳状态变化 → 点蚀、剥落或断裂路径形成。
热处理变形和硬度不稳定温度、时间、冷却或装炉状态偏移 → 硬度、硬化层和尺寸变化 → 磨削余量和承载状态波动。
磨削烧伤或表面损伤砂轮、冷却、进给或修整状态异常 → 表面组织和残余应力变化 → 疲劳和噪声路径形成。
轴承游隙和配组不一致滚动体分组、套圈尺寸或装配状态偏移 → 内部间隙变化 → 噪声、温升和寿命状态波动。
齿形齿向偏差刀具、机床、夹具或热处理变形异常 → 啮合接触和载荷分布变化 → 噪声、振动和齿面磨损路径形成。
齿轮箱孔系和轴系偏差箱体孔距、同轴或轴承座位置偏移 → 轴系和齿轮啮合状态变化 → 温升、噪声、泄漏或效率波动。
润滑和清洁不足磨粒、切屑、油脂量或油品状态异常 → 摩擦副表面受扰动 → 磨损、点蚀和温升路径形成。
密封和防尘状态不足密封件、油封或防尘盖装配偏移 → 外部颗粒或水汽进入 → 润滑状态和腐蚀路径变化。
动平衡和旋转状态不稳定联轴器、传动轴或齿轮质量分布偏差 → 不平衡量增加 → 振动和轴承载荷路径变化。
包装防锈不足防锈、封装、干燥或运输支撑不足 → 锈蚀、碰伤或污染路径形成 → 装配和运行状态受扰动。
