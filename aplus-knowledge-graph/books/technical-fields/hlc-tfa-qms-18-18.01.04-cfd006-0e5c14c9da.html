18.01.04 其他龙头和阀门的制造 专业小类基础卡

A. 标识与定位

A1 小类名称、分类代码、在分类体系中的位置

字段内容

所属大类18 机械和设备制造相关活动
所属中类18.01 通用动力、流体控制和机械传动设备制造
本卡定位描述用于管路、容器、设备和流体系统中截断、调节、止回、分配、保护或释放介质的龙头、阀门、阀体、启闭件、密封副和执行机构组合件制造活动的行业事实。
与上层文件关系本卡只记录底层行业事实、技术边界、过程、设备、投入、检测手段和维护信息，不记录任何上层视图判断。

A2 定义与范围界定

本小类是指制造安装在液体、气体、蒸汽、油品、化工介质、给排水、燃气、暖通、食品卫生、消防、能源或工业过程管路中的龙头、阀门及其主要部件的活动。其核心功能是通过阀体、阀盖、阀座、阀瓣、闸板、球体、蝶板、阀杆、密封件、执行机构和连接端，控制介质通断、流向、压力、流量、泄放或防倒流。

本小类通常包括闸阀、截止阀、球阀、蝶阀、止回阀、安全阀、减压阀、调节阀、疏水阀、旋塞阀、针型阀、隔膜阀、卫生阀、燃气阀、暖通阀、水龙头、角阀、混水阀、阀门驱动装置配套装配和阀门主要金属部件制造。产品可为标准管道阀门，也可为按压力、温度、介质、连接方式和工况定制的工业阀门。

本小类不包括液压系统专用阀、泵和压缩机、管道安装工程、仪表独立制造、消防系统成套工程、液压设备、燃烧器、橡胶密封件独立制造、陶瓷卫浴制品和单纯机加工服务。若阀门作为锅炉、泵组、压缩机组、液压站或成套设备内部配套件采购，应根据主导交付对象识别。

B3 关键技术概念说明

阀门制造的核心不是单纯金属外形加工，而是压力边界、流体通道、启闭运动和密封副的组合。阀体和阀盖承受介质压力，启闭件改变流道状态，阀座和密封件控制泄漏，阀杆和执行机构传递动作。不同阀门结构的流体控制原理不同：闸阀以闸板升降截断，球阀以球体旋转通断，蝶阀以蝶板旋转调节，止回阀依靠介质流向自动启闭，调节阀则通过阀芯开度改变流量。

密封副是理解本小类的关键。金属密封面需要控制硬度、粗糙度、研磨、同轴度和接触带；软密封需要控制材料、压缩量、温度和介质适配。阀座泄漏、填料泄漏、法兰泄漏和阀杆泄漏是不同路径，不应混为一个概念。

介质和工况决定阀门材料和结构。水、蒸汽、油品、燃气、腐蚀性化学品、浆液和食品介质对材料、密封、内腔清洁、防腐、防磨和温度适应性要求不同。高温、高压、大口径、频繁启闭或调节工况会增加阀体强度、热膨胀、阀杆传动和执行机构匹配的复杂度。

阀门试验通常包括壳体承压、上密封、阀座密封、动作、扭矩、流量或调节特性等项目。不同阀门类型的试验组合不同，安全阀、调节阀、燃气阀和卫生阀还会出现更专门的动作或介质适配项目。

D. 过程与技术

D1 主要工艺/过程流程

D1.1 工业阀门典型制造流程

`mermaid flowchart LR A["图纸/介质/压力温度参数"] --> B["阀体阀盖毛坯和材料确认"] B --> C["流道、法兰、密封面和孔系加工"] C --> D["阀座、阀瓣、球体或闸板制造"] D --> E["密封面研磨、表面处理和清洗"] E --> F["阀杆、填料、密封件和执行机构装配"] F --> G["壳体、密封、动作和扭矩试验"] G --> H["涂装、标识、封堵和包装"] `

工业阀门制造通常从阀体、阀盖、启闭件和密封副开始。阀体可能为铸件、锻件、焊接件或棒材加工件，需完成流道、法兰端面、螺栓孔、阀座孔、阀杆孔、填料函和连接面加工。铸钢、不锈钢、合金钢和有色金属阀体还可能涉及补焊、热处理、无损检测和材料标识。

密封副制造是阀门过程的中心。金属密封面常需堆焊、车削、磨削、研磨或硬化处理；软密封阀需控制阀座材料、压缩量和装配位置。启闭件和阀杆需要与阀体中心线、阀座、填料和执行机构保持运动一致。总装后通过壳体试验、阀座密封、上密封、动作和扭矩试验确认状态。

D1.2 龙头和水暖阀典型制造流程

`mermaid flowchart LR A["铜材/不锈钢/锌合金/图纸"] --> B["铸造、锻压或机加工成形"] B --> C["螺纹、阀芯腔和密封面加工"] C --> D["抛光、表面处理和清洗"] D --> E["阀芯、密封圈、手柄和附件装配"] E --> F["耐压、泄漏、流量和外观检查"] F --> G["包装和标识"] `

龙头和水暖阀通常具有外观件和功能件双重属性。主体材料可能为铜合金、不锈钢、锌合金或工程塑料复合件。制造过程除流道和螺纹加工外，还常涉及抛光、电镀或表面涂层、陶瓷阀芯装配、混水结构、过滤网、手柄和装饰件装配。外观、镀层、手感、泄漏和流量是常见状态信息。

D1.3 调节阀、安全阀和特种阀典型制造流程

`mermaid flowchart LR A["工况参数/动作要求"] --> B["阀体和内件材料确认"] B --> C["阀芯阀座和节流部件加工"] C --> D["执行机构、弹簧或附件匹配"] D --> E["总装和行程调整"] E --> F["泄漏、整定、流量或动作试验"] F --> G["封存和交付"] `

调节阀和安全阀比普通截断阀更强调动作特性。调节阀需要阀芯行程、定位器、执行机构和流量特性匹配；安全阀需要弹簧、阀瓣、阀座、导向和调节机构稳定，动作点和回座状态可重复。特种介质阀还可能涉及衬里、波纹管、夹套保温、低温延伸阀盖、防磨材料或防腐结构。

E. 产业链与边界

E1 上游供应

本小类位于金属材料、铸锻件、密封件、执行机构和表面处理资源之后，管路系统、工艺装置和终端用水用气系统之前，是把材料、流体通道、密封结构和启闭机构转化为管路介质控制能力的环节。阀门既可作为独立产品，也可作为泵、压缩机、锅炉、压力容器、液压站或成套设备的配套件。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类技术跨度较大。普通水暖龙头和通用低压阀门批量化程度较高，工业高参数阀门、调节阀、安全阀、低温阀、化工耐腐阀和大口径阀门复杂度较高。其共同技术基础是阀体承压、介质通道、启闭运动和密封泄漏控制。

自动化程度随产品类型差异明显。小型龙头和标准阀门可采用自动加工、自动抛光、自动装配和自动试压；高参数工业阀、调节阀和安全阀仍需要材料识别、密封面研磨、动作调试、试验判读和文件资料管理。人工经验在研磨接触带、密封件安装、扭矩判断、阀杆顺畅性和泄漏观察中仍然重要。

通用阀门企业闸阀、截止阀、球阀和蝶阀为主阀体加工、密封面研磨、装配和压力试验资源。

H3 客观存在的易出问题环节/技术敏感点

敏感点客观影响链
工况介质识别偏差介质、温度、压力或腐蚀性信息偏移 → 材料和密封方案偏移 → 泄漏、腐蚀、卡滞或寿命状态波动。
阀体铸锻件缺陷缩孔、夹渣、裂纹或壁厚异常 → 承压边界不稳定 → 壳体试验和运行泄漏路径形成。
密封面加工和研磨不稳定粗糙度、接触带或硬度状态偏移 → 阀座贴合不足 → 泄漏量和启闭扭矩变化。
软密封材料适配不足密封材料与温度、介质或压缩量不匹配 → 膨胀、老化、变形或磨损 → 密封状态波动。
阀杆和启闭件同轴偏差阀杆、填料函、阀座或启闭件位置偏移 → 运动阻力增加 → 卡滞、磨损或密封偏压路径形成。
执行机构匹配不足扭矩、行程、气源电源或控制信号不匹配 → 阀门开度和动作状态偏移 → 流量和密封状态变化。
压力试验条件不稳定试验介质、压力、保压时间或排气状态异常 → 微漏、渗漏或变形信息不充分。
表面处理和涂层异常镀层、涂层、抛光或防腐状态偏移 → 腐蚀、外观或密封接触状态变化。
标识和流向信息错误规格、压力、材料、流向或开关方向标识不一致 → 安装接口和使用状态被扰动。
内腔清洁和封堵不足加工屑、砂粒、焊渣或包装异物残留 → 密封面划伤、阀芯卡滞或下游系统污染路径形成。

H3 只记录行业中客观存在的敏感点及事实因果链，不对其在任何上层视图中的重要性作判断。
