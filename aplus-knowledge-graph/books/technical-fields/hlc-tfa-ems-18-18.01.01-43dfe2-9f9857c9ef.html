18.01.01 发动机和涡轮机的制造（飞机、汽车和摩托车发动机除外） 专业小类基础卡

A. 标识与定位

A1 小类名称、分类代码、在分类体系中的位置

字段内容
专业小类代码18.01.01
专业小类名称发动机和涡轮机的制造（飞机、汽车和摩托车发动机除外）
所属大类18 机械和设备制造相关活动
所属中类18.01 通用动力、流体控制和机械传动设备制造
本卡定位描述除飞机、汽车和摩托车发动机以外，以燃料、蒸汽、燃气、水力或其他介质能量转换为机械功、轴功率或驱动能力的发动机、涡轮机及主要部件制造活动的行业事实。
与上层文件关系本卡只记录底层行业事实、技术边界、过程、设备、投入、检测手段和维护信息，不记录任何上层视图判断。

A2 定义与范围界定

本小类是指制造用于工业、船舶、发电、工程机械、农业机械、压缩机驱动、泵站、发电机组、能源回收或其他非航空、非道路车辆主发动机用途的发动机和涡轮机的活动。其核心对象是把热能、压力能、流体动能或燃料化学能转化为可输出机械功的动力设备，包括整机、核心转子部件、壳体部件、燃烧或做功部件、调速控制部件和必要的辅机接口。

本小类通常包括工业柴油机、船用柴油机、固定式燃气发动机、工业燃气轮机、蒸汽轮机、水轮机、小型动力机、发动机组用动力主机、汽轮机转子、叶片、汽缸、喷嘴、隔板、转轮、导叶、调速机构和相关动力设备部件制造。若企业主要制造发电机、电动机、泵、压缩机、液压马达、阀门、轴承齿轮、燃烧器、锅炉或整套发电站工程，应按其主导产品或活动另行识别。

本小类排除飞机发动机、汽车发动机和摩托车发动机。排除的关键不是发动机原理是否相同，而是产品用途、结构规范、供应链、检测验证、法规准入和产业链归属具有专门性。若企业制造通用工业发动机并被安装到工程机械、发电机组或船舶辅机中，应结合合同产品、设计用途和主导交付对象识别。

分组比较提示本小类与泵压缩机、液压设备和传动部件在加工、装配、密封、试验方面有共性，但本小类以动力输出和能量转换为中心。汽轮机、燃气轮机、水轮机和内燃机内部差异较大，上层调用时应特别识别主导动力原理、转子转速、介质条件和试验资源。

B3 关键技术概念说明

发动机和涡轮机的共同基础是能量转换。内燃机通过燃料燃烧推动活塞或转子输出功率，汽轮机通过蒸汽膨胀推动叶片，燃气轮机通过压缩、燃烧和膨胀形成连续做功，水轮机通过水流压力和流速推动转轮。虽然产品形态差异很大，但都围绕功率、转速、效率、振动、温度、压力、密封、润滑和控制保护形成技术链条。

高速旋转是理解本小类的核心。转子、叶轮、叶片、主轴、联轴器和轴承在运行中承受离心力、热应力、流体激振和扭转载荷。材料缺陷、加工偏心、装配间隙、动平衡不足或润滑状态异常，都会沿着转子系统放大为振动、磨损、温升或疲劳路径。

热工与流体通道决定设备性能。汽轮机关注喷嘴、隔板、级组、汽封和蒸汽流道；燃气轮机关注压气机、燃烧室、透平和冷却气路；水轮机关注转轮、导叶、蜗壳、尾水和水力型线；内燃机关注进排气、燃烧、冷却、润滑和曲柄连杆机构。制造过程不仅是零件加工，还包括把这些流道、间隙和接口组合成稳定运行的设备。

试验验证在本小类中具有基础地位。发动机和涡轮机的很多性能无法只从零件尺寸推断，需要通过空载、负载、转速、功率、温度、压力、振动、噪声、油耗或介质流量等运行参数确认。整机试验条件、试验台能力、传感器布置和记录方法，是理解该行业过程能力的重要事实。

D. 过程与技术

D1 主要工艺/过程流程

D1.1 发动机整机典型制造流程

`mermaid flowchart LR A["设计参数/图纸/材料"] --> B["铸锻件和关键件确认"] B --> C["缸体、曲轴、连杆等加工"] C --> D["热处理、表面处理和清洗"] D --> E["部件装配和间隙调整"] E --> F["燃油、润滑、冷却和控制系统装配"] F --> G["磨合、台架试验和参数记录"] G --> H["标识、包装和交付"] `

工业发动机制造通常从缸体、缸盖、曲轴、连杆、凸轮轴、活塞、齿轮室和进排气部件等关键件开始。缸体和缸盖多为铸件或合金铸件，需进行粗加工、时效、精加工、油水道清理、密封面加工和压力或泄漏检查。曲轴、连杆、凸轮轴等承载运动件需要锻造或铸造毛坯、热处理、车铣磨、动平衡或重量分组。

整机装配的技术基础是间隙、同轴、清洁和润滑。主轴瓦、连杆瓦、活塞环、气门、喷油器、燃油泵、增压器、冷却系统和润滑系统都需要与运行参数匹配。装配后通常通过盘车、冷试、热试、磨合或负载试验确认转速、功率、油压、水温、排气温度、振动和泄漏状态。

D1.2 汽轮机和燃气轮机典型制造流程

`mermaid flowchart LR A["热力参数/级组设计"] --> B["转子、叶片、壳体材料确认"] B --> C["叶片、轮盘、汽缸和流道加工"] C --> D["无损检测、热处理和表面处理"] D --> E["转子装配和动平衡"] E --> F["汽缸、轴承、密封和调速装配"] F --> G["空转、性能或出厂试验"] G --> H["防护、封存和发运"] `

涡轮机制造的专业重心在转子和流道。叶片型线、安装角、叶根、轮槽、隔板、喷嘴、汽封间隙和壳体中分面共同决定流体能量转换路径。转子加工通常需要大型车削、磨削、铣槽、叶片装配、超速或动平衡相关工序。汽缸、隔板和喷嘴则涉及大型铸件或焊接件加工、密封面加工、配合间隙和流道表面。

燃气轮机热端部件对材料和表面状态更敏感，压气机叶片、燃烧室、透平叶片、冷却孔、隔热或耐热涂层、密封结构和转子连接方式均影响运行基础。汽轮机则更多受蒸汽参数、热膨胀、汽封、轴承润滑和调速系统影响。二者都需要对转子系统进行动平衡、振动和装配间隙确认。

D1.3 水轮机典型制造流程

`mermaid flowchart LR A["水头/流量/转速参数"] --> B["转轮、导叶和壳体材料准备"] B --> C["铸造、焊接或锻件成形"] C --> D["水力型线加工和尺寸检测"] D --> E["焊缝、表面和动静平衡检查"] E --> F["总装预装和调速机构接口"] F --> G["防腐防护、包装和发运"] `

水轮机制造以水力型线和大型金属结构为核心。转轮可能采用铸造、焊接或组合制造，导叶和活动机构需要保持开度一致、密封状态和运动灵活。大型水轮机常采用分瓣制造、工厂预装、编号发运和现场组装接口，制造过程需考虑尺寸大型化、焊接变形、动静平衡、防空蚀表面和涂层保护。

E. 产业链与边界

E1 上游供应

上游包括铸锻件、合金材料、叶片毛坯、轴承、密封、紧固件、燃油或燃气部件、调速控制部件、传感器、润滑冷却部件、铸造和热处理资源、无损检测资源、试验台资源以及包装运输资源。上游毛坯的组织、缺陷、余量、材料证明和标识状态会传递到转子、壳体和流道部件。

对涡轮机而言，叶片、转子、壳体和密封件供应对最终设备状态影响较大；对发动机而言，缸体、曲轴、连杆、燃油系统和增压器等供应接口较多；对水轮机而言，大型铸焊件、水力型线加工和防腐防空蚀处理资源更突出。

E2 下游应用/客户

下游包括发电机组制造、工业驱动设备、船舶、泵站、压缩机站、水电站、热电联供、余热余压利用、矿山、石化、冶金、造纸、食品、农业和工程装备等场景。下游通常以功率、转速、负荷曲线、介质条件、安装空间、控制接口、维护周期、备件供应和运行环境提出需求。

E3 本小类在产业链中的位置

本小类位于材料和关键零部件供应之后、成套动力系统和终端工况之前，是把材料、流体通道、燃烧或介质条件、转子系统和控制保护组合成动力输出设备的环节。它既可以作为独立整机制造，也可以作为发电机组、船舶动力、压缩机拖动、水电设备或能源站的核心动力模块供应。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类属于技术复杂度较高的动力机械制造活动。其复杂性来自多学科叠加：材料、热处理、精密加工、流体通道、燃烧或介质条件、高速旋转、润滑密封、控制保护和运行试验同时存在。小型通用动力机可高度标准化和流水化，大型汽轮机、水轮机、燃气轮机和船用动力设备则具有项目化、单件小批、大型加工、专用试验和外部接口多的特点。

自动化程度随产品路线差异明显。叶片加工、缸体加工、转子加工和检测可采用数控和专用设备，但装配间隙调整、轴系找中、盘车判断、泄漏观察、试验异常识别、封存防护和大型设备预装仍高度依赖专业经验。

H3 客观存在的易出问题环节/技术敏感点

敏感点客观影响链
动力参数转换偏差功率、转速、介质或负荷条件理解不一致 → 结构和试验条件偏移 → 输出能力和运行状态波动。
铸锻件内部缺陷毛坯组织、缩孔、夹杂或裂纹异常 → 加工和运行承载路径受扰动 → 疲劳、泄漏或强度状态波动。
转子质量分布不均加工偏心、装配差异或叶片质量偏差 → 不平衡量增加 → 振动、轴承载荷和疲劳路径变化。
叶片型线偏差型线、安装角或表面状态偏移 → 流体通道效率和载荷分布变化 → 功率、温度或振动状态波动。
壳体孔系和密封面偏差轴承座、汽封、缸体孔系或中分面异常 → 轴系位置和泄漏路径变化 → 温升、磨损或效率波动。
润滑和冷却通道污染油道、水道、冷却孔或管路残留杂质 → 流量和换热状态受阻 → 轴承、密封或热端部件状态变化。
热处理和表面处理不稳定温度、时间、冷却或涂层状态偏移 → 硬度、组织、残余应力或耐热表面变化 → 寿命和表面状态波动。
装配间隙调整不一致轴承、汽封、活塞环、导叶或联轴器间隙偏移 → 摩擦、泄漏、振动或效率路径变化。
试验台条件不稳定传感器、燃料、介质、负载或环境条件偏移 → 运行参数可比性下降 → 性能确认信息失真。
封存和运输保护不足油封、防潮、接口封堵或支撑状态不足 → 锈蚀、污染、变形或碰伤路径形成。
