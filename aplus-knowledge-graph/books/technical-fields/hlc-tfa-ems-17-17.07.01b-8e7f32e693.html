A2 定义与范围界定

本小类是指制造用于建筑物、区域供热、集中采暖或类似热水供暖系统的金属散热器、采暖锅炉、热水锅炉及其主要金属部件的活动。其核心对象包括以水、蒸汽或其他热媒进行热量传递的散热终端，以及为集中供暖系统提供热源的锅炉或锅炉本体相关产品。

集中供暖散热器通常包括钢制散热器、铸铁散热器、铝制散热器、铜铝复合散热器、钢铝复合散热器、板式散热器、柱翼型散热器、翅片管散热器、对流散热器等。其制造过程一般涉及材料成形、焊接或机械连接、组合装配、压力检漏、表面处理和包装。

集中供暖锅炉通常包括以热水供暖为主要用途的燃气、燃油、生物质、燃煤或电加热供暖锅炉，以及锅炉本体、换热器、炉胆、烟管、水套、集箱、外壳和部分配套金属部件。若产品属于特种设备范围或涉及承压部件制造，其具体许可、监督检验和技术文件要求应按产品属性、压力等级、介质和现行监管规则确认。本卡不将这些要求扩展为某一上层视图的结论。

本小类不包括单纯供暖系统安装工程、管网施工、热力站运行服务、锅炉维修服务、供热运营服务、燃烧器独立制造、泵阀仪表独立制造、家用电暖器和独立热水器制造、空调或热泵设备制造、电站锅炉和大型工业蒸汽发生设备制造。企业同时从事安装、调试或售后服务的，应根据主导活动是否为散热器或集中供暖锅炉制造来确认归属。

B3 关键技术概念说明

本小类的技术主线是“金属壳体或散热面形成热媒通道，再通过金属壁面实现热量传递”。散热器侧重终端换热和室内空间散热，锅炉侧重热源形成、燃烧或加热、受热面换热和热媒输出。二者都离不开金属成形、连接密封、压力检漏和表面防护，但过程重心并不完全相同。

散热器的有效工作状态取决于热媒流道、散热面积、壁厚、焊接或连接状态、接口尺寸和表面涂装。板式散热器通过压制水道和焊接形成换热单元，柱翼型或铸铁散热器通过单片组合形成散热能力，铜铝复合或钢铝复合散热器则通过不同金属材料协同传热。

供暖锅炉的技术核心在于热源、受热面和水侧通道的匹配。燃料燃烧或电能加热产生热量，高温烟气或加热元件通过受热面把热量传给水或其他热媒。锅炉本体的板材、管材、焊缝、炉胆、烟管、集箱、水套、密封件和控制接口共同构成设备的运行基础。

承压密封是本小类的重要客观属性。散热器和锅炉在使用中均可能承受系统水压、温度变化和热胀冷缩。材料缺陷、焊缝不连续、密封件选型不当、螺纹接口偏差、试压条件不稳定或表面处理前后状态变化，都可能改变产品的密封状态。

表面防护对散热器和锅炉外壳具有长期作用。散热器外表面通常需兼顾外观、耐蚀和散热，内腔则可能受到水质、氧含量和沉积物影响。锅炉本体外表面可能涉及防腐、保温、外护板和高温部位隔离，内侧则与水垢、腐蚀、烟气冷凝和沉积有关。

C2 主要功能、性能维度

本小类产品的主要功能是为供暖系统提供热源或把热媒热量传递至室内环境。散热器更关注散热面积、热输出、接口尺寸、承压密封、耐腐蚀、外观和安装适配；供暖锅炉更关注热功率、热效率、受热面布置、水侧流动、燃烧或加热接口、承压部件、排烟通道、控制接口和运行配套状态。

常见客观性能维度包括：外形尺寸、接口尺寸、壁厚、材料牌号、焊缝外观、焊缝内部状态、密封状态、试验压力、热输出、热效率、流阻、涂层厚度、涂层附着状态、耐腐蚀状态、表面外观、保温层状态、烟气通道阻力、燃烧接口匹配、控制接口完整性、铭牌参数、包装保护和运输稳定性。

不同产品之间性能重点差异明显。散热器产品通常以外观、散热、承压、连接和涂装为主；锅炉产品通常以承压结构、热交换、燃烧或加热、控制接口和运行参数为主；翅片管散热器和空气加热器还涉及翅片间距、管胀接或焊接状态、气流通道和换热面积。

散热器制造通常由产品规格、散热量要求、安装接口和外观要求引出材料准备。钢制板式散热器需要对钢板进行冲压或辊压，形成水道和表面结构后再焊接成散热单元；钢制柱型或管型散热器需要对管材、片材或柱片进行下料、焊接和组合；铸铁散热器通常依赖铸件毛坯、机加工、组合和试压；铝制或复合散热器则更依赖型材、复合管或胀接结构。

散热器的制造过程对几何尺寸、接口螺纹、焊缝连续性、内部清洁、试压状态、涂层均匀性和包装保护较为敏感。由于产品通常直接暴露在室内可见位置，外观缺陷、色差、涂层划伤和接口渗漏都容易被使用端感知。

D1.2 集中供暖锅炉典型制造流程

`mermaid flowchart LR A["设计文件/技术参数"] --> B["材料复核与下料"] B --> C["板材卷制、管材加工、坡口制备"] C --> D["炉胆、烟管、集箱和壳体焊接"] D --> E["无损检测与尺寸检查"] E --> F["水压试验和密封确认"] F --> G["燃烧/加热/控制接口装配"] G --> H["保温、外护板和附件装配"] H --> I["性能或出厂项目检查"] I --> J["标识、包装、发运"] `

供暖锅炉制造通常以设计参数、热功率、额定压力、介质温度、燃料类型、安装方式和接口要求为输入。材料准备阶段需要确认板材、管材、焊材、法兰、管接头、密封件、保温材料和配套部件。承压部件加工通常包括下料、卷制、胀接、坡口、组对、焊接、校形、无损检测和水压试验。

锅炉装配阶段把炉胆、烟管、集箱、水套、壳体、底座、烟道接口、燃烧器接口、循环水接口、排污接口、仪表接口、保温层和外护板组成完整设备。若产品包含燃烧器、控制柜、循环泵或保护装置，这些部件通常通过采购配套或专业分包进入装配过程，制造企业需要保持接口尺寸、参数和装配状态一致。

D1.3 翅片管或对流散热设备典型制造流程

`mermaid flowchart LR A["管材/翅片/端板"] --> B["管材切割与清洁"] B --> C["翅片成形或套片"] C --> D["胀接、焊接或钎焊"] D --> E["集管和框架装配"] E --> F["检漏与尺寸检查"] F --> G["表面处理和包装"] `

翅片管和对流类产品通过增加金属换热面积强化热量传递。其过程敏感点集中在翅片间距、管翅结合、管端连接、集管焊接、气流通道和外形尺寸。由于此类产品常用于工业厂房、大空间或通风换热场景，产品结构可能更偏向组件化和工程配套。

E. 产业链与边界

E1 上游供应

本小类上游主要包括钢铁材料、铝材、铜材、铸件、管材、焊接材料、密封材料、涂料、保温材料、燃烧器、仪表、阀门、控制部件、包装材料以及检测服务等。散热器企业高度依赖材料表面状态、壁厚、可焊性、涂装适应性和接口标准化；供暖锅炉企业还依赖承压材料、焊材、燃烧部件、控制部件和配套仪表的规格匹配。

上游供应对本小类产品状态具有直接传递作用。材料厚度、管材椭圆度、铸件砂眼、型材截面、焊材批次、涂料固化条件、密封件耐温性能、燃烧器接口尺寸和仪表量程，都可能在成品中形成可见或不可见的差异。

E2 下游应用/客户

下游主要包括住宅建筑、公共建筑、学校、医院、商业综合体、工业厂房、区域供热站、小区换热站、供暖工程承包商、房地产开发项目、建筑设备安装企业和终端用户。散热器产品多进入室内采暖终端，锅炉产品多进入热源站、设备间或集中供暖系统。

下游需求通常以建筑面积、热负荷、安装空间、接口尺寸、热媒参数、燃料条件、外观要求、交付批次和维护便利性体现。不同地区气候、建筑形式、供暖方式和工程管理习惯会影响产品规格和交付模式。

E3 本小类在产业链中的位置

本小类位于金属材料和供暖工程系统之间，是把金属材料、换热结构、承压密封和配套部件转化为供暖热源或散热终端的制造环节。它既不同于上游材料和部件制造，也不同于下游供热运行或建筑安装活动。

散热器制造更靠近建筑末端产品，通常按型号、片数、尺寸和外观交付；锅炉制造更靠近热源设备，通常按热功率、压力、燃料、接口和运行参数交付。二者同属供暖设备制造，但内部技术重心存在明显差异，A4 已将该差异作为上层分组调用时的提示。

E4 常见委外/外包环节

委外/外包环节行业常见原因边界提示
铸件毛坯生产铸造设备和工艺专业化程度高仅作为散热器或锅炉毛坯输入时，不改变本小类制造属性。
材料预处理和表面处理喷涂、酸洗、镀层和烘干设施投入较大外协后仍需关注来料状态、颜色、涂层和运输保护。
无损检测检测设备和人员能力要求专业可由外部检测资源完成，但检测对象仍属于制造过程的一部分。
燃烧器和控制部件供应部件专业化、型号多作为配套件进入锅炉装配，不等同于本企业独立制造燃烧器或控制柜。
性能试验热工、燃烧和散热量试验设施投入较大小型企业可能委托外部试验资源完成部分项目。
保温和外护板加工可能由钣金或保温专业方完成属于配套加工或部件供应，应与锅炉本体制造边界区分。
运输和现场安装配合产品体积大、工程地点分散安装活动不应替代制造活动作为分类依据。

F. 适用法规与技术标准

F1 行业准入/资质/许可要求

集中供暖锅炉及其承压部件可能涉及特种设备制造许可、监督检验、型式试验、制造过程资料和铭牌标识等行业门槛类别。是否适用取决于锅炉类型、额定压力、介质、容量、热功率、使用场景和现行监管规则。散热器产品通常不按锅炉承压设备处理，但仍可能涉及建筑供暖产品、采暖散热器、材料和表面涂装等技术要求。

燃气、燃油、生物质、燃煤或电加热供暖锅炉还可能客观涉及燃料适配、燃烧状态、烟气排放、能效、控制保护和安装接口等监管或产品要求类别。本卡只记录这些门槛类别和检索方向，不展开具体组织适用性清单。

涂层检测涂层测厚、附着力、硬度、耐腐蚀试验、色差检查散热器外表面、锅炉外壳和金属外护板。
运行接口检查阀口、法兰、管接头、控制接口、铭牌参数核对锅炉、散热器和配套部件。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类横跨散热器终端产品和供暖锅炉热源设备，技术复杂度差异较大。普通散热器制造以金属成形、焊接、试压、涂装和包装为主，工艺相对成熟，但规格多、外观要求高、接口尺寸多样。供暖锅炉制造涉及承压结构、热交换、燃烧或加热、控制接口、试压和技术文件，复杂度通常高于普通散热器。

自动化水平随企业规模和产品分支差异明显。散热器企业可能采用冲压焊接自动线、自动喷涂线和批量试压装置，也可能以人工焊接、手工装配和外协喷涂为主。锅炉制造企业通常需要较强的板管成形、焊接、检测、起重、试压和装配能力，部分企业还配置热工试验或燃烧调试平台。

人工经验仍在本小类中占有重要位置。焊接组对、变形校正、试压观察、表面缺陷处理、散热器组合、锅炉部件装配和异常状态判断，都需要操作人员理解材料、设备、工装和产品结构之间的关系。

H3 客观存在的易出问题环节/技术敏感点

敏感点客观影响链
材料牌号或厚度与设计不一致材料输入偏差 → 成形、焊接和承压状态变化 → 成品强度、密封和使用状态波动。
板管成形精度不足卷制、折弯或胀接偏差 → 组对间隙和圆度异常 → 焊接变形或装配困难。
焊接参数和组对状态不稳定坡口、间隙、热输入或焊材状态偏移 → 焊缝缺陷或变形增加 → 试压、密封和外观状态受扰动。
散热器内部清洁不足成形和焊接残留物滞留 → 热媒通道杂质增加 → 运行后堵塞、噪声或局部腐蚀路径出现。
试压条件控制不一致试验压力、保压时间、温度或观察方式偏差 → 微漏、变形或接口异常不易被发现。
散热器涂装前处理不足油污、锈蚀或表面残留未清除 → 涂层附着状态下降 → 使用中起皮、锈蚀或色差扩大。
锅炉受热面布置偏差炉胆、烟管、水套或集箱位置偏移 → 烟水换热路径变化 → 热效率、局部温度和流动状态波动。
燃烧或加热部件接口不匹配燃烧器、控制件、烟道或电加热接口参数不一致 → 装配困难、燃烧状态偏移或运行参数不稳定。
密封件耐温耐压不匹配垫片、密封圈或密封胶选型偏差 → 热循环后压缩回弹或老化异常 → 接口渗漏路径形成。
包装和运输支撑不足散热器片体、喷涂表面或锅炉外护板受力不均 → 运输后变形、划伤、接口碰伤或部件松动。
