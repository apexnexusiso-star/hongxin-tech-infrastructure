A1 小类名称、分类代码、在分类体系中的位置

本卡定位描述以液压油或其他工作液为能量传递介质，通过液压泵、液压缸、液压马达、阀组、油箱、管路和控制元件实现压力、流量、方向和执行动作的液压设备及部件制造活动的行业事实。

A2 定义与范围界定

本小类是指制造以液压传动和液压控制为核心的设备、部件和系统的活动。其本质是把机械能转化为液压能，再通过执行元件把液压能转化为直线运动、旋转运动、夹紧力、举升力、制动力或调节动作。典型对象包括液压泵、液压马达、液压缸、液压阀组、液压站、液压动力单元、伺服液压执行机构、工程机械液压部件、工业装备液压系统和液压集成块。

本小类的主导技术不是一般流体输送，而是压力油路、密封、配合间隙、清洁度、流量控制、压力控制、泄漏控制和执行动作稳定性。液压设备通常由精密加工件、密封件、阀芯阀套、柱塞、齿轮、叶片、缸筒、活塞杆、油箱、管接头、过滤器、蓄能器、压力表、传感器和控制部件组合而成。

本小类不包括以介质长距离输送为主的普通泵和压缩机、不以液压传动为核心的管道阀门、单纯金属机加工服务、橡胶密封件制造、液压设备维修服务和整台工程机械或机床制造。若企业制造的液压部件已嵌入工程机械、机床、冶金设备、船舶或风电设备整机，应按合同交付对象和主导产品属性识别。

B3 关键技术概念说明

液压设备的核心是“压力、流量、方向、密封和执行动作”的组合。液压泵提供压力油源，阀控制油流方向、压力和流量，液压缸或液压马达把压力能转化为运动。一个液压系统能否稳定工作，不仅取决于单个部件尺寸，还取决于油路孔道、密封、油液、过滤、温升、响应和控制逻辑之间的匹配。

配合间隙和表面状态是液压部件的基础。阀芯阀套、柱塞副、齿轮泵端面、缸筒内孔、活塞杆镀层和密封沟槽都需要兼顾泄漏、摩擦和磨损。间隙过大容易内泄漏，间隙过小可能卡滞、发热或磨损。表面粗糙度、圆度、直线度和清洁度会直接影响密封寿命和动作平稳性。

清洁度是液压行业不可绕开的底层概念。阀芯小间隙、节流口、过滤元件和伺服阀对颗粒污染敏感，残留切屑、磨粒、焊渣、密封碎屑或纤维可能造成卡滞、划伤、泄漏或响应异常。因此液压设备制造通常需要油路去毛刺、清洗、吹扫、过滤、冲洗和封堵。

压力试验和功能调试是液压设备形成过程的重要环节。液压缸需要确认耐压、泄漏、行程、速度和爬行状态；液压站需要确认泵流量、压力设定、阀动作、温升、噪声和泄漏；电液伺服系统还需要关注响应、重复性、传感器和控制信号。

C2 主要功能、性能维度

本小类产品的客观性能维度包括额定压力、最高压力、流量、转速、排量、容积效率、总效率、输出力、输出扭矩、行程、速度、响应时间、位置重复性、内泄漏、外泄漏、耐压、密封寿命、清洁度、油温、噪声、振动、表面粗糙度、缸筒直线度、活塞杆硬度和镀层、阀芯配合间隙、启闭特性、压力设定稳定性和接口尺寸。

液压设备的性能不是单一零件性能的简单相加。泵、阀、缸、马达、管路、油箱、过滤、冷却和控制元件共同构成回路。压力损失、泄漏、油温、污染物和密封摩擦会在系统内相互影响，形成动作速度、压力波动和响应稳定性差异。

D. 过程与技术

D1 主要工艺/过程流程

D1.1 液压缸典型制造流程

`mermaid flowchart LR A["图纸/缸筒/活塞杆材料"] --> B["材料确认和下料"] B --> C["缸筒加工、珩磨和清洗"] C --> D["活塞杆加工、热处理或表面处理"] D --> E["端盖、活塞和密封沟槽加工"] E --> F["总装和密封装配"] F --> G["耐压、泄漏、行程和动作试验"] G --> H["封堵、防护和交付"] `

液压缸制造的主线是缸筒、活塞杆、密封和装配间隙。缸筒内孔需要满足圆度、直线度、粗糙度和清洁度要求，常通过镗削、滚压或珩磨形成。活塞杆需要具备直线度、表面硬度、镀层或耐磨表面和密封配合状态。密封沟槽、导向套、端盖和连接耳环则决定密封安装、受力和装配接口。

液压缸装配前需要确认零件清洁、密封方向、润滑、导向件和紧固状态。装配后通常进行空载动作、耐压、保压、内泄漏、外泄漏、行程、缓冲和低速爬行相关项目确认。长行程和大直径液压缸还要关注活塞杆挠度、支撑、运输防护和现场安装接口。

D1.2 液压泵、马达和阀件典型制造流程

`mermaid flowchart LR A["壳体/阀体/精密件"] --> B["精密加工和热处理"] B --> C["研磨、配磨和去毛刺"] C --> D["清洗、吹扫和防污染"] D --> E["零件配对和装配"] E --> F["跑合、压力、流量和泄漏试验"] F --> G["封存、标识和包装"] `

液压泵和马达的技术重点在高压容腔、配流、摩擦副和密封。齿轮泵关注齿轮、轴套、端面间隙和壳体；叶片泵关注定子曲线、叶片滑动和配油盘；柱塞泵关注柱塞、缸体、配流盘、斜盘、回程机构和变量控制。部件加工后常需要研磨、配磨、去毛刺、清洗和跑合。

液压阀制造的专业重点在阀芯阀套配合、阀口形状、弹簧、阻尼孔、密封和控制机构。阀体或阀块的交叉孔、插装孔和螺纹孔需要防止毛刺残留。比例阀、伺服阀和插装阀对阀芯运动、污染、响应和压力稳定性更敏感。

D1.3 液压站和系统集成典型制造流程

`mermaid flowchart LR A["回路图/动作参数"] --> B["元件选型和油路布置"] B --> C["油箱、底座和管路制造"] C --> D["泵组、阀组、过滤和冷却装配"] D --> E["电控、仪表和传感器接线"] E --> F["冲洗、注油和功能调试"] F --> G["压力、动作、泄漏和温升记录"] `

液压站制造不是简单把泵、阀和油箱装在一起，而是按动作逻辑、压力流量、油温、过滤、管路阻力和维护空间组织系统。管路弯曲、焊接、酸洗清洗、软管布置、过滤精度、油箱隔板和冷却方式会影响运行状态。电液系统还需要把压力、位移、速度和温度信号与控制程序相匹配。

E. 产业链与边界

E1 上游供应

上游包括钢管、棒材、铸锻件、密封件、液压油、过滤器、泵阀元件、传感器、控制器、接头管路、表面处理资源、精密加工资源和检测设备。上游材料的硬度、直线度、表面状态、清洁度和标识直接传递到液压部件的密封、运动和压力状态。

密封件、过滤元件和液压油虽然通常不是本小类企业自行制造，但对系统状态影响明显。高压和伺服场景还会对元件匹配、油液污染、温升和响应提出更高的过程资源要求。

E2 下游应用/客户

下游包括工程机械、机床、冶金设备、矿山设备、船舶、港口机械、风电、农业机械、塑料机械、压机、注塑机、试验设备、自动化生产线和工业装备维护配套。下游通常以压力、流量、动作、负载、空间、接口、控制信号、维护方式和环境条件提出需求。

E3 本小类在产业链中的位置

本小类位于金属材料、精密零件、密封件、油液和控制元件之后，整机装备和执行机构使用端之前，是把压力油源、控制元件、执行元件和辅助部件整合为液压动力或动作控制能力的环节。液压设备既可作为独立部件供应，也可作为整机装备的核心子系统。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类技术复杂度跨度较大。普通液压缸和简单液压站技术成熟，但高压柱塞泵、比例阀、伺服阀、伺服液压缸、工程机械核心液压件和大型冶金液压系统复杂度较高。其共同特征是精密加工、密封、油液清洁、压力试验和系统调试高度耦合。

自动化程度随产品族差异明显。批量液压缸和标准阀件可采用数控加工、自动清洗、自动试验和数据采集；非标液压站、大型油缸和电液系统仍依赖工艺人员对回路、管路、动作顺序和现场工况的理解。人工经验在去毛刺、密封安装、异常声音、泄漏观察、压力设定和故障定位中仍然重要。

H3 客观存在的易出问题环节/技术敏感点

敏感点客观影响链
油路孔道毛刺残留交叉孔、螺纹孔或阀口去毛刺不足 → 颗粒进入油路 → 阀芯卡滞、划伤或泄漏路径形成。
油液清洁度不足清洗、冲洗、过滤或封堵不足 → 颗粒污染增加 → 摩擦副磨损、阀件响应异常或密封损伤。
密封件选型或装配方向错误密封材料、沟槽或安装状态异常 → 密封压缩和摩擦状态偏移 → 内外泄漏或爬行状态变化。
缸筒内孔状态不稳定圆度、直线度、粗糙度或划伤异常 → 活塞运动阻力和密封接触变化 → 低速爬行、泄漏或磨损路径形成。
活塞杆表面异常镀层、硬度、直线度或表面划伤异常 → 密封唇口磨损或腐蚀路径形成 → 外泄漏和动作状态波动。
阀芯阀套配合偏差间隙、圆度、表面或清洁状态偏移 → 滑动阻力和内泄漏变化 → 压力设定和响应状态波动。
泵马达摩擦副状态异常配流面、柱塞、齿轮或叶片间隙偏移 → 容积效率和温升变化 → 流量、噪声和寿命状态波动。
压力试验条件不稳定压力表、介质温度、保压时间或接口密封偏移 → 泄漏和承压状态信息不稳定。
管路布置和固定不足管路弯曲半径、支撑或接头状态不当 → 振动、压力脉动和泄漏路径形成。
电液控制信号不匹配传感器、控制器、比例阀或执行机构参数偏移 → 动作响应和重复性状态波动。
