  • 文件定位说明

本文件用于质量管理体系认证中 QG14-2 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦塑料板片管壳、塑料包装、建筑用塑料制品及其他塑料制品制造在 QMS 轴下的质量形成链、顾客要求转化、原辅材料和配方控制、关键过程和特殊过程、检验放行、批次追溯、不合格控制、客户反馈和改进闭环。

本文件不承担行业百科说明功能，基础行业事实由对应专业小类基础卡承载。本文件只调用与分组论证、能力后果和审核抽样有关的信息。本组采用“统一领域包 + 板片管壳分支 + 包装分支 + 建筑塑料分支 + 其他塑料制品分支 + 条件扩展 + 专项边界控制”的使用口径；组内共同基础可以共享，但分支差异必须通过能力标注、条件扩展、专项确认和项目边界控制落地。

  • 技术领域包构成
小类编码小类名称纳入本包的活动范围主要内部路线特殊边界
14.02.01塑料板、塑料片、塑料管及塑料壳体的制造包括以树脂、改性料和助剂经挤出、压延、定径、冷却、切割、热成型或二次加工形成塑料板、片、管、壳和类似基础形态制品。板片连续挤出、管材挤出、共挤板片管、热成型壳体、板材焊接加工。本分支偏基础形态材料和半成品；若以包装或建筑构配件功能交付，应按目标分支确认。
14.02.02塑料包装产品的制造包括塑料袋、卷膜、复合膜、瓶、桶、盒、托盘、泡罩、瓶盖、周转箱和功能包装材料制造。吹膜流延、复合印刷、制袋热封、吹塑瓶桶、注塑盖、吸塑托盘、物流周转包装。包装功能、热封、密封、阻隔、迁移、洁净、标签和客户灌装适配应专项确认。
14.02.03建筑用塑料制品的制造包括塑料门窗型材、门窗成品、建筑装饰板、线槽、采光板、防水排水构件、木塑和发泡建筑制品。PVC 型材挤出、共挤耐候层、门窗下料焊角、五金密封装配、建筑装饰板、采光板和木塑制品。建筑系统接口、耐候、阻燃、焊角、排水密封和现场安装边界应受控。
14.02.04其他塑料制品的制造包括除板片管壳、包装和建筑塑料以外的日用、工业、电子电器、车辆配套、文教、休闲、滚塑、发泡和装配类塑料制品。注塑件、吹塑或滚塑中空件、发泡件、嵌件件、表面处理件、焊接装配件。集合性小类内部跨度大，应按注塑、滚塑、发泡、装配、外观件和客户用途记录分支能力。
  • 分组设立的基本逻辑

本包在 QMS 轴下的共同对象是以塑料树脂、改性料、助剂、模具或成型设备为基础，通过热塑或热固成型、冷却固化、后加工和检验放行形成的塑料制品。分组判断的核心不是产品名称是否相近，而是顾客要求如何转化为材料、配方、工艺、检验和放行要求，关键质量特性如何在过程链条中形成，批次和变更如何保持可追溯，以及出现不合格或客户反馈时能否形成闭环。

本包可概括的共同质量形成链为：顾客规格、图纸或用途要求 -> 材料牌号、改性和配方选择 -> 原料干燥、混配和批次确认 -> 模具、模头或工装准备 -> 挤出、注塑、吹塑、压延、热成型、滚塑、发泡或装配 -> 尺寸、外观、力学、密封、阻隔、耐候、阻燃或功能检验 -> 放行、标识、包装、储运和客户反馈。该链条决定了本包共享的专业能力基础，审核员应能够沿订单、配方或材料批次、关键过程参数、检验记录、放行记录、交付和反馈建立纵向证据链。

组内差异主要表现为产品用途和质量特性不同：板片管壳重在连续成型、厚度、壁厚、定径和尺寸稳定；包装重在热封、泄漏、阻隔、印刷、洁净和内容物适配；建筑塑料重在型材腔体、焊角、耐候、阻燃和施工接口；其他塑料制品则以注塑、滚塑、发泡、嵌件和装配为主，内部跨度最大。这些差异不否定设组，但要求本包按“统一领域包 + 分支能力标注 + 条件扩展 + 边界受控”的方式使用，不得把某一产品族或工艺路线经历视为覆盖全部组内小类的充分证明。

  • 专业小类关系类型与授权后果
关系类型含义授权后果典型控制方式
共同基础关系组内小类共享高分子材料、配方或材料选型、成型过程、检验放行、批次追溯和客户反馈闭环等 QMS 基础。可简化通用材料加工和过程控制基础评价，但仍需确认目标小类、产品族或工艺路线的实际经历。资料评审、专业面谈、典型批次追溯、产品族经历核对。
并列分支关系同属本技术领域包，但产品结构、关键质量特性、特殊过程、检测项目或客户用途不同。应记录实际分支能力，不把同包经历视为全分支能力。分支标注、限定使用、项目技术支持、见证审核。
条件扩展关系已具备相邻分支能力，具有共同材料和过程基础，但目标分支存在专门质量形成链。完成补充培训、案例评审、专业面谈、见证审核或技术支持后方可扩展。培训考核、案例评审、首个项目技术支持、现场见证。
专项确认关系涉及高结构复杂度、强客户用途约束、食品接触、建筑使用、翻新再造、压力或密封承载等特殊路线。项目使用前应专项确认；必要时增加产品族限定或配置技术专家。专项面谈、技术专家评审、样本案例评价、授权备注。
不可直接替代关系相关高分子材料或通用成型经历不足以证明目标产品族的完整质量形成能力。不得作为目标能力的单独授权依据，应补充目标经历、见证或限定项目类型。重新评价、补充经历、限定产品族或工艺路线。
边界受控关系当产品认证、食品接触、建筑应用、客户安全件、再制造、外包检测或法定接口改变使用边界时，同包授权应增加边界说明。授权记录应写明适用产品族、工艺路线和特殊边界；项目匹配按实际活动确认。授权备注、项目匹配确认、合规类别清单、技术支持。
四个塑料小类之间均共享塑料材料选择、模具或模头成型、过程参数、尺寸外观检验和批次追溯基础。可共享通用塑料成型基础评价，但应按板管、包装、建筑、其他塑料四个分支标注能力。分支案例评价、目标产品族面谈、首个项目技术支持。
板片管壳与包装均可能涉及片材、薄膜或吹塑技术，但包装具有热封、阻隔、迁移、标签和内容物适配。板片管壳经历不能替代包装功能确认；包装经历扩展到通用板片管也需确认连续定径和尺寸链。卷膜、袋、瓶、管材和片材样本分别追溯。
板片管壳与建筑塑料均可能使用挤出、型材、板材和共挤技术，但建筑塑料具有建筑接口、耐候、焊角和阻燃要求。通用挤出经历不能替代门窗型材、建筑装配和建筑性能分支能力。型材截面、焊角、五金密封、耐候或阻燃案例确认。
包装与其他塑料制品均可能使用注塑、吹塑和热成型，但包装的主导功能是容纳、密封、保护和流通。瓶盖、托盘、容器等相近经历应按实际用途确认，不以成型方式单独扩展。包装功能、内容物适配、泄漏和标签样本评价。
14.02.04 集合性小类内部同属塑料制品制造，但注塑精密件、日用品、滚塑中空件、发泡件、电子电器外观件和装配件差异明显。仅可按已确认产品族和成型路线使用，不宜按小类名称笼统扩展。产品族授权备注、模具成型案例、装配或表面处理样本。
  • 本体系共同能力基础
共同能力维度本包共同基础可共享的审核判断不能共享的边界
顾客要求和用途识别均需识别材料牌号、尺寸、公差、外观、颜色、功能、客户图纸、用途环境、包装或建筑适配等要求。可共享合同评审、技术文件转换、首件确认、客户特殊要求和变更控制判断。食品包装、建筑门窗、压力管、电子阻燃外壳、汽车外观件等用途不能互相替代。
材料和配混控制均依赖树脂、改性料、色母、填料、助剂、回料或嵌件的批次、干燥、配比和相容性控制。可共享供应商评价、来料验证、干燥、配料、回料比例、材料替代和批次追溯判断。阻隔层、食品接触材料、耐候共挤层、阻燃材料和增强材料需按用途确认。
模具、模头和工装能力塑料制品的尺寸、外观和结构主要由模具、模头、定径套、热成型模具或装配治具形成。可共享模具管理、首件、设备参数、过程监控、维修保养和防错判断。宽幅板片模头、管材定径、包装热封刀、门窗焊角工装和精密注塑模具差异应分支确认。
成型和冷却过程均涉及热、压力、流动、冷却或固化对尺寸、外观和性能的影响。可共享关键参数识别、工艺窗口、首件确认、巡检、异常停机和过程变更判断。吹膜膜泡、复合熟化、管材定径、建筑共挤、滚塑和发泡不能用单一注塑经验覆盖。
检验放行和追溯反馈均需通过尺寸、外观、力学、热性能、密封、阻隔、耐候、阻燃、装配或客户验收确认交付状态。可共享检验计划、测量设备、放行责任、不合格控制、批次追溯、投诉和纠正措施判断。包装迁移和泄漏、建筑气水密或焊角、管材耐压、电子外壳阻燃、外观件色差等检验不能互相替代。
  • 本体系核心控制要求

本组所称关键质量特性，是指产品或服务输出中影响顾客可接受性、使用适配性和交付符合性的材料性能、结构尺寸、外观状态、功能性能、可靠性、密封性、耐久性、洁净状态、标识追溯和客户特殊要求。QMS 审核应把顾客要求、技术文件、工艺参数、检验放行、变更控制和质量反馈连成证据链，而不是只查看最终检验记录。

第一，审核应确认顾客要求和用途边界是否清楚。塑料制品同样由树脂成型，但包装、建筑、工业零件和日用品的关键质量特性完全不同。组织应把材料牌号、尺寸、公差、颜色、外观、力学性能、密封、阻隔、耐候、阻燃、装配孔位、标签和交付方式转化为受控要求。

第二，审核应追溯材料和配混控制。树脂水分、熔体流动、色母分散、回料比例、增强材料、阻燃剂、耐候助剂、食品接触材料、阻隔材料和嵌件状态都会影响成品。应关注材料替代、回料使用、干燥记录、配料复核、批次隔离和客户认可材料的一致性。

第三，模具、模头、热封刀具、定径套和装配治具是本组质量形成的重要资源。板片管壳关注模头、冷却和牵引；包装关注印刷复合、热封刀和瓶口模具；建筑塑料关注型材模具、共挤层、焊角和五金孔位；其他塑料关注注塑模具、浇口、排气、保压冷却、嵌件定位和装配治具。

第四，过程控制应与成型路线匹配。挤出线需要关注温区、熔体压力、牵引、冷却和在线尺寸；包装软袋需要关注膜厚、复合、熟化、制袋和热封；吹塑容器需要关注型坯、吹气、壁厚和泄漏；建筑型材需要关注真空定型、共挤耐候层和焊角；注塑件需要关注干燥、注射、保压、冷却、脱模和外观。

第五，检验放行不能只停留在外观和尺寸。包装应关注热封、泄漏、阻隔、迁移或残留、印刷和标签；建筑塑料应关注壁厚、焊角、耐候、阻燃、启闭或气水密；板片管壳应关注厚度、壁厚、耐压、翘曲和二次加工适配；其他塑料应关注装配、阻燃、外观色差、嵌件拉拔、跌落、疲劳或客户功能验证。

第六，不合格和客户反馈应能回到材料、模具、参数、检验和放行节点。典型问题包括水分导致银纹、模头污染、壁厚偏心、复合脱层、虚封泄漏、瓶口尺寸漂移、焊角虚焊、共挤层不足、注塑缩水翘曲、嵌件松动和多规格混料混标。审核应验证纠正措施是否针对真实质量形成原因。

  • 分小类或内部路线差异分析
小类/路线与本包共同基础主要差异差异对能力授权的影响控制方式
14.02.01 板片管壳共享塑料材料、挤出或热成型、尺寸检验和追溯基础。连续截面、模头、定径、牵引、厚度或壁厚均匀、翘曲和二次加工适配突出。应标注板片管壳或连续挤出分支；不能替代包装热封、建筑焊角或注塑装配分支。抽取板、片、管或壳体订单，追溯材料、模头、定径冷却、尺寸和放行。
14.02.02 软包装共享塑料薄膜、材料、成型和检验基础。吹膜、流延、印刷、复合、熟化、分切、制袋、热封、阻隔和迁移突出。属于包装分支；从通用塑料成型扩展到软包装需专项确认。抽取卷膜或袋类产品，追溯基膜、印刷、复合、热封、泄漏和客户灌装反馈。
14.02.02 硬包装和吸塑包装共享注塑、吹塑、热成型、尺寸和外观检验基础。瓶口、容量、壁厚、泄漏、跌落、托盘腔体、洁净和标签适配突出。应与一般注塑件区分；食品、日化、医药或电子包装需按内容物确认。抽取瓶、桶、盖或托盘，追溯材料、模具、成型、泄漏、扭矩或腔体尺寸。
14.02.03 建筑塑料型材和门窗共享塑料挤出、共挤、尺寸、外观和装配基础。型材腔体、耐候层、焊角、五金、密封、排水、阻燃和建筑接口突出。应标注建筑塑料分支；通用管板挤出经历不能替代门窗和建筑系统能力。抽取型材或门窗，追溯混料、挤出、共挤、焊角、五金密封和功能检验。
14.02.03 装饰板、采光板、木塑和防水排水构件共享塑料材料、挤出、发泡、热成型和尺寸外观基础。户外耐候、阻燃、透光、发泡密度、排水通道和安装扣合突出。应按建筑用途和产品族限定能力。抽取建筑构件，追溯材料、成型、耐候或阻燃、尺寸和安装接口。
14.02.04 注塑和装配类其他塑料制品共享塑料材料、模具成型、尺寸外观、功能检验和追溯基础。集合性强，注塑精密件、日用品、电子外壳、汽车配套、嵌件、表面处理和装配差异明显。应按产品族和工艺路线标注；不宜以 14.02.04 名称笼统授权。抽取注塑件或组件，追溯材料、模具、注射保压、冷却、外观、装配和客户反馈。
14.02.04 滚塑、吹塑、发泡和大型中空件共享塑料材料、模具、热成型和检验基础。壁厚、密度、泡孔、低应力成型、泄漏和冷却变形突出。从普通注塑扩展到滚塑、发泡或大型中空件需补充目标路线案例。抽取中空或发泡产品，追溯材料、成型、壁厚、泄漏、密度或泡孔。
  • 分组合理性论证结论

本组可以设立的理由在于，四个小类均以塑料材料选择、配混或干燥、模具或模头赋形、成型参数、冷却固化、检验放行和批次追溯为共同质量形成基础。QMS 审核可以共享顾客要求转化、材料批次控制、工装设备能力、关键参数监控、检验放行、不合格和客户反馈闭环的判断方法。

因此，QG14-2 可以作为质量管理体系技术领域包使用，使用口径为“统一领域包 + 板片管壳分支 + 包装分支 + 建筑塑料分支 + 其他塑料制品分支 + 条件扩展 + 专项边界控制”。审核员授权、项目匹配、能力扩展和持续保持均应体现分支差异；当项目产品族超出已确认经历时，应通过案例评价、专业面谈、见证审核或技术支持补足证据。

  • 培训、考核与作业指导书需求

本组应建立塑料制品 QMS 专业培训，内容包括热塑性和热固性材料、树脂干燥、熔体流动、改性料和回料控制、模具模头管理、挤出定径、吹膜流延、复合热封、吹塑注塑、热成型吸塑、建筑型材共挤、门窗焊角、注塑保压冷却、嵌件和装配、滚塑发泡、外观色差、阻燃耐候、包装泄漏阻隔和典型不合格追溯。

考核宜采用场景式案例和批次追溯题，要求审核员能够从一份订单或客户技术要求出发，说明材料选择、配方或工艺转换、关键过程控制、特殊过程确认、检验放行、不合格处置、变更控制和客户反馈之间的证据关系。作业指导书应提供分支化抽样路径、典型记录清单、访谈问题库、授权边界提示和首个项目技术支持触发条件。

  • 常见合规义务类别与标准适用提示

本组可能涉及食品接触材料类别、药品或卫生用品包装类别、危险品包装类别、强制性产品认证类别、建筑产品应用类别、消防阻燃类别、塑料管材和压力用途类别、计量和检验检测类别、产品标识和消费者权益类别、客户安全件要求、限制物质和进出口客户要求等类别。本文件不列具体标准编号和年份；适用性应使用机构受控的有效清单、客户合同、产品技术文件、产品目录、认证规则、检测报告和所在地监管要求确认。上述类别用于识别外部要求如何转化为产品要求、过程控制、检验放行、标识追溯和交付确认，不替代政府许可、行政执法、产品认证决定或客户专项验收。

  • 分组使用限制和法定边界

本组 QMS 分组不替代食品接触材料符合性判断、药品包装审批或备案、危险品包装法定检验、建筑工程产品应用认可、消防或阻燃法定审查、压力管道或特种用途法定检验、强制性产品认证决定、客户安全件批准和政府监管。涉及食品接触包装、医药包装、危险品容器、建筑门窗和线槽、压力管、电子电器阻燃件、汽车安全相关塑料件、滚塑大型中空件和复杂装配件时，应确认审核员具备对应分支能力。

管理体系审核仅用于评价组织是否在其产品实现范围内建立并实施质量管理控制，不替代行政许可、强制性产品认证、工业产品许可、法定检验、食品接触材料符合性判断、建筑工程验收、消防审查、特种设备监督检验、政府监管、行政处罚、司法判断或客户专项验收结论。当项目涉及上述边界时，应在项目匹配阶段确认审核员分支能力和必要的技术支持。

  • 分组结论与使用口径

QG14-2 可作为质量管理体系塑料制品制造技术领域包使用。授权时应记录审核员在板片管壳连续挤出、塑料包装、建筑塑料、注塑和装配类其他塑料制品、滚塑发泡和大型中空件等分支上的实际能力。组内扩展应通过培训、案例评审、专业面谈、见证审核或项目技术支持控制。文件维护触发条件包括：材料体系、包装用途、建筑产品接口、特殊产品准入类别、主要成型路线、关键检测方法或上层分组使用中出现能力匹配争议。
