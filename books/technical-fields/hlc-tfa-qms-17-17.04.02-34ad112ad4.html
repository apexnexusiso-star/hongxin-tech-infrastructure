17.04.02 铝的生产专业小类基础卡

A. 标识与定位

A1 小类名称、分类代码、在分类体系中的位置

字段内容

上位技术领域有色金属冶炼及基础材料生产

17.04.02 铝的生产，是有色金属冶炼领域中规模化、连续化和能源密集特征非常突出的专业小类。其核心活动是将含铝资源或含铝中间物转化为氧化铝、原铝、铝液、铝锭、重熔用铝锭或基础铝合金锭等初级铝产品。典型流程包括铝土矿经拜耳法等工艺生产氧化铝，氧化铝经熔盐电解生产原铝，以及铝液经净化、合金化、铸造形成基础铝产品。

本小类处于铝产业链的上游基础生产段，连接铝土矿、氧化铝、炭素阳极、冰晶石、电力、废铝等投入与铝液、铝锭和基础铝合金锭等产出。它不覆盖后续铝压延、铝挤压、铝型材、铝合金门窗、铝箔、铝板带、铝制品、汽车铝部件等加工制造活动，也不覆盖单纯铝土矿采选或废铝回收分拣活动。

A2 定义与范围界定

铝的生产，是指以铝土矿、氧化铝、废铝、铝中间物、炭素阳极、冰晶石、氟化盐、合金添加剂和电力等为主要投入，通过氧化铝制备、熔盐电解、熔体净化、合金化、铸锭或连续铸造等过程，形成原铝、铝液、铝锭、重熔用铝锭、基础铝合金锭或其他初级铝产品的活动。

在多数产业链场景中，铝的生产至少涉及两个核心层次：一是氧化铝生产，即将铝土矿中的含铝矿物转化为适合电解使用的氧化铝；二是电解铝生产，即在熔融冰晶石体系中通过电解将氧化铝还原为金属铝。部分企业还包括铝液净化、合金化、铸锭、铸棒、铸轧坯或重熔用铝产品形成等初级成形过程。

如果组织主要从事废铝收集、分拣、打包或贸易，而不实施熔炼、净化、合金化和铸造形成基础铝产品，通常不纳入本小类。如果组织主要将铝锭、铝坯或铝合金锭加工为板、带、箔、管、棒、型材、门窗、结构件或终端铝制品，应按其主导加工活动另行识别。

B3 关键技术概念说明

铝生产的关键技术概念之一是“从矿物氧化物到金属铝的能量和物质转化”。铝在自然界中通常以氧化物或含铝矿物形式存在，不能像某些金属那样通过普通碳热还原直接经济地获得金属铝。现代原铝生产通常先将铝土矿转化为高纯度氧化铝，再在熔融冰晶石体系中进行电解，使氧化铝中的铝离子转化为金属铝。

另一个关键概念是“氧化铝质量、电解槽状态和铝液状态的连续传导”。氧化铝粒度、杂质、水分和流动性会影响电解槽加料和电解状态；电解质组成、槽温、极距、阳极状态、电流效率和氧化铝浓度会影响铝液形成；铝液后续净化、除气、扒渣、合金化和铸造条件又影响基础铝产品状态。铝生产的专业性，体现在对湿法化学、熔盐电化学、热工设备和金属熔体处理的连续理解上。

C2 主要功能、性能维度

氧化铝的客观维度包括 Al2O3 含量、SiO2、Fe2O3、Na2O 等杂质含量、粒度分布、安息角、流动性、灼减、水分、比表面积和电解适应性。氧化铝作为电解铝原料，不只是化学成分对象，也具有粉体和加料行为属性。

原铝和铝锭的客观维度包括铝含量、铁、硅、铜、镁、锌、钛等杂质或合金元素含量、重量、锭型、表面状态、夹渣、气体含量、批次标识、包装和交付状态。基础铝合金锭还涉及合金成分窗口、熔体净化状态、晶粒细化状态和下游加工适配性。

再生铝产品的客观维度除成分和形态外，还包括废铝来源稳定性、分选精度、熔炼损耗、杂质累积、除铁或除杂能力、铝渣金属含量和批次一致性。不同原料来源会显著影响再生铝熔炼和成品成分稳定性。

C3 常见产品或服务分型

按产业链阶段，可以分为氧化铝生产、电解铝生产和铝液铸锭或铝合金锭生产。氧化铝生产以铝土矿、苛性碱和湿法过程为主；电解铝生产以氧化铝、电解质、炭素阳极和直流电为主；铝液铸锭和基础合金锭生产以熔体净化、合金化和铸造凝固为主。

按原料来源，可以分为原生铝路线和再生铝路线。原生铝路线以前端氧化铝和电解为主，设备连续性和电力供应影响明显；再生铝路线以废铝分选、熔炼、净化、合金化和铸锭为主，原料混杂性和杂质控制更突出。

按产品形态，可以分为氧化铝粉体、铝液、重熔用铝锭、铝合金锭、铸轧坯、铸棒和其他基础中间产品。若后续已经进入板带箔、型材、管棒线、铝铸件或终端制品加工，则通常不再属于本小类的主导活动。

D. 过程与技术

D1 主要工艺或过程流程

铝生产的典型过程链可以分为氧化铝生产、电解铝生产和再生铝生产三类。

氧化铝生产的典型链路为：铝土矿接收和破碎磨矿 → 石灰、苛性碱和循环母液配制 → 高温高压溶出 → 赤泥分离和洗涤 → 铝酸钠溶液精制 → 种分分解形成氢氧化铝 → 氢氧化铝过滤洗涤 → 焙烧形成氧化铝 → 氧化铝冷却、输送、包装或转序。

电解铝生产的典型链路为：氧化铝、冰晶石、氟化盐、预焙阳极和电力准备 → 电解槽启动或正常运行 → 氧化铝加料和电解质控制 → 熔盐电解生成铝液 → 出铝和铝液转运 → 铝液净化、除气、扒渣或合金化 → 铸锭、铸棒或基础铝产品形成 → 成品检验、标识、包装和入库。

再生铝生产的典型链路为：废铝来料识别和分类 → 去除非铝杂物、破碎或预处理 → 熔炼 → 扒渣、除气、除杂和成分调整 → 合金化 → 铸锭或铸棒 → 检验、标识、包装和入库。再生铝路线与原生电解铝路线在原料控制和杂质控制上差异明显。

D4 主要原辅材料与投入

主要原料包括铝土矿、氧化铝、废铝、铝中间物、回炉料和基础合金料。主要辅料和技术投入包括苛性碱、石灰、絮凝剂、晶种、燃料、冰晶石、氟化铝、氟化盐、预焙阳极、阴极炭块、合金添加剂、精炼剂、除气介质、过滤材料、铸造脱模材料、包装材料、标准样品、分析试剂和过程控制数据。

氧化铝生产对铝土矿铝硅比、矿物组成、粒度、碱耗和杂质状态敏感；电解铝生产对氧化铝粒度、水分、流动性、电解质组成、阳极质量和直流电供应敏感；再生铝生产对废铝分类、涂层、油污、铁杂质、镁锌铜等元素含量和夹杂物状态敏感。

D5 常见工艺路线差异

氧化铝生产企业通常围绕铝土矿性质选择拜耳法、烧结法或联合法等路线。不同矿石品位、硅含量和矿物组成会影响溶出条件、赤泥量、碱耗、分解率和焙烧能耗。氧化铝企业的过程重点在湿法化学和粉体产品状态。

电解铝企业通常以预焙电解槽为核心，生产连续性强，对电力、槽控、阳极、氧化铝加料和电解质管理依赖明显。大型电解铝企业通常自动化水平较高，电解槽群规模大，过程数据密集；小规模或老旧装备则可能在槽况稳定性、能耗和阳极管理方面差异较大。

再生铝企业与原生铝企业的差异，主要体现在废铝来源、预处理、熔炼除杂、合金成分调整和金属收得率上。再生铝产品可能面向铸造铝合金锭、压铸铝合金或其他基础合金料，不应简单等同于电解原铝。

E. 产业链与边界

E1 上游供应

本小类上游包括铝土矿供应、苛性碱和石灰等化工原料供应、氧化铝供应、电力供应、炭素阳极供应、冰晶石和氟化盐供应、合金料供应、废铝回收和预处理供应、耐火材料和电解槽材料供应、检测计量服务和设备备件服务。

上游输入对本小类影响明显。铝土矿品质影响氧化铝生产的碱耗和赤泥状态；氧化铝粒度和杂质影响电解槽运行；阳极质量影响电解稳定性；电力供应影响连续生产；废铝分类和杂质状态影响再生铝成分稳定。

E2 下游应用或客户

下游客户包括铝压延企业、铝挤压企业、铝铸造企业、铝合金材料企业、电线电缆企业、交通运输材料企业、包装材料企业、建筑型材企业、电子电器材料企业和贸易流通企业。不同下游对铝锭、铝液、铝合金锭或氧化铝的成分、形态、批次、包装和交付状态要求不同。

铝生产企业的部分产品可能在集团内部直接转入铝加工工序，也可能作为标准化基础金属产品对外销售。是否纳入本小类，应看组织主导活动是否仍是基础铝产品形成，而不是后续加工形态形成。

E3 本小类在产业链中的位置

本小类位于铝产业链上游基础生产段，是从铝土矿、氧化铝、电力、炭素材料和废铝等投入向原铝、铝锭和基础铝合金产品转化的关键环节。它前接矿产资源、化工原料、电力、炭素材料和再生资源，后接压延、挤压、铸造、交通、建筑、包装、电气和电子材料制造。

由于铝锭、铝液和基础铝合金锭通常是多个下游行业的原料，本小类的成分稳定性、批次标识、重量计量、熔体状态和交付形态会沿产业链向后续加工和制品制造传导。

E4 常见委外或外包环节

行业中常见外包或外部接口包括铝土矿运输、废铝预处理、阳极制造或供应、槽大修、设备检修、计量校准、部分化学分析、物流运输、赤泥或铝灰综合利用接口、耐火材料施工、铸造备件维修和信息系统维护等。大型一体化企业可能将部分上游和公辅过程纳入内部控制，小型企业则更依赖外部供应和专业服务。

外部接口会影响过程事实。例如阳极供应质量影响电解槽运行，废铝预处理影响再生铝杂质输入，计量校准影响称量数据可信度，槽大修质量影响电解槽寿命和运行状态。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类技术复杂度较高，既包括氧化铝生产中的湿法化学、固液分离、粉体焙烧和大宗物料连续输送，也包括电解铝生产中的熔盐电化学、电解槽群控制、阳极管理、电力系统和铝液铸造。大型企业通常自动化程度较高，具有集中控制、槽控系统、在线监测和完善的实验室能力，但原料波动、槽况判断、阳极更换、异常槽处理和再生铝杂质控制仍依赖专业经验。

铝生产整体具有连续化、规模化和强能源依赖特征。氧化铝和电解铝过程投资大、装备专业化程度高，工序之间存在明显的物料和参数传导。再生铝企业的装备规模和自动化水平差异更大，来料识别和杂质控制对人员经验依赖更明显。

H2 典型组织形态

行业典型组织包括大型氧化铝企业、大型电解铝企业、铝电一体化企业、氧化铝-电解铝一体化企业、基础铝合金锭企业、再生铝熔炼企业和集团内配套铝液供应单元。大型一体化企业通常具备完整原料、生产、公辅、实验室、物流和能源系统；专业化企业可能只承担氧化铝、电解铝、铝液铸锭或再生铝某一段活动。

不同组织形态在资源能力上差异明显。氧化铝企业重在矿石、湿法系统和粉体产品；电解铝企业重在电力、槽控、阳极和铝液；再生铝企业重在废铝来源、熔炼净化和合金化；铝合金锭企业重在成分窗口、熔体处理和铸锭稳定性。
