29.01.01 轿车和轻型汽车的销售 专业小类基础卡

> 本卡为技术领域分组底层知识卡，记录不依附于特定管理体系的行业事实、过程边界、术语、产品或服务、过程技术、产业链、法规标准类别、检验计量手段和维护信息。凡涉及具体管理体系下的人员能力、样本选择、合格评定结论或体系风险分级的内容，应在上层分组论证文件中展开。

A2 定义与范围界定

本小类包括面向个人、家庭、小微组织和一般公务商务用途的轿车、运动型乘用车、多用途乘用车、轻型客车、轻型货车等车辆销售活动。其本质不是车辆制造，而是围绕车辆来源确认、车型配置匹配、交易洽谈、订单合同、车辆库存、交付准备、车辆移交和交付后服务接口形成的流通服务。 本小类既可能表现为品牌授权经销、直营门店、综合展厅、二手车经销、网络线索转化、城市展厅交付中心等形态，也可能与金融、保险、上牌、精品附件、置换和延保服务形成组合式交易。只要主导活动仍是轿车和轻型汽车销售，本卡均可作为底层知识来源。 本小类的专业性集中在车型配置、车辆唯一性识别、车况和随车文件、车辆交付准备、客户用途匹配、交易合规边界、库存车辆保管以及售前售后接口衔接。其交付对象是车辆所有权或使用权交易服务结果，而不是车辆维修作业或零部件单独销售。

A3 边界说明、相邻小类区分点和排除项

相邻活动容易混淆的原因主要区分依据本卡处理原则
29.01.02 其他汽车的销售均属于汽车整车销售，均涉及车辆来源、配置和交付车辆用途、总质量、车辆结构和客户场景是否以乘用/轻型用途为主轿车、SUV、MPV、轻型客车和轻型货车销售归入本卡；重型货车、客车、专用车、工程车辆销售归入 29.01.02。
29.02.00 汽车的保养和修理汽车销售门店常设售后服务工位主导收入和活动是否为车辆交易还是车辆技术状态恢复销售过程中附带交付检查和交车说明可归入本卡；独立维修、保养、钣喷和故障诊断归入 29.02.00。
29.03.02 汽车零部件及配件的零售车辆销售常捆绑精品、附件和易损件交易对象是否为整车还是零部件或附件随车赠送、加装和交付配套属于销售服务接口；独立销售轮胎、电瓶、机油、装饰件等归入零部件零售。
汽车金融、保险和租赁服务汽车销售常与贷款、保险、融资租赁和长租服务相连企业主导活动是否为资金安排或租赁资产运营销售门店代办或协助办理作为外部接口记录；以金融、保险、租赁为主的活动不纳入本卡。
二手车经纪和拍卖活动轻型车销售可包含置换、认证二手车和寄售是否承担车辆经销交易主体责任，还是仅提供撮合、拍卖或平台服务经销主体买断再售车辆可纳入本卡；纯撮合、拍卖和信息平台按主导活动另行识别。
整车制造企业销售部门制造企业自有销售网络可能直接面向客户组织主导活动是否为整车制造，或是否为独立销售经营单元独立销售公司按本卡识别；整车制造过程不纳入本卡。

明确排除项：

  • 汽车、底盘、发动机和车辆零部件的制造活动。
  • 独立汽车维修、救援、清洗、美容、检测和改装服务。
  • 以车辆融资、保险代理、租赁运营或网约平台运行为主的活动。
  • 重型卡车、客车、专用汽车、工程车辆等非轻型车辆销售活动。
  • 仅销售轮胎、机油、蓄电池、行车记录仪、车载电子件等零配件的活动。

A4 分组特征摘要

维度本小类特征上层分组调用提示
主导活动类型乘用车和轻型车辆整车销售服务上层调用时应先确认交易对象是整车，而不是维修服务、零部件流通或金融租赁。
核心过程性质销售线索转化、车型配置匹配、车辆来源与 VIN 核验、库存车辆保管、交付前检查、随车文件交接和客户使用说明其技术命脉在车辆唯一性、配置一致性和交付状态确认，不是通用商品零售。
主要技术基础车型谱系、配置版本、车辆识别代码、PDI、库存车养护、随车资料、二手车车况描述和交车仪式链条具备普通零售经验不等于理解车辆配置、车况和交付文件。
产业链段位上接整车厂、区域总代、二手车车源和物流仓储，下接个人客户、单位用车、小型车队和售后维修网络上游供应和下游交付均带有明显车辆身份和服务接口。
典型规模跨度从单品牌 4S 店、城市展厅到多品牌综合销售和网络直营交付中心均存在不同规模主体的核心差异在车源控制、库存深度、交付资源和售后接口。
主要分型轴按新车/二手车、授权/非授权、线下展厅/线上获客、库存现车/订单交付、个人/单位客户分型分型差异会改变资料核验、车况说明和交付链条。
分组比较提示与 29.01.02 同属整车销售，但本卡更强调乘用和轻型用途、配置版本、客户体验、金融保险接口和交付细节如与其他汽车销售共组，应把重型商用车的载荷、上装和行业场景差异单独识别。
分组敏感边界二手车置换、精品附件、上牌代办和售后保养容易把销售服务边界拉宽使用本卡时应以主导交易对象和主导收入活动为边界判据。

A4 是从 C、D、E、G、H 各段提炼出的调用索引。上层文件使用本卡时，应先通过 A4 识别本小类技术命脉，再回到 D 段过程链、G 段方法工具和 H3 客观敏感点核对事实基础。

B. 术语与概念

B1 专业术语和行业常用表达

术语解释本小类中的使用语境
车辆识别代码车辆唯一身份编码，通常用于车辆来源、配置、登记和维修追溯。用于库存、合同、交付文件和售后接口的一致性确认。
PDI交付前检查，通常包括外观、内饰、随车工具、油液、电气功能、胎压和软件状态等确认。是车辆从库存状态转为可交付状态的重要节点。
车型配置同一车系按动力、驱动、内饰、智能化、选装包等形成的具体版本。决定报价、合同、车辆实物和客户预期是否一致。
库存车已进入销售库存但尚未交付给终端客户的车辆。需要关注存放环境、蓄电池维护、轮胎保护和外观状态。
合格证或随车证明文件车辆流通和登记所需的法定或技术证明资料类别。用于交付、登记和客户权益文件交接。
置换客户以原有车辆抵扣或转让并购买新车的交易安排。涉及旧车车况描述、权属核验、估值和过户接口。
精品附件销售过程中常见的脚垫、膜类、行车记录仪、装饰件和保护件等。属于整车销售附带服务时仍需与独立零售区分。
延保在原有质保之外延长服务期限或范围的商业服务。属于车辆交易附加服务，需要清楚边界和服务主体。
试乘试驾客户在销售人员陪同或安排下体验车辆性能和功能的活动。涉及试驾车辆状态、路线、人员资格和客户告知。
金融方案车辆购买中的贷款、分期、融资租赁等资金安排类别。通常作为外部接口，不改变本卡主导活动属性。
保险代办销售机构协助客户完成车辆保险购买或信息提交的服务。需与独立保险代理活动区分。
交车车辆、钥匙、文件、随车工具和使用说明移交给客户的过程。是销售服务结果形成的最后可见节点。
二手车车况既有车辆的里程、事故、维修、外观、结构、手续和使用状态描述。二手车销售和置换业务中的核心事实基础。
厂家授权整车品牌对经销商销售、服务、配件和形象标准的授权安排。影响车源、价格政策、售后接口和品牌资料使用。

B3 关键技术概念说明

轿车和轻型汽车销售必须同时理解“商品交易”和“车辆身份”两层逻辑。普通商品可以主要依靠型号和数量管理，而车辆销售必须把车系、配置、颜色、生产批次、车辆识别代码、随车文件和登记接口连成一条链。 交付前检查不是维修过程的替代，而是销售服务将库存车辆转为客户可接收车辆的状态确认。它覆盖外观、功能、油液、电瓶、轮胎、随车工具、软件版本和文件齐套性，重点在发现运输、存储和准备过程中的状态偏差。 二手车或置换场景使本小类的边界更复杂。既有车辆的权属、事故、维修、里程、结构件状态和手续资料会进入交易事实描述，销售人员必须把事实披露和价格形成区分清楚。 线上获客和线下交付并不改变本小类属性。无论客户从展厅、平台、直播、电话还是企业客户渠道进入，最终仍要回到车辆来源、合同、付款、文件、交付和售后接口这条服务链。

C. 产品或服务描述

C1 典型产品或服务类别与用途

类别典型内容主要用途或服务场景
新乘用车轿车、SUV、MPV、轻型客车等个人、家庭、商务出行和单位一般用车。
轻型货车和轻型客货两用车轻卡、小型厢式车、皮卡等城市配送、小微经营、工程服务和个体运输。

C2 主要功能和性能维度

维度客观内容说明
身份维度车辆识别代码、发动机或电机信息、配置版本、随车文件决定车辆实物、合同和登记信息是否对应。
状态维度外观、内饰、功能、电气、油液、电瓶、轮胎、里程决定车辆是否达到可交付状态。
配置维度动力形式、驱动形式、车身颜色、智能化配置、选装包决定客户选择和价格形成。
交易维度报价、合同、付款、发票、交付日期、附加服务决定交易权利义务和客户预期。
文件维度随车证明、保养手册、使用说明、钥匙、工具、票据决定客户后续登记和使用便利性。
体验维度试乘试驾、功能讲解、交车说明、售后入口决定客户理解车辆功能和服务路径。
库存维度库龄、存放环境、充电或电瓶维护、外观保护决定车辆在交付前的状态保持。
二手车维度权属、事故、维修、里程、结构、手续和价格依据决定二手车交易事实描述。

D. 过程与技术

D1 主要过程流程：从投入到产出的完整链路

本小类的过程链通常从市场线索、客户到店或线上咨询开始，经需求识别、车型配置说明、报价、试乘试驾、订单确认、车辆锁定、合同签署、付款安排、随车服务协调、库存车辆准备、交付前检查、文件核对、车辆移交和后续服务入口告知完成。 车辆销售服务不同于普通零售的关键在于“车、证、款、人、服务接口”必须同步闭合。车辆实物与车辆识别代码对应，合同与配置版本对应，付款和票据与交易主体对应，客户身份和登记资料与交付接口对应，后续保养、质保和救援入口与交车说明对应。 在二手车和置换场景中，过程链还包括旧车接收、权属核验、车况检测或评估、价格形成、车辆整备、信息披露、过户接口和售后责任边界说明。该链条的难点不是制造技术，而是交易事实和车辆状态的一致表达。

通用链路可表示为：

`text 客户或市场需求 → 对象识别 → 技术或规格匹配 → 商务确认 → 资源准备 → 交付或服务作业 → 状态确认 → 文件和售后接口 → 反馈与维护 `

D7 轻型汽车销售的车辆身份、配置和交付链条深化说明

轻型汽车销售的深水区在于车辆交易不是单一货物买卖，而是车辆身份、配置承诺、交付状态和后续服务接口的组合交付。车辆识别代码把实车、合同、发票、随车文件和售后档案连接在一起，任何一处不一致都会改变客户接收事实。 配置链条是本小类区别于普通零售的另一核心。相同车系下，不同动力、电池容量、驾驶辅助、内饰、轮毂、颜色和选装包会形成不同价格和客户预期。销售服务应能把配置口径、库存实车和合同表达对应起来。 交付链条则把库存车辆保管、PDI、清洁整备、随车文件、钥匙、工具、功能说明和售后入口统一起来。轻型车客户通常不是专业用户，车辆功能复杂度上升后，交车说明本身成为服务结果的重要组成。

链条典型要素客观作用
车辆身份链VIN、钥匙、随车证明、合同、发票、售后档案同一车辆在不同文件和系统中保持一致。
配置承诺链车系、版本、颜色、选装、附加服务防止客户理解的配置与实车配置不一致。
库存状态链库位、库龄、电瓶、轮胎、外观、充电状态保持车辆从入库到交付期间的状态稳定。
PDI链检查清单、异常处理、复查、交车确认将运输和存储期间状态问题在交付前闭合。
文件交接链随车资料、票据、登记资料、保养凭证保障客户后续登记和使用路径清楚。
客户说明链基本操作、补能、保养、质保、救援、软件功能减少客户因不理解功能而产生使用偏差。
二手车事实链权属、里程、事故、维修、整备和价格依据使既有车辆状态和交易条件相匹配。
外部服务链金融、保险、上牌、精品、延保明确本机构服务边界和外部主体责任。

E. 产业链与边界

E1 上游供应

上游来源提供内容对本小类的影响
整车生产企业提供车辆、车型资料、价格政策、售后接口决定车源稳定性和资料完整性。
区域总代或批发渠道提供跨区域车辆资源影响车辆来源、价格和服务责任表达。
物流和仓储服务商承担车辆运输、仓储和交付前周转影响外观、里程、电瓶和交付状态。
二手车车源方个人、车商、租赁公司、拍卖平台影响权属、车况和信息披露。

精品附件供应商提供随车加装和装饰用品影响交车配置和附加服务履行。

E2 下游应用或客户

下游对象使用或需求场景对服务的影响
个人和家庭客户日常通勤、家庭出行、代步和消费升级更关注配置、价格、交付体验和售后入口。
小微企业和个体经营者经营运输、门店配送、工具车辆更关注载货能力、使用成本和售后便利。
单位客户公务、商务、行政或项目用车更关注批量合同、票据、交付节奏和统一配置。
网约、租赁和平台运营客户高频运营车辆采购更关注能耗、维保成本、残值和批量交付。
二手车消费者预算敏感和车况敏感更关注信息透明、车辆状态和过户资料。
售后维修网络承接保养、维修和客户反馈是交付后服务链的主要接口。

E3 本小类在产业链中的位置

本小类位于流通和服务产业链中，不改变车辆或商品的基本制造属性，而是通过信息匹配、资源组织、交易安排、状态确认和服务接口，把上游车辆、配件或资料转化为客户可接收、可使用或可继续处理的服务结果。

对于 29 大类而言，产业链位置判断尤其依赖主导活动：同一组织可能同时存在销售、维修、配件、金融、保险、平台和外包接口，但分类时应识别哪一类活动构成主要服务输出。

E4 常见委外和外部接口

外部接口常见内容边界提示
车辆运输由物流商从厂家或仓库运至门店运输里程、外观保护和交接记录。
上牌和登记协助由门店或外部代办机构协助完成客户资料、车辆文件和时限接口。

H. 行业本底特征

H1 技术复杂度、自动化和人工依赖程度

维度本底特征说明
技术复杂度车辆和配件涉及机械、电气、电子、软件、材料和使用场景不同小类复杂度来源不同。
信息依赖车型、VIN、零件号、配置、库存和客户资料高度重要信息错误会直接传导到交付或服务结果。
人工经验销售说明、适配判断、诊断和客户沟通仍大量依赖人员经验系统工具不能完全替代专业判断。
自动化程度库存、订单、目录和平台系统逐步提高自动化现场交付、维修和客户解释仍需人工完成。
规模跨度从小型门店到连锁平台、品牌经销和区域仓均存在组织形态跨度大。

H2 典型组织形态

组织形态典型特点说明
品牌授权经销或服务站厂家资源、资料和服务接口较完整常见于整车销售和维修。
独立门店经营灵活、人员复合、外部接口多常见于配件零售和维修。
区域批发商或仓配平台库存深、SKU多、配送范围广常见于配件批发。
线上平台店远程获客、系统订单、物流交付适配说明和退换货突出。
综合复合门店销售、维修、配件、精品和外部服务交织边界识别需要看主导活动。

H3 客观存在的易出问题环节和技术敏感点

敏感点客观表现客观影响链
车辆身份信息错配VIN、合同、发票或随车文件不一致身份信息错配 → 登记或售后接口受阻 → 交易纠纷。
配置表达不清口头承诺、报价单和实车配置不一致配置理解偏差 → 价格争议 → 客户接收事实不一致。
库存车状态退化长时间停放导致电瓶亏电、轮胎变形或外观损伤存放维护不足 → 交付状态下降 → 后续补救成本增加。
PDI流于形式只签表不查车或异常未闭合运输存储问题未发现 → 交车后暴露 → 客户信任下降。
二手车事实披露不足事故、里程、权属或维修历史表达不完整事实基础不清 → 价格依据失真 → 交易争议。
试驾车辆管理薄弱试驾路线、车况和人员确认不足体验活动失控 → 财产损失或人员伤害事件。
附加服务边界模糊金融、保险、精品、延保主体不清服务主体混淆 → 权责不清 → 纠纷处理困难。
客户资料流转不当身份、贷款、保险和联系方式多方流转资料管理不当 → 隐私泄露 → 信任损害。
新能源交车说明不足充电、软件、续航和高压注意事项讲解不足客户理解不足 → 使用偏差 → 投诉和服务压力。
跨区域交付接口复杂异地提车、物流、上牌和售后衔接多接口断点增加 → 文件或车辆状态追溯困难。

H3 仅写事实因果链，不把这些敏感点预先归入任何特定管理体系视角。

I1 主管部门、行业协会和权威信息源类别

信息源类别可提供的信息用途
国家市场监督管理相关部门经营主体登记、广告、价格、消费者权益、产品责任和网络交易等通用监管信息。用于确认流通服务活动的外部规则类别。
商务主管部门及流通业信息源汽车流通、二手车流通、成品油流通、批发零售业统计和行业运行信息。用于理解渠道结构、经营模式和行业边界。
交通运输相关主管部门机动车维修、道路运输车辆、维修企业备案和车辆技术服务信息。用于识别维修服务和车辆技术状态相关规则类别。
公安交通管理相关信息源机动车登记、号牌、车辆识别、报废、转移登记和道路车辆管理信息。用于理解车辆交付、过户和信息核验接口。
行业协会和标准化组织汽车流通、维修、零部件、摩托车流通、商用车服务等行业自律和标准化资料。用于持续维护术语、服务流程和技术资料。
汽车流通和后市场资料源汽车销售、配件、售后和客户服务资料。用于维护汽车后市场服务边界。

I2 引用和待核实资料清单

资料类别用途维护要求
国民经济行业分类及其注释用于确认本小类活动范围、相邻类别和排除项。应保持与机构技术领域分类表一致。
汽车销售与流通行业公开资料用于确认经销、直营、代理、二手车、售后服务等经营模式。需由维护人员核验现行有效版本。
机动车维修行业公开资料用于确认工单、诊断、拆装、调试、交车等维修服务链。涉及地方备案和工位条件时只保留类别指针。
车辆及零部件产品技术资料用于理解 VIN、车型配置、适配件、总成件、易损件和安全相关部件。具体车型资料属于企业资料，不写入通用卡。
消费者权益、产品责任、广告和价格领域通用资料用于描述流通服务行业共同法律主体。不作具体组织适用性判断。
危险品、特种设备、金融保险、数据保护等跨领域规则线索仅在业务涉及时作为外部接口类别。具体适用性留给上层或专项文件。
轿车和轻型汽车的销售行业公开资料用于补充本小类典型业务流程、术语和边界案例。应由维护人员定期核验。
现行有效标准目录检索记录用于确认 F2 中各类标准的现行有效版本。正式受控发布前完成。
