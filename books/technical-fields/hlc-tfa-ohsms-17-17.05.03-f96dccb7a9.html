17.05.03 轻金属的铸造专业小类基础卡

A. 标识与定位

A1 小类名称、分类代码、在分类体系中的位置

字段内容
专业小类编码17.05.03
专业小类名称轻金属的铸造
对应分类基础参考国民经济行业分类中铝、镁等轻金属铸件生产活动，并结合机构受控技术领域分类使用
上位技术领域金属铸造及基础零部件成形
本卡定位专业小类底层知识卡，用于沉淀轻金属铸造的行业事实、技术过程、边界、检测手段和基础信息

17.05.03 轻金属的铸造，是以铝、镁及其合金等轻金属为主要材料，通过熔化、合金配制、精炼除气、变质或细化处理、模具准备、压铸、低压铸造、重力铸造、砂型铸造、金属型铸造、熔模铸造、挤压铸造或其他铸造成形过程，形成轻金属铸件、毛坯件或基础零部件的生产活动。

轻金属铸件广泛用于汽车、摩托车、航空航天、电子电器、通信、家电、机械装备、交通工具和一般工业部件。与铁钢铸造相比，轻金属铸造具有熔点较低、密度小、导热快、氧化膜敏感、气孔倾向、模具和压铸设备依赖程度高等特点。铝合金铸造和镁合金铸造在熔体处理、保护介质、模具温度和缺陷形态上存在差异，但都属于轻金属熔体通过铸造成形获得零部件的基础制造活动。

A2 定义与范围界定

轻金属的铸造通常指以铝锭、铝合金锭、再生铝合金锭、镁锭、镁合金锭、回炉料、合金元素、精炼剂、变质剂、细化剂和其他辅料为投入，经熔化、配料、成分调整、除气、除渣、变质、细化、保温和浇注或压射，使金属液进入模具或铸型并凝固形成轻金属铸件的活动。

本小类包括铝合金压铸件、铝合金重力铸件、铝合金低压铸件、铝合金砂型铸件、镁合金压铸件、镁合金重力铸件、轻金属熔模铸件、挤压铸造件和其他轻金属基础铸件。产品可以是毛坯铸件，也可以是经去毛刺、抛丸、喷砂、热处理、浸渗、初加工、清洗或防护后交付的铸件，但主导活动应仍为轻金属铸造成形。

本小类不覆盖铝、镁等轻金属冶炼和基础金属锭生产，不覆盖铝型材挤压、铝板带箔压延、镁合金板材或型材加工，不覆盖铁的铸造、钢的铸造、铜锌等其他非铁金属铸造，不覆盖塑料压铸、锻造、粉末冶金、纯机加工、表面处理服务、电子产品装配和汽车零部件总成装配。

B3 关键技术概念说明

轻金属铸造的第一个关键概念是熔体氧化和夹杂。铝、镁熔体容易形成氧化膜，熔体翻动、浇注紊流、回炉料氧化和模具排气不当，可能使氧化膜和夹杂进入铸件内部，形成折叠、夹杂或力学不连续区域。

第二个关键概念是气体和孔洞。铝熔体中的氢含量、湿炉料、潮湿工具、型砂水分和熔体处理状态，会影响气孔倾向。压铸件还可能因高速充型卷气形成气孔。气孔、缩孔和缩松形态不同，来源也不同。

第三个关键概念是模具热平衡。压铸和金属型铸造高度依赖模具温度、冷却水、喷涂、脱模剂和循环节拍。模温过低可能导致冷隔或欠铸，模温过高可能导致粘模、变形或组织粗化。

第四个关键概念是工艺路线差异。砂型铝铸件、低压车轮、压铸壳体和镁合金件的过程对象差异很大。压铸偏向设备参数、模具和节拍；砂型偏向型砂、浇冒口和凝固；低压偏向保温炉压力控制和自下而上充型；镁合金还涉及防氧化和保护介质。

C2 主要功能和性能维度

轻金属铸件的主要功能来自低密度、可成形性、导热性、耐蚀性、可加工性和一定的强度重量比。铝合金铸件常用于需要减重、散热、复杂结构和批量制造的场景；镁合金铸件常用于更高减重需求和电子、交通部件。

客观描述轻金属铸件时，常见维度包括合金牌号、化学成分、热处理状态、尺寸精度、表面状态、孔隙率、内部致密性、气密性、硬度、拉伸性能、延伸率、金相组织、二次枝晶间距、变形、残留浇口飞边、机加工余量、清洁度和批次标识。

D. 过程与技术

D1 主要工艺或过程流程

`mermaid flowchart LR A["铝镁合金锭、回炉料、合金料"] --> B["炉料验收和配料"] B --> C["熔化和保温"] C --> D["成分调整、除气、除渣、变质或细化"] D --> E["模具或铸型准备"] E --> F["压射、低压充型或重力浇注"] F --> G["凝固和开模"] G --> H["去浇口、去飞边和清理"] H --> I["热处理、浸渗或初加工"] I --> J["轻金属铸件"] `

轻金属铸造从合金锭、回炉料和合金料配比开始。回炉料比例、氧化夹杂、油污、水分和牌号防混会影响熔体状态。铝合金和镁合金熔化温度较铁钢低，但对氧化、气体、夹杂和熔体翻动较敏感。

熔化和保温后通常需要成分调整、精炼除气、除渣、变质和晶粒细化。铝硅合金常涉及变质和细化处理，镁合金常涉及防氧化保护和熔体安全控制。熔体处理后进入压铸机、低压铸造机、重力金属型、砂型或其他铸型系统。

压铸路线中，压射速度、增压压力、模具温度、喷涂、排气、真空辅助、保压和冷却节拍是主要过程对象。低压铸造中，升液压力、保压、模具温度和金属液洁净度较突出。砂型或重力铸造中，浇注系统、冒口、排气、型砂或金属模状态更突出。

凝固后铸件需要开模、取件、去浇口、去飞边、抛丸或喷砂、清洗、热处理、整形、浸渗、机加工或表面防护。不同产品的后处理深度差异很大，但判断本小类时仍应看主导活动是否为轻金属铸造成形。

E3 本小类在产业链中的位置

轻金属铸造位于轻金属基础材料和下游零部件制造之间。它把铝镁合金锭、回炉料和铸造辅料转化为复杂形状铸件，为汽车轻量化、电子散热、通信设备、家电和机械装备提供毛坯或基础零部件。

本小类上接铝镁合金材料、再生金属和模具制造，下接机加工、表面处理、装配和终端产品制造。分类时应识别企业主导活动是否为轻金属熔体铸造成形，而不是只看产品最终流向。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

轻金属铸造属于材料、熔体处理、模具、设备参数和后处理高度耦合的制造活动。压铸企业的自动化程度通常较高，可能配置自动给汤、喷涂、取件、切边、机器人打磨和在线检测；砂型和小批量铝铸件企业则可能更多依赖人工造型、浇注和工艺经验。

轻金属铸造的技术复杂度来自合金成分、熔体气体和夹杂、模具温度、充型速度、冷却条件、热处理和尺寸变形之间的相互作用。镁合金铸造还具有更强的防氧化和熔体保护要求。大批量压铸看似节拍稳定，但模具磨损、排气变化、喷涂状态和设备曲线漂移都会改变铸件状态。

组织形态典型特征说明
铝合金压铸企业大批量、模具和设备依赖高汽车和电子件常见

H3 客观存在的易出问题环节和技术敏感点

环节或敏感点客观事实描述客观影响链
回炉料比例回炉料可能含氧化物、油污和牌号差异回炉料波动 → 熔体夹杂和成分变化 → 铸件内部状态变化
熔体吸气铝熔体可吸收氢，潮湿工具和炉料会增加气体来源氢含量升高 → 凝固析出气体 → 气孔形成
氧化膜卷入熔体表面氧化膜可能在紊流中卷入充型紊流 → 氧化膜进入型腔 → 内部不连续区域形成
除气除渣熔体处理影响气体和夹杂状态处理不足 → 气体或夹杂残留 → 孔洞和夹杂倾向变化
模具温度模温影响充型、凝固和脱模模温偏离 → 冷隔、粘模或变形倾向变化
排气系统压铸高速充型需要排出型腔气体排气受阻 → 卷气增加 → 内部孔隙变化
压射曲线速度和压力决定充型和增压曲线偏离 → 充型和补压状态变化 → 缺陷分布变化
热处理变形铝合金热处理可能引起尺寸变化装炉或冷却不均 → 残余应力释放 → 尺寸变形
镁合金防护镁熔体氧化和燃烧敏感性较高保护不足 → 氧化或燃烧倾向变化 → 熔体和现场状态变化
机加工暴露孔洞铸件内部孔洞可能在加工后暴露加工去除表层 → 内部孔洞显露 → 表面和气密状态变化
