17.04.01 贵金属的生产专业小类基础卡

A. 标识与定位

A1 小类名称、分类代码、在分类体系中的位置

字段内容
专业小类编码17.04.01
专业小类名称贵金属的生产
对应分类基础参考国民经济行业分类中贵金属冶炼、精炼和相关基础金属生产活动，并结合机构受控技术领域分类使用
上位技术领域有色金属冶炼及贵金属基础材料生产
本卡定位专业小类底层知识卡，用于沉淀贵金属生产的行业事实、技术过程、边界和基础信息

17.04.01 贵金属的生产，是指以金、银及铂族金属等贵金属资源为对象，通过火法、湿法、电解、化学分离、还原、熔铸、粉体制备等过程，将矿产原料、冶炼中间物、阳极泥、含贵金属废料或其他含贵金属物料转化为贵金属单质、贵金属锭、贵金属粉体、海绵金属或其他基础贵金属产品的活动。

本小类具有明显的高价值物料、复杂成分体系、精密分析计量、多来源原料和多路线精炼特征。它既可能出现在大型有色金属冶炼企业的综合回收系统中，也可能出现在专业金银精炼企业、铂族金属分离企业、贵金属再生资源企业和贵金属材料前端制备企业中。与一般有色金属冶炼相比，本小类对批次追溯、取样代表性、成分纯度、贵金属收率、防混料、防损耗和计量结算的依赖更强。

A2 定义与范围界定

贵金属的生产，通常包括金、银、铂、钯、铑、铱、钌、锇等贵金属及其基础形态产品的冶炼、精炼、分离、提纯和基础成形活动。生产对象既可以来自原生矿产资源，例如金精矿、银精矿、含贵金属多金属矿物料；也可以来自冶炼副产物和二次资源，例如铜、铅、锌、镍等冶炼过程形成的阳极泥、烟尘、渣料、含贵金属催化剂、电子材料废料、镀层废料、含金银废液和其他含贵金属物料。

本小类的核心是“贵金属元素的提取、分离和基础产品形成”。如果组织的主导活动是将含贵金属物料经过预处理、富集、浸出、分离、精炼、电解、还原、熔铸或粉体制备，形成可作为后续投资、工业、电子、催化、首饰或其他用途基础投入的贵金属产品，通常属于本小类。

本小类不以终端消费品制造为主。金条、银锭、铂钯海绵、贵金属粉、贵金属基础颗粒等可作为基础产品纳入；首饰、工艺品、电子元器件、催化剂成品、医疗器械部件、贵金属镀层制品等终端产品制造，应按其主导加工或产品类别另行识别。

B3 关键技术概念说明

贵金属生产的关键技术概念之一是“高价值低含量目标元素的富集和选择性分离”。许多含贵金属物料中，目标元素含量可能远低于主体基体元素，且金、银、铂、钯、铑等元素之间可能伴生。生产过程需要先通过预处理和富集提高目标金属浓度，再通过湿法、火法、电解或化学分离方式逐步去除基体元素和伴生杂质。

另一个关键概念是“成分纯度、收率和防损耗的耦合”。贵金属产品往往以纯度、重量、杂质含量和批次一致性作为基础交付信息，但生产组织同时还要控制目标金属在渣、液、泥、粉尘、中间物、废液和设备残留中的分布。纯度高不必然意味着收率高；收率高也不必然意味着产品达到高纯等级。贵金属生产的专业性，体现在对化学体系、分离路径、计量分析和物料闭合关系的综合控制。

C2 主要功能、性能维度

贵金属基础产品的客观维度包括主元素含量、杂质元素含量、纯度等级、重量、形态、粒度、比表面积、含水率、批次均匀性、包装状态、标识、可追溯性和后续加工适配性。不同产品形态的关注维度不同：金锭和银锭通常更强调重量、纯度和铸锭外观；贵金属粉体通常更强调粒度、松装密度、流动性和杂质控制；铂族海绵金属通常更强调主元素含量、杂质谱、含水或挥发物状态和后续溶解或加工适配性。

贵金属生产还具有显著的计量属性。由于单位价值高，原料接收、取样制样、湿重干重、金属含量、过程损耗、成品重量和结算数据之间需要建立严格的物料对应关系。对于多来源、多客户、多批次物料，批次隔离和混料防止是基础生产事实之一。

C3 常见产品或服务分型

按金属种类，可以分为金生产、银生产和铂族金属生产。金银生产常见于原生矿冶炼、铜铅锌冶炼综合回收和贵金属再生资源精炼；铂族金属生产更多依赖复杂分离化学、催化剂回收、镍铜冶炼副产物或含铂族二次资源。

按原料来源，可以分为原生矿来源、冶炼副产物来源和二次资源来源。原生矿来源更强调矿物组成、预处理和浸出或熔炼路线；冶炼副产物来源更强调阳极泥、烟尘、渣料等复杂基体处理；二次资源来源更强调来料识别、预处理、混杂物控制和贵金属含量评估。

按技术路线，可以分为火法富集或熔炼路线、湿法浸出分离路线、电解精炼路线、化学还原沉淀路线和多路线组合。实际企业往往不是单一路线，而是火法预处理、湿法浸出、萃取分离、电解或还原、熔铸成形的组合。

按产品形态，可以分为锭材、颗粒、粉体、海绵金属、中间沉淀物和贵金属溶液。产品形态不同，对成分、物理状态、包装、计量和后续使用适配性的要求不同。

D. 过程与技术

D1 主要工艺或过程流程

贵金属生产的典型过程链可以分为金银精炼、铂族金属分离和二次资源回收精炼三类。

金银精炼的典型链路为：含金银原料接收和批次识别 → 取样制样和初始含量分析 → 预处理或熔炼富集 → 浸出、氯化、硝酸处理、电解或其他精炼过程 → 杂质去除和金银分离 → 还原、沉淀或电解沉积 → 洗涤、干燥、熔铸或粉体处理 → 成品分析、称量、包装和入库。

铂族金属分离的典型链路为：含铂族物料接收和预处理 → 富集或焙烧 → 溶解或浸出 → 基体元素去除 → 铂、钯、铑、铱、钌等元素的选择性分离 → 沉淀、还原、煅烧或精制 → 海绵金属或粉体产品形成 → 分析、称量、包装和批次归档。铂族金属分离通常比金银精炼具有更复杂的化学体系和更长的分离链。

二次资源回收精炼的典型链路为：废催化剂、电子废料、镀层废料、含贵金属废液等来料识别 → 分拣、拆解、破碎、焙烧或其他预处理 → 贵金属富集或转入浸出系统 → 分离提纯 → 贵金属产品形成 → 残余物分类、过程物料平衡和批次结算。

D4 主要原辅材料与投入

主要原料包括金精矿、银精矿、含贵金属多金属精矿、合质金、合质银、铜阳极泥、铅阳极泥、镍冶炼副产物、含贵金属烟尘、渣料、废催化剂、电子材料废料、镀层废料、含贵金属废液和其他含贵金属物料。不同来源原料的基体元素、贵金属含量、水分、杂质谱、物理状态和权属关系差异很大。

主要辅料和技术投入包括酸、碱、氧化剂、还原剂、络合剂、萃取剂、沉淀剂、助熔剂、硼砂、硝石、氯化物、活性炭、离子交换树脂、电解液、阴阳极材料、熔铸辅料、过滤材料、包装材料、封签、批次标签、分析试剂和标准物质。对于贵金属生产，试剂纯度、试剂适配性、分析标准物质和计量器具状态都会影响数据可信度和产品判断。

D5 常见工艺路线差异

金银精炼企业通常以合质金银、阳极泥、金银精矿或含金银二次资源为对象，工艺重点在取样、富集、金银分离、电解或还原、熔铸和成品计量。其过程通常围绕纯度、重量、收率和结算数据展开。

铂族金属分离企业通常面对含铂、钯、铑等复杂物料，工艺重点在溶解体系、元素选择性分离、反复净化、沉淀还原和杂质谱控制。铂族金属之间化学性质相近，且部分元素含量低、价值高，分离链条通常更长。

二次资源贵金属企业的路线差异更大。废催化剂、电子废料、镀层废料和含贵金属废液在来料形态、贵金属含量、杂质组成和预处理方式上差异明显。企业可能先进行拆解、破碎、焙烧、熔炼或湿法浸出，再转入专业精炼系统。对于多客户来料加工企业，批次隔离和金属归属记录通常比单一来源企业更复杂。

大型综合冶炼企业往往将贵金属回收作为铜、铅、锌、镍等冶炼系统的一部分，原料来源和中间物稳定性较强；专业精炼企业则可能处理多来源小批量物料，对来料鉴别、合同结算、取样代表性和防混料要求更突出。

E. 产业链与边界

E1 上游供应

本小类上游包括贵金属矿山和选矿企业、有色金属冶炼企业、废催化剂产生单位、电子材料和电子产品拆解处理单位、表面处理和镀层企业、首饰回收渠道、工业废液产生单位、贵金属贸易和来料加工客户。上游输入既可能是标准化较高的精矿或合质金属，也可能是成分复杂、来源分散、形态不稳定的二次资源。

上游供应对本小类影响明显。物料中贵金属含量低、分布不均或基体复杂，会增加取样和分离难度；来料含水、含油、含有机物或含多种贱金属，会影响预处理和浸出体系；来料权属复杂或多客户混批，会影响批次管理和金属归属记录。

E2 下游应用或客户

下游客户包括贵金属投资和储备机构、首饰材料企业、电子材料企业、催化剂制造企业、化工材料企业、玻璃和特种材料企业、医疗和精密制造相关材料企业、贵金属贸易和金融服务相关机构。不同下游对产品形态和纯度要求不同，有的使用锭材，有的使用粉体或海绵金属，有的需要特定杂质谱和物理状态。

贵金属基础产品往往不是最终消费品，而是后续材料、制品、化学品或投资产品的基础投入。下游要求会反向影响本小类的产品形态、纯度等级、包装、标识、留样、检测报告和批次追溯方式。

E3 本小类在产业链中的位置

本小类处于贵金属资源向基础贵金属产品转化的关键环节。它前接矿产资源、有色冶炼副产物和二次资源，后接首饰、电子材料、催化剂、化工材料、投资储备和特殊材料制造。它既不是单纯资源回收，也不是终端贵金属制品制造，而是完成贵金属元素提取、分离、提纯和基础形态形成的中间基础生产段。

在产业链中，本小类还具有价值确认功能。贵金属物料的交易、来料加工和产品交付通常依赖成分分析、重量计量、批次对应和金属收率数据。生产过程不仅形成产品，也形成用于结算、追溯和后续使用的基础数据。

E4 常见委外或外包环节

行业中常见外包或外部接口包括来料运输、危险属性识别、部分物料预处理、第三方含量复核、计量器具校准、设备检修、废包装或残余物处理、贵金属押运、标准样品制备和部分专业分析服务。核心精炼、分离和高价值物料计量通常由生产组织重点控制，但某些企业会将前端拆解、焙烧、破碎或后端部分检测交由外部单位完成。

外部接口可能影响过程事实。例如第三方复核结果会影响结算争议处理；运输和封签状态会影响来料完整性；外部预处理会影响物料均匀性；计量校准服务会影响重量和分析数据可信基础。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类技术复杂度较高，体现在原料来源复杂、目标元素含量跨度大、伴生元素多、化学体系多样、物料价值高和分析计量要求严。大型综合冶炼企业可能具有自动化湿法系统、在线监测、完善实验室和较强物料平衡能力；专业精炼企业和再生资源企业则常面对小批量、多来源、差异化物料，对人员经验、来料判断、取样制样和批次隔离依赖更强。

贵金属生产的自动化程度差异较大。部分熔炼、电解和湿法系统可以实现较高程度的设备化和记录化，但来料识别、异常物料判断、分离路线选择、样品代表性判断、贵金属去向追踪和结算复核仍然高度依赖专业人员经验和稳定的技术规则。

H2 典型组织形态

行业典型组织包括大型有色金属冶炼企业内设贵金属综合回收系统、专业金银精炼企业、铂族金属分离企业、贵金属再生资源精炼企业、贵金属材料前端制备企业和来料加工型企业。大型综合企业通常原料来源相对稳定，过程链较完整；来料加工型企业面对多客户、多批次和复杂权属关系；铂族金属分离企业通常专业化程度较高，化学分离链更长。

不同组织形态在资源能力上差异明显。大型企业通常拥有较完整的实验室、库房、计量、安防和过程记录系统；小型专业企业可能在灵活处理特定物料方面经验丰富，但需要更清楚地界定可处理物料范围、分离能力、检测能力和外部接口。
