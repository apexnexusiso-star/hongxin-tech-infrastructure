A2 定义与范围界定

本小类是指制造利用燃料燃烧、电加热、余热回收或其他热源把水加热并转化为蒸汽的蒸汽发生设备，以及与蒸汽发生直接相关的金属受压部件和成套装配活动。本小类排除集中供暖用热水锅炉。其核心对象不是一般金属容器，而是具备受压边界、受热面、汽水流程、热源接口、蒸汽输出和安全保护配置的热工设备。

本小类通常包括工业蒸汽锅炉、快装蒸汽锅炉、组装蒸汽锅炉、散装蒸汽锅炉、水管锅炉、火管锅炉、贯流式蒸汽发生器、电蒸汽发生器、余热蒸汽发生器、小型蒸汽发生器、锅炉汽包、集箱、受热面管束、炉胆、烟管、省煤器、过热器、蒸发器、锅炉钢架或本体配套金属部件等制造活动。若企业主要制造燃烧器、泵阀、仪表、控制柜、锅炉安装工程或运行服务，应按其主导活动另行识别。

蒸汽发生器与集中供暖热水锅炉的根本差异在于输出介质和工作过程。集中供暖热水锅炉以热水供暖为主，不以产生可供工艺、动力、灭菌、烘干或其他用途的蒸汽为主；本小类产品则以蒸汽产出为核心，涉及水汽分离、蒸汽品质、额定蒸发量、蒸汽压力、给水处理、排污、汽包水位、过热温度和安全附件配置等对象。

本小类产品通常具有较强的特种设备属性或监管边界属性。具体是否需要制造许可、监督检验、型式试验、设计文件鉴定、材料追溯、焊接工艺评定、焊接人员资格、无损检测、耐压试验和出厂资料，应由技术管理部门结合产品结构、压力、容积、介质、热功率和现行监管规则核准。本卡不展开具体组织适用性清单。

B3 关键技术概念说明

蒸汽发生器制造的核心不是把金属做成容器，而是把水、热源、受热面、汽水流程和安全保护组织成能够持续产生蒸汽的设备。水在给水系统进入设备后，经过省煤、蒸发、汽水分离和必要的过热过程，最终以规定压力、温度和干度的蒸汽输出。任何一个环节的结构、材料或连接状态变化，都可能改变设备的运行基础。

受压边界是理解本小类的首要概念。锅筒、集箱、炉胆、烟管、水冷壁、管束、接管、法兰和封头共同构成承受压力的金属边界。受压部件的材料、壁厚、焊缝、热处理、无损检测和水压试验，是蒸汽发生器区别于普通金属制品的重要事实。

受热面是蒸汽形成的核心结构。燃料燃烧、电加热或余热介质提供热量，热量通过炉膛、烟道、管壁或加热元件传给水和蒸汽。受热面布置、烟水流动方向、管排间距、清灰或检修通道、热膨胀空间和介质流速，都会影响设备的热工状态。

汽水分离和水位控制是蒸汽设备特有的基础内容。汽包内的汽水分离装置、水位空间、给水入口、排污口和蒸汽出口影响蒸汽品质和运行稳定。贯流式设备虽然没有传统汽包，但对给水量、热输入和出口蒸汽状态的匹配更加敏感。

燃烧、给水、排污和控制保护部件通常作为蒸汽发生器成套交付的一部分。燃烧器、炉排、风机、给水泵、水位控制、压力控制、安全阀、压力表、水位计、排污阀、烟道接口和控制柜的配置，需要与锅炉本体参数和运行方式匹配。制造企业可能不独立生产这些部件，但其装配接口和成套一致性仍属于设备形成过程的一部分。

C2 主要功能、性能维度

本小类产品的主要功能是把水转化为满足规定参数的蒸汽，并通过设备接口稳定输出。其功能维度包括蒸汽产量、蒸汽压力、蒸汽温度、蒸汽干度、给水适应性、热效率、燃料适配、受压密封、运行稳定、排污和清理便利、控制保护配置、运输安装适配和检修维护条件。

常见客观性能维度包括：额定蒸发量、额定蒸汽压力、额定蒸汽温度、给水温度、热效率、燃料消耗量、烟气温度、烟气阻力、锅炉水容量、水位空间、排污量、受压部件壁厚、材料牌号、焊缝状态、无损检测状态、水压试验压力和保压时间、安全阀整定范围、压力表量程、水位计配置、控制保护接口、外形尺寸、运输单元尺寸、保温层厚度和外护状态。

不同产品类型之间差异明显。火管锅炉通常结构紧凑，制造重心在锅壳、炉胆、烟管、管板和焊接胀接状态；水管锅炉重心在汽包、集箱、管排、膜式壁和受热面布置；贯流式蒸汽发生器重心在给水流量、加热强度和出口蒸汽状态匹配；余热锅炉重心在烟气侧条件、管束布置、积灰磨损和热膨胀处理。

D. 过程与技术

D1 主要工艺/过程流程

D1.1 火管或锅壳式蒸汽锅炉典型制造流程

`mermaid flowchart LR A["设计文件/蒸汽参数"] --> B["材料复核与下料"] B --> C["锅壳、炉胆、管板成形"] C --> D["坡口制备和组对"] D --> E["焊接、胀接或管端连接"] E --> F["无损检测和尺寸检查"] F --> G["水压试验"] G --> H["燃烧器、烟箱、保温和外护装配"] H --> I["出厂项目确认"] I --> J["标识、包装、发运"] `

火管或锅壳式蒸汽锅炉通常以锅壳、炉胆、烟管、管板、烟箱和燃烧器接口为核心。材料准备阶段需确认钢板、钢管、封头、法兰、焊材和配套件的规格与技术文件一致。板材经卷制、校圆、开孔和坡口制备后，与炉胆、管板、烟管进行组对连接。

焊接和管端连接是该类设备的主要制造环节。锅壳纵环缝、炉胆焊缝、管板连接、烟管与管板连接、接管角焊缝和人孔法兰等部位共同形成受压和烟气边界。制造过程中通常需要进行尺寸检查、焊缝外观检查、无损检测、水压试验、烟箱装配、燃烧器接口确认、保温外护和铭牌标识。

D1.2 水管蒸汽锅炉和受热面模块典型制造流程

`mermaid flowchart LR A["汽包/集箱/管排设计参数"] --> B["板材、管材、锻件复核"] B --> C["汽包和集箱加工"] C --> D["管子弯制、坡口、通球"] D --> E["管排、膜式壁或蛇形管组焊"] E --> F["焊缝检测和热处理"] F --> G["水压或部件试验"] G --> H["模块预装、编号和防护"] `

水管蒸汽锅炉以汽包、集箱、水冷壁、对流管束、省煤器、过热器和连接管为核心。管材加工包括切割、弯管、坡口、通球、管端清理和编号。汽包和集箱制造包括筒体成形、封头装配、接管开孔、焊接、热处理、无损检测和水压试验。

受热面模块通常由多根管子、鳍片、集箱和定位件组成。管排间距、焊接变形、通球状态、管内清洁、热膨胀空间和运输支撑都需要在制造过程中形成稳定状态。大型设备可能采取部件预制、工厂试拼、编号发运和现场组装接口管理。

D1.3 余热蒸汽发生器和贯流设备典型制造流程

`mermaid flowchart LR A["烟气/给水/蒸汽参数"] --> B["热工和结构参数转换"] B --> C["受热面管束加工"] C --> D["壳体、烟道和框架制造"] D --> E["管束与集箱装配"] E --> F["水压、气密和尺寸检查"] F --> G["保温、外护和仪控接口装配"] G --> H["分段包装或整体发运"] `

余热蒸汽发生器的输入条件通常来自上游烟气或工艺余热，烟气温度、流量、含尘状态、腐蚀性成分和空间布置会影响管束材料、换热面积、清灰方式和壳体结构。贯流式设备则更强调给水量与热输入的快速匹配，受热面内水汽相变过程连续发生，制造上对管路通畅、加热均匀、控制接口和出汽稳定性较为敏感。

E. 产业链与边界

E1 上游供应

本小类上游主要包括锅炉钢板、锅炉管、合金管、不锈钢材料、封头、锻件、铸件、焊材、无损检测资源、燃烧器、风机、给水泵、阀门、仪表、控制部件、耐火材料、保温材料、防腐涂料和包装运输资源。材料和部件规格直接决定受压边界、热工状态、接口匹配和出厂资料。

上游供应具有较强的专门化特征。锅炉管的牌号、壁厚、弯曲性能、通球状态和表面状态会传递到受热面制造；焊材批次和焊接工艺匹配会传递到焊缝状态；燃烧器、风机、给水和控制部件的型号参数会传递到整机运行接口。

E2 下游应用/客户

下游主要包括食品加工、饮料、纺织印染、造纸、化工、医药、橡胶塑料、木材加工、建材、洗涤、灭菌、工业园区公用工程、热电联产、余热利用、医院消毒供应、学校和公共设施蒸汽供应等场景。蒸汽可用于加热、蒸煮、灭菌、干燥、反应伴热、清洗、驱动、加湿或工艺介质。

下游需求通常以蒸汽量、压力、温度、蒸汽品质、负荷波动、燃料条件、给水条件、安装空间、排烟条件、控制接口、运行维护方式和交付周期体现。不同用户行业对蒸汽参数和设备布置差异明显，因此本小类具有项目化、参数化和成套接口化特征。

E3 本小类在产业链中的位置

本小类位于金属材料、锅炉部件、燃烧和控制部件供应之后，工业用汽、公用工程、余热利用和工艺生产之前。它的产业链价值在于把金属受压部件、受热面、燃烧或加热条件、汽水流程和安全附件整合为可产生蒸汽的设备或部件。

本小类与金属容器、供暖热水锅炉、换热器和工业设备均有交叉，但其中心是蒸汽发生。无论设备形式是锅壳式、水管式、贯流式还是余热式，只要主导输出为蒸汽，且制造对象是蒸汽发生设备或其核心受压热工部件，就应优先从本小类事实框架理解。

委外/外包环节行业常见原因边界提示

F. 适用法规与技术标准

F1 行业准入/资质/许可要求

蒸汽发生器和蒸汽锅炉通常处在特种设备或承压热工设备监管边界内。是否涉及制造许可、设计文件鉴定、监督检验、型式试验、材料追溯、焊接工艺评定、焊接人员资格、无损检测、热处理、水压试验、出厂资料和铭牌标识，取决于产品压力、容积、介质、温度、蒸发量、结构类型和销售使用区域。

电蒸汽发生器、贯流式设备、小型蒸汽发生器、余热蒸汽发生器和大型工业锅炉之间监管边界可能不同。燃料燃烧设备还可能客观涉及燃料适配、烟气参数、燃烧保护、排烟接口和能效类别；余热设备可能涉及上游工艺烟气条件和换热结构适配。本卡只记录这些门槛类别和检索方向，不展开具体组织适用性清单。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类属于复杂度较高的受压热工设备制造活动。普通金属加工能力不足以完整覆盖本小类，企业通常需要理解锅炉原理、承压边界、材料追溯、焊接工艺、无损检测、水压试验、热处理、燃烧或加热接口、控制保护和出厂资料。产品容量、压力、热源和结构不同，制造资源和技术文件深度差异较大。

自动化水平随产品类型差异明显。小型电蒸汽发生器和快装锅炉可能以标准化壳体、成套装配和电控配置为主；水管锅炉和大型余热锅炉则需要管排自动焊、膜式壁焊接、大型卷制、起重翻转、无损检测、局部热处理和分段预制。即便具备自动化设备，组对、焊接顺序、变形控制、检测判读、试压观察和文件追溯仍高度依赖专业经验。

本小类的行业本底还表现为监管边界多、技术文件多、外部配套多和交付边界复杂。一个蒸汽发生设备往往同时包含本体、受压部件、燃烧或加热部件、给水部件、安全附件、控制保护、保温外护、运输安装接口和出厂资料，任何部分的接口失配都可能引起后续装配或运行状态异常。

H3 客观存在的易出问题环节/技术敏感点

敏感点客观影响链
蒸汽参数和热源条件转换不准确蒸发量、压力、温度、燃料或烟气参数偏差 → 受热面和接口配置偏移 → 产汽能力、热工状态和装配接口波动。
受压材料牌号或壁厚不一致材料输入偏差 → 焊接、成形和承压状态变化 → 受压边界状态不稳定。
筒体卷制和开孔尺寸偏差圆度、错边、开孔坐标或坡口状态偏差 → 组对焊接和接管装配困难 → 焊缝和接口状态波动。
管子弯制后通畅性不足弯曲减薄、椭圆度或内壁杂物异常 → 管内流动阻力和局部状态改变 → 受热面运行状态波动。
焊接热输入和顺序控制不稳定坡口、间隙、热输入或焊接顺序偏差 → 焊缝缺陷、变形或残余应力增加 → 检测、热处理和试压状态受扰动。
无损检测范围或方法选择不匹配检测方法、比例或灵敏度与焊缝特征不匹配 → 缺陷识别信息不足 → 返修和复检判断失准。
水压试验排气或保压条件不稳定排气不足、压力波动、水温或保压时间偏差 → 微漏、变形或异常声响不易被识别。
汽包内部件或水位接口装配偏差汽水分离件、水位计接口或给水入口位置异常 → 汽水分离和水位显示条件变化 → 蒸汽品质和运行判断波动。
燃烧器、烟道和炉膛接口不匹配热源接口、风量、烟道阻力或炉膛尺寸偏差 → 燃烧状态、烟气温度和换热条件变化。
安全附件型号或安装位置不一致安全阀、压力表、水位计或控制部件配置偏差 → 压力、水位和温度信息传递路径异常。
保温耐火层施工不连续耐火材料、保温厚度或固定状态异常 → 局部散热、外表面温度或炉膛状态变化。
分段运输和现场接口保护不足受压部件、接管、管排或外护板受力不均 → 变形、碰伤、封口失效或接口污染路径形成。
