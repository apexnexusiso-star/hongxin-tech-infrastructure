  • 文件定位说明

本文件用于环境管理体系认证中 EG33-1 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。本文件围绕 EMS 轴的环境因素、污染源、污染物、废水、废气、固体废物、监测、合规义务和生命周期视角展开，不承担软件和信息技术行业百科说明功能。

本组采用“统一领域包 + 办公研发服务分支 + 机房/数据中心分支 + 客户现场实施分支 + 条件扩展 + 专项边界控制”的使用口径。组内小类可以共享信息技术服务环境管理基础，但自建机房、数据中心、灾备、备用电源、制冷系统、客户现场安装和电子废弃物处置等情形不得被普通办公型软件服务经历替代。

  • 技术领域包构成
小类编码小类名称纳入本包的活动范围主要内部路线特殊边界
33.01.01电脑游戏发行游戏版本发行、渠道交付、补丁、账号和用户服务接口。游戏发行、平台发行、联网游戏发行、持续运营型发行。环境和安全重点不在代码内容本身，而在办公场所、服务器资源、外包云服务、用户服务和可能的机房/运营支撑。
33.01.02其他软件发行现成软件、企业软件、工具软件、云订阅软件、许可和版本发布。传统安装包发行、企业批量授权、云订阅发行、开源商业发行。关注办公和研发支撑、软件交付介质、客户部署支持、外包云服务和电子资料管理。
33.02.01计算机编程活动需求、设计、编码、测试、构建、部署准备和维护性开发。前端、后端、移动端、接口、数据库、脚本、低代码、维护性开发。长期伏案和视屏作业明显；若进入客户现场部署或机房调试，边界发生变化。
33.02.02计算机咨询活动IT 规划、架构设计、选型、可行性研究、项目管理咨询和技术尽调。规划咨询、架构咨询、选型咨询、云咨询、数据咨询。通常以办公、差旅、客户现场访谈和资料处理为主；不等同于现场施工或运维。
33.02.03计算机设备管理活动终端、服务器、网络、账号、配置、补丁、备份、事件、变更和服务台管理。桌面外包、服务器运维、网络运维、驻场管理、远程运维中心。机房、弱电间、夜间值守、备份设备、UPS、电气和搬运边界更突出。
33.02.04其他信息技术及计算机服务活动，特别是系统集成软硬件部署、网络联通、软件安装、数据迁移、灾难恢复、系统联调和验收移交。基础设施集成、应用集成、弱电信息系统集成、云迁移实施、灾难恢复服务。客户现场安装、登高、布线、搬运、临时用电、割接和承包方接口需要专项控制。
33.03.01数据处理、托管及相关活动数据中心、服务器托管、云资源、数据库托管、数据处理、备份、灾备和运行支撑。物理托管、云托管、数据库托管、批量数据处理、备份灾备。数据中心和机房环境可显著改变环境因素和危险源，应作为重点分支。
33.03.02门户网站综合门户、垂直门户、企业门户、搜索导航、内容聚合、用户账号和访问统计。综合门户、行业门户、企业门户、搜索导航、社区内容门户。通常为办公和平台运行；若自建机房、演播采编或线下活动，需按实际边界确认。
  • 分组设立的基本逻辑

本包的共同对象是软件、信息技术、数据处理、托管和门户网站服务过程中的办公资源、电子设备、服务器资源、网络设备、客户数据平台、外包云资源和服务交付活动。EMS 关注的不是软件功能本身，而是服务活动所带来的资源消耗、废弃物产生、设备运行、外包接口和合规义务。

本包共同环境影响链可概括为：服务需求和场所边界识别 → 办公、研发、机房或客户现场资源投入 → 电力、纸张、电子设备、耗材、冷媒、备用电源、包装材料和外包服务使用 → 噪声、生活废水、设备废气、固体废物、危险废物或电子废弃物产生 → 分类收集、暂存、转移、委托处置、运行监测和合规记录 → 节能、减纸、设备复用、外包方控制和源头减量。

八个小类均属于服务型信息技术活动，直接生产性污染通常不强，环境因素具有较高共性；但数据处理托管、服务器机房、系统集成现场和灾难恢复服务可能使环境因素强度明显上升。该差异不否定设组，但应通过分支标注和专项确认控制。

  • 专业小类关系类型与授权后果
关系类型含义授权后果典型控制方式
共同基础关系共享信息技术服务的需求识别、资源配置、运行记录、外包接口和合规义务识别基础。可简化基础专业面谈，但仍应确认目标体系、目标小类和目标路线的实际经历。资料评审、专业面谈、案例判断。
并列分支关系同属本包但服务对象、现场条件、环境因素或危险源不同。应记录实际分支能力，不把同包经历理解为全分支能力。分支标注、限定使用、项目技术支持。
条件扩展关系已具备相邻分支能力，具备扩展基础，但目标分支仍有专门证据要求。完成补充培训、案例评审、专业面谈或见证审核后方可扩展。培训考核、案例评审、见证审核。
专项确认关系涉及数据中心、机房工程、客户现场安装、灾备、备用电源、强内容平台或复杂外包链。项目使用前应专项确认，必要时配置技术专家支持。专项面谈、技术专家评审、项目前确认。
不可直接替代关系相关 IT 经历不足以证明目标环境或职业健康安全能力。不得作为目标能力的单独授权依据。重新评价、补充经历或限定项目类型。
边界受控关系法定许可、客户现场、数据中心、外包处置、内容服务或特殊作业改变使用边界。授权记录应写明边界，项目匹配时按实际活动确认。授权备注、合规类别清单、技术支持。
办公研发型服务之间软件发行、编程、咨询和门户运营通常共享办公、研发、电子资料和外包云服务环境因素。可共享办公型 IT 服务 EMS 基础能力。办公现场、能耗、耗材、电子废弃物和外包方样本追溯。
办公研发到数据中心数据中心增加机房、电力、制冷、UPS、电池、备用电源和灭火系统边界。不得凭普通办公型经历承担复杂数据中心或托管项目。机房案例、能源资源、冷媒、电池和委外处置专项确认。
软件服务到系统集成现场系统集成可能进入客户现场，产生包装、线缆、旧设备、施工废弃物和现场扰民因素。应确认客户现场环境因素识别和承包方控制能力。项目案例、现场记录、废弃物交接和客户边界确认。
  • 本体系共同能力基础
共同能力维度本包共同基础可共享的审核判断不能共享的边界
环境因素识别均需识别办公、研发、服务器、网络设备、耗材、纸张、差旅、外包云服务和客户现场活动的环境因素。能判断组织是否按场所、活动、设备和外包接口识别环境因素。数据中心、备用电源、制冷冷媒、现场施工和电子废弃物处置需单独确认。
资源能源消耗均存在电力、办公耗材、电子设备、网络资源和云资源使用。能追溯资源消耗统计、节约措施和外包服务边界。能源绩效深度评价属于能源管理体系；本文件只作为 EMS 资源消耗因素识别。
废弃物控制均可能产生废纸、包装物、废墨盒硒鼓、废旧电子设备、线缆和电池等固体废物。能判断分类、暂存、交接、回收和委托处置记录。含电池、UPS、电子废弃物和含油或含化学介质设备应专项确认。
污染源和监测常见污染源包括办公设施、打印耗材、服务器噪声、制冷系统、备用电源和客户现场作业。能判断噪声、废气、废水和固体废物控制是否与实际活动匹配。自建机房、柴油备用电源、制冷剂泄漏和大型设备运行需更高粒度。
外包和生命周期云服务、IDC、电子设备回收、保洁、物业、物流、安装承包方均可能影响环境绩效。能判断外包方环境要求、转移记录和生命周期考虑是否被控制。仅使用云服务时，应确认组织对外包服务环境接口的控制深度。
  • 本体系核心控制要求

EMS 审核应围绕“源头识别、分类控制、监测记录、转移处置、合规接口和改进”展开。第一，应核对组织是否按办公场所、研发区域、机房、客户现场、数据处理平台、外包云服务和门户运营边界识别环境因素。第二，应核对电力、纸张、电子设备、耗材、包装物、线缆、电池、制冷剂和备用燃料等投入是否与实际活动相匹配。第三，应核对生活废水、备用电源废气、机房或设备噪声、固体废物、危险废物和电子废弃物是否按类别控制。第四，应核对委外回收、物业、IDC、云服务、安装承包方和废弃物处置方的环境接口。第五，应核对节约资源、电子化交付、设备复用、外包服务选择和异常事件处置的改进证据。

普通软件服务组织可重点抽样办公、研发、电子耗材和外包服务；数据中心和托管组织应增加电力和制冷资源、机房噪声、UPS 电池、备用电源、灭火介质和电子废弃物；系统集成组织应增加客户现场包装物、线缆、旧设备、施工废弃物和承包方环境控制。

  • 分小类或内部路线差异分析
小类/路线与本包共同基础主要差异差异对能力授权的影响控制方式
33.01.01 电脑游戏发行共享办公、研发支撑、服务器外包、用户服务和电子资料环境因素。联网游戏可能依赖高负载服务器、云资源和用户服务外包。可按办公型软件服务授权；自建运营机房需专项确认。发行和运营场所、云服务边界、电子耗材和外包方记录抽样。
33.01.02 其他软件发行共享办公、电子交付、许可资料和客户支持环境因素。企业部署包、实体介质、包装和客户现场支持可能增加废弃物。普通软件发行可共享；实体介质和现场部署需补充确认。交付介质、包装回收、客户现场支持和废弃物记录。
33.02.01 计算机编程共享办公研发、电子设备、纸电消耗和外包云环境因素。持续开发测试可能增加测试服务器、云资源和电子设备更新频率。可作为办公研发型 IT EMS 基础经历。研发场所、测试环境、电子设备和云资源边界抽样。
33.02.02 计算机咨询共享办公、差旅、纸张、电子资料和客户现场访谈因素。项目差旅和客户现场活动更突出。可共享办公型能力；现场驻场项目需确认客户边界。差旅、客户现场、电子化交付和资料管理抽样。
33.02.03 计算机设备管理共享电子设备、机房、网络设备、耗材和外包接口。旧设备、备件、电池、备份介质、机房噪声和客户设备处置更突出。应标注设备管理分支。CMDB、备件、废旧设备、UPS 电池和服务现场抽样。
33.02.04 系统集成及其他 IT 服务共享设备、包装、线缆、客户现场和承包方控制基础。现场安装、布线、旧设备替换、包装物和施工废弃物突出。应标注系统集成分支；弱电施工或大规模改造专项确认。项目现场、包装物、旧设备、线缆和承包方交接记录抽样。
33.03.01 数据处理托管共享平台服务、设备运行、外包接口和服务记录基础。数据中心、电力、制冷、备用电源、电池、灭火系统和电子废弃物突出。属于本包环境重点分支，应专项确认。机房、资源、制冷、备用电源、电池和委外处置链追溯。
33.03.02 门户网站共享办公运营、服务器资源、内容平台和访问服务环境因素。流量增长可能增加云资源、CDN 和数据服务外包环境接口。可按平台运营分支授权；自建机房或线下活动需确认。CMS/平台运营场所、云服务、外包方和电子耗材抽样。
  • 分组合理性论证结论

EG33-1 可以作为 EMS 技术领域包设立。八个小类均属于软件和信息技术服务活动，直接环境影响通常围绕办公研发、电子设备、服务器资源、耗材、废弃物、外包服务和客户现场活动展开，环境因素识别、分类控制、转移处置、监测记录和外包接口具有共同基础。

本组不能按普通办公服务一概处理。数据中心、托管、灾备、备用电源、制冷、UPS 电池、客户现场安装和电子废弃物处置会显著改变污染源和环境影响链。机构应采用“统一领域包 + 分支能力标注 + 条件扩展 + 专项边界控制”的使用口径。

  • 审核关键要点与抽样方法
抽样场景现场必看记录必查纵向追溯路径追问方向
办公研发场所办公区、研发区、打印区、电子设备存放点、生活垃圾点。环境因素清单、耗材台账、废弃物分类、节能记录、物业接口。活动识别 → 资源消耗 → 废弃物分类 → 交接处置 → 改进记录。废纸、硒鼓、电子设备和生活废水如何分类控制。
软件发行或门户运营发布/运营场所、用户服务区、云服务接口、电子资料管理。云服务合同、平台运行记录、电子交付资料、用户服务记录。服务需求 → 平台资源 → 外包接口 → 运行记录 → 环境因素复核。外包云服务和电子化交付如何纳入生命周期考虑。
数据中心或机房机柜、电力、制冷、UPS、电池间、备用电源、灭火系统、噪声源。设备清单、能源资源统计、冷媒维护、电池更换、备用电源维护、废弃物交接。资源投入 → 设备运行 → 污染源/废物流 → 监测或检查 → 委外处置。废气、噪声、电池、冷媒和电子废弃物如何控制。
系统集成客户现场安装区域、包装物、线缆、旧设备、临时材料、承包方作业区。项目计划、现场交接、废弃物清单、旧设备处理、承包方要求。项目输入 → 现场实施 → 废弃物产生 → 分类转移 → 客户确认。客户现场环境边界和废弃物责任如何划分。
电子废弃物处置暂存区域、标签、包装、防混放措施。设备报废审批、资产台账、回收合同、转移和接收记录。资产报废 → 分类暂存 → 委托回收 → 接收证明 → 台账关闭。含电池、存储介质和电子元件的环境接口如何控制。
  • 能力扩展与条件授权

  • 培训、考核与作业指导书需求

本组应建立 IT 服务 EMS 专业培训，内容包括办公和研发环境因素识别、电子设备和耗材控制、固体废物和危险废物类别识别、生活废水和设备废气边界、噪声源识别、云服务和 IDC 外包接口、客户现场项目环境控制、电子废弃物和旧设备处置。

考核应采用场景式题目，要求审核员分别完成办公研发场所、数据中心机房、系统集成现场、电子废弃物处置和外包云服务接口的环境影响链追溯。作业指导书应提供办公型 IT 服务、机房托管、客户现场集成和电子废弃物处置四类抽样路径。

  • 常见合规义务类别与标准适用提示

本组可能涉及环境保护、固体废物、危险废物、电子废弃物回收、噪声、废水、废气、节约资源、制冷剂管理、备用电源、消防灭火介质、物业管理、外包处置、数据中心运行和客户现场施工相关类别。文件不列具体标准编号和年份；适用性应使用机构受控的现行有效清单、客户合同、场所边界和项目活动确认。

上述类别用于识别外部要求如何转化为环境因素控制、运行控制、监测检查、委外处置和改进措施，不替代政府许可、排污许可核发、环境监测法定报告、行政执法或第三方处置合规判断。

  • 分组使用限制和法定边界

本分组仅用于 EMS 认证中的技术领域包论证和审核员专业能力控制。管理体系审核不替代政府许可、排污许可、环境影响评价、法定监测、危险废物行政管理、电子废弃物法定处置、消防或特种设备监管、行政执法或客户专门验收。

当项目涉及自建数据中心、大型机房、备用柴油发电、UPS 电池系统、冷媒系统、电子废弃物集中处置、客户现场弱电施工、跨地域云服务或外包处置链复杂情形时，应在项目匹配阶段追加专项确认或技术专家支持。

  • 分组结论与使用口径

EG33-1 可作为环境管理体系软件、信息技术、数据处理及门户网站技术领域包使用。授权时应记录审核员在办公研发型 IT 服务、软件发行、编程咨询、设备管理、系统集成现场、数据中心托管、门户运营和电子废弃物处置等分支上的实际能力。组内扩展应通过培训、案例评审、专业面谈、见证审核或技术支持控制。

文件维护触发条件包括：数据中心运行方式、云服务外包、电子废弃物处置、备用电源和制冷系统、客户现场集成模式、环境合规类别或上层分组使用中出现能力匹配争议。
