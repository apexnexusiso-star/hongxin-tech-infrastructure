  • 文件定位说明

本文件用于环境管理体系认证中 EG29-3 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦燃料批发与汽车燃料零售经营在环境管理体系轴下的燃料储运、加注、挥发性污染物、含油废物、泄漏防控、废水废气和环境应急，不承担行业百科说明功能；基础行业事实由对应专业小类基础卡承载。

本组采用“专项环境领域 + 条件授权 + 场景限定”的使用口径。组内小类可以共享本体系轴下的基础判断方法，但不得把某一分支经历等同于另一分支完整能力。对污染源、危险源、外部合规接口、客户现场或外包链条发生实质变化的情形，应在授权和项目匹配阶段追加分支确认。

  • 分组设立的基本逻辑

本组在本体系轴下的共同对象是以固体、液体、气体燃料及汽车燃料的批发、储运、加注和相关产品零售为主的燃料经营活动。分组判断的核心不是小类名称是否相近，而是环境因素、污染源、污染物、废水、废气、固体废物、监测、外包处置和合规义务的形成机理、控制路径和审核证据是否足够接近。

本组可概括的共同证据链为：客户或车辆需求 -> 燃料接收 -> 储罐或容器储存 -> 计量装卸或加注 -> 油气和泄漏控制 -> 含油废物与废水管理 -> 应急处置和监测改进。该链条决定了审核员可以共用的专业能力基础，也决定了现场抽样时应从源头识别、过程控制、记录追溯、异常处置和改进闭环几个方向建立证据。

批发和零售在储存规模、装卸方式、车辆流线、油气回收、顾客接触和应急组织上不同；固体、液体、气体燃料的污染物也不同。这些差异不否定设组，但要求本组按条件授权和边界受控方式使用。

边界受控关系实际业务包含仓储、运输、维修、拆解、加注、清洗、冷链或客户现场服务时，环境因素边界发生变化。授权和项目匹配应按实际活动边界使用。授权备注、现场边界确认、外包链条核验。
燃料专项关系燃料批发和燃料零售共享泄漏、挥发、含油废物和应急逻辑，但介质和设施不同。应按固体、液体、气体燃料及加注场景限定授权。储罐区、加注区、装卸区、应急物资和油气回收证据确认。
  • 共同过程与专业机制分析

燃料经营的环境管理核心是源头封闭、过程防泄漏、污染物收集、异常应急和外部合规接口。液体燃料关注挥发性有机物、油气回收、含油废水、油泥、废吸附材料和泄漏入土入水；气体燃料关注泄漏、放散、通风和应急；固体燃料关注扬尘、雨水径流和堆场管理。汽车燃料零售还叠加车辆进出、加注枪、油气回收、地面冲洗和顾客区域管理。

过程环节环境因素和污染源形成机制审核关注的证据
燃料接收槽车、容器、管线、装卸接口可能发生跑冒滴漏、油气挥发和扬尘。接收记录、装卸检查、计量记录、异常记录。
储存和加注储罐、瓶组、堆场、加注设备、油气回收和地面防渗构成核心污染源。设备点检、防渗检查、油气回收检查、巡检记录。
废物和废水含油废水、油泥、废吸附材料、废包装、清罐废物和泄漏污染物需受控。废物台账、暂存点、外包处置、事故收集记录。
应急和监测泄漏、火灾、暴雨径流、异常气味和设备故障需要应急响应与监测。应急预案、演练、物资点检、监测或巡检记录。
  • 本体系核心控制要求

第一，应从燃料介质和设施形态确定环境因素。液体燃料、气体燃料和固体燃料不能简单按同一污染源处理；审核员应确认组织实际经营的燃料种类、储罐或容器、装卸方式、加注设备、防渗区域和雨污水去向。

第二，应追溯泄漏和挥发控制证据。加油加气、油品批发、燃料储存和配送的关键环境证据包括管线阀门、计量设备、油气回收、围堰或防渗、吸附材料、泄漏检查、地面清洁和异常报告。现场证据应与巡检记录相互印证。

第三，应确认含油废物和清罐、检维修废物的去向。燃料经营的固体废物不仅是包装物，还包括油泥、废吸附棉、废滤芯、废油桶、含油抹布和污染土壤或砂土等异常废物。审核员应核对暂存、标识、防雨防渗和外包处置。

第四，应检查外包运输和客户交付边界。燃料批发组织可能不自有车辆和仓库，但仍可能通过合同、订单、承运方、储运方和客户交付要求影响环境控制。EMS 审核应评价其外包控制是否覆盖泄漏、装卸、应急和异常反馈。

  • 分组结论

EG29-3 组内小类均围绕燃料经营形成环境因素，污染源集中在储存、装卸、加注、挥发、含油废水、含油固体废物、泄漏污染和应急处置。批发与零售、汽车用与非汽车用、固体与液体或气体燃料之间存在明显差异，但其污染控制机理和审核证据链高度相关，因此可以设为同一专项环境技术领域包，并按介质和设施场景实施条件授权。

因此，EG29-3 可以作为环境管理体系技术领域包使用，使用方式为“专项环境领域 + 条件授权 + 场景限定”。审核员授权、项目匹配和能力扩展均应体现分支差异，不得把同包经历理解为跨全部小类的充分证明。

  • 审核员共同能力评价与条件授权

本章用于界定本技术领域包可共享的共同能力，以及不同分支在授权、项目匹配和能力扩展时需要追加确认的内容。

能力要素评价内容可接受证据授权控制
环境因素识别识别服务场所、仓储、运输、维修、燃料、化学品、废弃物和外包链条形成的环境因素。环境因素清单、现场走查记录、外包合同、废物转移或处置记录。按分支标注；特殊商品需专项确认。
污染源与污染物判断判断废水、废气、固体废物、危险废物、油气、异味、粉尘、制冷剂和化学品泄漏来源。现场照片、台账、监测或检查记录、应急物资、处置凭证。燃料、化工、维修和冷链类项目需目标经历或专家支持。
合规义务转化将许可、产品经营、废物处置、排放、运输和客户要求转化为组织内部控制。合规义务清单、合同评审、供应商评价、外包方资质和内审记录。不替代行政许可判断，仅评价管理体系控制。
运行控制与应急检查泄漏预防、废物分类、外包处置、清洁消毒、冷链、维修废物和异常处置。运行规程、点检记录、培训记录、应急演练、异常整改记录。按实际活动抽样，不能用纯办公经历替代现场经营。
绩效与改进评价监测、巡检、废物去向、能资源消耗和投诉事件的趋势与改进。目标指标、统计报表、纠正措施、管理评审输入。证据应能追溯到具体场所或服务样本。

能力扩展应采用“基础经历确认、目标分支差异培训、案例评审或专业面谈、必要时见证审核、授权记录标注”的路径。对燃料、危险化学品、车辆维修、个人家庭用品维修、冷链、废旧材料和含客户现场复杂接口的项目，应在项目匹配阶段再次确认适用边界。

  • 审核关键要点与抽样路径

本组抽样必须进入燃料接收、储存、加注或交付相关现场；若组织为贸易型或外包储运型，也应追溯外包方和合同接口，不宜停留在销售合同层面。

  • 培训、考核与作业指导书需求

培训应覆盖燃料介质特征、储罐和装卸环境因素、挥发性污染物、含油废水和废物、油气回收、防渗、防泄漏、应急处置和外包储运控制。对未接触过燃料经营的审核员，应通过案例评审和现场见证确认专项能力。

考核宜采用场景题、案例追溯题和边界判断题，要求审核员能够从一个真实或模拟项目出发，说明本体系轴下的识别、评价、控制、记录、异常处置和改进之间的证据关系。作业指导书应提供分支化抽样路径、记录清单、访谈问题和授权边界提示。

  • 常见合规义务类别与标准适用提示

常见合规义务类别包括燃料经营许可和储运要求、危险化学品经营边界、油气回收和废气控制、含油废水和雨污分流、危险废物管理、消防和环境应急、道路运输和外包储运方控制、客户和所在地监管要求。本文件不列入具体标准编号和年份；适用性应使用机构受控的有效清单、客户合同、服务目录、项目范围和所在地监管要求确认。上述类别用于识别外部要求如何转化为管理体系控制，不替代政府许可、法定检验、行政执法或客户专项验收。

  • 使用限制和法定边界

本组不覆盖炼油、燃料生产、化工生产、危险废物处置、车辆维修或油气管道运营。若组织实际开展生产、清罐检维修、报废油品处理或危险废物经营，应另行确认对应技术领域能力。

管理体系审核仅用于评价组织是否在其服务范围内建立并实施相应管理控制，不替代行政许可、法定检验、行政执法、政府监管、司法判断或强制性专项评价。涉及受监管资质、特种商品、危险化学品、燃料、药品、医疗器械、个人信息、资金信用、道路运输、客户现场和外包服务时，应在项目匹配阶段确认审核员分支能力和必要的技术支持。
