  • 文件定位说明

本文件用于质量管理体系认证中 QG29-4 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦农业原料、食品饮料、家庭用品、信息通信设备、机械设备、工业品及非专营批发贸易在 QMS 轴下的质量形成链、客户要求转化、关键质量特性、检验放行、记录追溯、投诉反馈和改进闭环。本文件不承担行业百科说明功能，基础行业事实由对应专业小类基础卡承载。

本组采用“统一批发贸易领域包 + 商品族分支标注 + 冷链/危化/药品/燃料/废旧材料专项确认 + 条件扩展”的使用口径。组内小类可以共享通用商业服务质量管理判断方法，但不得把某一商品、服务或渠道分支经历等同于另一分支完整能力；对特殊商品、复杂服务、法定接口或高价值交付，应追加分支确认。

  • 分组设立的基本逻辑

本包在 QMS 轴下的共同对象是面向商业客户的批量采购、库存、分拣、仓储、配送、结算和售后反馈控制。质量管理体系审核关注的核心不是商品名称或服务名称是否完全相同，而是客户需求如何被识别和转化，商品或服务对象如何受控，交易、工单或订单过程如何记录，交付前后如何检验或确认，客户反馈如何形成闭环。

本包可概括的共同质量形成链为：客户批量需求或采购计划 -> 供应商和商品资料确认 -> 采购入库 -> 仓储防护和库存管理 -> 分拣配货 -> 配送交付 -> 签收结算 -> 客户投诉、退换和供应商反馈闭环。该链条决定了本包共享的专业能力基础，即审核员应能够围绕客户要求、商品或服务对象、过程记录、输出验证、交付确认和反馈闭环建立审核证据链。

组内差异主要表现为商品族的保存条件、规格指标、批量交付方式和外部接口不同：食品生鲜强调冷链和效期，机械设备强调选型和技术资料，燃料化工强调属性和储运，药品烟草具有外部要求类别，废旧材料强调分拣杂质和再生用途。这些差异不否定设组，但要求本包不能按无差别能力包使用，应通过分支标注、专项确认、条件扩展和抽样控制加以处理。

  • 本体系核心控制要求

本组所称关键质量特性，是指商品或服务输出中影响客户可接受性的适配性、真实性、完整性、及时性、一致性、可追溯性、功能状态、数量准确性和售后响应。商业服务场景中的检验和放行，通常表现为订单复核、商品验收、库存盘点、称量计量、温度或效期检查、工单复核、交付签收、客户确认、主管抽查或质检记录。审核员应把这些复核和确认活动作为服务结果进入客户使用前的质量控制证据。

第一，应确认批发客户需求和订单评审。批发贸易通常涉及批量商品、商业客户、多个仓库和多批次交付。审核员应追溯订单中规格、数量、交期、包装、运输、结算、温度、效期或技术资料要求如何进入采购、库存和配送安排。

第二，应评价供应商和商品资料控制。食品饮料、农牧原料、药品、烟草、燃料、化工品、金属矿物、机械设备、家用商品和废旧材料的资料差异明显，但均需确保商品身份、规格、批次、等级和适用要求被识别并保持一致。

第三，应追溯仓储防护和库存准确性。审核样本应覆盖入库验收、库存记录、库位、盘点、分区、温湿度或普通防护、先进先出、临期或异常品处理。冷链、活体动物、花卉、药品、燃料、危化、废旧材料和大件机械应按分支选择样本。

第四，应核查分拣配货、配送交付和放行。批发质量问题常发生在错发、漏发、混批、破损、短装、温控失效、型号不匹配或技术资料缺失。放行证据应包含订单复核、拣配复核、装车交接、运输条件和客户签收。

第五，应评价客户投诉、退换和供应商反馈闭环。批发组织应能沿一个投诉样本追溯到采购批次、入库验收、仓储、拣配、配送、客户签收和供应商处理。对重复错发、温控异常、批次不清和供应商质量问题，应有原因分析和防止再发生措施。

  • 分组合理性论证结论

本组可以设立的理由在于，组内活动均以商业客户批量采购和批发交付为共同质量形成对象，均需要控制客户订单、供应商、商品资料、入库验收、仓储防护、库存准确、分拣配送、客户签收和投诉闭环。商品族差异显著，但可通过分支能力标注、特殊商品专项确认和抽样路径控制。

因此，QG29-4 可以作为质量管理体系技术领域包使用，但其使用方式应为“统一批发贸易领域包 + 商品族分支标注 + 冷链/危化/药品/燃料/废旧材料专项确认 + 条件扩展”。审核员授权、项目匹配和能力扩展均应体现分支差异，不得把同包经历理解为跨全部小类的充分证明。

  • 培训、考核与作业指导书需求

本组应建立批发贸易 QMS 培训，内容包括批发订单评审、供应商评价、采购和入库验收、库存和仓储防护、批次效期、温控、计量、分拣配货、配送签收、退换索赔、商品族差异、冷链、药品烟草、燃料化工、机械设备和废旧材料边界。

考核宜采用场景式题目和案例追溯题，要求审核员能够从一个真实或模拟订单、交易、工单或交付样本出发，说明客户要求识别、资源配置、关键过程控制、输出复核、交付验收、投诉反馈和纠正措施之间的证据关系。作业指导书宜提供分支化抽样路径、典型记录清单、访谈问题库和授权边界提示。

  • 常见合规义务类别与标准适用提示

本组可能涉及食品经营、药品经营、烟草专卖、危险化学品经营、燃料和成品油、计量、仓储运输、消费者权益、产品标识、广告宣传、废旧物资回收、动物检疫资料类别、木材建材、机械设备、电子通信设备、个人信息和客户行业专项要求等类别。文件不列具体标准编号和年份；适用性应使用机构受控的有效清单、客户合同、服务目录、项目范围和所在地监管要求确认。上述类别用于识别外部要求如何转化为客户要求、商品控制、服务过程、记录保存、客户沟通和输出复核，不替代政府许可、行政执法或客户专项验收。

  • 分组使用限制和法定边界

本组的 QMS 分组不替代食品药品监管、烟草专卖监管、危险化学品经营监管、燃料经营监管、计量检定、废旧物资行政管理、产品准入、动物检疫、行政执法或客户专项验收。涉及冷链、活体动物、药品、烟草、燃料、含危险化学品化工、废旧材料和复杂机械设备时，应确认对应分支能力。

管理体系审核仅用于评价组织是否在其服务范围内建立并实施质量管理控制，不替代行政许可、法定检验、行政执法、政府监管、司法判断、强制检验、产品准入、计量检定、食品药品监管、烟草专卖监管、危险化学品经营监管、特种商品管理或其他法定结论。涉及受监管资质、特殊商品、个人信息、资金、现场作业和外包服务时，应在项目匹配阶段确认审核员分支能力和必要的技术支持。

  • 分组结论与使用口径

QG29-4 可作为质量管理体系批发贸易技术领域包使用。授权时应记录汽车配件、农牧原料、食品饮料烟草、家庭用品、ICT设备、机械设备、燃料金属化工、建材五金、废旧材料和非专营批发等分支能力。文件维护触发条件包括：批发商品族、仓配模式、冷链、特殊商品外部要求、供应商控制、物流配送或基础卡信息发生实质变化。
