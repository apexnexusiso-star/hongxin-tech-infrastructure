A2 定义与范围界定

本小类是指制造用于连接、固定、定位、夹紧、调节或传递直线运动的紧固件和螺杆机械产品的活动。典型产品包括螺栓、螺钉、螺母、螺柱、垫圈、铆钉、销轴、开口销、卡簧类连接件、木螺钉、自攻螺钉、膨胀螺栓、牙条、丝杆、梯形丝杆、滚珠丝杠相关金属部件和类似产品。

紧固件制造常以冷镦、热镦、冲压、车削、滚丝、搓丝、攻丝、热处理、表面处理和分选包装为主要过程。螺杆机械产品还可能涉及长轴加工、螺纹磨削、校直、表面硬化和配套螺母加工。

本小类不包括单纯线材冷拔、机加工服务、金属丝弹簧链条制造、刃具和工具制造、整套机械传动设备制造、轴承制造、门窗五金成品制造和贸易服务。若企业仅进行表面镀锌或热处理，应按处理涂覆识别。

B3 关键技术概念说明

紧固件的核心是通过螺纹、杆部、头部、支承面或铆接结构实现连接、夹紧和定位。材料强度、螺纹几何、热处理和表面摩擦共同影响紧固状态。

批量一致性是紧固件制造的基础。紧固件数量大、规格多、外观相似，混料、错标、螺纹不通、强度等级错误或镀层异常都会造成下游装配状态变化。

高强度紧固件需要特别理解材料、热处理、表面处理和氢脆之间的关系。酸洗、电镀、热处理和烘烤条件可能改变延迟断裂路径。

C4 典型产品族专业差异补充

紧固件和螺杆类产品的底层差异主要由“螺纹形成方式、强度来源、表面状态和装配用途”共同决定。普通冷镦螺钉、热处理高强度螺栓、攻丝螺母、铆钉和传动丝杆虽然都属于连接或传力件，但过程资源和检测组合差异明显。

产品族过程差异对底层识别有价值的专业信息
标准螺栓和螺钉线材改制、冷镦、搓丝、热处理或表面处理、分选和包装构成主线。头部、杆部、螺纹、强度等级和标识是识别抓手。
高强度螺栓材料、热处理、脱碳、表面处理、摩擦或扭矩相关状态更突出。硬度、拉伸、保证载荷和延迟断裂相关项目需与普通件区分。
螺母和垫圈冷镦、热镦、攻丝、冲压、热处理和表面处理路线不同。内螺纹通止、支承面、垫圈厚度和防松结构是主要信息。
自攻、自钻和电子微型螺钉牙型、尖端、钻尾、微小尺寸和高速分选突出。尖端状态、螺纹牙型、混料和表面毛刺需要单独描述。
铆钉、销和开口销冷镦、拉拔、切断、开槽、冲压或抽芯装配形成。铆接变形部、销径、剪切状态和装配方向是识别重点。
丝杆、牙条和梯形丝杆棒材校直、滚丝、车削、磨削、调质和端部加工占比高。螺距累计、直线度、传动面粗糙度和端部接口需要描述。
汽车、风电、轨道和钢结构紧固件专项用途文件、材料炉批、热处理批次和表面处理批次关联更强。用途、规格、强度、表面状态和追溯链条需要一并识别。

D. 过程与技术

D1 主要工艺/过程流程

`mermaid flowchart LR A["线材/棒材/图纸"] --> B["材料确认和下料"] B --> C["冷镦、热镦、冲压或车削"] C --> D["搓丝、滚丝、攻丝或螺纹磨削"] D --> E["热处理和校直"] E --> F["表面处理和防锈"] F --> G["尺寸、机械性能和外观分选"] G --> H["包装、标识、交付"] `

螺栓螺钉常采用线材酸洗磷化、拉拔、冷镦成头、搓丝或滚丝、热处理、表面处理和分选包装。螺母通常经冷镦或热镦、攻丝、热处理和表面处理。丝杆和螺杆产品可能采用棒材车削、滚丝、磨削、校直和表面处理。

D1.1 冷镦搓丝和螺纹形成过程深度

冷镦紧固件的专业基础是线材、模具和润滑之间的匹配。线材通常需经过酸洗、磷化、皂化、拉拔或退火，使其具备合适的表面和塑性。冷镦过程中，头部成形可能经历切料、一冲、二冲、多工位镦制和整形，模具中的金属流动决定头部充满、杆部同轴、支承面和内六角或十字槽状态。材料硬度偏高、润滑不足或模具圆角不当，会造成头部裂纹、折叠、偏心和模具崩裂。

螺纹形成常通过搓丝或滚丝完成。搓丝板或滚丝轮不是切削螺纹，而是使金属表层塑性流动形成牙型，因此坯径、材料硬度、滚压力和模具磨损直接影响通止、牙顶、牙底和表面压伤。内螺纹螺母则需控制底孔、攻丝刀具、润滑、排屑和通止规检查，避免乱牙、烂牙和螺纹不通。

D1.2 热处理、表面处理和高强度紧固件

普通低强度紧固件可能不需要复杂热处理，高强度螺栓、汽车紧固件和建筑钢结构连接副则通常需要淬火回火形成强度等级。热处理后的硬度、脱碳层、组织、变形和表面氧化状态会影响保证载荷、楔负载和扭矩状态。若强度等级高而表面存在划伤、滚丝折叠或氢进入路径，后续延迟断裂敏感性会升高。

表面处理包括电镀锌、热浸镀锌、发黑、磷化、机械镀、锌铝涂层和防锈油等。不同表面处理会改变摩擦系数、耐腐蚀性、螺纹配合和装配扭矩。高强度钢酸洗或电镀后常需关注烘烤释放氢的类别要求，具体适用范围应在标准核验中确认。

D1.3 批量分选和包装追溯

紧固件产品规格多、数量大、外观相似，分选和包装本身就是重要过程。光学分选可识别长度、头型、螺纹、缺槽、混料和表面缺陷，涡流或硬度分选可辅助识别材料或热处理状态。包装标签通常承载规格、强度等级、表面处理、批次、数量和标准信息，错标和混料会直接影响下游装配。

热镦或大规格路线棒材加热、热成形、滚丝、热处理和表面处理。大尺寸成形和热处理变形信息突出。
螺母攻丝路线冷镦或热镦毛坯、攻丝、倒角、热处理和表面处理。内螺纹、支承面和攻丝排屑突出。
冲压垫圈路线板材冲裁、去毛刺、热处理、表面处理和分选。平面度、毛刺和弹性状态是主要信息。
铆钉销类路线冷镦、切断、开槽、抽芯装配或车削。铆接变形端和定位尺寸突出。
丝杆牙条路线棒材校直、滚丝、车削、磨削、端部加工和防锈。螺距累计和直线度比普通短件更突出。
专用紧固件路线材料炉批、专项图纸、表面处理、分选和包装标识。用途文件和追溯链条信息较多。

E. 产业链与边界

E1 上游供应

上游包括钢材线材、棒材、模具、热处理和表面处理材料、包装材料、检测设备。材料批次、线径、硬度、表面和模具状态直接传递到紧固件状态。

E2 下游应用/客户

下游包括机械、汽车、建筑钢结构、电子电器、家具、轨道交通、工程设备、能源设备、门窗和五金流通。

E3 本小类在产业链中的位置

本小类位于金属材料和装配连接使用端之间，是大量制造业实现连接、固定、定位和传动的基础零件环节。

E4 常见委外/外包环节

委外环节常见原因边界提示
热处理炉型和强度等级专业化常作为后段接口。
表面处理镀锌、发黑、涂覆专业化独立处理归 17.10.01。
机械性能检测拉伸、扭矩和氢脆试验资源有限可由外部检测资源完成。
包装分选小件数量大、规格多需保持规格和批次识别。

E5 典型接口资料与实物流转补充

紧固件处在材料供应、热处理、表面处理和装配使用之间。底层记录应体现材料批次、强度来源、表面层和规格防混接口。

接口环节常见资料或实物识别价值
材料输入线材、棒材、板材、牌号、炉批、盘元状态和表面状态。决定冷镦、热处理和螺纹形成基础。
图纸标准输入规格、牙型、强度等级、表面要求、标记和包装要求。决定产品族和检测组合。
热处理接口淬火回火、调质、渗碳、去应力、硬度和脱碳信息。反映强度和组织状态来源。
表面处理接口镀锌、镀镍、发黑、达克罗类涂覆、防锈和去氢。反映防腐、摩擦和延迟断裂相关状态。
分选包装光学分选、涡流、计数、称重、标签和混料隔离。反映多规格小件的防混交付状态。
下游使用汽车、机械、钢结构、轨道、风电、电子和家具装配。反映紧固件用途差异和接口边界。

G. 检验、检测与计量手段

G1 行业常用检测/试验/计量方法

方法类别常用手段适用对象
尺寸检测卡尺、千分尺、影像仪、专用检具长度、头部、杆部、垫圈和螺母。
螺纹检测通止规、螺纹环规、塞规、三针法内外螺纹。
力学性能检测拉力机、保证载荷、楔负载、扭矩测试螺栓、螺钉、螺母和螺杆。
硬度和组织硬度计、金相、脱碳层检查热处理紧固件。
表面检测膜厚、盐雾、外观、氢脆相关试验镀层和高强度产品。
分选检测光学分选、涡流、尺寸分选批量小件和高要求紧固件。

G2 关键检测参数与对应方法

参数/项目常见方法说明
螺纹通止通止规快速确认配合状态。
强度等级拉伸、硬度、保证载荷确认机械性能。
硬度HV/HRC/HB反映热处理状态。
表面镀层膜厚、盐雾反映防腐状态。
氢脆状态延迟断裂或相关试验适用于高强度镀覆产品。
混料光学分选、标识核对适用于多规格批量产品。

G3 典型检测组合与适用对象

紧固件检测一般不是只看螺纹通止，材料、热处理、表面层、力学性能、尺寸分选和包装标识共同决定产品状态。不同产品族应采用不同的客观检测组合。

适用对象常见检测组合识别意义
普通螺栓螺钉头部尺寸、杆径、长度、螺纹通止、外观、镀层和包装规格。反映标准连接件的基本配合状态。
高强度螺栓拉伸、楔负载、保证载荷、硬度、脱碳、表面层和标识。反映高强度连接件的材料和热处理状态。
螺母内螺纹通止、保证载荷、对边尺寸、支承面、攻丝毛刺和镀层。反映内螺纹配合和承载状态。
垫圈和冲压紧固件厚度、平面度、内外径、硬度、毛刺、弹性状态和表面层。反映片状配套件的冲压和防松状态。
自攻自钻螺钉钻尾、牙型、表面硬度、扭入试验、镀层和尖端毛刺。反映成孔与连接一体化产品的工作端状态。
铆钉和销直径、长度、头部、剪切、铆接变形、开口状态和表面。反映铆接或定位件的装配接口。
丝杆和牙条螺距、直线度、螺纹通止、表面粗糙度、硬度和端部加工。反映长螺纹件的传动或调节状态。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类具有批量大、规格多、标准化程度高的特点。普通紧固件技术成熟，高强度、汽车、风电、建筑钢结构和精密电子紧固件复杂度较高。自动化程度从单机冷镦到高速成形、在线搓丝、热处理连续线和光学分选均有分布。

H2 典型组织形态

组织形态典型特征常见资源配置
小型螺丝厂规格集中、外协多冷镦、搓丝、包装。
标准件企业多规格批量生产冷镦、搓丝、热处理、表面处理接口。
高强度紧固件企业汽车、建筑和机械配套材料追溯、热处理、力学性能和分选。
螺母企业攻丝和通止检测突出冷镦、攻丝、表面处理和检测。
螺杆丝杆企业长件和传动件车削、滚丝、磨削、校直和检测。

H4 典型组织形态差异补充

紧固件行业既有标准件大批量企业，也有高强度、汽车、风电、电子微型和丝杆专业企业。不同组织的设备、热处理和分选资源差异明显。

组织形态典型表现技术识别提示
标准件企业冷镦、搓丝、表面处理和包装分选为主。规格防混和批量分选信息突出。
高强度紧固件企业材料、热处理、脱碳和表面处理资源较强。拉伸、硬度、延迟断裂相关状态较有识别价值。
螺母垫圈企业攻丝、冲压、倒角、热处理和表面处理占比高。内螺纹和支承面信息突出。
汽车或专项紧固件企业客户图纸、追溯、自动分选和包装标签更复杂。图纸版本和批次链条需要描述。
电子微型紧固件企业小规格、高速分选和精细表面状态突出。毛刺、混料和微小尺寸信息突出。
丝杆牙条企业长件校直、滚丝、磨削、端部加工和防锈较多。直线度和螺距累计信息较有识别价值。

H3 客观存在的易出问题环节/技术敏感点

敏感点客观影响链
材料强度和线径波动材料输入偏差 → 冷镦和热处理状态变化 → 裂纹、硬度或力学性能波动。
模具磨损冷镦模或搓丝板磨损 → 头部、螺纹和尺寸漂移 → 配合状态受扰动。
热处理参数偏差温度、时间或冷却状态异常 → 硬度和组织变化 → 强度或脆性状态波动。
螺纹加工异常搓丝、滚丝或攻丝状态偏移 → 牙型和通止变化 → 装配卡滞或夹紧状态异常。
表面处理氢引入酸洗、电镀和后处理状态异常 → 高强度钢吸氢路径形成 → 延迟断裂状态变化。
混料和错标多规格小件分选识别不足 → 规格、强度或表面状态混入 → 下游装配状态受扰动。
冷镦头部折叠未识别材料流动、模具圆角或润滑异常 → 头部内部折叠或裂纹形成 → 承载时局部开裂路径出现。
螺母攻丝排屑不畅底孔、刀具或润滑状态异常 → 螺纹毛刺和乱牙增加 → 通止和装配状态波动。
表面处理后螺纹余量不足镀层厚度或热浸镀锌层堆积 → 螺纹配合间隙变小 → 装配卡滞或扭矩异常路径形成。

H3 只记录行业中客观存在的敏感点及事实因果链，不对其在任何上层视图中的重要性作判断。
