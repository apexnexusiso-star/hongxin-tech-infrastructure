A2 定义与范围界定

本小类包括围绕咖啡、茶、可可和调味料开展的批发贸易活动，典型对象包括咖啡豆、烘焙咖啡、茶叶、可可粉、香辛料、复合调味料、餐饮调料等。其主导结果不是制造加工本身，而是通过商品识别、库存或接修管理、交易或服务条件确认、交付或修复状态确认，使客户获得可接收的商品或服务结果。

本小类的专业性集中在产地等级、香气风味、烘焙批次、含水防潮、避味仓储和餐饮渠道供货。这些要素决定了本小类不能只按一般商业服务理解，而应结合商品对象、客户用途、储运条件、资料链和相邻类别边界进行识别。

实际组织可能同时存在采购、仓储、配送、陈列、线上交易、上门服务、维修、安装、售后和平台接口。分类时应识别主导服务结果：是批量供货、终端零售、非店铺远程交易、市场摊位即时交易，还是既有物品修复。

A3 边界说明、相邻小类区分点和排除项

相邻活动容易混淆的原因主要区分依据本卡处理原则
销售代理批发和代理都面向经营客户并形成交易是否取得货权、是否承担库存和差价经营自营采购和批量销售归入本卡；受托撮合和佣金服务归入 29.05。
零售贸易批发商可能兼有门店或线上销售客户对象和交易批量面向经营者、机构或项目客户批量供货归入本卡；终端零售归入相应零售小类。
制造或加工批发商可能分装、切配、组套或简单整理是否改变商品基本属性并形成加工产品流通整理归入本卡；主导制造加工另行识别。
仓储物流批发活动依赖仓库和配送主导服务结果是商品交易还是保管运输为自营批发配套的仓配归入本卡；独立仓储物流另行识别。
进出口和平台服务批发可通过平台或跨境渠道完成是否自营商品交易自营批发归入本卡；单纯平台或进出口手续服务另行识别。
相邻批发小类29 大类批发小类之间商品对象接近主导商品属性和客户用途按主导品类、货权和客户用途识别。

明确排除项：

  • 商品制造、加工、分装、改性或再制造为主的活动。
  • 仅提供仓储、运输、平台撮合、广告推广或支付结算的活动。
  • 以销售代理、佣金撮合或受托渠道开发为主的活动。
  • 主导商品或服务可归入更具体小类时，不应使用集合类兜底。
  • 具体组织适用的资质、许可、合规结论和数字风险评价。

A4 分组特征摘要

维度本小类特征上层分组调用提示
主导活动类型咖啡、茶、可可和调味料批发贸易上层调用时应先确认主导服务结果，而不是只看商品名称。
核心过程性质产地等级、香气风味、烘焙批次、含水防潮、避味仓储和餐饮渠道供货这一行是本卡最重要的技术命脉，不能被一般采购销售话术替代。
主要技术基础咖啡烘焙度、茶叶等级、可可和香辛料风味、防潮避光、气味串味和批次追溯具备一般商业经验不等于理解本小类商品状态、资料链和交付边界。
产业链段位上接咖啡、茶、可可和调味料供应、客户物品或市场来源，下接生产、渠道、项目、终端消费者或修理客户本卡位于流通或服务末端，主要通过信息、库存、交付或修复形成价值。
典型规模跨度从小型门店、市场摊位、维修工位到区域仓配、连锁渠道和平台化经营均可能存在规模差异会影响记录、设备、库存和外部接口。
主要分型轴按商品对象、客户类型、交易方式、储运条件、特殊属性、服务深度和边界敏感性分型不同分型会改变 D 段过程链和 H3 敏感点。
分组比较提示与其他食品批发相比，本卡更强调风味、产地等级和避味保存。如与相邻小类共组，应单独说明本小类的对象、过程和边界差异。
分组敏感边界商品对象和相邻小类边界容易被主导交易方式掩盖，需要以品类、客户用途、货权和服务结果共同判定。应以主导商品、客户用途、货权或客户财产、交付状态和服务结果综合判断。

A4 是从 C、D、E、G、H 各段提炼出的调用索引。上层文件使用本卡时，应先通过 A4 识别本小类技术命脉，再回到 D 段过程链、G 段方法工具和 H3 客观敏感点核对事实基础。

B3 关键技术概念说明

理解本小类必须先理解服务对象。咖啡、茶、可可和调味料的品类、状态、规格、证明资料、交付方式或可修性，决定了本小类与相邻小类的实质差异。

本小类的过程链不是抽象的商业流程，而是围绕咖啡茶调味品的风味等级和防潮避味展开。只写采购、销售、收款、交付，会丢失真正支撑后续分组判断的行业事实。

货权、客户财产和服务责任边界需要分开理解。批发和零售通常围绕商品交易，修理围绕客户既有物品状态恢复，非店铺和摊位零售则围绕特殊交易场景组织交付。

D. 过程与技术

D1 主要过程流程：从投入到产出的完整链路

本小类通常遵循以下链路：供应商开发 → 商品资料整理 → 采购或订货 → 到货验收 → 仓储保管 → 客户询价 → 订单拣配 → 配送交付 → 退换索赔 → 库存和客户维护。

在该链路中，咖啡、茶、可可和调味料不是一个抽象商品名，而是具有咖啡烘焙度、茶叶等级、可可和香辛料风味、防潮避光、气味串味和批次追溯等客观属性的服务对象。过程记录应能够说明商品或客户物品如何被识别、如何被保管或处理、如何形成交易或修理结果，以及后续问题如何回到原始批次、订单或接修记录。

同一组织如果同时存在多种经营方式，应以主导服务结果划分边界。批发看批量供货和库存交付，零售看终端客户和即时交易，非店铺看远程订单和仓配，摊位看现场交易，修理看既有物品状态恢复。

`text 供应商开发 → 商品资料整理 → 采购或订货 → 到货验收 → 仓储保管 → 客户询价 → 订单拣配 → 配送交付 → 退换索赔 → 库存和客户维护 `

计量和检测工具称重、数量、尺寸或状态辅助确认交易确认。
配送车辆或物流接口同城、干线、冷链或专业配送交付资源。
客户资料系统记录客户类型、需求和账期复购维护。
退货检视区确认退回商品状态和责任售后处理。

D3 与 G 段的分工：D3 写资源和工具本身，G 段写这些资源用于确认哪些参数、状态或事实。

D7 咖啡、茶、可可和调味料的批发的咖啡茶调味品的风味等级和防潮避味链条深化说明

本小类最容易被写薄的部分是咖啡茶调味品的风味等级和防潮避味。如果只保留一般商业流程，就无法解释为什么咖啡、茶、可可和调味料的批发应当作为独立基础卡被调用。

产地等级、香气风味、烘焙批次、含水防潮、避味仓储和餐饮渠道供货构成本小类的核心链条。它把商品对象、客户用途、资料证明、储运或修理状态连接起来，使上层文件能够判断本小类与相邻小类之间的共性和差异。

该链条还承担边界控制功能：当企业同时经营多个品类、多个渠道或多种服务时，应回到本链条识别主导对象，而不是直接按企业名称、门店形态或经营范围文字归类。

链条典型要素客观作用
对象识别链咖啡、茶、可可和调味料确定本卡适用对象。
专属指标链产地等级、香气风味、烘焙批次、含水防潮、避味仓储和餐饮渠道供货形成与相邻小类的区分。
资料证明链咖啡烘焙度、茶叶等级、可可和香辛料风味、防潮避光、气味串味和批次追溯支撑客户接收和后续追溯。
储运或作业链仓储、陈列、配送、现场交易、上门或维修工位保持商品或物品状态。
客户用途链生产、渠道、工程、家庭、个人、专业或修理场景决定规格和服务说明。
交付确认链签收、收款、复测、客户确认和票据证明服务结果已经形成。
售后反馈链退换、补货、返修、投诉和索赔闭合后续问题。
边界维护链主导品类、相邻类别、特殊属性和经营方式防止集合类或复合经营误判。

H. 行业本底特征

H1 技术复杂度、自动化和人工依赖程度

维度本底特征说明
技术复杂度取决于商品专业属性、特殊规则类别、储运条件或修理难度不同小类差异大。
信息依赖品类、规格、批次、标签、库存、客户和售后记录高度重要信息偏差会传导到交付结果。
人工经验选品、陈列、客户解释、修理判断和边界识别仍大量依赖经验系统只能辅助。

H2 典型组织形态

组织形态典型特点说明
小型门店或摊位人员复合、库存有限、现场交易多记录和边界容易薄弱。
专业批发商SKU多、仓配强、客户稳定库存和追溯突出。
连锁零售主体门店标准化、系统化程度高陈列和售后规则较统一。
平台化经营者远程获客、仓配履约、数据驱动页面和物流接口突出。
专业修理工坊依赖手工经验和备件资源接修记录和复核重要。
综合复合组织批发、零售、安装、修理和平台接口交织必须识别主导服务结果。

H3 客观存在的易出问题环节和技术敏感点

敏感点客观表现客观影响链
商品资料不完整规格、批次、标签或证明资料不足资料不足 → 客户判断偏差 → 交易延迟。
库存账实不符系统数量、库位和实物不一致库存不准 → 承诺失实 → 订单延误。
批次追溯断裂入库、出库和客户批次未对应追溯断裂 → 退换索赔困难 → 损失扩大。
仓储条件不适配温湿度、防潮、防压或隔离不足保管不当 → 商品状态下降 → 客户异议。
拣配错发型号、规格、数量或客户错配错发 → 客户停工或缺货 → 补发成本增加。
交付短少破损运输、装卸或签收环节出现差异交付异常 → 结算争议 → 客户关系受损。
专属指标遗漏产地等级、香气风味、烘焙批次、含水防潮、避味仓储和餐饮渠道供货未在交易或服务资料中体现专属信息遗漏 → 适配判断偏差 → 后续协调成本增加。
相邻类别误判商品对象和相邻小类边界容易被主导交易方式掩盖，需要以品类、客户用途、货权和服务结果共同判定。边界误判 → 文件调用偏差 → 后续分组依据变弱。
价格口径不清运费、安装、损耗、账期、维修费或促销条件表达不清价格口径不清 → 结算差异 → 商务争议。
售后主体不清供应方、门店、平台、修理方或承运方责任未区分主体不清 → 处理延迟 → 客户信任下降。

H3 仅写事实因果链，不把这些敏感点预先归入任何特定管理体系视角。
