29.02.00 汽车的保养和修理 专业小类基础卡

> 本卡为技术领域分组底层知识卡，记录不依附于特定管理体系的行业事实、过程边界、术语、产品或服务、过程技术、产业链、法规标准类别、检验计量手段和维护信息。凡涉及具体管理体系下的人员能力、样本选择、合格评定结论或体系风险分级的内容，应在上层分组论证文件中展开。

A2 定义与范围界定

本小类包括对汽车进行日常保养、故障诊断、机械维修、电气维修、发动机和传动系统维修、制动和转向维修、空调维修、钣金喷漆、轮胎服务、车辆整备、事故车修复、新能源车辆相关维护以及交车确认等服务活动。 汽车保养和修理的服务对象是既有车辆技术状态，其结果是使车辆恢复、保持或改善可使用状态。与整车销售不同，本小类的核心证据不是交易合同和车辆配置，而是客户报修、维修接待、诊断、维修方案、备件和工时、维修作业、过程确认、试车或功能检查、交车解释和返修处理。 本小类的专业性高度依赖车辆系统知识、故障诊断逻辑、维修工艺、专用工具、检测设备、备件适配、软件和电子控制系统以及维修安全边界。随着新能源和智能网联车辆增加，高压系统、动力电池状态、软件标定、辅助驾驶传感器校准等内容成为重要的客观技术接口。

A3 边界说明、相邻小类区分点和排除项

相邻活动容易混淆的原因主要区分依据本卡处理原则
29.01.01/29.01.02 汽车销售销售门店常附带售后维修，维修厂也可能销售车辆主导活动是否为车辆交易还是技术状态恢复独立保养、故障诊断和修复归入本卡；整车交易归入汽车销售小类。
29.03.01/29.03.02 汽车零部件流通维修服务大量使用配件，配件店可能提供简易安装是否对整车进行诊断、拆装、调试并承担维修服务结果仅销售配件不纳入本卡；含诊断和安装修复的归入本卡。
机动车检测服务维修后常进行检测或客户先检测再维修是否以第三方检测报告为主导产出维修过程中的检测调试归入本卡；独立检测机构活动另行识别。
汽车美容和清洗部分维修企业提供洗车、美容、内饰护理是否涉及车辆技术状态维护或修复普通清洗、美容和装饰服务不纳入本卡；钣喷、修复、保养和功能维护归入本卡。
道路救援服务救援常将车辆拖至维修厂或现场简修主导活动是救援拖带还是维修服务现场应急修理和后续维修归入本卡；单纯拖车救援另行识别。
车辆改装服务维修过程中可能加装或改装部件是否改变车辆原有结构、用途或主要技术参数维护性更换和修复归入本卡；以改装为主的活动需按主导活动另行判断。

明确排除项：

  • 汽车整车、发动机、零部件和维修设备的制造活动。
  • 以整车销售、配件批发或零售为主且不承担维修结果的活动。
  • 独立机动车安全技术检验、排放检测和鉴定评估服务。
  • 普通洗车、美容、停车、拖车和道路运输服务。
  • 以车辆改装、赛事调校或租赁运营为主的活动。

A4 分组特征摘要

维度本小类特征上层分组调用提示
主导活动类型汽车保养、故障诊断和维修服务上层调用时应把工单、诊断、维修作业和修后确认作为识别抓手。
核心过程性质客户报修接待、车辆诊断、维修方案、备件适配、拆装修复、电子控制系统检测、路试或功能复检、交车说明其技术命脉在车辆系统诊断与修复闭环，不是商品销售。
主要技术基础发动机、底盘、制动、转向、传动、电气电子、车身钣喷、空调、新能源高压系统、诊断仪、扭矩工艺和维修资料具备汽车销售或配件知识不自动覆盖维修诊断和修复能力。
产业链段位上接车主、车队、保险、配件供应和整车厂技术资料，下接车辆再次使用、售后保障和客户反馈服务结果直接影响既有车辆使用状态。
典型规模跨度从品牌授权服务站、综合维修厂到快修快保门店和钣喷中心均存在不同规模主体的差异在诊断设备、工位、技术资料和专业分工。
主要分型轴按快修保养/综合维修/钣喷/事故车/新能源/商用车/轮胎服务分型分型不同导致设备、人员技能和过程链不同。
分组比较提示与 29.03 零部件流通共享配件适配知识，但本卡要求把配件装入整车系统并验证技术状态如与配件流通共组，应单独识别诊断、拆装、调试和交车复检差异。
分组敏感边界配件店安装、汽车美容、道路救援和车辆检测容易与本小类交叉应以是否承担车辆技术状态恢复和维修服务结果为主要判据。

B. 术语与概念

B1 专业术语和行业常用表达

术语解释本小类中的使用语境
维修工单记录客户报修、车辆信息、维修项目、备件、工时和交车情况的服务单据。贯穿接待、诊断、维修、复检和结算。
故障诊断通过询问、读取故障码、测量、试车和拆检判断故障原因。是维修方案形成的技术基础。
保养按里程、时间或使用条件更换油液、滤芯、易损件并检查车辆状态。用于保持车辆正常技术状态。
诊断仪与车辆电子控制系统通信并读取故障码、数据流或执行测试的设备。现代汽车维修的常用工具。
数据流车辆控制单元实时输出的运行参数。用于判断传感器、执行器和控制策略状态。
路试在受控条件下驾驶车辆确认故障现象或维修效果。常用于异响、制动、转向、动力和变速系统确认。
扭矩螺栓、螺母等紧固件拧紧力矩。影响轮胎、制动、悬架和发动机部件连接可靠性。
钣金修复对车身金属或结构件进行整形、焊接、校正和修复。事故车维修和外观修复中的重要过程。
喷涂对车身表面进行底材处理、调漆、喷漆和烘干。影响外观、附着和防护状态。
四轮定位调整或测量车轮定位参数。用于解决跑偏、轮胎异常磨损和操稳问题。
高压系统新能源车辆动力电池、电机、电控和高压线束系统。维修时涉及绝缘、断电、警示和专用工具。
ADAS校准对驾驶辅助系统相关摄像头、雷达或传感器进行标定。事故修复、玻璃更换和底盘调整后可能涉及。
返修车辆交付后同一问题或相关问题再次进入维修的情形。用于反映维修方案和过程确认是否充分。
维修资料厂家手册、线路图、维修工艺、扭矩和标准工时资料。指导诊断和拆装作业。

B3 关键技术概念说明

汽车维修的核心是诊断逻辑。客户描述的现象只是入口，维修人员需要通过车辆信息、故障码、数据流、机械测量、试车和拆检判断真正原因，再形成维修方案。 维修过程不是简单换件。现代汽车由机械、液压、电气电子、软件和网络通信系统组成，同一故障现象可能来自传感器、执行器、线束、控制单元、机械磨损或使用条件。 修后确认是服务结果形成的关键节点。完成拆装或更换备件后，需要通过静态检查、功能测试、路试、泄漏检查、故障码复查或客户确认来证明车辆状态已经恢复到约定水平。 新能源和智能网联车辆使维修边界更复杂。高压断电、绝缘检测、动力电池状态、软件版本、传感器校准和远程数据接口，已经成为不少维修场景中的技术前提。

D. 过程与技术

D1 主要过程流程：从投入到产出的完整链路

本小类过程链一般从预约或到店接待开始，经车辆信息登记、客户故障描述、预检、诊断、维修报价、客户确认、备件准备、车辆拆装或保养、过程检查、功能确认、路试或静态测试、结算交车、客户说明和后续跟踪完成。 维修服务的主线是“现象到原因、原因到方案、方案到作业、作业到确认”。如果只记录更换了什么零件，而没有诊断依据和修后状态确认，维修服务链条就不完整。 维修企业的差异主要来自车型复杂度、诊断设备、维修资料、工位条件、备件渠道和人员经验。新能源、智能驾驶辅助、商用车和事故车修复往往需要更细的作业边界。

通用链路可表示为：

`text 客户或市场需求 → 对象识别 → 技术或规格匹配 → 商务确认 → 资源准备 → 交付或服务作业 → 状态确认 → 文件和售后接口 → 反馈与维护 `

D7 汽车维修诊断、备件适配和修后确认链条深化说明

汽车维修服务的深水区在诊断闭环，而不是更换备件本身。车辆故障常以客户主观感受出现，如异响、抖动、无力、油耗升高、报警灯点亮或制动脚感异常；这些现象需要通过系统化诊断转化为可执行的维修方案。 备件适配是维修结果的重要基础。相同车型在年款、配置、发动机、电控系统和生产批次上可能存在零件差异，简单按名称取件容易造成装配不匹配或功能异常。 修后确认把服务结果从“已施工”变成“车辆状态已恢复”。它可以是故障码复查、数据流复核、泄漏检查、路试、定位数据、制动力感觉、空调温度或客户故障现象复现确认，必须与原始报修问题对应。

链条典型要素客观作用
现象链客户描述、试车感受、报警灯、异响、抖动形成诊断入口。
诊断链故障码、数据流、测量、拆检、维修资料把现象转化为原因判断。
方案链维修项目、备件、工时、费用、客户授权把原因转化为服务计划。
备件链VIN、零件号、替换关系、库存、旧件保证备件与车辆匹配。
作业链拆装、清洁、扭矩、密封、加注、标定把方案转化为车辆状态变化。
复检链功能测试、数据复核、路试、泄漏检查证明状态变化达到约定要求。
交车链维修说明、旧件处理、费用解释、后续提示让客户理解服务结果。
返修链再次报修、原因复盘、资料闭合识别维修链条中的薄弱环节。

E3 本小类在产业链中的位置

本小类位于流通和服务产业链中，不改变车辆或商品的基本制造属性，而是通过信息匹配、资源组织、交易安排、状态确认和服务接口，把上游车辆、配件或资料转化为客户可接收、可使用或可继续处理的服务结果。

对于 29 大类而言，产业链位置判断尤其依赖主导活动：同一组织可能同时存在销售、维修、配件、金融、保险、平台和外包接口，但分类时应识别哪一类活动构成主要服务输出。

高压作业边界不清新能源车辆断电和绝缘确认不足高压状态不明 → 作业风险增加 → 车辆损坏或人员受伤。
钣喷前处理不足打磨、除油、遮蔽或调漆不充分表面处理偏差 → 漆膜缺陷 → 返工。
修后确认缺失未复查原始故障或未路试状态未确认 → 问题带出厂 → 返修。
客户授权不清增项维修或旧件处理未说明服务边界不清 → 费用争议 → 信任下降。
维修资料滞后新车型、新软件或新系统资料不足资料不足 → 诊断路径偏差 → 维修周期延长。

H3 仅写事实因果链，不把这些敏感点预先归入任何特定管理体系视角。
