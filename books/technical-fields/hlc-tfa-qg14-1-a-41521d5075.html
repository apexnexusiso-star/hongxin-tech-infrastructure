  • 文件定位说明

本文件用于质量管理体系认证中 QG14-1 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦橡胶轮胎、内胎、翻新再造轮胎及其他橡胶制品制造在 QMS 轴下的质量形成链、顾客要求转化、原辅材料和配方控制、关键过程和特殊过程、检验放行、批次追溯、不合格控制、客户反馈和改进闭环。

本文件不承担行业百科说明功能，基础行业事实由对应专业小类基础卡承载。本文件只调用与分组论证、能力后果和审核抽样有关的信息。本组采用“统一领域包 + 轮胎与翻新分支 + 非轮胎橡胶制品分支 + 产品族能力标注 + 条件扩展 + 专项边界控制”的使用口径；组内共同基础可以共享，但分支差异必须通过能力标注、条件扩展、专项确认和项目边界控制落地。

  • 技术领域包构成
小类编码小类名称纳入本包的活动范围主要内部路线特殊边界
14.01.01橡胶轮胎和内胎的制造，橡胶轮胎翻新和再造包括新轮胎、内胎、轮胎半成品以及可用胎体经检查、打磨、修补、贴胎面和二次硫化形成翻新轮胎的制造活动。新胎制造、内胎制造、轮胎半成品、预硫化胎面翻新、模压翻新。轮胎为复合承载和旋转使用产品；翻新再造需确认胎体筛选、修补和二次硫化能力，不能按普通橡胶件处理。
14.01.02其他橡胶制品的制造包括胶管、胶带、密封件、减震件、橡胶板、橡胶型材、橡胶辊、橡胶衬里、包胶件和非轮胎类橡胶复合件制造。模压密封件、挤出胶管和型材、压延胶板胶带、橡胶金属粘接件、工业衬胶和减震件。本小类内部跨度大，应按密封、输送、减震、耐介质、包胶衬胶等产品族记录实际能力。
  • 分组设立的基本逻辑

本包在 QMS 轴下的共同对象是以橡胶或弹性体为主体、通过配方混炼、成型、硫化及必要的骨架复合形成最终功能的橡胶制品。分组判断的核心不是产品名称是否相近，而是顾客要求如何转化为材料、配方、工艺、检验和放行要求，关键质量特性如何在过程链条中形成，批次和变更如何保持可追溯，以及出现不合格或客户反馈时能否形成闭环。

本包可概括的共同质量形成链为：顾客规格或图纸 -> 胶种和配方要求 -> 原材料、填料、助剂和骨架材料确认 -> 配料混炼和胶料检验 -> 成型、贴合、挤出、压延或模压 -> 硫化或粘接特殊过程 -> 尺寸、外观、物性、气密、耐压、粘合或动态性能检验 -> 放行、标识、储运和客户反馈。该链条决定了本包共享的专业能力基础，审核员应能够沿订单、配方或材料批次、关键过程参数、检验记录、放行记录、交付和反馈建立纵向证据链。

组内差异主要表现为产品结构和验证重点不同：轮胎具有胎体、带束层、胎圈、胎面、内衬层和旋转使用特性，翻新轮胎还依赖旧胎体可用性判断；其他橡胶制品则围绕密封、输送、减震、耐介质、粘接或衬胶等功能展开，产品族差异明显。这些差异不否定设组，但要求本包按“统一领域包 + 分支能力标注 + 条件扩展 + 边界受控”的方式使用，不得把某一产品族或工艺路线经历视为覆盖全部组内小类的充分证明。

  • 专业小类关系类型与授权后果
关系类型含义授权后果典型控制方式
共同基础关系组内小类共享高分子材料、配方或材料选型、成型过程、检验放行、批次追溯和客户反馈闭环等 QMS 基础。可简化通用材料加工和过程控制基础评价，但仍需确认目标小类、产品族或工艺路线的实际经历。资料评审、专业面谈、典型批次追溯、产品族经历核对。
并列分支关系同属本技术领域包，但产品结构、关键质量特性、特殊过程、检测项目或客户用途不同。应记录实际分支能力，不把同包经历视为全分支能力。分支标注、限定使用、项目技术支持、见证审核。
条件扩展关系已具备相邻分支能力，具有共同材料和过程基础，但目标分支存在专门质量形成链。完成补充培训、案例评审、专业面谈、见证审核或技术支持后方可扩展。培训考核、案例评审、首个项目技术支持、现场见证。
专项确认关系涉及高结构复杂度、强客户用途约束、食品接触、建筑使用、翻新再造、压力或密封承载等特殊路线。项目使用前应专项确认；必要时增加产品族限定或配置技术专家。专项面谈、技术专家评审、样本案例评价、授权备注。
不可直接替代关系相关高分子材料或通用成型经历不足以证明目标产品族的完整质量形成能力。不得作为目标能力的单独授权依据，应补充目标经历、见证或限定项目类型。重新评价、补充经历、限定产品族或工艺路线。
边界受控关系当产品认证、食品接触、建筑应用、客户安全件、再制造、外包检测或法定接口改变使用边界时，同包授权应增加边界说明。授权记录应写明适用产品族、工艺路线和特殊边界；项目匹配按实际活动确认。授权备注、项目匹配确认、合规类别清单、技术支持。
轮胎制造与其他橡胶制品二者共享橡胶配方、混炼、成型和硫化基础，但轮胎具有复合承载、旋转均匀性和胎体结构链条。可共享橡胶材料和硫化基础评价；轮胎、新胎结构和翻新再造应进行分支确认。轮胎结构案例、胎体或带束层过程追溯、均匀性和气密检验样本。
新胎制造与翻新再造均以轮胎使用功能为目标，但翻新再造的起点是旧胎体状态而非全新材料部件。新胎经历不能替代翻新胎体筛选和修补能力；翻新经历也不能替代全流程新胎结构成型能力。胎体检查、打磨、修补、贴合和二次硫化案例评价。
密封件、胶管、胶带、减震件和衬胶件同属非轮胎橡胶制品，但关键质量特性分别落在尺寸压缩、耐压层间、骨架强度、动静刚度和界面粘接。非轮胎橡胶授权应记录产品族；跨产品族扩展应补充目标产品案例。按产品族抽取订单和工艺记录，核对检验项目是否匹配用途。
  • 本体系共同能力基础
共同能力维度本包共同基础可共享的审核判断不能共享的边界
顾客要求和技术文件转化组内产品均需把规格、图纸、材料牌号、硬度、尺寸、用途、耐介质、耐压、耐久或外观要求转化为配方、工艺和检验要求。审核员可共享合同评审、技术文件转换、首件确认、变更控制和客户特殊要求识别的审核判断。轮胎速度承载、翻新胎体、胶管耐压、密封件压缩变形和减震件刚度等不能互相替代。
原辅材料和配方控制均依赖橡胶、填料、硫化体系、防老剂、加工助剂、骨架材料或嵌件的批次控制和称量控制。可共享材料证明、配方权限、称量复核、胶料批次、混炼参数和供应商控制判断。轮胎帘线和胎圈钢丝、胶管增强层、橡胶金属嵌件、翻新胎面和修补胶应专项确认。
混炼和胶料状态配方分散、门尼粘度、硫化特性、停放和复炼共同影响后续成型与硫化结果。可共享混炼设备、投料顺序、温度、排胶、胶料标识、胶料检验和批次追溯的审核方法。不同胶种和产品族的混炼窗口不同，不能只凭通用混炼经历确认目标能力。
成型和硫化特殊过程橡胶制品的最终弹性网络通常在硫化中形成，过程结果具有较强不可逆性。可共享硫化参数、模具工装、设备能力、首件确认、过程监控和特殊过程确认判断。轮胎胎坯成型、包封翻新、胶管连续硫化、橡胶金属粘接和大型衬胶过程应按路线确认。
检验放行和追溯反馈均需通过尺寸、外观、硬度、物性、气密、耐压、粘合、动态或客户验收项目确认交付状态。可共享检验计划、检测设备、放行责任、不合格控制、批次追溯和客户反馈闭环判断。轮胎均匀性、内胎检漏、胶管爆破、密封件压缩永久变形、减震件疲劳等检验不能互相代替。
  • 本体系核心控制要求

本组所称关键质量特性，是指产品或服务输出中影响顾客可接受性、使用适配性和交付符合性的材料性能、结构尺寸、外观状态、功能性能、可靠性、密封性、耐久性、洁净状态、标识追溯和客户特殊要求。QMS 审核应把顾客要求、技术文件、工艺参数、检验放行、变更控制和质量反馈连成证据链，而不是只查看最终检验记录。

第一，审核应确认顾客要求如何被转化为配方、结构、工艺和检验要求。橡胶制品的客户要求通常不是单一尺寸，而是材料牌号、硬度、拉伸、耐磨、耐油、耐热、气密、耐压、动态疲劳、装配界面或使用环境的组合。轮胎还涉及规格、胎面、承载、速度、均匀性和标识；翻新轮胎涉及胎体来源和翻新次数；胶管、密封和减震件则更依赖图纸、公差、介质和装配条件。

第二，审核应把原材料和配方作为质量形成链前端。橡胶、炭黑、白炭黑、硫化剂、促进剂、防老剂、软化剂、骨架材料、金属嵌件和修补材料的批次差异会传递到成品。应关注配方权限、称量复核、投料顺序、混炼温度、排胶温度、胶料标识、停放期限和胶料检验，特别是配方变更和替代材料使用是否经过评审。

第三，硫化、粘接和轮胎成型属于本组 QMS 审核的核心过程。硫化温度、压力、时间、模具状态和装料方式会形成不可逆的交联状态；橡胶与金属、织物或旧胎体界面形成后通常难以通过外观完全判断。审核员应关注特殊过程确认、参数监控、设备维护、模具管理、首件确认、异常批处理和返工边界。

第四，检验放行应与产品族相匹配。轮胎应关注外观、尺寸、气密、均匀性、动平衡和必要的耐久或强度验证；内胎应关注接头、气门嘴和检漏；胶管应关注层间、耐压、爆破或脉冲；密封件应关注尺寸、硬度和压缩变形；减震件应关注刚度和疲劳；衬胶或包胶件应关注界面粘接和覆盖完整性。

第五，不合格控制和客户反馈应能追溯到材料、胶料、设备、模具、硫化批次、检验放行和交付批次。典型问题包括胶料误配、混炼分散不足、硫化不足、胎体误判、粘接脱层、气密泄漏、尺寸变形、表面裂纹和客户装配不适配。审核应验证纠正措施是否回到真实质量形成节点。

  • 分小类或内部路线差异分析
小类/路线与本包共同基础主要差异差异对能力授权的影响控制方式
14.01.01 新轮胎制造共享橡胶配方、混炼、成型、硫化、检验和追溯基础。轮胎由胎面、胎侧、内衬层、帘布、带束层和胎圈组成，动态承载和旋转均匀性突出。应标注轮胎分支；仅有普通橡胶件经历不足以证明轮胎结构和均匀性检验能力。抽取轮胎规格订单，追溯配方、半成品、成型、硫化、均匀性和放行。
14.01.01 内胎制造共享胶料混炼、挤出、硫化、外观和批次追溯基础。内胎流程较短，气密、接头、气门嘴结合和检漏是核心。可作为轮胎包内分支确认，但不能替代新胎复合结构成型能力。抽取内胎批次，追溯挤出管坯、接头、气门嘴、硫化和检漏。
14.01.01 翻新轮胎共享轮胎使用功能、胎面胶、硫化和成品确认基础。以旧胎体状态为起点，胎体筛选、损伤判断、打磨、修补、贴合和二次硫化决定结果。属于专项确认路线；新胎制造经历不能替代翻新胎体判断能力。抽取翻新胎，追溯胎体接收、检查、打磨、修补、贴合、硫化和成品确认。
14.01.02 密封件共享胶料、模压或注压、硫化和尺寸检验基础。尺寸、公差、硬度、压缩永久变形、介质相容和装配界面突出。可作为非轮胎橡胶分支；扩展到胶管、轮胎或减震件需补充目标案例。抽取密封件图纸订单，追溯材料、模具、硫化、尺寸和压缩性能。
14.01.02 胶管、胶带和输送带共享混炼、挤出、压延、骨架材料和硫化基础。增强层、层间粘合、耐压、爆破、脉冲、接头和覆盖胶耐磨突出。应记录输送或承压类分支；仅有普通模压件经历不足以覆盖。抽取胶管或胶带，追溯增强材料、成型、硫化、耐压或粘合检验。
14.01.02 减震、包胶和衬胶件共享橡胶配方、硫化和复合界面控制基础。橡胶金属粘接、动静刚度、疲劳、表面处理、衬里完整性和耐介质突出。粘接复合件和大型衬胶应作为专项确认或产品族限定。抽取复合件，追溯基体处理、底涂、装模、硫化、粘合或功能检验。
  • 分组合理性论证结论

本组可以设立的理由在于，两个小类均以橡胶材料配方、混炼分散、成型、硫化或界面粘接为质量形成主线，均需要把顾客要求转化为材料、配方、工艺参数和检验放行要求，并通过批次追溯和反馈闭环控制质量波动。QMS 轴下的共同能力足以支撑统一领域包使用。

因此，QG14-1 可以作为质量管理体系技术领域包使用，使用口径为“统一领域包 + 轮胎与翻新分支 + 非轮胎橡胶制品分支 + 产品族能力标注 + 条件扩展 + 专项边界控制”。审核员授权、项目匹配、能力扩展和持续保持均应体现分支差异；当项目产品族超出已确认经历时，应通过案例评价、专业面谈、见证审核或技术支持补足证据。

  • 审核关键要点与抽样方法
抽样场景现场必看记录必查纵向追溯路径追问方向
新轮胎制造密炼、压延、挤出、成型、硫化、均匀性和成品检验现场。订单规格、配方、胶料批次、帘线胎圈材料、成型记录、硫化记录、均匀性和放行记录。顾客规格 -> 配方和半成品 -> 胎坯成型 -> 硫化 -> 均匀性/气密 -> 放行 -> 客户反馈。胎体结构如何防错；硫化异常如何判定；均匀性不合格如何处置。

  • 培训、考核与作业指导书需求

本组应建立橡胶制品 QMS 专业培训，内容包括橡胶胶种和配方基础、填料和硫化体系、混炼分散、胶料检验、模压挤出压延、硫化特殊过程、橡胶金属或织物粘接、轮胎结构、内胎气密、轮胎翻新胎体评估、胶管耐压、密封件尺寸压缩、减震件动静刚度、衬胶界面和不合格案例追溯。

考核宜采用场景式案例和批次追溯题，要求审核员能够从一份订单或客户技术要求出发，说明材料选择、配方或工艺转换、关键过程控制、特殊过程确认、检验放行、不合格处置、变更控制和客户反馈之间的证据关系。作业指导书应提供分支化抽样路径、典型记录清单、访谈问题库、授权边界提示和首个项目技术支持触发条件。

  • 常见合规义务类别与标准适用提示

本组可能涉及强制性产品认证类别、轮胎产品准入类别、再制造和翻新标识类别、工业产品许可类别、产品标识和消费者权益类别、计量和检验检测类别、客户安全件要求、压力或承压软管用途、食品接触或医用配套用途、特种用途产品和进出口客户要求等类别。本文件不列具体标准编号和年份；适用性应使用机构受控的有效清单、客户合同、产品技术文件、产品目录、认证规则、检测报告和所在地监管要求确认。上述类别用于识别外部要求如何转化为产品要求、过程控制、检验放行、标识追溯和交付确认，不替代政府许可、行政执法、产品认证决定或客户专项验收。

  • 分组使用限制和法定边界

本组 QMS 分组不替代轮胎强制性产品认证、翻新轮胎市场准入判断、承压胶管或特殊用途产品法定检验、食品接触或医疗用途合规判断、特种设备相关监督检验、安全生产条件确认和客户安全件专项批准。涉及轮胎翻新、工程轮胎、高速或高承载轮胎、高压胶管、橡胶金属关键粘接件、医用或食品接触橡胶件时，应确认审核员具备对应产品族能力。

管理体系审核仅用于评价组织是否在其产品实现范围内建立并实施质量管理控制，不替代行政许可、强制性产品认证、工业产品许可、法定检验、食品接触材料符合性判断、建筑工程验收、消防审查、特种设备监督检验、政府监管、行政处罚、司法判断或客户专项验收结论。当项目涉及上述边界时，应在项目匹配阶段确认审核员分支能力和必要的技术支持。

  • 分组结论与使用口径

QG14-1 可作为质量管理体系橡胶制品制造技术领域包使用。授权时应记录审核员在新轮胎、内胎、翻新轮胎、密封件、胶管胶带、减震件、包胶衬胶和其他非轮胎橡胶制品上的实际分支能力。组内扩展应以培训、案例评审、专业面谈、见证审核或项目技术支持作为控制手段。文件维护触发条件包括：轮胎翻新模式、橡胶配方体系、主要产品族、客户安全件要求、产品认证类别、关键检测方法或上层分组使用中出现能力匹配争议。
