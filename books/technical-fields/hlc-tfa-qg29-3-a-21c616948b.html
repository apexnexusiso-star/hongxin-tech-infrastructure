  • 文件定位说明

本文件用于质量管理体系认证中 QG29-3 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦在收费或合同基础上的各类产品销售代理服务在 QMS 轴下的质量形成链、客户要求转化、关键质量特性、检验放行、记录追溯、投诉反馈和改进闭环。本文件不承担行业百科说明功能，基础行业事实由对应专业小类基础卡承载。

本组采用“统一销售代理领域包 + 商品类别分支标注 + 特殊商品边界控制 + 条件扩展”的使用口径。组内小类可以共享通用商业服务质量管理判断方法，但不得把某一商品、服务或渠道分支经历等同于另一分支完整能力；对特殊商品、复杂服务、法定接口或高价值交付，应追加分支确认。

  • 分组设立的基本逻辑

本包在 QMS 轴下的共同对象是受委托开展的客户开发、产品信息传递、订单撮合、合同协调和售后反馈接口服务。质量管理体系审核关注的核心不是商品名称或服务名称是否完全相同，而是客户需求如何被识别和转化，商品或服务对象如何受控，交易、工单或订单过程如何记录，交付前后如何检验或确认，客户反馈如何形成闭环。

本包可概括的共同质量形成链为：委托协议 -> 代理范围和产品要求识别 -> 客户或渠道开发 -> 产品资料和报价传递 -> 订单或合同协调 -> 交付接口跟踪 -> 佣金结算、投诉和反馈闭环。该链条决定了本包共享的专业能力基础，即审核员应能够围绕客户要求、商品或服务对象、过程记录、输出验证、交付确认和反馈闭环建立审核证据链。

组内差异主要来自代理商品类别和外部接口：农牧纺原料、燃料矿石金属化工、木材建材、机械设备、家居五金、纺织服装、食品烟草、其他特定产品和杂项物品的商品属性不同；含危险化学品代理具有更强边界控制要求。这些差异不否定设组，但要求本包不能按无差别能力包使用，应通过分支标注、专项确认、条件扩展和抽样控制加以处理。

边界受控关系商品或服务外部要求、法定接口、客户行业要求或外包链条改变使用边界。授权记录应写明适用边界，项目匹配时按实际业务内容确认。授权备注、合规类别清单、技术支持。

共同能力维度本包共同基础可共享的审核判断不能共享的边界
委托范围识别均以委托协议、代理范围、产品目录、区域、价格权限和客户类型为输入。可共享委托权限、合同评审、客户沟通和代理边界判断。特殊商品、独家代理、工程项目代理和跨区域代理需分支确认。
产品资料控制均需向客户传递产品规格、报价、交付条件、质量证明类别和售后信息。可共享产品资料版本、报价控制和沟通记录判断。危化、食品、机械、建材和农牧原料的资料重点不同。
客户开发和订单协调均需控制客户需求、样品或资料、商务沟通、订单确认和合同接口。可共享客户开发、订单追踪、变更和投诉处理判断。大型装备、活体动物和工程材料的技术确认深度不同。
交付接口和反馈代理方通常协调供应方和客户之间的交付、验收、投诉和售后。可共享交付接口、客户反馈和闭环处理判断。代理方责任边界与自营库存责任应区分。
  • 本体系核心控制要求

本组所称关键质量特性，是指商品或服务输出中影响客户可接受性的适配性、真实性、完整性、及时性、一致性、可追溯性、功能状态、数量准确性和售后响应。商业服务场景中的检验和放行，通常表现为订单复核、商品验收、库存盘点、称量计量、温度或效期检查、工单复核、交付签收、客户确认、主管抽查或质检记录。审核员应把这些复核和确认活动作为服务结果进入客户使用前的质量控制证据。

第一，应确认委托协议和代理权限。审核员应追溯代理范围、区域、产品类别、价格权限、客户类型、信息披露、合同签署权限、佣金结算和投诉处理责任，避免把一般业务介绍误认为完整销售代理服务。

第二，应评价产品资料和报价资料受控。代理服务质量很大程度取决于向客户传递的信息是否准确、完整、及时。对于燃料、化工、机械、建材、食品、烟草、农牧原料等商品，应确认规格、等级、型号、适用场景、交付条件和特殊说明是否与供应方资料一致。

第三，应追溯客户开发、样品或资料传递、订单确认和变更协调过程。代理组织应能说明客户需求如何记录，报价如何批准，订单或合同如何确认，供应方和客户之间的信息差异如何处理。

第四，应核查交付接口和售后反馈闭环。代理不一定控制仓储运输，但应控制其承担的协调责任，包括交付信息传递、客户投诉转交、供应方回复、补救措施和佣金或费用争议处理。

29.05.06共享纺织服装鞋革代理基础。季节波段、尺码色号、样品和渠道订货突出。应标注服饰鞋革代理分支。样品、色号、尺码配比和订单变更抽样。
29.05.07共享食品饮料烟草代理基础。保质期、温控、渠道动销和特殊商品边界突出。食品烟草代理需确认对应分支。批次效期、客户渠道、陈列要求和投诉反馈评审。
29.05.08、29.05.09共享集合类代理基础。其他特定产品和杂项物品内部跨度大。应按实际商品类别限定授权。按真实代理合同和商品资料建立分支备注。
  • 分组合理性论证结论

本组可以设立的理由在于，组内小类均以受托销售代理为共同质量形成对象，均需要控制委托权限、产品资料、客户沟通、报价订单、合同协调、交付接口、费用结算和反馈闭环。不同商品类别带来的差异可以通过商品分支标注和特殊商品专项确认控制。

因此，QG29-3 可以作为质量管理体系技术领域包使用，但其使用方式应为“统一销售代理领域包 + 商品类别分支标注 + 特殊商品边界控制 + 条件扩展”。审核员授权、项目匹配和能力扩展均应体现分支差异，不得把同包经历理解为跨全部小类的充分证明。

  • 培训、考核与作业指导书需求

本组应建立销售代理 QMS 培训，内容包括委托协议、代理权限、产品资料控制、报价和订单协调、客户沟通、合同接口、交付反馈、佣金结算、投诉处理、商品类别差异和特殊商品边界。

考核宜采用场景式题目和案例追溯题，要求审核员能够从一个真实或模拟订单、交易、工单或交付样本出发，说明客户要求识别、资源配置、关键过程控制、输出复核、交付验收、投诉反馈和纠正措施之间的证据关系。作业指导书宜提供分支化抽样路径、典型记录清单、访谈问题库和授权边界提示。

  • 常见合规义务类别与标准适用提示

本组可能涉及代理合同、商业秘密、价格和广告、消费者权益、食品烟草、危险化学品、机械装备、建材、农牧产品、活体动物检疫资料类别、知识产权、反商业贿赂、客户行业要求和跨区域销售规则等类别。文件不列具体标准编号和年份；适用性应使用机构受控的有效清单、客户合同、服务目录、项目范围和所在地监管要求确认。上述类别用于识别外部要求如何转化为客户要求、商品控制、服务过程、记录保存、客户沟通和输出复核，不替代政府许可、行政执法或客户专项验收。

  • 分组使用限制和法定边界

本组的 QMS 分组不替代特殊商品经营许可、危险化学品经营监管、食品烟草监管、动物检疫、产品准入、商业代理法律责任判断、行政执法或客户专项验收。代理组织是否承担货权、库存、运输、安装或售后责任，应按合同和实际活动确认。

管理体系审核仅用于评价组织是否在其服务范围内建立并实施质量管理控制，不替代行政许可、法定检验、行政执法、政府监管、司法判断、强制检验、产品准入、计量检定、食品药品监管、烟草专卖监管、危险化学品经营监管、特种商品管理或其他法定结论。涉及受监管资质、特殊商品、个人信息、资金、现场作业和外包服务时，应在项目匹配阶段确认审核员分支能力和必要的技术支持。

  • 分组结论与使用口径

QG29-3 可作为质量管理体系销售代理服务技术领域包使用。授权时应记录农牧纺原料、大宗工业品、危险化学品、建材、机械装备、家居五金、服饰鞋革、食品烟草、其他特定产品和杂项商品代理等分支能力。文件维护触发条件包括：代理模式、特殊商品边界、客户行业要求、产品资料传递方式或基础卡信息发生实质变化。
