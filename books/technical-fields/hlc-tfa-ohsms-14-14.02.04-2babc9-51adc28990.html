14.02.04 其他塑料制品的制造 专业小类基础卡

> 本卡为技术领域分组底层知识卡，记录不依附于特定管理体系的行业事实、过程边界、术语、产品、工艺、产业链、法规标准类别、检测计量手段和维护信息。凡涉及具体管理体系下的专业能力、抽样重点、人员授权、合格评定结论或体系风险分级的内容，应在上层分组论证文件中展开。

A2 定义与范围界定

本小类包括将热塑性或热固性塑料、改性料、填料、增强材料、色母、嵌件和辅料投入，通过注塑、挤出、吹塑、滚塑、压制、模压、发泡、热成型、焊接、粘接、表面处理、印刷、装配和检验形成未另分类塑料制品的活动。

典型产品包括日用塑料制品、家居用品、办公文教用品、工业塑料零件、电子电器塑料配件、汽车和机械配套塑料件、塑料容器非包装用途、塑料家具部件、运动休闲塑料件、实验室或医疗配套塑料件以及其他难以归入包装、建筑或板片管小类的塑料制品。

本小类是集合性小类，内部跨度明显。其底层共同点是塑料材料成型和制品交付，但具体技术命脉可能是模具注塑、嵌件包覆、外观纹理、尺寸装配、阻燃绝缘、耐冲击、滚塑大型中空、发泡轻量化或多部件装配。

A3 边界说明、相邻小类区分点和排除项

相邻活动容易混淆的原因主要区分依据本卡处理原则
14.02.01 塑料板片管壳部分产品由板片管二次加工而来是否以基础形态材料交付终端塑料零件、日用品和复杂装配件归入本卡；基础板片管壳归入 14.02.01。
14.02.02 塑料包装产品塑料盒、瓶、箱可能同时具有容纳功能主导用途是否为包装、灌装或物流周转非包装用途的塑料器具和零件归入本卡。
14.02.03 建筑用塑料制品装饰件、型材和家居件可能用途接近是否为建筑构配件或施工系统产品非建筑系统用途的塑料制品归入本卡。
电子电器制造塑料外壳和结构件用于电子电器企业主导活动是否为塑料件制造还是整机制造只制造塑料壳体或配件的归入本卡；整机装配另行识别。
汽车零部件制造汽车塑料件属于整车供应链机构分类中是否按汽车零部件单独归类若企业主导为塑料件成型，可纳入本卡；专门汽车系统件按分类规则确认。
模具制造塑料件离不开模具是否生产模具本体还是使用模具成型制品模具制造不纳入本卡。

明确排除项：

  • 塑料板、片、管、壳等基础形态产品制造。
  • 塑料包装产品制造和包装服务。
  • 建筑用塑料构配件制造和现场安装。
  • 塑料原料、改性料、母粒和化学单体生产。
  • 模具制造、电子整机制造、车辆系统件制造和医疗器械整机制造中已另有明确分类的活动。

B3 关键技术概念说明

其他塑料制品是典型集合性小类。它的共同底座是塑料成型，但不能只用“注塑、检验、包装”概括全部内容，因为精密工程件、日用品、滚塑中空件、发泡件和外观装饰件的技术难点不同。

注塑件的技术核心是材料、模具和成型窗口之间的平衡。干燥、熔体温度、注射速度、保压、冷却、浇口、模温和顶出共同决定尺寸、外观、变形和装配适配。

对于多部件塑料产品，后加工和装配同样构成制造链。超声焊接、热熔、螺钉、卡扣、嵌件和表面处理会把单件成型转化为功能性组合产品。

C2 主要功能和性能维度

本小类产品的性能维度包括尺寸精度、外观、颜色、表面纹理、耐冲击、拉伸和弯曲、刚度、耐热变形、耐磨、阻燃、绝缘、耐候、耐化学介质、装配孔位、卡扣强度、焊接强度、螺纹嵌件拉拔、跌落、气味、挥发、密度和泡孔状态。

精密塑料件重视尺寸、收缩和模具状态；日用塑料件重视外观、色差和耐冲击；电子电器塑料件重视阻燃、绝缘和装配；汽车配套塑料件重视材料认可、外观纹理和耐热；滚塑件重视壁厚和中空完整；发泡件重视密度和泡孔。

本小类的产品用途边界比过程边界更复杂。同样是注塑成型，若产品成为包装瓶盖或建筑门窗配件，可能进入其他塑料小类；若只是通用零件或未另分类日用品，则归入本卡。

D. 过程与技术

D1 主要工艺或过程流程

注塑类产品典型流程为：树脂和色母接收 -> 干燥或预混 -> 模具安装和试模 -> 注射充模 -> 保压 -> 冷却 -> 脱模顶出 -> 修边或去浇口 -> 外观尺寸检验 -> 二次加工或装配 -> 包装。

吹塑和滚塑类产品典型流程为：材料准备 -> 型坯挤出或粉料投放 -> 模具闭合 -> 吹胀或旋转加热 -> 冷却定型 -> 修边开孔 -> 泄漏或尺寸检查 -> 包装。大型中空件更强调壁厚和冷却变形。

发泡、焊接和装配类产品可包括预发泡、模压、切割、热熔、超声焊接、螺钉装配、嵌件压入、表面处理、印刷和喷涂。其共同点是从单一塑料件进一步形成具有特定使用功能的组合产品。

过程环节为什么是关键或特殊过程主要控制对象客观证据形态

表面处理和印刷外观件和标识件表面状态形成清洁、喷涂、烫印、移印、固化首件、色差、附着和外观记录。

D2 记录的是过程本身需要形成稳定输出的技术控制对象；H3 记录的是行业中客观易出问题环节及事实影响链，两者不互相替代。

D7 本小类技术链条深化说明

本小类的技术链条具有集合性，可概括为“材料选择 -> 模具或工装赋形 -> 成型窗口稳定 -> 后加工装配 -> 用途适配”。它不像包装和建筑塑料那样由单一用途牵引，而是由多行业终端需求牵引。

因此，D7 用注塑为主轴，同时保留吹塑、滚塑、发泡和装配节点。后续上层文件引用本卡时，应结合具体产品族从这条链中选取相关节点。

链条节点投入或状态技术转换输出或结果本小类特异性
用途转译客户图纸、样件或规格转化为材料、模具和过程参数制造输入集合性小类高度依赖客户用途。
材料准备树脂、改性料、色母和嵌件干燥、混合、预热和识别稳定投料材料水分和批次影响外观。
模具赋形熔体和模具型腔注射、保压、冷却和脱模塑料件模具是多数产品的核心资源。
中空或发泡型坯、粉料或发泡料吹胀、滚塑或发泡成型中空件或泡沫件非注塑路线不能被忽略。
尺寸稳定脱模后制品冷却、放置、修边和检验稳定尺寸状态收缩和翘曲是塑料件共性。
表面形成塑料件和表面材料喷涂、印刷、烫印、纹理或抛光外观件外观缺陷常独立于结构缺陷。
连接装配多个塑料件、嵌件和五金焊接、卡扣、螺钉、热熔组件产品连接界面定义功能。
用途确认成品尺寸、外观、功能、力学或特殊性能确认可交付产品不同下游参数差异大。

H3 客观存在的易出问题环节和技术敏感点

敏感点客观表现客观影响链底层记录边界
材料干燥不足银纹、气泡、降解或强度变化水分进入熔体 -> 外观和物性变化 -> 成品状态改变客观链条。
模具排气不足烧焦、缺料或困气气体滞留 -> 充模异常 -> 表面和内部缺陷注塑敏感点。

回料比例波动颜色、气味、物性和杂质变化材料来源变化 -> 熔体状态变化 -> 成品一致性变化不作体系判断。
喷涂附着不足掉漆、色差或表面颗粒表面清洁和固化变化 -> 涂层状态变化外观链条。
超声焊接虚焊组件松动、开裂或功能失效焊接能量不足 -> 界面未熔合 -> 连接状态变化装配敏感点。
滚塑壁厚不均大型中空件局部薄弱粉料分布和加热变化 -> 壁厚变化 -> 承载状态改变特殊路线敏感点。
多规格混料混标材料、颜色、标签或订单错配换模换料频繁 -> 识别失误 -> 交付信息不一致组织形态敏感点。
