A2 定义与范围界定

本小类包括将天然橡胶、合成橡胶、再生胶、补强填料、硫化体系、增塑剂、防老剂和骨架材料等，通过配方设计、混炼、挤出、压延、模压、注压、注射、连续硫化、粘接、裁切和检验制成非轮胎类橡胶产品的活动。

典型产品包括橡胶胶管、胶带、密封件、减震件、橡胶板、橡胶型材、橡胶辊、橡胶衬里、工业橡胶件、生活或运动橡胶件以及含金属、织物或塑料嵌件的橡胶复合件。

本小类的共同技术底座是配方与硫化。与塑料制品不同，橡胶在成型后通常通过硫化形成弹性网络；与轮胎不同，本小类产品形态分散，更多围绕密封、输送、减振、耐磨、绝缘、耐油、耐介质和柔性连接等功能展开。

A3 边界说明、相邻小类区分点和排除项

相邻活动容易混淆的原因主要区分依据本卡处理原则
14.01.01 橡胶轮胎和内胎均使用橡胶混炼、成型和硫化是否形成轮胎、内胎或翻新胎体结构非轮胎类胶管、胶带、密封、减震等制品归入本卡。
14.02 塑料制品制造部分热塑性弹性体外观和用途接近橡胶主材加工机理和产品弹性来源以橡胶硫化交联为主的归入本卡；热塑性树脂成型为主的归入塑料小类。
金属制品或机械部件制造橡胶件常与金属骨架、法兰、轴套或阀体组合主导增值过程是否为橡胶成型硫化金属骨架外购后包胶或粘接橡胶的，通常归入本卡；金属主体加工为主的另行识别。
胶粘剂、涂料和化学品制造橡胶制品会使用粘合剂、溶剂和处理剂最终产品是否为成型橡胶件仅生产橡胶胶粘剂、处理剂或化工助剂不纳入本卡。
橡胶修理或现场衬胶服务输送带、胶辊和衬胶设备可能现场修复是否在制造场所形成橡胶制品产品工业化制品制造归入本卡；单纯现场维修服务按服务活动识别。
医疗器械或专用产品制造部分橡胶件用于医疗或特种装备行业主管分类和产品主导功能若产品监管属性另有明确分类，应按机构分类规则单独确认。

明确排除项：

  • 轮胎、内胎、翻新轮胎和轮胎再制造。
  • 合成橡胶、橡胶助剂、炭黑等基础材料制造。
  • 以塑料树脂为主材的热塑性制品制造。
  • 橡胶制品现场安装、维护和维修服务。
  • 金属件、机械件或电气件为主、橡胶仅作辅件的产品制造。

A4 分组特征摘要

维度本小类特征上层分组调用提示
主导活动类型非轮胎类橡胶配方成型和硫化制造与轮胎共用橡胶基础，但产品功能更分散，需按密封、输送、减震、耐介质等功能族识别。
核心过程性质混炼、预成型、模压或挤出、硫化、修边、粘接、后处理和检测本小类不应被压缩成通用材料加工，应突出硫化方式和产品应用功能。
主要技术基础橡胶配方、填料分散、硫化交联、模具或口型、骨架增强、橡胶与金属或织物粘接具备塑料注塑知识不能替代橡胶硫化和粘接界面知识。
产业链段位上接橡胶材料、填料和骨架件，下接汽车、机械、矿山、化工、建筑、电子和生活消费下游用途跨度大，上层分组时可按功能和成型路线进一步识别。
典型规模跨度从大型汽车橡胶件企业到小型密封件、胶板和胶辊企业均存在规模差异会影响模具、实验室和过程记录形态。
内部差异提示胶管、胶带、密封件、减震件和胶板在骨架材料、成型方式和检验项目上不同A4 应提示上层关注产品族差异，而非只看橡胶这一共同材料。
分组比较提示与 14.01.01 共享橡胶混炼和硫化，但缺少轮胎的复合旋转结构若共组，应明确轮胎、翻新与普通橡胶件的能力边界。
分组敏感边界热塑性弹性体、包胶金属件和现场修复容易造成边界混淆应按主材、主导工艺和最终交付物判定。

A4 不是新的事实来源，而是从 C、D、E、G、H 各段提炼出的调用索引。上层文件使用本卡时，应以 A4 先形成初判，再回到 D 段过程链、G 段检测手段和 H3 客观敏感点核对证据。

B. 术语与概念

B1 专业术语和行业常用表达

术语解释本小类中的使用语境
胶料橡胶与填料、助剂混合后的加工材料配方和混炼状态决定后续硫化结果。
门尼粘度表征未硫化胶料加工流动性的指标用于判断混炼和加工适用性。
硫化橡胶分子形成交联网络的过程橡胶制品从可塑状态转变为弹性状态的核心。
焦烧胶料在加工前过早发生交联的现象会导致流动性下降和成型困难。
模压胶料在模具中受热受压成型硫化密封件、减震件和异形件常用。
注压胶料经料筒或注射系统进入模腔硫化用于批量橡胶件。
挤出硫化胶料经口型连续成型并硫化胶管、密封条和型材常用。
压延胶料通过辊筒压成胶片或贴合骨架橡胶板、胶带和骨架增强件常用。
骨架材料织物、钢丝、金属件或纤维增强材料提高强度、尺寸稳定和承载能力。
粘接体系橡胶与金属、织物或塑料结合的处理体系包胶件和复合件关键。
O形圈截面为圆形的环状密封件液压、气动和机械密封中常见。
胶管用于输送气体、液体或颗粒介质的柔性管件可含纤维或钢丝增强层。
输送带用于连续输送物料的橡胶带状产品常含织物或钢丝绳骨架。
减震橡胶利用橡胶弹性吸收振动和冲击的制品汽车、机械和建筑隔振中常见。
橡胶衬里覆盖在容器、管道或设备内壁的耐磨耐腐蚀层化工、矿山和防腐设备中常见。
后硫化成型硫化后继续热处理的过程部分橡胶材料用于稳定性能或去除挥发物。

缩略语或代号含义说明

NBR丁腈橡胶常用于耐油密封和胶管。

B3 关键技术概念说明

橡胶制品的核心技术不是简单形状加工，而是通过配方、混炼和硫化把可塑胶料转化为具有弹性、耐介质、耐磨、密封或减振功能的制品。

橡胶与骨架材料或金属嵌件的界面是本小类常见技术核心。粘接表面处理、底涂、胶料相容性、硫化压力和界面污染都会影响复合件结构稳定性。

同属其他橡胶制品，胶管、胶带、密封件、减震件和胶板的技术命脉并不相同。胶管看层间结构和爆破压力，密封件看尺寸和压缩永久变形，减震件看动静刚度，胶带看骨架强度和接头。

C2 主要功能和性能维度

本小类产品的功能维度包括硬度、拉伸强度、伸长率、撕裂强度、压缩永久变形、耐磨、耐油、耐酸碱、耐热、耐寒、耐臭氧、耐候、绝缘、阻燃、回弹、动静刚度、爆破压力、层间粘合和尺寸稳定。

不同产品族的性能主轴差异明显。密封件重视尺寸、压缩变形和介质相容性；胶管重视层间结构、耐压和接头；输送带重视骨架强度、覆盖胶耐磨和接头；减震件重视弹性、疲劳和粘接；胶板和衬里重视厚度、硬度和耐介质。

橡胶材料对储存、温度和时间敏感，未硫化胶料和成品都可能受到老化、迁移、污染或形变影响，因此批次、停放和储运状态是客观产业特征。

C3 常见产品或服务分型

分型轴主要类型差异体现对底层知识建模的意义

D. 过程与技术

D1 主要工艺或过程流程

模压或注压橡胶件典型流程为：原材料接收 -> 配方称量 -> 混炼 -> 胶料停放与复炼 -> 预成型或裁片 -> 模具准备 -> 模压或注压硫化 -> 脱模 -> 修边 -> 后硫化或表面处理 -> 尺寸、硬度、外观和物性检验 -> 包装。

挤出橡胶制品典型流程为：胶料混炼 -> 过滤或复炼 -> 挤出 -> 牵引定型 -> 连续硫化或分段硫化 -> 冷却 -> 裁切 -> 接头或后加工 -> 检验。胶管和密封条在该路线中常增加骨架编织、缠绕或在线尺寸控制。

橡胶与金属或织物复合件典型流程为：基体处理 -> 涂胶或底涂 -> 胶料贴合或装模 -> 硫化粘接 -> 后处理 -> 粘接界面、尺寸和功能检测。界面清洁和处理状态会直接传递到成品结构。

D7 本小类技术链条深化说明

本小类的技术链条可概括为“配方分散 -> 成型几何 -> 硫化交联 -> 界面或骨架复合 -> 功能验证”。与轮胎不同，它没有单一产品结构，而是围绕密封、输送、减振、耐介质等功能族分化。

因此，本卡在 D7 中同时保留模压件、挤出件和复合件的共同底层链条，并在每个节点标明其区别于塑料件和轮胎件的特异性。

链条节点投入或状态技术转换输出或结果本小类特异性
配方设计和混炼橡胶、填料、硫化体系和助剂分散、塑化和胶料状态形成可加工胶料弹性和耐介质来自硫化胶网络。
胶料停放混炼胶内应力释放和加工状态稳定待成型胶料时间和温度会改变加工窗口。
成型胶料、模具或口型模压、注压、挤出、压延或缠绕未完全硫化制品形态成型方式随产品族差异很大。
硫化成型胶料和热压环境交联反应和尺寸固定硫化胶制品不可逆过程是橡胶制品的核心。
复合界面橡胶与金属、织物或塑料基体表面处理、粘接和硫化结合复合橡胶件界面失败常不易从外观识别。
后加工硫化制品修边、打磨、清洗、涂层、裁切交付形态后处理影响外观和尺寸边界。
功能确认成品或试样尺寸、硬度、耐压、压缩、粘合或老化测试检测记录不同产品族参数差异大。
储运保持橡胶成品避光、防热、防压和防污染可交付状态橡胶老化和形变具有时间敏感性。

E3 本小类在产业链中的位置

本小类位于橡胶材料和多行业功能部件之间，是典型的材料配方到功能件转换节点。其产业链不是围绕单一终端产品展开，而是嵌入车辆、机械、建筑、化工、矿山、电子和消费品等多个下游。

这种产业位置导致同一橡胶制造底座会被不同下游重塑为不同产品族。基础卡需要保留材料、成型、硫化和界面的共同链条，同时不能抹平密封、输送、减振和耐介质之间的差异。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

敏感点客观表现客观影响链底层记录边界
