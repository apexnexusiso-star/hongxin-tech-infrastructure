17.12.03 金属丝制品、链条和弹簧的制造 专业小类基础卡

A. 标识与定位

A1 小类名称、分类代码、在分类体系中的位置

字段内容

A2 定义与范围界定

本小类是指对金属线材或金属丝进行拉拔后续加工、编织、捻制、焊接、弯曲、卷绕、成形、热处理、表面处理和装配，制造金属丝制品、链条和弹簧的活动。其产品既可作为独立金属制品，也可作为机械、建筑、交通、家具、电子、电器、矿山和包装等行业的功能部件。

典型产品包括金属丝网、焊接网、编织网、钢丝绳、钢绞线、刺绳、金属筛网、金属网篮、链条、传动链、起重链、装饰链、链节、压缩弹簧、拉伸弹簧、扭转弹簧、片簧、碟簧、卡簧、异形弹簧和弹簧组件。

本小类不包括钢丝或线材的冶炼轧制主过程、紧固件和螺杆产品制造、机加工零件制造、金属结构件制造、汽车悬架总成或机械成套设备制造、非金属绳网制造和单纯贸易。

B3 关键技术概念说明

金属丝制品的基础是线材直径、强度、表面和成形状态。丝网关注网孔和焊点，钢丝绳关注捻制和股线，链条关注链节连接和节距，弹簧关注弹性变形和疲劳。

弹簧制造的关键不只是绕成形状，而是让材料在规定载荷下产生可重复弹性变形。线径、圈径、圈数、热处理、表面缺陷和残余应力共同决定弹簧状态。

链条和钢丝绳涉及承载和连接路径。链节焊接、热处理、节距、表面防护、绳股捻距和润滑状态会影响使用中的运动和承载。

C4 典型产品族专业差异补充

本小类内部跨度很大，从简单丝网到承载链条、钢丝绳和精密弹簧，过程机理并不相同。底层识别应先判断产品是否主要依赖线材成形、焊点连接、捻制结构、链节传力或弹性储能，再进一步描述材料和表面状态。

产品族过程差异对底层识别有价值的专业信息
编织网、筛网和过滤网经纬线编织、网孔控制、裁切包边和表面防护构成主线。线径、网孔、编织方式、平整度和边部处理是识别抓手。
焊接网和护栏网矫直切断、排焊、成片、折弯、喷涂或镀锌突出。焊点强度、网片尺寸、涂层和安装接口需要描述。
钢丝绳和绞线单丝、股绳、捻制、芯材、润滑、预张拉和端部处理相互关联。股数、捻向、捻距、断丝、润滑和拉力状态是主要信息。
传动链和输送链链板冲压、销轴套筒、热处理、装配、预拉和润滑构成主线。节距、铰接间隙、硬度和运转状态决定产品识别。
起重链和承载链圆环链焊接、热处理、校准、拉伸和表面处理突出。焊口、环尺寸、拉力和永久变形状态应与装饰链区分。
压缩、拉伸和扭转弹簧卷簧、去应力、端面磨削、热处理、表面处理和载荷分选形成。自由高度、圈数、刚度、端部形态和旋向是识别抓手。
异形线制品和网篮挂钩线材折弯、焊接、夹具定位、表面处理和装配配套较多。几何形状、焊点、支撑面、毛刺和包装防变形需要描述。

D. 过程与技术

D1 主要工艺/过程流程

`mermaid flowchart LR A["线材/图纸/性能要求"] --> B["矫直、清理和材料确认"] B --> C["编织/焊网/捻绳/制链/卷簧"] C --> D["焊接、端部处理或整形"] D --> E["热处理、去应力或表面处理"] E --> F["尺寸、载荷和外观检测"] F --> G["包装、防锈、交付"] `

丝网生产包括金属丝矫直、编织或焊接、裁切、整平和表面处理。链条生产包括线材成形、链节弯制、焊接、热处理、校准和表面处理。弹簧生产包括线材送线、卷簧、切断、端面磨削、去应力回火、抛丸或镀层、载荷检测和包装。

D1.1 金属丝网和钢丝绳过程深度

金属丝网分为编织网、焊接网、冲孔网配套线制品和筛网等类型。编织网关注经纬丝张力、网孔尺寸、边部收口和卷绕平整；焊接网关注焊点电流、压力、焊接节距和网片平面度；筛网和过滤网还关注丝径、开孔率、表面毛刺和堵孔状态。网类产品常以大卷或网片交付，裁切、边缘处理和包装防变形会影响后续安装或使用。

钢丝绳制造通常包括钢丝准备、捻股、合绳、润滑、预变形、定径、切断和端部处理。其核心参数包括丝径、股数、捻向、捻距、绳芯、润滑脂和破断拉力。绳股张力不均、捻距漂移、断丝、压伤或润滑不足，会改变钢丝绳的柔性、承载和磨损状态。

D1.2 链条和弹簧过程深度

链条制造通常经历线材或板材成形、链节弯制、焊接或铆接、热处理、校准拉伸、表面处理和润滑包装。传动链需要关注内外链板、销轴、套筒、滚子、节距和灵活性；起重链需要关注链环焊缝、热处理、校准载荷和表面裂纹；输送链还涉及附件、弯板和耐磨状态。

弹簧制造从线材送线和卷绕开始，随后进行切断、端面磨削、去应力回火、抛丸强化、表面处理、载荷检测和包装。压缩弹簧关注自由高度、圈径、端面垂直度和刚度；拉伸弹簧关注钩环形状和初拉力；扭转弹簧关注臂角、扭矩和旋向；碟簧和片簧则更接近冲压成形和热处理组合。

D1.3 疲劳和表面状态的共性

线制品、链条和弹簧普遍受到表面缺陷和反复载荷影响。划伤、压痕、脱碳、腐蚀坑、镀层裂纹和焊点缺陷都可能成为应力集中位置。抛丸、去应力回火、倒角、润滑、防锈和包装不是附属工作，而是延缓疲劳和腐蚀路径的重要后段过程。

D6 典型工艺路线识别提示

本小类应按线材成形后的主导功能识别路线。丝网、钢丝绳、链条和弹簧在材料处理、连接方式和受力机理上差异明显。

路线类型典型识别信息与其他路线的差异
编织网路线线材、编织机、网孔、裁边、整平和表面防护。以网面几何连续性为主。
焊接网路线矫直切断、排焊、网片尺寸、折弯和涂覆。焊点连接和网片安装接口突出。
钢丝绳路线单丝、股绳、芯材、捻制、润滑、预张拉和端部。股结构和破断拉力是独有识别点。
链条路线链板、销轴、套筒、滚子、装配、预拉和润滑。节距和铰接状态决定传动连续性。
起重链路线圆环成形、焊接、热处理、校准和拉伸。焊口和永久变形状态突出。
弹簧路线卷簧、去应力、端面、热处理、表面处理和载荷分选。弹性储能和载荷曲线是主要差异。
异形线制品路线折弯、焊接、夹具定位、装配和表面保护。图纸和工装夹具对形状一致性影响明显。

E. 产业链与边界

E1 上游供应

上游包括线材、钢丝、弹簧钢丝、不锈钢丝、镀层材料、热处理资源、表面处理资源和检测设备。线径、强度、表面缺陷和镀层状态会直接传递到制品。

E2 下游应用/客户

下游包括机械、汽车、建筑、矿山、输送设备、家具、电子电器、五金、农业、包装、过滤和防护设施。

E3 本小类在产业链中的位置

本小类位于线材材料之后，是把线材转化为柔性连接、弹性元件、网孔结构和链式传动承载部件的制造环节。

E4 常见委外/外包环节

委外环节常见原因边界提示
热处理弹簧和链条需要专用炉可作为后段接口。
表面处理镀锌、喷涂、防锈专业化常由外部处理企业完成。
载荷和疲劳检测设备投入大可由外部检测资源完成。
端部附件套环、吊钩、端子专业化作为配套输入。

E5 典型接口资料与实物流转补充

本小类与线材供应、热处理、表面处理、端部装配和下游传力使用场景连接紧密。底层记录应说明线材状态和后续功能接口。

接口环节常见资料或实物识别价值
线材输入钢丝、弹簧钢丝、不锈钢丝、镀锌丝、铜铝丝和强度信息。决定成形回弹、拉力和表面状态。
工装和设备编织机、排焊机、捻绳机、制链机、卷簧机和专用夹具。反映产品主导路线。
热处理接口去应力、淬火回火、表面硬化和校准。反映弹簧、链条和承载件的状态来源。
表面处理接口镀锌、喷涂、发黑、润滑、防锈和包装。反映耐蚀和运动接触状态。
端部和附件绳套、压套、挂钩、链节连接、弹簧端部和固定件。反映产品与使用场景的连接方式。
下游使用筛分、防护、起重、传动、缓冲、复位和定位。反映不同产品族的功能边界。

G3 典型检测组合与适用对象

金属丝、链条和弹簧产品的检测组合随“受力方式”变化明显。筛分防护类看几何和表面，承载传动类看力学和连接状态，弹性件看载荷曲线和疲劳路径。

适用对象常见检测组合识别意义
编织网和筛网线径、网孔、平整度、边部、断丝、表面镀层和外观。反映筛分或防护面的几何连续状态。
焊接网和护栏网网片尺寸、焊点拉脱、折弯角度、涂层、锌层和安装孔位。反映网片连接和围护安装状态。
钢丝绳直径、股数、捻距、破断拉力、断丝、润滑、端部压套和表面状态。反映绳股结构和传力状态。
传动链节距、销轴硬度、链板厚度、装配间隙、预拉伸和运转试验。反映链节连续传动和铰接状态。
起重链环尺寸、焊口、拉伸、永久变形、硬度、表面裂纹和标识。反映承载环链的结构保持状态。
弹簧线径、自由高度、圈数、垂直度、刚度、载荷、疲劳和表面。反映弹性储能件的几何与力学状态。
异形线制品外形尺寸、焊点、毛刺、承载、表面层和包装变形。反映定制线材小件的成形和装配接口。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类内部跨度明显。普通丝网和小弹簧生产较成熟，精密弹簧、起重链条、钢丝绳和高疲劳产品技术复杂度较高。自动化程度从单机卷簧和人工裁网到高速制链、全自动弹簧机和连续焊网线均有分布。

H2 典型组织形态

组织形态典型特征常见资源配置
小型弹簧厂多品种小批量卷簧机、回火炉、弹簧试验机。
金属网厂网孔和规格多编织、焊网、裁切和表面处理。
链条企业传动或起重链专业化制链、焊接、热处理和拉力检测。
钢丝绳企业绳股结构和拉力突出捻股、合绳、润滑和拉力检测。
综合线制品企业异形丝件和五金配套线材成形、焊接、装配和包装。

H4 典型组织形态差异补充

本小类组织形态高度分化。丝网厂、钢丝绳厂、链条厂、弹簧厂和异形线制品厂通常需要分开识别。

组织形态典型表现技术识别提示
丝网企业编织、焊网、裁切、包边和表面处理为主。网孔、线径和边部状态突出。
钢丝绳企业股绳、捻制、润滑、预张拉和端部处理资源明显。捻距、断丝和拉力信息突出。
链条企业链板冲压、销轴、装配、热处理和预拉较多。节距、硬度和运转状态需要描述。
起重链企业焊接环链、热处理、拉伸和校准资源突出。焊口、拉伸和永久变形信息突出。
弹簧企业自动卷簧、去应力、端面磨削和载荷分选较多。刚度、自由高度和疲劳信息较有识别价值。
异形线制品企业小批定制、折弯焊接和表面处理并存。图纸、夹具和包装防变形是识别重点。

H3 客观存在的易出问题环节/技术敏感点

敏感点客观影响链
线径和强度波动线材输入偏差 → 成形回弹和载荷状态变化 → 网孔、节距、刚度或拉力波动。
成形回弹未补偿卷簧、折弯或链节成形参数偏差 → 几何尺寸回弹 → 配合和功能状态偏移。
焊点或链节连接不连续焊接参数或接头状态异常 → 局部强度不足 → 拉伸或运动中失效路径形成。
热处理不足或过度温度时间偏差 → 残余应力和硬度状态变化 → 永久变形、脆裂或疲劳波动。
表面缺陷残留划伤、锈蚀或镀层不连续 → 应力集中或腐蚀路径形成 → 使用寿命变化。
包装混规格多规格小件识别不足 → 线径、长度或刚度混入 → 下游装配状态受扰动。
钢丝绳捻距和张力不均股线张力或合绳状态偏移 → 绳股受力分配变化 → 局部磨损、断丝或伸长路径形成。
弹簧端面和旋向错误端面磨削、旋向识别或包装标识异常 → 装配受力方向变化 → 倾斜、卡滞或载荷状态异常。
链条节距累计偏差单节尺寸和校准状态轻微偏移 → 多节累计后总长变化 → 啮合、输送或吊装接口受扰动。

H3 只记录行业中客观存在的敏感点及事实因果链，不对其在任何上层视图中的重要性作判断。
