  • 文件定位说明

本文件用于环境管理体系认证中 EG29-2 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦汽车与摩托车保养维修服务在环境管理体系轴下的维修服务环境因素、油液和危废、清洗废水、喷涂废气、废旧件和外包处置，不承担行业百科说明功能；基础行业事实由对应专业小类基础卡承载。

本组采用“并列分支 + 维修过程专项确认”的使用口径。组内小类可以共享本体系轴下的基础判断方法，但不得把某一分支经历等同于另一分支完整能力。对污染源、危险源、外部合规接口、客户现场或外包链条发生实质变化的情形，应在授权和项目匹配阶段追加分支确认。

  • 技术领域包构成

本技术领域包包括 2 个专业小类。下表仅列示本组在本体系轴下的调用范围和分组边界，专业小类的完整定义、产业链、术语和基础工艺知识由基础卡提供。

小类代码小类名称主导活动类型主要环境因素载体分组边界提示
29.02.00汽车的保养和修理汽车维修办公能源、包装、运输、退换货和废弃物。按实际商品和服务边界确认。
29.04.00摩托车的销售、保养、维修及零部件和配件的销售摩托车复合服务办公能源、包装、运输、退换货和废弃物。按实际商品和服务边界确认。
  • 分组设立的基本逻辑

本组在本体系轴下的共同对象是围绕车辆诊断、保养、维修、清洗、零部件更换、钣喷和修后交付形成的维修服务活动。分组判断的核心不是小类名称是否相近，而是环境因素、污染源、污染物、废水、废气、固体废物、监测、外包处置和合规义务的形成机理、控制路径和审核证据是否足够接近。

本组可概括的共同证据链为：接车和故障确认 -> 工单开立 -> 维修方案 -> 油液和备件准备 -> 拆装维修或钣喷清洗 -> 修后验证 -> 废油废件收集 -> 客户交付和投诉处理。该链条决定了审核员可以共用的专业能力基础，也决定了现场抽样时应从源头识别、过程控制、记录追溯、异常处置和改进闭环几个方向建立证据。

汽车和摩托车在车型结构、维修深度、油液用量、试车方式和维修场地规模上存在差异。这些差异不否定设组，但要求本组按条件授权和边界受控方式使用。

  • 组内关系结构与授权后果
关系类型含义授权后果典型控制方式
共同基础关系组内活动均需要识别环境因素、污染源、污染物、资源能源消耗、废水、废气、固体废物、外包处置和合规义务。可共享基础 EMS 审核能力，但应确认具体商品、服务场所和外包链条。资料评审、环境因素清单复核、现场走查、废物流向追溯。
并列分支关系同属本环境领域包，但商品属性、场所形态、储存条件、废物类别或客户现场接口不同。授权应保留分支标注，不把单一分支经历理解为全分支能力。分支面谈、样本追溯、项目匹配备注。
条件扩展关系相邻分支具备相同控制基础，但目标分支存在专门污染源、危险废物、冷链、燃料、化学品或维修废物。完成补充培训、案例评审、专业面谈或见证审核后方可扩展。培训考核、案例评审、见证审核。
专项确认关系涉及燃料、危险化学品、药品、冷库、废旧材料、制冷剂、油液、电子废弃物等高边界环境因素。项目使用前应确认实际经营内容和污染控制责任，必要时配置技术支持。专项问询、合同边界确认、外包方证据复核。
不可替代关系纯办公、纯代理或普通零售经历不能证明燃料经营、维修服务、废旧材料或化学品经营的环境控制能力。不得作为目标分支能力的单独依据。补充目标经历或限定项目类型。
边界受控关系实际业务包含仓储、运输、维修、拆解、加注、清洗、冷链或客户现场服务时，环境因素边界发生变化。授权和项目匹配应按实际活动边界使用。授权备注、现场边界确认、外包链条核验。
维修专项关系车辆维修经历可提供维修环境因素识别基础，但钣喷、新能源车、制冷剂、清洗和废油废件控制需要目标场景确认。授权应标注汽车、摩托车、钣喷或新能源等分支。维修工单追溯、危废暂存点走查、试车和钣喷现场确认。
  • 共同过程与专业机制分析

本组的环境因素直接依附于维修过程，污染源比一般商贸服务更明确。接车诊断决定维修范围，拆装维修产生废旧件、油液、滤芯、蓄电池、轮胎和包装物，清洗产生含油废水，钣喷产生漆雾和有机废气，空调维修可能涉及制冷剂回收，修后试车产生尾气和噪声。环境管理的有效性取决于工单是否能够把维修项目、材料消耗、废物产生和处置去向串成闭环。

过程环节环境因素和污染源形成机制审核关注的证据
接车诊断识别维修项目、车辆类型、油液系统、空调系统、钣喷需求和清洗需求。接车单、工单、客户确认、初检记录。
维修实施拆装、换油、轮胎、电气、钣金、喷涂和清洗形成废油、废滤芯、废件、废水、废气和噪声。维修记录、材料领用、设备点检、现场分区。
危废和一般废物废矿物油、废油桶、废滤芯、废蓄电池、废漆渣、废活性炭、废轮胎和废包装分类暂存。危废台账、暂存点标识、转移或处置凭证、外包协议。
修后验证试车、检测和交付可能产生尾气、噪声和异常返工。试车记录、交付确认、返修和投诉记录。
  • 本体系核心控制要求

第一，应以维修工单为主线追溯环境因素。审核员不宜只看危废台账，应从一张真实工单出发，核对维修项目、材料领用、废旧件产生、废油收集、清洗或喷涂过程、修后交付和废物去向是否一致。

第二，应重点确认含油和含化学品废物控制。废机油、废滤芯、废油桶、制动液、冷却液、蓄电池、废漆渣、废活性炭、擦拭物和含油污泥是汽车维修 EMS 审核的关键证据，应检查分类、容器、标识、防渗、防雨、防混放和外包处置。

第三，应区分机械维修、钣喷、清洗、空调维修和新能源车维修。不同维修项目的污染源不同，若组织声称覆盖所有维修服务，应有相应场地、设备、人员和处置路径；若仅开展快修保养，授权和审核结论应按实际范围限定。

第四，应关注摩托车复合服务的边界。摩托车小类包含销售、保养、维修和配件销售，EMS 抽样应区分销售门店和维修工位，不能用销售资料替代维修废物、油液和试车控制证据。

  • 差异分析与可接受性判断

本章用于说明组内小类为什么能够设为同一技术领域包，同时说明哪些差异需要通过授权备注、专项确认或现场抽样补足。差异分析不用于弱化专业能力要求，而是用于把能力边界写清楚。

小类共同基础主要差异边界控制可接受理由抽样落点
29.02.00 汽车的保养和修理均通过客户需求、商品或服务对象、仓储交付、外包运输、现场服务和废弃物流形成环境因素识别证据。以一般固体废物和资源消耗为主。按实际商品和服务边界确认。可共用环境因素识别、污染源追溯、废物流向确认和合规义务转化方法。抽取 汽车维修 样本，追溯污染源、污染物、废水或固体废物去向、外包处置和监测记录。

  • 分组结论

EG29-2 组内小类均以车辆或摩托车保养维修为污染源形成核心，环境因素集中在油液、废旧件、清洗废水、喷涂废气、维修噪声、制冷剂、试车尾气和外包处置。汽车和摩托车的维修对象不同，但工单驱动、材料领用、维修实施、废物分类、修后验证和客户交付的证据链一致，因此可以设为同一技术领域包，并通过分支标注控制差异。

因此，EG29-2 可以作为环境管理体系技术领域包使用，使用方式为“并列分支 + 维修过程专项确认”。审核员授权、项目匹配和能力扩展均应体现分支差异，不得把同包经历理解为跨全部小类的充分证明。

  • 审核员共同能力评价与条件授权

本章用于界定本技术领域包可共享的共同能力，以及不同分支在授权、项目匹配和能力扩展时需要追加确认的内容。

能力要素评价内容可接受证据授权控制
环境因素识别识别服务场所、仓储、运输、维修、燃料、化学品、废弃物和外包链条形成的环境因素。环境因素清单、现场走查记录、外包合同、废物转移或处置记录。按分支标注；特殊商品需专项确认。
污染源与污染物判断判断废水、废气、固体废物、危险废物、油气、异味、粉尘、制冷剂和化学品泄漏来源。现场照片、台账、监测或检查记录、应急物资、处置凭证。燃料、化工、维修和冷链类项目需目标经历或专家支持。
合规义务转化将许可、产品经营、废物处置、排放、运输和客户要求转化为组织内部控制。合规义务清单、合同评审、供应商评价、外包方资质和内审记录。不替代行政许可判断，仅评价管理体系控制。
运行控制与应急检查泄漏预防、废物分类、外包处置、清洁消毒、冷链、维修废物和异常处置。运行规程、点检记录、培训记录、应急演练、异常整改记录。按实际活动抽样，不能用纯办公经历替代现场经营。
绩效与改进评价监测、巡检、废物去向、能资源消耗和投诉事件的趋势与改进。目标指标、统计报表、纠正措施、管理评审输入。证据应能追溯到具体场所或服务样本。

能力扩展应采用“基础经历确认、目标分支差异培训、案例评审或专业面谈、必要时见证审核、授权记录标注”的路径。对燃料、危险化学品、车辆维修、个人家庭用品维修、冷链、废旧材料和含客户现场复杂接口的项目，应在项目匹配阶段再次确认适用边界。

  • 审核关键要点与抽样路径

本组应至少抽取一个保养或机修工单、一个废油废件处置样本、一个清洗或钣喷样本；若组织开展新能源车、空调制冷剂、事故车钣喷或摩托车维修，应追加对应场景。

  • 培训、考核与作业指导书需求

培训应覆盖车辆维修环境因素识别、油液和危险废物管理、钣喷废气、清洗废水、制冷剂、废旧件和修后试车控制。对仅有商贸或普通服务经历的审核员，应通过维修工单案例和现场见证确认其能够追溯污染源和废物流向。

考核宜采用场景题、案例追溯题和边界判断题，要求审核员能够从一个真实或模拟项目出发，说明本体系轴下的识别、评价、控制、记录、异常处置和改进之间的证据关系。作业指导书应提供分支化抽样路径、记录清单、访谈问题和授权边界提示。

  • 常见合规义务类别与标准适用提示

常见合规义务类别包括机动车维修经营管理、危险废物贮存和转移、废水接管或排放、废气和噪声控制、油品和化学品储存、消防和应急、外包处置方控制、客户和物业方要求。本文件不列入具体标准编号和年份；适用性应使用机构受控的有效清单、客户合同、服务目录、项目范围和所在地监管要求确认。上述类别用于识别外部要求如何转化为管理体系控制，不替代政府许可、法定检验、行政执法或客户专项验收。

  • 使用限制和法定边界

本组不覆盖汽车制造、零部件制造、深度拆解再制造、报废机动车回收拆解或燃料零售加注。若维修组织实际开展上述活动，应另行确认对应技术领域能力。

管理体系审核仅用于评价组织是否在其服务范围内建立并实施相应管理控制，不替代行政许可、法定检验、行政执法、政府监管、司法判断或强制性专项评价。涉及受监管资质、特种商品、危险化学品、燃料、药品、医疗器械、个人信息、资金信用、道路运输、客户现场和外包服务时，应在项目匹配阶段确认审核员分支能力和必要的技术支持。

  • 文件维护与复评触发
触发事项复评关注点处理方式
新增钣喷或喷涂废气、漆渣、废活性炭和喷漆房运行控制。追加专项培训和现场见证。
新增新能源车维修高压电系统、动力电池和相关废物边界。复核分支授权和专家支持。
