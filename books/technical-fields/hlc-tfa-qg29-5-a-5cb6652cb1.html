  • 文件定位说明

本文件用于质量管理体系认证中 QG29-5 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦消费电子、家电园艺、鞋革、家具、钟表珠宝及其他个人家庭用品修理服务在 QMS 轴下的质量形成链、客户要求转化、关键质量特性、检验放行、记录追溯、投诉反馈和改进闭环。本文件不承担行业百科说明功能，基础行业事实由对应专业小类基础卡承载。

本组采用“统一家庭用品修理领域包 + 物品类别分支标注 + 高价值/电气/结构专项确认 + 条件扩展”的使用口径。组内小类可以共享通用商业服务质量管理判断方法，但不得把某一商品、服务或渠道分支经历等同于另一分支完整能力；对特殊商品、复杂服务、法定接口或高价值交付，应追加分支确认。

  • 分组设立的基本逻辑

本包在 QMS 轴下的共同对象是客户交付的个人或家庭用品故障、损坏、磨损、外观缺陷或功能异常的修复服务。质量管理体系审核关注的核心不是商品名称或服务名称是否完全相同，而是客户需求如何被识别和转化，商品或服务对象如何受控，交易、工单或订单过程如何记录，交付前后如何检验或确认，客户反馈如何形成闭环。

本包可概括的共同质量形成链为：客户送修或上门需求 -> 物品接收和状态记录 -> 故障或损坏诊断 -> 报价和维修方案确认 -> 备件或材料准备 -> 维修实施 -> 功能、外观或适配确认 -> 交付和质保反馈闭环。该链条决定了本包共享的专业能力基础，即审核员应能够围绕客户要求、商品或服务对象、过程记录、输出验证、交付确认和反馈闭环建立审核证据链。

组内差异主要表现为被修理物品的材料、功能、价值和验证方式不同。消费电子和家电强调功能、电气和数据；鞋革强调材料、粘接、缝补和外观；家具强调结构、承重和表面；钟表珠宝强调精密、高价值和交接保管；其他家庭用品属于集合类，应按实际对象限定。这些差异不否定设组，但要求本包不能按无差别能力包使用，应通过分支标注、专项确认、条件扩展和抽样控制加以处理。

  • 专业小类关系类型与授权后果
关系类型含义授权后果典型控制方式
共同基础关系组内活动均以客户需求、商品或服务对象、交易或工单记录、交付确认和反馈闭环为质量形成基础。可简化通用商业服务过程、客户沟通、记录追溯和服务评价等基础能力评价，但仍需确认目标分支经历。资料评审、案例判断、专业面谈、现场样本追溯。
并列分支关系同属本技术领域包，但商品属性、服务对象、过程重点、设施设备或合规接口不同。应记录实际分支能力，不把同包经历理解为全分支能力。分支标注、限定使用、项目技术支持。
条件扩展关系已具备相邻分支能力，具有扩展基础，但目标分支仍有专门商品知识、服务过程或证据要求。完成培训、考试、案例评审、专业面谈、见证审核或技术支持后方可扩展。培训考核、案例评审、见证审核、专家确认。

不可直接替代关系相关商业服务经历不足以证明目标分支的质量形成链能力。不得作为目标能力的单独授权依据，应补充目标经历或限定项目类型。重新评价、补充经历、限定项目类型。
边界受控关系商品或服务外部要求、法定接口、客户行业要求或外包链条改变使用边界。授权记录应写明适用边界，项目匹配时按实际业务内容确认。授权备注、合规类别清单、技术支持。
电子电器修理与普通物品修理均共享接收、诊断、维修、确认和交付基础。电子电器涉及电气安全、功能测试和客户数据，应专项确认。维修工单、功能复测和数据交接记录追溯。
高价值物品修理钟表、珠宝和部分高价值物品修理强调交接、保管、证书和精密作业。不得仅凭普通修理经历承担高价值物品项目。专项面谈、交接保管记录和案例评审。
集合类其他家庭用品与各类修理共享服务过程，但对象跨度大。仅按已确认具体物品类别使用。授权备注和项目匹配确认。
  • 本体系共同能力基础
共同能力维度本包共同基础可共享的审核判断不能共享的边界
客户财产接收均需登记客户物品、状态、附件、瑕疵、客户要求、报价和交付期限。可共享接收、拍照、编号、保管和客户确认判断。高价值珠宝、数据设备、家具上门和大型家电附件需分支确认。
诊断和方案确认均需判断损坏或故障原因，形成维修方案和报价。可共享诊断、客户授权、变更沟通和方案记录判断。电路诊断、机芯、防水、结构承重和皮革染色差异明显。
维修实施和材料备件均需控制备件、材料、工具、作业人员和过程记录。可共享备件适配、材料批次、工艺过程和异常处置判断。电子元件、电气部件、家具五金、珠宝镶嵌和鞋革材料不能互相替代。
修后确认和放行均需通过功能、外观、尺寸、牢固度、防水、承重或客户试用确认修复结果。可共享修后检查、客户验收和质保承诺判断。电气安全、防水测试、机芯精度、承重结构和数据完整性需专项确认。
返修和客户反馈均需处理返修、投诉、质保和再次维修记录。可共享返修闭环、原因分析和能力改进判断。高价值物品争议和数据损失投诉应提高控制深度。
  • 本体系核心控制要求

本组所称关键质量特性，是指商品或服务输出中影响客户可接受性的适配性、真实性、完整性、及时性、一致性、可追溯性、功能状态、数量准确性和售后响应。商业服务场景中的检验和放行，通常表现为订单复核、商品验收、库存盘点、称量计量、温度或效期检查、工单复核、交付签收、客户确认、主管抽查或质检记录。审核员应把这些复核和确认活动作为服务结果进入客户使用前的质量控制证据。

第一，应确认客户物品接收和状态记录。修理服务的输入不是普通商品，而是客户财产；接收时应记录物品名称、型号、数量、附件、现有瑕疵、客户诉求、预计交付和保管方式。对高价值物品、带数据设备和大型物品，应保留更完整的交接证据。

第二，应评价诊断、报价和客户授权。电子产品、家电、鞋革、家具、钟表珠宝的故障和损坏判断方法不同，但均应形成可追溯的维修方案。维修范围变更、增加费用或无法修复时，应有客户确认。

第三，应追溯维修过程和备件材料控制。审核样本应覆盖备件或材料来源、适配性、维修人员能力、工具设备、过程记录和异常处置。电气部件、机芯零件、家具五金、皮革染料、胶粘剂和装饰材料的控制证据不同。

第四，应核查修后确认和交付。消费电子应关注功能复测和数据交接；家电园艺设备应关注试机和安全说明；鞋革应关注粘接、缝补和外观；家具应关注结构牢固和表面效果；钟表珠宝应关注机芯、防水、镶嵌、成色和高价值交接。

第五，应评价返修和投诉闭环。典型问题包括故障未排除、外观色差、粘接脱落、结构松动、防水失效、数据丢失、珠宝镶嵌松脱、维修周期延误和客户财产争议。审核应追溯登记、原因、补救、客户沟通和防止再发生。

  • 分小类或内部路线差异分析
小类/路线与本包共同基础主要差异差异对能力授权的影响控制方式
29.22.01 消费用电子产品的修理共享接收、诊断、维修、复测和交付基础。数据备份、电子元件、屏幕、电池、功能复测和客户数据突出。应标注消费电子分支。抽取一项电子产品维修，追溯数据告知、配件、功能测试和交付。
29.22.02 家用电器、家庭及园艺设备的修理共享维修工单和修后确认基础。上门维修、制冷、电机、电热、园艺机械和安全试机突出。电气和大型家电维修需专项确认。上门工单、试机、配件、客户签收和返修记录抽样。
29.22.03 鞋类及皮革制品的修理共享客户财产接收、材料和外观确认基础。鞋底鞋跟、皮革修补、染色、缝补和护理突出。可作为普通物品修理分支，不覆盖电子或钟表。鞋革维修工单、材料、外观确认和返修记录抽样。
29.22.04 家具及家居摆设的修理共享接收、诊断、材料和交付基础。结构加固、五金更换、表面修补、上门作业和承重突出。结构性家具维修需专项确认。家具维修方案、五金材料、牢固度确认和客户签收抽样。
29.22.05 手表、钟表和珠宝首饰的修理共享客户财产交接、维修和交付基础。高价值、机芯、防水、镶嵌、成色、证书和保管突出。属于专项确认路线。交接保管、机芯或镶嵌维修、防水或外观确认和客户签收抽样。
29.22.06 其他个人及家庭用品的修理共享小件家庭用品修理服务过程基础。集合类跨度大，应先识别主属性并排除相邻修理小类。仅按实际物品类别限定使用。按真实工单确认物品类别、维修方法、材料和交付。
  • 分组合理性论证结论

本组可以设立的理由在于，组内活动均以客户财产修复为共同质量形成对象，均需要控制接收登记、诊断报价、客户授权、备件材料、维修实施、修后确认、交付和返修闭环。不同物品类别导致维修技术和验证方式不同，可通过物品类别分支标注、高价值或电气结构专项确认控制。

因此，QG29-5 可以作为质量管理体系技术领域包使用，但其使用方式应为“统一家庭用品修理领域包 + 物品类别分支标注 + 高价值/电气/结构专项确认 + 条件扩展”。审核员授权、项目匹配和能力扩展均应体现分支差异，不得把同包经历理解为跨全部小类的充分证明。

抽样场景现场必看记录必查纵向追溯路径追问方向

  • 能力扩展与条件授权
起点能力目标能力可扩展依据必须补充确认授权限制
鞋革或普通物品修理消费电子或家电修理共享接收、工单、维修和交付基础。电气安全、功能测试、备件适配、数据告知和试机案例。未确认前不得用于电子电器修理项目。

本组的 QMS 分组不替代产品安全法定判断、特种设备或强制检测、珠宝鉴定结论、数据恢复法律责任判断、消费者争议行政处理、司法判断或客户专项验收。涉及高价值物品、数据设备、电气安全、承重结构、防水机芯和复杂上门服务时，应确认对应分支能力。
