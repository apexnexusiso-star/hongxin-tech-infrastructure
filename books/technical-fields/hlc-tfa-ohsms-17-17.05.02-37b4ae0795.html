17.05.02 钢的铸造专业小类基础卡

A. 标识与定位

A1 小类名称、分类代码、在分类体系中的位置

字段内容
专业小类编码17.05.02
专业小类名称钢的铸造
对应分类基础参考国民经济行业分类中铸钢件生产活动，并结合机构受控技术领域分类使用
上位技术领域金属铸造及基础零部件成形
本卡定位专业小类底层知识卡，用于沉淀铸钢件生产的行业事实、技术过程、边界、检测手段和基础信息

17.05.02 钢的铸造，是以钢液为主要金属材料，通过熔炼、精炼、脱氧、合金化、造型制芯、浇注、凝固、落砂清理、热处理、焊补或整修、检验和必要初加工，形成铸钢件、铸钢坯件或铸钢基础零部件的生产活动。本小类的对象是钢液在铸造工艺条件下形成特定形状和组织的过程。

铸钢件常用于矿山、水泥、电力、船舶、阀门、泵、铁路、工程机械、冶金装备、压力设备、耐热耐磨部件和大型承载结构件等领域。与铸铁相比，铸钢通常不以石墨形态作为材料组织基础，而更强调钢液洁净度、脱氧状态、合金元素、凝固收缩、热处理组织、焊补修复和力学性能。与锻件和焊接结构件相比，铸钢件的核心特征是通过液态金属充型和凝固直接形成复杂形状。

A2 定义与范围界定

钢的铸造通常指以废钢、返回料、合金料、生铁或其他金属炉料为投入，经电弧炉、感应炉、精炼炉或其他熔炼设备形成钢液，通过脱氧、脱硫、合金化、温度调整、镇静、扒渣、取样和浇注，形成碳素铸钢、低合金铸钢、高合金铸钢、不锈铸钢、耐热铸钢、耐磨铸钢和其他铸钢件的活动。

本小类覆盖砂型铸钢、熔模铸钢、壳型铸钢、消失模铸钢、离心铸钢、树脂砂铸钢、水玻璃砂铸钢和大型铸钢件生产等多种路线。产品既可以是毛坯铸钢件，也可以是经清理、热处理、焊补、粗加工或防护处理后的铸钢件，只要主导活动仍为钢液铸造成形。

本小类不覆盖炼钢企业以连铸坯、钢锭、钢材为主导产出的冶炼和轧制活动，不覆盖铸铁件、铝镁等轻金属铸件、铜锌等非铁金属铸件，不覆盖锻造、焊接结构件、粉末冶金、纯机加工和整机装备制造。若企业从铸钢件进一步加工为阀门、泵、矿山机械、轨道部件或其他整机部件，应按主导活动和交付物识别。

A3 边界说明、相邻小类区分点和排除项

相邻小类或活动容易混淆的原因区分依据本卡处理原则
钢铁冶炼和连铸都使用钢液并形成金属坯料连铸和钢锭以材料坯料为主；铸钢以复杂铸件或基础零部件为主钢材坯料生产不纳入
铁的铸造都属于铁基金属铸造铸铁以高碳和石墨组织为特征；铸钢以钢液凝固和热处理组织为主按材料体系和产品牌号识别
轻金属铸造都有造型、浇注和清理铝镁等金属熔点、氧化膜、模具体系和缺陷机理不同不纳入本卡
其他非铁金属铸造铜、锌等也可铸造复杂零件非铁金属不属于钢液材料体系不纳入本卡
锻造钢件可通过铸造或锻造成形锻造以塑性变形和锻压设备为主；铸钢以钢液充型凝固为主锻件不纳入
焊接结构件大型钢件可由铸钢或焊接制造焊接结构以板材、型材切割焊接为主焊接结构件不纳入
熔模精密铸造可生产铸钢和非铁金属件若主导材料为钢且以钢铸件为主，纳入本卡；若主导为铝、铜或钛等，按对应小类按主导材料识别
铸钢件机加工铸钢件常需粗加工和精加工机加工以尺寸和装配表面形成为主，铸造以成形和凝固为主纯机加工不纳入
铸件热处理服务铸钢件通常必须热处理单独热处理以材料状态调整服务为主单独服务不纳入
装备整机制造铸钢件可用于阀门、矿机、泵、轨道设备整机制造以装配和功能部件交付为主整机装配不纳入

明确排除项包括炼钢连铸坯生产、钢材轧制、铸铁件、轻金属铸件、其他非铁金属铸件、锻件、焊接结构件、独立模具制造、单独机加工、单独热处理、单独表面处理、铸钢件贸易、成套设备和整机装配。

B3 关键技术概念说明

钢的铸造首先要理解钢液洁净度。钢液中的氧、硫、磷、氢、氮和非金属夹杂会影响凝固和最终铸件状态。脱氧、精炼、扒渣、浇包准备和浇注保护共同决定钢液进入型腔时的洁净程度。

第二个概念是铸钢的凝固收缩。铸钢凝固收缩通常比铸铁更突出，冒口、冷铁、补贴、浇注系统和凝固顺序设计对缩孔缩松、热裂和变形有直接作用。大型厚壁铸钢件常需要较完整的凝固工艺设计。

第三个概念是热处理。许多铸钢件的交付状态不是铸态，而是通过退火、正火、回火、调质、固溶或稳定化处理获得需要的组织和性能。热处理制度与铸件材料、壁厚、用途和缺陷敏感性有关。

第四个概念是铸钢件的修整和焊补。由于铸钢件常用于大型复杂结构，局部缺陷清理、补焊、消除应力和复检在行业中较常见。焊补属于铸钢件整修链条的一部分，但不能将焊接结构件制造混同为钢的铸造。

C2 主要功能和性能维度

铸钢件的功能主要来自钢材料的强度、韧性、耐磨性、耐热性、耐蚀性、可焊性和复杂形状成形能力。与轧制钢材相比，铸钢件可以形成复杂几何结构、局部厚大截面和一体化形状；与焊接结构相比，铸钢件可以减少焊缝和拼接，但需要面对凝固收缩和内部致密性问题。

客观描述铸钢件时，常见维度包括化学成分、力学性能、热处理状态、金相组织、硬度、尺寸公差、形位偏差、表面质量、内部缺陷等级、焊补状态、重量、批次、炉号、热处理号、加工余量、耐磨或耐热用途状态等。

D. 过程与技术

D1 主要工艺或过程流程

`mermaid flowchart LR A["废钢、返回料、合金料"] --> B["炉料验收和配料"] B --> C["熔炼"] C --> D["精炼、脱氧和合金化"] D --> E["造型和制芯"] E --> F["合箱和浇注"] F --> G["凝固冷却"] G --> H["落砂清理"] H --> I["热处理"] I --> J["焊补、整修或粗加工"] J --> K["铸钢件"] `

铸钢件生产从炉料验收和配料开始。废钢、返回料、生铁、铁合金、增碳剂、脱氧剂和造渣材料的选择，会影响钢液基础成分和杂质来源。对于高合金、不锈或耐热铸钢，合金料管理和牌号防混尤其重要。

熔炼可采用电弧炉、感应炉或其他熔炼设备。熔炼后通常需要脱氧、脱硫、合金化、扒渣、测温和取样。部分铸钢企业还会使用钢包精炼、氩气搅拌、真空处理或其他方式改善钢液状态。钢液温度窗口、浇包状态和浇注等待时间会影响充型和夹杂状态。

造型制芯通常使用树脂砂、水玻璃砂、熔模型壳、壳型或其他铸型体系。大型铸钢件对浇冒口系统、冷铁、工艺补贴、砂型强度和砂芯定位要求较高；熔模铸钢件则更关注蜡模、制壳、脱蜡、焙烧和浇注条件。

凝固后铸件需要落砂、切割浇冒口、打磨、清理和热处理。铸钢件热处理是过程链中的重要环节，可能包括退火、正火、回火、调质、固溶等。局部缺陷清理和焊补在部分铸钢件中较常见，焊补后可能还需再次热处理或检测。

E3 本小类在产业链中的位置

钢的铸造位于钢铁材料向复杂零部件转化的成形制造段。它把废钢、返回料和合金材料转化为具有特定形状、组织和性能的铸钢件，为重型装备、泵阀、矿山、电力、轨道交通和机械制造提供基础部件。

本小类上接钢铁材料和铸造材料，下接机加工、装配和装备制造。判断本小类边界时，应识别企业主导活动是否是“钢液铸造成形”，而不是只看企业是否同时存在加工、焊补、热处理或装配。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

钢的铸造属于材料冶金、铸造工艺、热处理和修整过程耦合较强的制造活动。其技术复杂度来自钢液洁净度、合金体系、凝固收缩、铸件结构、铸型材料、热处理制度和缺陷修整之间的相互作用。大型铸钢件尤其依赖工艺设计、冒口补缩和热处理安排。

自动化程度随企业类型差异明显。熔模铸钢和批量小件企业可能在制壳、浇注、清理和检测上形成较稳定的流程；大型重型铸钢企业通常单件周期长、手工工序多、吊装和现场经验依赖较强。钢液处理、热处理和无损检测通常需要较强的专业资源支撑。

H2 典型组织形态

小型砂型铸钢厂多品种、小批量、设备配置相对简单工艺经验依赖较明显
大型重型铸钢厂单件大、周期长、热处理和吊装复杂补缩、热裂和内部缺陷控制突出

H3 客观存在的易出问题环节和技术敏感点

环节或敏感点客观事实描述客观影响链
炉料和合金料防混铸钢牌号多，合金元素差异大炉料混入错误 → 钢液成分偏离 → 材料牌号状态变化
钢液脱氧脱氧状态影响夹杂和凝固脱氧不足或过量 → 夹杂物状态变化 → 铸件内部或表面状态变化

砂型耐火性钢液温度高，对型砂热负荷大型砂耐火性不足 → 粘砂或烧结 → 表面清理状态变化
冒口补缩铸钢凝固收缩明显补缩路径不足 → 热节供液不足 → 缩孔缩松形成
热裂敏感区厚薄过渡和约束部位易产生应力凝固收缩受阻 → 局部拉应力增大 → 裂纹形成
热处理制度铸钢件组织常依赖热处理温度或保温偏离 → 组织状态变化 → 硬度和力学性能变化
焊补区域焊补改变局部热循环和材料状态焊补参数不匹配 → 局部组织和应力变化 → 表面或内部状态变化
大型件冷却大型件截面差异大，冷却不均冷却速度差异 → 残余应力变化 → 变形或裂纹倾向
取样代表性试棒和铸件本体凝固条件可能不同试样与本体差异 → 数据代表性变化 → 批次判断基础变化
