17.10.02 机加工 专业小类基础卡

A. 标识与定位

A1 小类名称、分类代码、在分类体系中的位置

字段内容
专业小类代码17.10.02
专业小类名称机加工
所属大类17 金属制品制造及金属材料加工相关活动
所属中类17.10 金属加工服务
本卡定位描述以金属毛坯、棒材、板材、铸锻件、焊接件、冲压件或半成品为对象，通过车、铣、刨、磨、钻、镗、拉、插、线切割、电火花、数控加工等方法去除材料或精修形状尺寸的行业事实。
与上层文件关系本卡只记录底层行业事实和技术边界，不记录任何上层视图判断。

A2 定义与范围界定

本小类是指利用机床、刀具、夹具、程序、冷却润滑介质和测量工具，对金属材料或金属半成品进行切削、磨削、电加工或精密去除加工，使其达到规定尺寸、形位、表面粗糙度和配合要求的活动。机加工可以作为独立来料加工服务，也可以作为其他金属制品、机械零部件、模具、工具、设备制造过程中的核心工序。

本小类通常包括普通车削、数控车削、铣削、钻孔、攻丝、镗削、铰孔、刨削、插削、拉削、磨削、珩磨、研磨、滚齿、插齿、剃齿、线切割、电火花加工、激光微加工、水切割辅助精修、五轴加工、加工中心加工、精密零件加工和来料机加工服务。

本小类不包括以塑性成形为主的锻造冲压挤压、以热处理或表面涂覆为主的金属处理、以铸造为主的毛坯生产、以最终工具或设备装配为主的成品制造、单纯维修服务、单纯模具设计销售和非金属材料加工。若企业以特定成品制造为主，机加工是内部工序，应按成品主导属性识别。

B3 关键技术概念说明

机加工的本质是用可控的材料去除过程获得尺寸和形位精度。图纸要求需要转化为工艺路线、基准选择、装夹方案、刀具路径和测量方法。即使机床精度较高，如果基准转换、夹紧力、刀具磨损、热变形或程序路径控制不当，也会出现尺寸漂移和形位异常。

刀具、夹具和机床构成机加工的基本三角。刀具决定切削能力和表面状态，夹具决定定位重复性和变形，机床决定运动精度和刚性。冷却润滑、切屑排出和去毛刺则影响加工稳定、表面和后续装配。

测量技术是机加工过程不可分割的一部分。尺寸、形位、粗糙度、硬度、螺纹、齿形和配合关系需要通过量具、检具、三坐标、轮廓仪、粗糙度仪和专用检测设备确认。

D. 过程与技术

D1 主要工艺/过程流程

`mermaid flowchart LR A["图纸/毛坯/技术要求"] --> B["工艺路线和基准确定"] B --> C["刀具、夹具、程序准备"] C --> D["装夹和首件加工"] D --> E["粗加工、半精加工、精加工"] E --> F["去毛刺、清洗、防锈"] F --> G["尺寸、形位和表面检测"] G --> H["标识、包装、交付或转序"] `

机加工从图纸理解和毛坯状态确认开始。工艺人员需确定加工基准、装夹方式、加工顺序、刀具、切削参数、热处理或表面处理接口。复杂零件往往需要粗加工释放应力、热处理或时效后再精加工。

数控加工需要将零件模型或图纸转化为程序、刀具表和工装方案。首件加工用于确认程序路径、刀补、装夹和测量结果。批量生产中需要监控刀具磨损、机床漂移、夹具重复定位和冷却液状态。

D1.1 轴类、盘类和箱体类零件的路线差异

轴类零件通常围绕中心孔、外圆、台阶、键槽、螺纹、热处理变形和同轴度展开。典型路线可能为下料、粗车、打中心孔、调质或时效、半精车、磨削、铣键槽、螺纹加工和最终检测。细长轴还要考虑跟刀架、中心架、夹紧方式、切削力和热变形，避免弯曲和振纹。

盘套类零件更关注内外圆同轴、端面跳动、孔轴配合和端面平行。法兰、端盖、套筒、轴承座和齿轮坯常需要先确定定位端面，再加工中心孔、外圆、螺纹孔和定位止口。若热处理在中间插入，余量和变形补偿需要提前安排。

箱体和壳体类零件通常来自铸件、焊接件或铝合金毛坯，工艺难点在基准建立、孔系位置、平面度和多面加工。泵体、阀体、机座、减速箱壳体和液压阀块还涉及流道、深孔、交叉孔、密封面和清洁度。加工过程中常需要专用夹具、翻转定位、试压或堵孔清理。

D1.2 数控、磨削和特种加工的过程深度

数控加工的核心是把几何模型转化为可靠刀路。程序不仅决定走刀形状，还决定进退刀、避让、刀具长度补偿、半径补偿、坐标系、换刀顺序和余量分配。复杂曲面和五轴加工还需要考虑刀轴姿态、干涉检查、后处理器、夹具避让和模拟验证。批量加工中，程序一旦稳定，刀具寿命、刀补更新、夹具磨损和机床热漂移会成为主要变量。

磨削加工常用于获得高精度尺寸和表面状态。外圆磨、内圆磨、平面磨、无心磨、成形磨和磨齿都需要关注砂轮粒度、硬度、修整、线速度、冷却、磨削烧伤和残余应力。对淬硬钢、轴承件、齿轮和精密模具零件，磨削不仅是尺寸工序，也是表面完整性形成过程。

电火花和线切割适用于高硬度材料、复杂型腔和窄缝轮廓。其过程敏感点在电参数、工作液、排屑、变质层、锥度、割缝补偿和电极损耗。深孔钻削和镗削则需要关注刀具导向、冷却排屑、孔偏斜和内壁粗糙度。

D1.3 测量反馈与工艺闭环

机加工的专业深度很大一部分体现在测量反馈。首件确认不是简单测几个尺寸，而是验证基准、装夹、程序、刀具、热处理余量和检测方法是否匹配。批量生产中，尺寸漂移可能来自刀具磨损、热伸长、夹具松动、毛坯硬度变化或测量温度变化。高精度零件还需要明确测量环境、清洁状态、测头路径和装夹释放后的尺寸变化。

精密磨削加工轴承、模具和精密零件企业砂轮、热变形、粗糙度和圆度更突出。
齿轮加工传动零件企业齿形、齿向、热处理后精加工和啮合状态更突出。
五轴复杂件加工航空、模具、医疗和自动化零件企业程序、刀具路径、坐标转换和测量更复杂。

D6 典型工艺路线识别提示

机加工的行业差异主要来自零件形状、基准体系、精度要求和加工设备。底层识别不能只写“车铣钻磨”，应说明主导零件族和路线组合。

路线类型典型识别信息与其他路线的差异
轴类车削路线车削中心、外圆、端面、螺纹、中心孔、热处理和磨削。以回转基准和同轴状态为主。
箱体孔系路线加工中心、镗孔、铣面、定位销孔、螺纹孔和坐标尺寸。以装夹基准、孔系位置和多面加工为主。
齿轮和传动件路线滚齿、插齿、剃齿、热处理、磨齿和齿形测量。齿形、齿向和热处理变形关联明显。
精密磨削路线平面磨、外圆磨、内圆磨、无心磨和超精加工。以表面粗糙度、形位和热损伤识别为主。
特种加工路线线切割、电脉冲、激光、水切割或电解加工。材料去除机理与普通切削不同。
多工序复合路线车铣复合、五轴加工、在线测量和自动换刀。程序、刀具、夹具和测量反馈一体化程度高。

E. 产业链与边界

E1 上游供应

上游包括金属材料、铸锻冲压毛坯、刀具、机床、夹具、切削液、检测设备和热处理/表面处理资源。毛坯余量、硬度、内应力和表面状态会直接影响加工方案。

E2 下游应用/客户

下游包括机械设备、汽车、电子电器、模具、航空航天、医疗器械、泵阀、液压气动、仪器仪表、工具和自动化装备制造企业。

E3 本小类在产业链中的位置

本小类是材料和毛坯向精确零件转化的核心环节，可独立作为加工服务，也可嵌入成品制造。其价值在于获得尺寸精度、形位精度、表面状态和配合关系。

E4 常见委外/外包环节

委外环节常见原因边界提示
热处理需要专用炉型和材料状态作为前后工序接口。
表面处理镀层、发黑、喷涂、防腐需专用线属于后处理接口。
特种加工五轴、电火花、深孔、磨齿资源有限可作为机加工分包。
检测三坐标、齿轮测量、材料检测资源有限外部检测资源可作为方法来源。

E5 典型接口资料与实物流转补充

机加工通常处在毛坯制造和装配使用之间，图纸、模型、材料状态、热处理外协和计量资料是识别其产业链位置的重要信息。

接口环节常见资料或实物识别价值
图纸模型输入零件图、三维模型、公差、基准、材料和技术条件。决定加工路线和测量方式。
毛坯输入铸件、锻件、型材、板材、焊接件和热处理件。反映余量、缺陷和前序过程状态。
工艺资源工艺卡、程序、夹具、刀具、量具和冷却液。反映过程能力来源和变更控制基础。
热处理外协调质、渗碳、淬火、时效、去应力和校直。反映加工前后尺寸变化和材料状态。
计量接口量具校准、三坐标报告、齿轮测量、粗糙度和形位数据。反映尺寸确认手段。
下游交付装配、焊接、表面处理、维修备件和整机制造。反映机加工件的最终使用接口。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

机加工覆盖面极广，技术复杂度从普通车铣到五轴精密加工差异很大。自动化程度从人工操作普通机床到柔性加工线和机器人上下料均有分布。人工经验在工艺路线、装夹、刀具选择、异常声音判断、去毛刺和测量解释中仍然重要。

H2 典型组织形态

组织形态典型特征常见资源配置
小型加工店来料加工、单件小批普通车铣钻磨和通用量具。
数控加工厂批量零件和多品种加工CNC、加工中心、夹具和三坐标。
精密零件企业高精度和洁净交付精密机床、恒温测量、精密量具。
齿轮加工企业传动件专门加工滚齿、磨齿、热处理接口和齿轮检测。
大型装备加工企业大件、重件和复杂件大型镗铣、龙门、起重和专用检测资源。

H4 典型组织形态差异补充

机加工企业从单机加工点到自动化生产线跨度很大。底层记录组织形态，有助于理解其设备、人员经验、程序和计量资源的差异。

组织形态典型表现技术识别提示
单机和小型加工点普通车床、铣床、钻床和人工测量为主。图纸理解、装夹经验和量具状态信息突出。
CNC 批量加工企业加工中心、数控车床、程序管理和专用夹具较多。程序版本、刀具寿命和首件状态较有识别价值。
精密零件企业恒温、磨削、三坐标、洁净包装或显微检测常见。微小尺寸、形位和表面状态要求较高。
模具零件企业单件小批、多工序、热处理和修配较多。图纸版本、加工余量和试模反馈需要描述。
齿轮和传动件企业齿形加工、热处理和专用测量设备明显。齿形、齿向、硬度和变形关联突出。
自动化生产线机器人上下料、在线测量、集中供液和数据采集较多。设备节拍和测量反馈对批量状态影响明显。

H3 客观存在的易出问题环节/技术敏感点

敏感点客观影响链
图纸和基准理解偏差基准选择或公差解释不一致 → 工艺路线偏移 → 尺寸和形位状态波动。
毛坯余量和硬度异常来料余量不足或硬度偏高 → 刀具磨损和加工变形增加 → 表面和尺寸不稳定。
装夹变形夹紧力或定位方式不当 → 工件弹性变形 → 松夹后尺寸和形位偏移。
刀具磨损刃口磨损或崩刃 → 切削力和温度变化 → 尺寸漂移、粗糙度变差或毛刺增加。
程序和刀补错误坐标、刀长、半径补偿或路径异常 → 过切、欠切或碰撞路径形成。
冷却和切屑排出不足热量和切屑积聚 → 表面划伤、烧伤或尺寸热漂移。
去毛刺清洗不足毛刺、切屑或油污残留 → 装配、涂覆或使用接口受扰动。
量具和测量环境异常量具状态、温度或测量基准不一致 → 测量结果偏移 → 批量判断失准。
工艺基准与设计基准转换不当装夹和测量基准未与图纸功能关系衔接 → 加工尺寸局部合格但配合关系偏移 → 装配接口异常。
热处理前后余量安排不足粗加工、热处理和精加工顺序不匹配 → 变形后无足够修正余量 → 尺寸或形位无法恢复。
深孔和交叉孔残屑滞留排屑、清洗或吹扫不足 → 孔道内切屑和油污残留 → 液压、气动或装配通道受扰动。

H3 只记录行业中客观存在的敏感点及事实因果链，不对其在任何上层视图中的重要性作判断。
