A2 定义与范围界定

本小类是在 29.05.02 基础上对涉及危险化学品销售代理情形的细分。其活动对象可能包括危险化学品目录管理范围内的燃料、溶剂、酸碱、气体、易燃液体、氧化性物质、有毒品、腐蚀品和相关工业化学品。代理活动必须围绕委托权限、客户资质类别、产品 SDS、标签、包装、运输储存条件和交付接口进行更严格的信息传递。

销售代理的服务结果通常不是商品实物的制造、加工或自营销售，而是围绕委托授权形成客户线索、询盘响应、规格澄清、报价传递、交易条件协调、订单跟踪、交付资料传递、售后问题协调和佣金结算。代理机构是否实际接触样品、是否代收代付、是否协助运输或是否参与合同签署，应根据委托权限逐项识别。

本小类的专业性集中在危险化学品属性识别、SDS资料、标签包装、客户资质类别、储运条件、禁配信息、应急资料和代理权限边界。同为销售代理，商品对象不同会显著改变术语、资料、样品、交付和外部接口，不能用一般商业中介服务替代本小类的专业描述。

A3 边界说明、相邻小类区分点和排除项

相邻活动容易混淆的原因主要区分依据本卡处理原则
自营批发贸易代理和批发都促成商品成交，且可能使用相同客户渠道是否取得货权、是否以买卖差价为主、是否承担库存和货物处分责任受托撮合、传递信息并以佣金或服务费为主的归入本卡；自购自销并承担库存货权的归入相应批发小类。
商品零售代理机构可能面对终端客户并展示样品交易对象是代理服务还是终端商品零售面向委托方提供销售代理服务的归入本卡；以门店或平台直接向终端销售商品为主的归入相应零售小类。
生产制造或初加工代理对象可能来自生产企业，代理人员熟悉产品技术是否进行制造、加工、分装、改性或实物生产只做销售代理和交易协调归入本卡；主导生产加工活动按制造或加工小类识别。
经纪、拍卖和平台撮合均可能撮合买卖双方并不持有货物是否为特定商品或委托方持续开发销售渠道，还是提供公开交易平台或拍卖程序长期受托代理特定商品或委托方归入本卡；公开平台、拍卖和一般经纪按主导活动另行识别。
物流、仓储和货运代理代理业务常协调运输、仓储、装卸和交付资料主导服务结果是销售成交还是物流履约交付接口协调属于本卡；以运输、仓储或货运代理为主的活动不纳入本卡。
进出口代理部分代理涉及进口货源、报关单证和国际结算主导活动是商品销售代理还是进出口手续代理围绕商品销售渠道开发归入本卡；以报关、单证和进出口服务为主另行识别。

明确排除项：

  • 取得货权并以自营差价为主的批发或零售活动。
  • 商品制造、加工、分装、维修、安装和实物处置活动。
  • 以仓储、运输、货运代理、报关或供应链金融为主的活动。
  • 公开拍卖、一般平台撮合和不针对特定商品的广告推广活动。
  • 超出委托权限直接承诺价格、质量、交付或售后责任的活动。

主要技术基础危险化学品目录属性、SDS、标签、包装、UN语境、危害类别、储运相容性、客户资质和应急资料具备一般商务沟通经验不等于理解本小类商品指标、资料链和交付接口。

典型规模跨度从个人或小团队代理、区域代理商到全国性渠道代理和项目型代理机构均存在规模差异主要体现在客户资源、资料系统、委托权限和交付协调能力。
主要分型轴按易燃/腐蚀/有毒/压缩气体/氧化性等属性、按桶装/槽车/瓶装/罐装、按国内/进口、按现货/订单代理分型不同分型改变样品、资料、合同、物流和售后协调方式。

B. 术语与概念

B1 专业术语和行业常用表达

术语解释本小类中的使用语境
销售代理受委托方委托，为特定商品或客户撮合交易、开发客户、传递信息并获取佣金或服务报酬的商业活动。用于区分代理服务与自营批发零售。
委托方授权代理机构开展市场开发、客户沟通或交易协调的一方。通常是生产商、供应商、进口商或品牌方。
代理权限代理机构可开展的区域、客户、品类、价格、合同签署和售后协调权限范围。决定代理服务边界。
货权商品所有权或处分权归属。判断代理与自营贸易边界的重要概念。
佣金代理机构根据成交、销售额、服务量或约定条件取得的报酬。销售代理的典型收益方式。
询盘潜在客户对商品、价格、交期、规格或服务条件提出的需求信息。代理服务链的入口之一。
报价围绕商品、数量、价格、交期、付款和服务条件形成的交易表达。代理机构常负责传递或协助形成。
客户开发识别、接触、筛选和维护潜在买方或渠道客户的活动。代理服务的核心过程。
样品或样本用于客户确认规格、外观、性能、产地或等级的代表性实物或资料。不同商品的样品形态差异很大。
交易条件价格、数量、账期、交付地点、运输、包装、索赔和售后等约定。代理机构沟通的主要内容。
信用额度供应方给予客户或渠道的赊销限额或账期控制条件。代理业务常涉及但不等同于金融服务。
售后协调代理机构协助处理交付、退换、投诉、索赔或技术问题的活动。通常不直接替代生产商或卖方责任。
危险化学品具有特定危险属性并受专门规则约束的化学品类别。本细分项边界核心。
SDS化学品安全数据资料。客户接收和使用说明的重要资料。
禁配不宜共同储存、运输或接触的物质组合。储运接口说明常见。
槽车用于散装液体或气体运输的车辆或容器形式。大宗交付常见。
钢瓶压缩或液化气体常用容器。工业气体代理常见。

B3 关键技术概念说明

销售代理首先要区分代理服务和商品买卖。代理机构可能掌握客户、样品、报价和交付信息，但不必然拥有货物所有权，也不必然承担制造者、卖方、仓储方或承运方责任。

理解本小类必须理解代理对象自身的商品属性。含危险化学品的燃料、工业化学品及相关工业品的规格、等级、证明资料、样品、包装、交付和客户用途具有专门含义，代理机构的信息传递如果偏差，会直接改变交易判断。

委托权限是本小类最重要的边界概念。代理机构可以被授权寻找客户、传递报价、协助谈判或跟踪履约，但能否签约、能否承诺价格、能否代收款、能否处理索赔，必须由委托关系决定。

代理服务的价值通常体现在信息不对称的降低。商品越专业、交易越跨区域、客户用途越复杂，代理机构越需要把技术资料、交易条件和交付接口翻译成供需双方都能理解的语言。

D. 过程与技术

D1 主要过程流程：从投入到产出的完整链路

销售代理过程通常从委托关系建立开始，经代理商品和权限确认、目标客户识别、市场信息收集、商品资料整理、客户询盘、规格或用途澄清、样品或资料传递、报价和交易条件协调、合同或订单形成、交付跟踪、售后反馈协调和佣金结算完成。

本小类的具体过程链围绕含危险化学品的燃料、工业化学品及相关工业品展开。代理人员既要理解代理服务的一般商务逻辑，也要理解该类商品的等级、规格、证明、包装、储运和客户用途，否则容易把客户真正关心的技术条件遗漏在报价之外。

与批发零售不同，代理过程的关键不在自有库存周转，而在委托权限、客户信息、交易条件和货权责任边界。代理机构可以参与很多交付接口，但是否承担实物责任必须回到合同和委托关系识别。

通用链路可表示为：

`text 委托授权 → 商品和资料识别 → 市场与客户开发 → 询盘澄清 → 报价协调 → 样品或证明资料传递 → 合同订单协调 → 交付接口跟踪 → 售后协调 → 佣金结算 `

D7 危险化学品销售代理的SDS、资质资料和储运相容性链条深化说明

本细分项的核心不是“化工品代理”四个字，而是危险化学品属性导致的资料链和外部接口显著加厚。代理机构即使不持有货物，也会参与产品名称、SDS、标签、包装、客户用途、承运方式和签收资料的传递。 危险化学品代理最容易发生边界误解：代理方可能只是撮合，但客户会把其视为实际卖方；代理方可能不储存，但仍传递储运条件；代理方可能不运输，但会协调承运方。基础卡必须把这些边界保留清楚。 SDS和标签是本小类重要的信息载体。它们把化学品名称、危险属性、成分、储运条件和应急信息连接起来，是客户理解和接收商品的重要基础。

链条典型要素客观作用
属性识别链危险化学品类别、产品名称、浓度和状态确定资料和交付要求。
SDS链供应方、产品名、版本、语言、应急信息支撑客户理解商品。
标签包装链桶标、瓶标、批号、包装完整性支撑交付识别。
客户资料链客户用途、接收条件、资质类别支撑交易边界。
承运链车辆、容器、禁配、路线、签收支撑运输接口。
仓储链温度、通风、防潮、隔离、相容性支撑存放接口。
异常链泄漏、破损、错发、资料缺失形成售后协调。
佣金链成交、发货、签收、回款、异常处理确定代理报酬节点。

D8 本小类与上层分组文件的接口提示

接口维度底层可提供的事实上层文件需要另行形成的判断
共性判断代理服务、委托权限、客户开发、交易撮合和佣金结算是否可与其他销售代理小类组成同一技术领域组。
差异判断商品对象、技术指标、样品资料、外部许可类别和交付接口差异是否需通过限定授权或补充能力处理。
边界判断货权、自营贸易、制造加工、物流仓储和平台撮合边界具体项目归属和人员授权边界。

E3 本小类在产业链中的位置

本小类位于商品生产供应方和购买使用方之间，是以客户、信息、渠道和交易条件为主要资源的服务环节。代理机构不必然持有货物，也不必然直接承担仓储运输责任，但会影响供需双方对商品规格、价格、交付和售后接口的理解。

在 29.05 销售代理族中，本卡的产业链位置由含危险化学品的燃料、工业化学品及相关工业品的专业属性进一步限定。商品对象越专业、证明资料越复杂、交付接口越多，代理机构对资料准确性和边界表达的依赖越高。

H. 行业本底特征

H1 技术复杂度、自动化和人工依赖程度

维度本底特征说明
技术复杂度取决于代理对象的专业属性、证明资料、交易规模和交付接口商品越专业，代理服务越依赖技术资料理解。
信息依赖委托权限、客户资料、商品规格、价格和交付信息高度关键信息偏差会直接传导到交易判断。
人工经验客户开发、商务谈判、商品解释和异常协调仍高度依赖人员经验系统只能辅助记录和匹配。
自动化程度客户关系、报价、合同和订单系统逐步普及样品、看货和现场协调仍需人工参与。
规模跨度个人代理、小团队、区域代理和全国渠道代理并存内部能力差异较大。

H2 典型组织形态

组织形态典型特点说明
个人或小团队代理依靠客户资源和行业经验资料管理和权限边界容易薄弱。
区域代理商负责特定区域客户开发和售后协调渠道维护能力突出。
品牌或厂家代理机构受供应方长期委托产品资料和价格政策较稳定。
采购代理机构受买方委托寻找货源需求识别和供应商比较突出。
平台化代理服务商通过线上工具撮合和跟踪数据和责任边界突出。
项目型代理机构围绕工程、设备或大宗采购技术澄清和合同节点复杂。

H3 客观存在的易出问题环节和技术敏感点

敏感点客观表现客观影响链
SDS资料不对应产品名称、浓度或版本与实物不一致资料错配 → 客户接收判断偏差 → 交付受阻。
客户资质类别未识别客户是否可接收相应商品资料不清资料缺口 → 订单暂停 → 交易延迟。
包装标签缺失桶标、瓶标或批号不清识别困难 → 签收受阻 → 退换争议。
储运相容性遗漏禁配、温控或通风条件未传递条件遗漏 → 储运异常 → 货物状态变化。
承运接口不清承运方条件和签收资料不完整运输节点不清 → 责任难分 → 索赔困难。
小样与大货差异样品和实际供货批次不同样品偏差 → 使用效果差异 → 客户投诉。
代理权限越界代理方承诺其无权承诺的交付或责任权限越界 → 合同责任错位 → 委托方争议。
异常反馈迟滞泄漏、破损或错发未及时传递信息迟滞 → 后续处置滞后 → 损失扩大。
进口资料不一致外文资料、中文标签和合同名称不同名称不一 → 清关或接收接口受阻。
佣金节点含糊资料齐套、签收或回款节点未定义节点含糊 → 报酬确认争议。

H3 仅写事实因果链，不把这些敏感点预先归入任何特定管理体系视角。
