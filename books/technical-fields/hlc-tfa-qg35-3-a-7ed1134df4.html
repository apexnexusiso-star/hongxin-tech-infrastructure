  • 文件定位说明

本文件用于质量管理体系认证中 QG35-3 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦 设施综合支持、建筑和工业清洗、其他清洁及景观维护服务 在 QMS 轴下的质量形成链、客户要求转化、服务过程控制、输出验证、记录追溯、投诉反馈和改进闭环。本文件不承担行业百科说明功能，基础行业事实由对应专业小类基础卡承载。

本组采用“统一领域包 + 设施支持分支 + 常规清洁分支 + 专项/工业清洗分支 + 景观服务分支 + 专项边界控制”的使用口径。组内小类可以共享通用服务质量管理判断方法，但不得把某一分支经历等同于另一分支完整能力；对专业责任强、客户损失后果高、现场活动复杂或外部合规接口明显的情形，应在授权和项目匹配阶段追加分支确认。

  • 技术领域包构成
小类编码小类名称纳入本包的活动范围主要内部路线特殊边界
35.15.00设施综合支持服务活动为客户设施提供清洁、维护、垃圾清理、警戒安保、邮件、接待、洗衣等组合支持服务。综合设施外包、物业式支持、驻场服务、后勤组合服务。若包含安保、设备维修、餐饮、洗衣或客户核心过程支持，应按实际服务确认。
35.16.01建筑物的一般清洁办公室、住宅、工厂、商店、研究所等建筑物的一般内部清洁及附带外部保洁。日常保洁、周期保洁、公共区域清洁、卫生间和地面清洁。客户场所、清洁频次、药剂、成品保护和服务验收标准应明确。
35.16.02其他建筑及工业清洗活动建筑外墙、窗户、烟囱、通风管、锅炉、工业机械等建筑和工业清洗。建筑专项清洗、设备清洗、管道清洗、炉膛和通风系统清洗。该小类下工业清洗和建筑专项清洗差异大，应按35.16.02a/35.16.02b分支确认。
35.16.02a工业清洗活动工业设备、管道、储罐、换热器、生产设施和特殊介质系统清洗。化学清洗、高压水射流、机械清洗、停机清洗、在线或离线清洗。隔离、置换、残液、设备复位、客户验收和特殊介质边界需专项确认。
35.16.02b其他建筑清洗活动建筑外墙、玻璃、烟囱、通风管、炉灶、锅炉和排气装置等建筑专项清洗。外墙清洗、玻璃清洗、烟道清洗、通风管清洗、屋面或立面清洗。高处、成品保护、材质适配和客户现场条件需专项确认。
35.16.03其他清洁活动游泳池、交通工具、罐体内部、消毒灭杀、洗瓶、道路清扫、扫雪除冰等其他清洁。交通工具清洁、消杀、罐体清洗、道路保洁、除雪、洗瓶。集合路线跨度大，涉及消毒、罐体、交通工具时应限定授权。
35.17.00景观服务活动公园、花园、道路绿化、运动场、屋顶花园、水体和防护植物的种植、护理和保养。绿化养护、苗木栽植、草坪管理、修剪、水肥、病虫害防治。植物成活、季节性、药剂、水体和客户场所边界需分支确认。
  • 分组设立的基本逻辑

本包在 QMS 轴下的共同对象是客户设施、建筑物、设备表面、公共区域、清洁对象和景观空间的持续维护服务。质量管理体系审核关注的核心不是服务名称是否相同，而是客户需求如何被识别和转化，服务资源如何配置，服务实施过程如何受控，服务输出如何被复核或验收，客户反馈如何形成纠正和改进。

本包可概括的共同质量形成链为：客户场所和服务范围确认 -> 现场勘查和服务方案 -> 人员、设备、药剂、工具和供应商配置 -> 作业计划与现场实施 -> 过程巡检和客户验收 -> 缺陷整改、投诉处理和周期改进。该链条决定了本包共享的专业能力基础，即审核员应能够围绕客户要求、人员能力、服务方案、过程记录、输出验证、交付确认和反馈闭环建立审核证据链。

组内差异主要体现在服务对象和现场复杂度：设施综合支持是多服务组合，常规清洁偏日常频次和一致性，建筑专项清洗强调材质和高处条件，工业清洗强调设备隔离、介质和复位，景观服务强调植物生命周期和季节性。这些差异不否定设组，但要求本包不能按无差别能力包使用，应通过分支标注、专项确认、条件扩展和抽样控制加以处理。

  • 专业小类关系类型与授权后果
关系类型含义授权后果典型控制方式
共同基础关系同属以合同、委托、项目任务或服务订单为输入的专业服务活动，均需识别客户要求、配置人员和资源、形成服务输出、保存服务证据并处理反馈。可简化通用服务过程、客户沟通、记录控制和服务评价等基础能力评价，但仍需确认目标小类或目标分支的实际经历。资料评审、案例判断、专业面谈、服务证据追溯。
并列分支关系同属本技术领域包，但服务对象、交付物、专业责任、现场条件或客户验收方式不同。应记录实际分支能力，不把同包经历理解为全分支能力。分支标注、限定使用、项目技术支持。
条件扩展关系已具备相邻分支能力，具有扩展基础，但目标分支仍存在专门知识、证据链或法规边界。完成补充培训、案例评审、专业面谈、见证审核或技术支持后方可扩展。培训考核、案例评审、见证审核、专家确认。
专项确认关系涉及强执业属性、高保密数据、高客户损失后果、特殊现场作业或复杂外包链。项目使用前应开展专项确认，必要时配置技术专家支持。专项面谈、技术专家评审、项目匹配确认。
不可直接替代关系相关服务经验不足以证明目标小类的质量形成链能力。不得作为目标能力的单独授权依据，应补充目标经历或限定项目类型。重新评价、补充经历、限定项目类型。
边界受控关系当执业资格、客户行业要求、个人信息、资金信用、现场安全、外包生产或法定接口改变服务边界时，统一包内授权应增加边界说明。授权记录应写明适用边界，项目匹配时按实际服务内容确认。授权备注、合规类别清单、技术支持。
设施支持与常规清洁设施支持常包含清洁模块，二者共享驻场服务、频次计划、巡检和客户投诉闭环。可共享日常服务基础能力，但设施组合服务需确认多供应商和服务目录管理。服务目录、驻场排班、巡检和月度服务报告抽样。
常规清洁与专项清洗均涉及清洁对象、工具药剂、作业人员和验收标准。常规清洁经历不能替代高处、通风管、工业设备或特殊介质清洗能力。专项作业方案、现场条件、工具药剂和验收记录确认。
清洁与景观服务均服务于客户场所维护和客户感知质量。植物养护、水肥、修剪、病虫害和季节性能力需单独确认。绿化养护计划、巡检、植物更换和客户验收记录抽样。
  • 本体系共同能力基础
共同能力维度本包共同基础可共享的审核判断不能共享的边界
服务范围和现场勘查均需明确服务区域、对象、频次、作业标准、客户限制和验收方法。判断合同、现场勘查、作业方案和服务计划是否一致。工业设备、外墙高处、消杀和景观水体等边界需专项确认。
资源配置均依赖人员、工具、设备、药剂、耗材、车辆和外包供应商。可共享人员培训、物料领用、设备维护、供应商控制和现场交接判断。工业清洗设备、特殊药剂和景观苗木不宜与普通保洁混用能力判断。
现场作业控制均通过作业计划、班组安排、作业记录、主管巡检和客户确认形成质量控制。可共享现场过程巡检、不合格服务纠正和客户投诉处理判断。隔离置换、高处作业、消杀残留和植物病虫害需分支确认。
验收和持续服务均以客户验收、质量巡检、服务报告、缺陷整改和周期复盘作为交付证据。可共享服务质量评价、缺陷闭环和合同续约反馈判断。工业清洗复位、建筑外墙成品保护和景观成活率需专项抽样。
  • 本体系核心控制要求

本组所称关键质量特性，是指服务输出中影响客户可接受性的准确性、完整性、及时性、一致性、可追溯性、响应性和交付符合性。在服务业场景中，检验和放行通常表现为主管复核、质检抽查、客户确认、验收签收、报告批准、脚本质检、现场巡检或交付前复核；审核员应把这些复核和确认活动作为服务结果进入客户使用前的质量控制证据。

QMS 审核应首先确认客户设施和服务边界是否清楚。服务合同、服务目录、区域清单、频次表、现场限制、验收标准和客户联系人应相互一致。对综合设施支持，还应确认各服务模块的责任界面；对清洁和景观服务，应确认服务对象、材质、植物、设备或现场条件是否已在作业方案中体现。

第二，应评价人员、设备、药剂、工具和供应商的配置。清洁和景观服务质量高度依赖一线人员作业技能、现场主管巡检、药剂适配、设备状态和物料供应。工业清洗、外墙清洗、消杀和交通工具清洁等路线还应确认专用工具、作业方案和客户验收要求。

第三，应追溯现场过程控制。日常保洁应关注频次完成、区域覆盖和缺陷整改；工业清洗应关注隔离、置换、介质、残液、复位和客户验收；建筑专项清洗应关注表面材质、成品保护和施工顺序；景观服务应关注季节性计划、水肥、修剪、病虫害、补植和养护记录。

第四，应评价巡检、验收和投诉闭环。清洁服务常见问题包括漏扫、残留、异味、损伤客户物品、药剂使用不当和服务响应延误；景观服务常见问题包括植物死亡、修剪不当、病虫害未控和灌溉不足。审核应追溯缺陷发现、整改责任、客户确认和预防措施。

  • 分小类或内部路线差异分析
小类/路线与本包共同基础主要差异差异对能力授权的影响控制方式
35.15.00 设施综合支持共享客户场所、服务目录、驻场人员、巡检和反馈基础。多服务组合、多供应商接口、接待邮件安保清洁等边界交织。应标注设施综合支持分支；含安保或维修时需确认对应能力。抽取月度服务样本，追溯服务目录、排班、巡检、投诉和供应商。
35.16.01 一般清洁共享现场作业、工具药剂、频次、巡检和客户验收基础。日常性强，重点在区域覆盖、频次稳定、作业一致性和投诉响应。可作为清洁基础分支，但不覆盖专项或工业清洗。抽取一周保洁记录，核对区域、频次、巡检和缺陷整改。
35.16.02 建筑及工业清洗共享专项清洁对象、方案、工具药剂和验收基础。内部包含建筑专项和工业设备清洗，差异较大。应按35.16.02a或35.16.02b路线细化授权。抽取专项清洗合同和作业方案，确认对象和验收标准。
35.16.02a 工业清洗共享清洁作业和客户验收基础。设备、管道、储罐、介质、隔离置换、残液和复位突出。属专项确认路线，不以普通清洁经历替代。抽取工业清洗项目，追溯隔离、药剂、作业、残液、复位和验收。
35.16.02b 建筑专项清洗共享清洁对象、作业计划和客户验收基础。外墙、玻璃、烟道、通风管、锅炉等对象材质和现场条件突出。应确认建筑专项清洗能力，尤其是成品保护和高处条件。抽取外墙或通风管项目，追溯勘查、方案、作业和验收。
35.16.03 其他清洁共享清洁对象、工具药剂和验收基础。交通工具、罐体、消杀、洗瓶、道路清扫、除雪等路线跨度大。应按实际路线限定授权，消杀和罐体需专项确认。抽取实际服务合同，确认对象、药剂、记录和客户确认。
35.17.00 景观服务共享客户场所维护、计划作业、巡检和投诉处理基础。植物、季节、水肥、修剪、病虫害、补植和成活质量突出。应标注景观养护分支；不能用清洁经历替代。抽取绿化养护样本，追溯计划、作业、巡检、缺陷和客户验收。
  • 分组合理性论证结论

本组可以设立的理由在于，各小类均围绕客户场所或设施状态维护形成服务质量，均通过服务范围确认、现场勘查、资源配置、作业计划、现场实施、巡检验收和客户反馈闭环来控制服务质量。审核员可共享现场服务过程、驻场人员、服务频次、工具药剂、供应商和客户验收的基础判断方法。

因此，QG35-3 可以作为质量管理体系技术领域包使用，但其使用方式应为“统一领域包 + 设施支持分支 + 常规清洁分支 + 专项/工业清洗分支 + 景观服务分支 + 专项边界控制”。审核员授权、项目匹配和能力扩展均应体现分支差异，不得把同包经历理解为跨全部小类的充分证明。

  • 审核关键要点与抽样方法
抽样场景现场必看记录必查纵向追溯路径追问方向
综合设施支持月度服务客户现场、服务台、驻场人员、服务区域。服务目录、排班、工单、巡检、供应商评价、月报和投诉。合同范围 -> 服务计划 -> 工单执行 -> 巡检 -> 客户月度确认。服务模块边界如何划分；客户投诉如何分派和关闭。

  • 分组使用限制和法定边界

本组的 QMS 分组不替代安全生产条件确认、职业健康评价、环境排放许可、危险废物处置、特种作业资格、特种设备检验、消防验收、客户设备复位验收或政府监管。涉及工业清洗、高处建筑清洗、罐体内部清洗、消毒灭杀、道路除雪和客户生产设备清洗时，应进行专项能力确认。

管理体系审核仅用于评价组织是否在其服务范围内建立并实施质量管理控制，不替代行政许可、司法判断、法定鉴证、执业资格审查、政府监管、行政处罚、强制检测、客户专项验收或其他法定结论。涉及受监管资质、敏感数据、资金信用、现场作业和第三方外包时，应在项目匹配阶段确认审核员分支能力和必要的技术支持。

  • 分组结论与使用口径

QG35-3 可作为质量管理体系设施支持、清洁及景观服务技术领域包使用。授权时应记录设施综合支持、日常清洁、建筑专项清洗、工业清洗、其他清洁和景观养护分支能力。文件维护触发条件包括：工业清洗介质、客户现场条件、药剂和设备、服务外包方式、景观养护对象或客户验收标准发生实质变化，或项目匹配中出现分支能力争议。
