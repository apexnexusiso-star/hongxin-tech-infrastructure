  • 文件定位说明

本文件用于职业健康安全管理体系（OHSMS）认证中 SG14-1 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦橡胶和塑料制品制造在 OHSMS 轴下的危险源、伤害机理、人员暴露、职业健康、高风险作业、设备防护、能量隔离和应急响应。

本文件不承担行业百科说明功能，基础行业事实由对应专业小类基础卡承载。本文件只调用与分组论证、能力后果和审核抽样有关的信息。本组采用“统一领域包 + 橡胶硫化分支 + 轮胎翻新分支 + 塑料成型分支 + 包装印刷复合分支 + 建筑塑料分支 + 其他塑料特殊路线 + 条件扩展”的使用口径；组内共同基础可以共享，但分支差异必须通过能力标注、条件扩展、专项确认和项目边界控制落地。

  • 技术领域包构成
小类编码小类名称纳入本包的活动范围主要内部路线特殊边界
14.01.01橡胶轮胎和内胎的制造，橡胶轮胎翻新和再造新轮胎、内胎、轮胎半成品和翻新再造轮胎制造。配料混炼、半成品成型、硫化、轮胎成型、胎体打磨修补、二次硫化。轮胎翻新、胎体打磨、硫化烟气、废胎体和重型轮胎搬运应作为边界控制。
14.01.02其他橡胶制品的制造胶管、胶带、密封件、减震件、橡胶板、型材、辊、衬里和包胶复合件制造。模压、挤出、压延、连续硫化、橡胶金属粘接、衬胶和后处理。溶剂粘接、乳胶浸渍、衬胶、胶管增强层和产品族差异应分支确认。
14.02.01塑料板、塑料片、塑料管及塑料壳体的制造塑料板片、管材、壳体和类似基础形态制品制造。挤出、压延、共挤、真空定径、热成型、板材焊接和切割。粉料混配、挤出烟气、冷却水、边角料和管材用途边界应确认。
14.02.02塑料包装产品的制造塑料袋、膜、瓶、桶、盒、托盘、泡罩、瓶盖和功能包装制造。吹膜流延、印刷复合、制袋热封、吹塑注塑、吸塑和周转包装。油墨、胶粘剂、溶剂、迁移检测、标签和内容物适配属于专项边界。
14.02.03建筑用塑料制品的制造塑料门窗型材、门窗成品、建筑装饰板、线槽、采光板、防水排水构件和木塑发泡制品。PVC 混料、型材挤出、共挤耐候层、门窗焊角、五金密封装配、发泡和切割。PVC 粉料、稳定剂、阻燃、建筑现场接口、长料搬运和门窗玻璃装配应受控。
14.02.04其他塑料制品的制造日用、工业、电子电器、车辆配套、文教、休闲、滚塑、发泡和装配类塑料制品。注塑、吹塑、滚塑、发泡、嵌件成型、焊接装配、喷涂印刷和表面处理。集合性小类内部跨度大，应按注塑、滚塑、发泡、喷涂、装配和用途分支限定。
  • 分组设立的基本逻辑

本包在 OHSMS 轴下的共同对象是高分子材料加工过程中形成的机械能、热能、化学品、粉尘、烟气、噪声、模具工装、搬运吊装、检维修和异常工况等危险源。分组判断的核心不是产品名称是否相近，而是能量、物质、设备、作业活动、人员暴露和异常状态如何造成夹卷、挤压、烫伤、中毒、窒息、火灾、爆炸、噪声聋、粉尘或化学品职业危害，以及组织如何通过工程控制、作业控制、职业健康、应急和承包方管理降低伤害可能性。

本包可概括的共同证据链为：原辅料和化学品输入 -> 粉料投加、混炼、塑化、硫化、印刷复合、成型、切割打磨、模具更换或检维修 -> 人员暴露和伤害机理识别 -> 防护装置、通风除尘、联锁、能量隔离、作业许可、个体防护和应急 -> 职业健康监测、事件学习和改进。该链条决定了本包共享的专业能力基础，审核员应能够沿现场产线、物料流、记录台账、控制设施和职业健康、事件调查、隐患整改和应急演练建立纵向证据。

组内差异主要表现为危险源组合不同：橡胶制品突出密炼开炼夹卷、炭黑粉尘、硫化烟气、热表面和溶剂粘接；轮胎和翻新突出重型轮胎搬运、胎体打磨粉尘、硫化机和修补刀具；塑料板管壳突出挤出高温熔体、牵引切割和长料搬运；包装突出印刷复合溶剂、收卷夹点、热封刀具和火灾；建筑塑料突出 PVC 粉尘、型材切割、焊角、门窗玻璃和长料搬运；其他塑料突出注塑机、模具吊装、滚塑加热、发泡、喷涂和装配。这些差异不否定设组，但要求本包按“统一领域包 + 分支能力标注 + 条件扩展 + 边界受控”的方式使用，不得把某一产品族或工艺路线经历视为覆盖全部组内小类的充分证明。

  • 专业小类关系类型与授权后果
关系类型含义授权后果典型控制方式
共同基础关系组内小类共享高分子材料加工、粉料和助剂接触、热加工设备、成型机械、模具工装、噪声、职业健康和应急管理基础。可简化通用危险源和人员暴露基础评价，但仍需确认目标小类的实际作业、设备和伤害机理。资料评审、危险源清单核对、现场路线追溯、作业许可和职业健康记录抽样。
并列分支关系同属本技术领域包，但橡胶混炼硫化、轮胎翻新打磨、包装印刷复合、建筑门窗组装和注塑滚塑发泡等路线的危险源不同。应记录实际分支能力，不把同包经历视为全分支能力。分支标注、限定使用、项目技术支持、见证审核。
条件扩展关系已具备相邻分支能力，具有共同机械、热、化学品和职业健康基础，但目标分支存在专门作业和人员暴露。完成补充培训、案例评审、专业面谈、见证审核或技术支持后方可扩展。培训考核、危险源案例评价、首个项目技术支持。
专项确认关系涉及轮胎翻新、重型轮胎吊运、溶剂印刷复合、粉尘爆燃、模具吊装、发泡、喷涂、玻璃门窗装配或高温熔体喷溅等路线。项目使用前应专项确认，必要时增加产品族或作业路线限定。专项面谈、技术专家评审、作业现场样本评价。
不可直接替代关系相关高分子加工经历不足以证明目标分支的危险源识别、伤害机理、人员暴露和应急能力。不得作为目标能力的单独授权依据，应补充目标经历或限定项目类型。重新评价、补充经历、限定作业路线。
边界受控关系当职业病危害、危险化学品、特种设备、消防、承包方、客户现场或法定许可接口改变边界时，同包授权应增加边界说明。授权记录应写明适用边界，项目匹配按实际活动确认。授权备注、合规类别清单、技术支持。
橡胶与塑料基础成型均有粉料或颗粒、热加工、成型机械、噪声和检维修危险源，但橡胶硫化烟气和塑料熔体喷溅不同。可共享高分子加工 OHSMS 基础，目标分支的人员暴露和伤害机理仍需确认。危险源清单、岗位暴露、设备防护和应急样本追溯。
包装印刷复合与普通塑料均可能使用吹膜、制袋或注塑，但包装溶剂、油墨、收卷、热封和清洗作业形成专门危险源。普通塑料经历不能替代包装印刷复合作业能力。溶剂库、印刷复合线、热封机、消防和职业健康记录抽样。
轮胎翻新和轮胎制造均涉及轮胎、硫化和橡胶加工，但翻新增加旧胎检查、打磨、修补、刀具和粉尘暴露。新胎经历扩展到翻新需补充胎体打磨、修补和废胎搬运安全能力。翻新作业、除尘、刀具、胎体搬运和二次硫化样本。
  • 本体系共同能力基础
共同能力维度本包共同基础可共享的审核判断不能共享的边界
危险源识别组内均需识别粉尘、烟气、VOCs、热表面、高温熔体、辊筒夹卷、模具挤压、切割刀具、噪声、搬运、化学品和检维修。可共享从工艺流程、设备状态、岗位活动和异常工况识别危险源的审核判断。翻新打磨、溶剂印刷、PVC 粉尘、模具吊装、滚塑和发泡需分支确认。
人员暴露和职业健康均可能存在粉尘、炭黑、塑料粉、硫化烟气、油墨溶剂、胶粘剂、噪声、热环境和重复动作暴露。可共享职业病危害识别、岗位接触、检测、健康监护、防护用品和告知培训判断。橡胶硫化烟气、印刷复合溶剂、粉尘和噪声暴露谱不同。
设备防护和能量控制均使用混炼、压延、挤出、注塑、吹塑、硫化、切割、收卷、模具和辅助动力设备。可共享防护罩、急停、联锁、夹点防护、检维修能量隔离、模具更换和设备点检审核方法。开炼机、硫化机、收卷机、注塑机、滚塑炉和门窗焊角设备防护差异明显。
高风险作业和承包方动火、临时用电、吊装、模具更换、设备检维修、进入治理设施、外包清洗和施工安装接口均可能存在。可共享作业许可、隔离、监护、承包方交底和应急准备判断。大型模具吊装、重型轮胎搬运、治理设施检维修和客户现场安装边界需专项确认。
应急响应均需针对火灾、化学品泄漏、粉尘异常、废气治理设施故障、高温烫伤、机械伤害、职业暴露和人员急救建立应急能力。可共享应急预案、物资、演练、事故学习和现场处置能力判断。溶剂火灾、粉尘爆燃、硫化烟气异常和高温熔体喷溅应按路线确认。
  • 本体系核心控制要求

本组 OHSMS 审核的核心控制对象是危险源、伤害机理和人员暴露。审核员应从原辅料、设备、作业、岗位、异常状态和检维修活动出发，沿危险源识别、工程控制、作业控制、职业健康、应急响应和事件改进建立证据链。

第一，应确认组织是否按工艺路线识别危险源。橡胶密炼开炼、压延挤出、硫化机、胎体打磨、塑料挤出、注塑吹塑、包装印刷复合、型材切割、模具更换、滚塑发泡和表面处理均应纳入危险源识别。危险源清单不能只写机械伤害和火灾，应体现具体伤害机理。

第二，应审核职业健康管理。粉尘、炭黑、塑料粉、PVC 粉料、硫化烟气、VOCs、油墨溶剂、胶粘剂、噪声和热环境均可能形成职业健康关注对象。审核应核对岗位接触识别、检测资料、健康监护、个体防护用品、局部排风、除尘和员工告知培训。

第三，应审核设备防护和联锁。开炼机和压延机夹卷、挤出机和注塑机高温高压、硫化机合模、热封刀具、收卷机夹点、切割锯片、粉碎机、滚塑加热炉和机器人取件均需要相应防护。审核应关注急停、联锁、防护罩、双手控制、警示、点检和缺陷整改。

第四，应审核高风险作业和能量隔离。模具吊装、轮胎和长料搬运、设备清机、切刀更换、治理设施检维修、动火、临时用电、高处、受限空间和承包方作业应有作业许可、风险交底、隔离挂牌、监护和应急准备。大型注塑模具和重型轮胎搬运不能按普通搬运处理。

第五，应审核危险化学品和火灾爆炸控制。溶剂、油墨、胶粘剂、清洗剂、硫化助剂、发泡剂、阻燃剂、增塑剂和粉尘积聚均可能形成泄漏、中毒、火灾或爆燃场景。审核应核对储存分区、通风、防静电、消防设施、泄漏处置、领用台账和废弃物暂存。

第六，应关注应急和事故学习。橡胶硫化烟气异常、溶剂泄漏、粉尘异常、高温熔体喷溅、机械夹卷、模具坠落、烫伤、火灾和职业暴露事件应有现场处置程序、急救物资、演练和复盘改进。应急演练应与组织实际危险源相匹配。

  • 分小类或内部路线差异分析
小类/路线与本包共同基础主要差异差异对能力授权的影响控制方式
14.01.01 轮胎和内胎制造共享橡胶混炼、成型、硫化、粉尘、烟气、热表面和机械伤害基础。轮胎体积重量大，成型和硫化设备大型化，胎圈钢丝、带束层、搬运和硫化机合模危险源突出。应标注轮胎分支；普通橡胶件经历不能替代重型轮胎设备和搬运能力。抽取轮胎线，追溯密炼、成型、硫化机、吊运搬运、职业健康和应急。
14.01.01 翻新再造轮胎共享轮胎和橡胶硫化基础。胎体检查、打磨粉尘、修补刀具、旧胎搬运、包封硫化和废胎堆存火灾场景突出。属于专项确认路线；新胎制造经历不能替代翻新打磨和胎体处理安全能力。抽取翻新现场，追溯打磨除尘、刀具、搬运、二次硫化和废胎堆存。
14.01.02 其他橡胶制品共享橡胶混炼、硫化、机械夹点、热表面、烟气和职业健康基础。胶管增强、连续硫化、橡胶金属粘接、衬胶、溶剂、乳胶浸渍和小件模压路线差异大。应按密封、胶管、衬胶、粘接和乳胶路线标注。抽取目标产品族，追溯化学品、硫化、夹点、通风、职业健康和应急。
14.02.01 板片管壳共享塑料粉料、挤出、切割、噪声、高温和机械伤害基础。连续挤出高温熔体、牵引夹点、切割锯片、长料搬运、热成型真空和管材定径设备突出。可作为塑料基础成型分支；不能替代包装溶剂或注塑模具吊装能力。抽取挤出线，追溯投料、温区、牵引切割、冷却和防护。
14.02.02 塑料包装共享塑料成型、收卷、热封、切割和噪声基础。印刷复合溶剂、油墨胶粘剂、膜卷搬运、收卷夹点、热封刀具和消防场景突出。从普通塑料扩展到包装需确认溶剂和收卷热封安全能力。抽取印刷复合或制袋线，追溯溶剂、通风、防火、热封和职业健康。
14.02.03 建筑用塑料共享塑料挤出、粉尘、切割、热合、搬运和装配基础。PVC 粉料和助剂、型材切割粉尘、焊角热压、长料搬运、门窗玻璃和五金装配突出。应标注建筑塑料分支；通用挤出经历不能替代门窗装配和建筑接口能力。抽取型材或门窗现场，追溯混料粉尘、切割、焊角、玻璃装配和搬运。
14.02.04 其他塑料制品共享塑料成型、模具、设备防护、热加工和职业健康基础。集合性强，注塑机合模、模具吊装、机器人、滚塑加热、发泡、喷涂、嵌件和装配差异明显。应按注塑、滚塑、发泡、喷涂和装配路线限定使用。抽取目标产品族，追溯设备防护、模具更换、化学品、职业健康和应急。
  • 分组合理性论证结论

本组可以设立的理由在于，六个小类均属于高分子材料加工和制品制造，OHSMS 轴下的共同危险源集中在粉尘、烟气、VOCs、化学品、热能、高温熔体、成型机械、辊筒夹点、模具工装、切割、噪声、搬运、检维修和火灾应急。其危险源识别、人员暴露评价、设备防护、作业许可、职业健康、应急响应和事件改进具有共同专业基础。

因此，SG14-1 可以作为职业健康安全管理体系（OHSMS）技术领域包使用，使用口径为“统一领域包 + 橡胶硫化分支 + 轮胎翻新分支 + 塑料成型分支 + 包装印刷复合分支 + 建筑塑料分支 + 其他塑料特殊路线 + 条件扩展”。审核员授权、项目匹配、能力扩展和持续保持均应体现分支差异；当项目产品族、工艺路线或现场条件超出已确认经历时，应通过案例评价、专业面谈、见证审核或技术支持补足证据。

  • 培训、考核与作业指导书需求

本组应建立橡胶和塑料制品 OHSMS 专业培训，内容包括高分子加工危险源识别、橡胶混炼和硫化烟气、轮胎翻新打磨和重型搬运、塑料挤出和注塑高温熔体、包装印刷复合溶剂和防火、PVC 粉尘和建筑型材切割、模具吊装、滚塑发泡、喷涂、设备防护、能量隔离、高风险作业、职业健康、个体防护、承包方管理、应急演练和典型事故案例分析。

考核宜采用场景式案例和纵向追溯题，要求审核员能够从一个真实或模拟现场出发，说明危险源识别、伤害机理、人员暴露、工程控制、作业控制、职业健康、应急响应和事件改进之间的证据关系。作业指导书应提供分支化抽样路径、典型记录清单、访谈问题库、授权边界提示和首个项目技术支持触发条件。

  • 常见合规义务类别与标准适用提示

本组可能涉及安全生产、职业病危害因素识别、职业健康监护、粉尘和化学品暴露、危险化学品储存和使用、消防管理、特种设备、起重吊装、压力容器和压力管道、机械安全防护、用电安全、动火和检维修、高处和受限空间、承包方管理、个人防护用品和客户现场安全要求等类别。本文件不列具体标准编号和年份；适用性应使用机构受控的有效清单、产品目录、项目范围、客户合同、排放或职业健康检测资料、许可文件类别和所在地监管要求确认。上述类别用于识别外部要求如何转化为管理控制、运行控制、记录保存和现场验证，不替代政府许可、行政执法或专项法定结论。

  • 分组使用限制和法定边界

本组 OHSMS 分组不替代安全生产许可审查、职业病危害评价、职业健康检查结论、消防验收、特种设备监督检验、危险化学品许可、事故调查、行政执法、工伤认定、客户现场安全准入或司法判断。涉及轮胎翻新、重型轮胎吊运、溶剂印刷复合、粉尘爆燃、模具吊装、滚塑发泡、喷涂、建筑门窗玻璃装配和治理设施检维修时，应确认审核员具备对应分支能力。

职业健康安全管理体系审核仅用于评价组织是否识别并控制其危险源、人员暴露和合规义务，不替代政府许可、法定检验、安全评价、职业病危害评价、消防审查、事故责任认定或其他法定结论。

  • 分组结论与使用口径

SG14-1 可作为职业健康安全管理体系橡胶和塑料制品制造技术领域包使用。授权时应记录审核员在橡胶混炼硫化、轮胎翻新、塑料挤出注塑、塑料包装印刷复合、建筑塑料和滚塑发泡喷涂等特殊路线上的实际能力。组内扩展应通过培训、案例评审、专业面谈、见证审核或项目技术支持控制。文件维护触发条件包括：主要设备变化、溶剂和化学品变化、职业健康暴露变化、模具和搬运方式变化、高风险作业变化、事故事件教训、法规许可类别变化或项目匹配中出现能力争议。
