A2 定义与范围界定

本小类包括将天然橡胶、合成橡胶、炭黑、白炭黑、硫化体系、增塑剂、帘线、钢丝、胎圈钢丝等投入，通过胶料混炼、压延、挤出、部件制备、轮胎成型、硫化、后整理和检验形成轮胎或内胎的活动。

轮胎翻新和再造属于本小类的重要组成部分，其核心不是简单修补，而是对可再利用胎体进行外观与无损检查、打磨、修补、贴合新胎面、包封或模压硫化、均匀性和气密性确认，使胎体重新进入使用链条。

本小类的技术对象具有明显的结构复合特征：胶料决定弹性、耐磨和老化行为，帘线和钢丝形成承载骨架，胎面花纹、胎侧、带束层、内衬层和胎圈共同影响承载、操纵、散热、气密和耐久。

A3 边界说明、相邻小类区分点和排除项

相邻活动容易混淆的原因主要区分依据本卡处理原则
14.01.02 其他橡胶制品均使用橡胶配方、混炼和硫化技术是否形成轮胎、内胎或翻新轮胎专用结构具有胎体、胎面、胎圈、帘布或带束层结构的，归入本卡；胶管、胶带、密封件等归入 14.01.02。
汽车零部件制造轮胎用于车辆，部分企业与整车配套紧密企业主导活动是否为轮胎产品制造制造轮胎本体归入本卡；轮辋、制动、悬架等车辆部件制造不纳入本卡。
橡胶材料生产轮胎企业大量使用天然橡胶、合成橡胶和混炼胶是否以最终轮胎产品为产出橡胶原料聚合、胶乳初加工和炭黑生产不纳入本卡。
轮胎维修服务翻新再造与维修都面对已使用轮胎是否进行工业化翻新再造并形成再制造产品工业化胎体评估、贴胎面和硫化归入本卡；门店补胎、动平衡和换胎服务不纳入本卡。
塑料制品制造部分轮胎含有塑料增强材料或包装材料主材和功能结构是否为橡胶弹性复合体塑料轮罩、塑料护板、包装膜不纳入本卡。
再生资源加工废胎可切割、破碎、制粉或裂解是否恢复轮胎使用功能仅从事废胎破碎、胶粉、裂解油等资源化处理的，不纳入本卡。

明确排除项：

  • 橡胶树种植、天然胶乳初加工和合成橡胶基础化学品制造。
  • 轮毂、轮辋、汽车底盘零部件和车辆总成制造。
  • 普通轮胎修补、换胎、充气、动平衡和道路救援服务。
  • 废旧轮胎破碎、胶粉、裂解、热解和燃料化利用。
  • 仅生产帘子布、钢丝帘线、胎圈钢丝而不进行轮胎成型的活动。

A4 分组特征摘要

维度本小类特征上层分组调用提示
主导活动类型橡胶复合结构产品制造和胎体再制造与普通橡胶件相比，本小类必须前置识别胎体结构、骨架材料和硫化成型链条。
核心过程性质配方混炼、骨架贴合、胎坯成型、模压硫化、均匀性和气密确认不能只按通用橡胶硫化处理，应把轮胎结构层次和动态使用特性作为分组判断抓手。
主要技术基础橡胶配方、帘线增强、胎圈结构、胎面花纹、热硫化、动平衡、耐久和翻新胎体评估具备一般橡胶制品知识并不自动覆盖轮胎翻新、带束层和胎体检测知识。
产业链段位上接橡胶、炭黑、钢丝、帘线和助剂，下接汽车、工程机械、摩托车、农业机械和替换胎市场下游对规格、速度级别、承载级别、使用环境和追溯信息要求差异较大。
典型规模跨度从大型自动化轮胎厂到区域性翻新胎厂均存在上层文件应区分全流程制造、专业部件制造和翻新再造三类能力边界。
内部差异提示新胎制造、内胎制造和翻新再造在投入、设备和验证链条上不同新胎重在结构成型与硫化一致性，翻新重在胎体可用性判断和修复过程。
分组比较提示与 14.01.02 共享橡胶配方和硫化基础，但轮胎具有更强的承载、旋转、散热和耐久结构特性如与其他橡胶制品共组，应补充轮胎结构、胎体检查和翻新过程边界说明。
分组敏感边界翻新再造容易被误认为维修服务或废胎资源化上层调用时应把是否恢复轮胎完整使用功能作为边界判据。

B. 术语与概念

B1 专业术语和行业常用表达

术语解释本小类中的使用语境
胎面轮胎与路面接触的外层胶部件决定磨耗、抓地、排水、散热和花纹性能。
胎体由帘布层、胎侧、内衬层等构成的承载结构翻新再造时必须先判断胎体是否可继续使用。
带束层位于胎面下方的增强层影响高速稳定性、承载能力和胎面刚性。
胎圈轮胎与轮辋密封和固定的环状结构由胎圈钢丝、三角胶和包布等组成。
内衬层无内胎轮胎保持气密的内侧胶层气密性不足会导致慢漏气和温升。
帘布层承担轮胎骨架作用的纤维或钢丝增强层帘线角度和贴合状态影响承载和变形。
混炼将橡胶、填料和助剂均匀分散的过程是胶料性能形成的源头环节。
压延将胶料压成胶片或与帘布贴合的过程用于帘布胶片、内衬层、带束层等部件制备。
挤出通过口型连续形成胎面、胎侧或胶条的过程口型、温度和牵引决定截面尺寸。
胎坯成型将各部件按结构顺序贴合成未硫化轮胎的过程层间位置和张力决定结构完整性。
硫化在温度、压力和时间作用下形成交联结构的过程决定胶料弹性、强度和耐热老化行为。
轮胎翻新对可用胎体重新贴合胎面并硫化的再制造活动包含胎体检测、打磨、修补、贴合和成品确认。
胎体打磨去除旧胎面并形成贴合表面的过程打磨深度和轮廓影响翻新结合强度。
动平衡检查轮胎旋转质量分布的过程用于发现局部质量分布不均。
均匀性轮胎圆周方向结构和力学响应的一致程度通常通过专用设备检测径向力、侧向力等指标。
包封硫化翻新轮胎常见的低温硫化方式胎体、预硫化胎面和包封套共同形成密封固化环境。

B3 关键技术概念说明

轮胎不是单一橡胶件，而是橡胶、纤维、钢丝和空气压力共同工作的复合承载结构。其产品功能来自材料配方、结构设计、成型几何和硫化状态的叠加。

硫化过程具有不可逆特征。胎坯进入硫化后，胶料交联结构、部件贴合状态和外形尺寸共同固化，后续只能通过外观、尺寸、均匀性、气密性和剖析等方式确认结果。

翻新再造的技术核心在于胎体判断。可用胎体、局部修补、贴合界面和二次硫化状态共同决定翻新产品能否继续承受循环载荷和温升。

C2 主要功能和性能维度

本小类产品的功能维度包括承载能力、耐磨性能、气密性、抗疲劳性能、耐热老化性能、抗刺扎和抗冲击能力、滚动阻力、湿滑抓着、噪声、均匀性、动平衡、外观缺陷控制和标识追溯。

内胎更强调气密性、接头强度、气门嘴结合、伸长变形和耐老化；翻新轮胎更强调胎体完整性、修补部位可靠性、胎面贴合强度、二次硫化状态和翻新后尺寸外观一致性。

不同用途轮胎的性能权重差异明显。乘用车胎更关注舒适、操纵和低噪声，载重胎关注承载和耐久，工程胎关注切割、刺扎和耐磨，翻新胎关注胎体历史和贴合界面可靠性。

D. 过程与技术

D1 主要工艺或过程流程

新轮胎典型流程为：原材料接收与储存 -> 配方称量 -> 密炼或开炼 -> 胶料停放 -> 压延帘布和内衬层 -> 胎面、胎侧、三角胶等挤出 -> 胎圈制造 -> 部件裁断 -> 胎坯成型 -> 硫化 -> 修边外观 -> 均匀性、动平衡、气密和外观检测 -> 标识、包装和入库。

内胎典型流程为：胶料混炼 -> 挤出管坯 -> 裁断接头 -> 气门嘴安装 -> 硫化 -> 充气检漏 -> 外观尺寸检查 -> 包装。其过程相对短，但气密、接头和气门嘴结合是主要链条。

轮胎翻新典型流程为：旧胎接收 -> 胎体身份和外观检查 -> 无损检查或充气检查 -> 打磨旧胎面 -> 局部修补 -> 胎面或胶条贴合 -> 包封或模压硫化 -> 成品外观、尺寸、气密和均匀性确认 -> 标识和出厂。

废胎处置不可翻新胎体外运资源化转移记录、接收方信息作为废旧物处置边界，不纳入轮胎制造链。

D7 本小类技术链条深化说明

本小类的技术链条可以理解为“橡胶配方状态 -> 增强骨架状态 -> 胎坯结构状态 -> 硫化定型状态 -> 旋转使用状态”的连续转换。与普通橡胶件相比，轮胎必须同时维持气密、承载、变形、散热和耐疲劳。

翻新再造则是在“旧胎体剩余能力”上重新建立胎面和界面。其技术逻辑不是简单恢复外观，而是把胎体筛选、损伤修补、界面处理和二次硫化连成闭环。

链条节点投入或状态技术转换输出或结果本小类特异性
胶料准备橡胶、填料、助剂、骨架粘合体系混炼分散和塑性控制可加工胶料配方微小差异会影响硫化和动态性能。
半成品制备胶片、帘布、钢丝、胎面、胎侧、胎圈压延、挤出、裁断和贴胶结构部件每个部件都有方向、张力和尺寸要求。
胎坯组合多层半成品在成型鼓上按顺序贴合和定型未硫化胎坯层间错位和气泡会固化进成品结构。
硫化定型胎坯、模具、胶囊、热介质温压时交联和花纹形成成品轮胎硫化不足或过度都会改变弹性和耐久。
成品确认硫化后轮胎外观、尺寸、气密、均匀性和动平衡确认可交付产品旋转件特性要求高于普通静态橡胶件。
胎体筛选旧轮胎胎体外观、无损和充气检查可翻新胎体或淘汰胎体翻新成败首先取决于胎体剩余状态。
翻新界面打磨胎体和新胎面修补、涂胶、贴合、包封待二次硫化组件界面清洁和贴合压力是翻新特异节点。
二次硫化翻新组件低温或模压硫化翻新轮胎既不能损伤旧胎体，又要形成可靠粘合。

D8 常见异常和过程补救方式

异常类型常见表现通常处理方式底层记录边界
胶料焦烧胶料加工中过早交联、表面粗糙或流动性下降隔离批次、复测硫化特性、调整使用条件只记录客观异常和处理方式。
部件尺寸漂移胎面宽度、胶片厚度或帘布角度偏离设定停机调整口型、辊距、牵引或裁断参数不引申到人员能力结论。
胎坯错位或夹气成型后出现层间偏移、气泡、搭接异常返工、剔除或按工艺规定处理记录缺陷类型和发生环节。
硫化外观缺陷缺胶、气泡、花纹不清、胎侧伤痕检查模具排气、胶囊、硫化参数和胎坯状态作为工艺敏感点记录。
翻新胎脱层胎面与胎体界面分离或鼓包追溯胎体检查、打磨轮廓、贴合和硫化状态保留为翻新链条特异异常。

E3 本小类在产业链中的位置

本小类位于橡胶材料和车辆、工程装备之间，是典型的材料复合成型和结构件制造节点。上游材料的稳定性会沿混炼、半成品、成型和硫化链条逐步放大或被控制。

轮胎产品直接进入移动设备使用场景，其产业链位置使其既受到材料工业影响，也受到车辆使用工况、道路条件和替换市场的影响。翻新再造又把使用后胎体重新拉回制造链，形成闭环式产业链特征。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

维度本小类客观特征表现形式
技术复杂度高材料配方、复合结构、硫化工艺和旋转使用特性叠加。
自动化程度大型企业较高，翻新和内胎企业跨度大成型、硫化和检测可自动化，胎体检查和修补仍依赖经验。
人工依赖中到高半成品贴合、外观判定、翻新胎体筛选和缺陷识别仍需人工参与。

H2 典型组织形态

组织类型典型特征过程能力形态
大型轮胎集团多基地、全流程、规格系列完整自动化设备和实验室能力较强。
专业内胎或小规格轮胎企业产品相对集中、设备投资较低依赖胶料、接头和检漏过程稳定。
区域翻新胎企业面对旧胎体来源复杂胎体判断和修补过程是能力核心。
半成品配套企业只生产胎圈、胎面、帘布等与下游轮胎厂接口紧密。
外贸和替换市场型企业规格变化快、客户标签多订单、标识和批次转换频繁。

H3 客观存在的易出问题环节和技术敏感点

敏感点客观表现客观影响链底层记录边界
胶料配方和称量偏差少量助剂或填料偏差导致胶料状态变化配方偏差 -> 硫化曲线变化 -> 成品物性和耐久状态变化只记录事实因果链。

帘线贴胶和张力异常帘线裸露、角度偏差或张力不均骨架异常 -> 承载不均 -> 运行中局部发热或变形记录客观敏感点。
胎坯成型错位带束层偏移、搭接异常或胎圈定位不准结构错位 -> 旋转不均 -> 振动和偏磨限于技术事实。
硫化参数异常硫化不足、过硫或模具排气不良交联状态异常 -> 弹性和强度变化 -> 使用中裂纹或鼓包不评价体系符合性。
内衬层或内胎气密不足针孔、接头漏气、气门嘴结合不良漏气 -> 胎压下降 -> 温升和变形增加记录产品事实。
胎体筛选失误翻新前未识别内部脱空或帘线损伤不可用胎体进入翻新 -> 缺陷被覆盖 -> 使用中界面或结构失效翻新特异敏感点。
翻新打磨过深或不足胎体损伤或贴合面轮廓不稳定界面处理异常 -> 粘合不足 -> 胎面脱层只陈述客观链条。
储存老化胶料或成品长期受热、光照、臭氧影响老化 -> 裂纹或粘性变化 -> 加工和使用状态改变作为行业本底事实。
规格切换频繁模具、部件和标签频繁更换切换失误 -> 部件混用或标识错误 -> 交付信息不一致记录组织形态敏感点。
