  • 文件定位说明

本文件用于质量管理体系认证中 QG29-1 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦终端零售、车辆销售、汽车零配件零售、专营店零售、摊位市场零售和非店铺零售在 QMS 轴下的质量形成链、客户要求转化、关键质量特性、检验放行、记录追溯、投诉反馈和改进闭环。本文件不承担行业百科说明功能，基础行业事实由对应专业小类基础卡承载。

本组采用“统一零售领域包 + 商品分支标注 + 特殊商品专项确认 + 渠道边界控制 + 条件扩展”的使用口径。组内小类可以共享通用商业服务质量管理判断方法，但不得把某一商品、服务或渠道分支经历等同于另一分支完整能力；对特殊商品、复杂服务、法定接口或高价值交付，应追加分支确认。

  • 分组设立的基本逻辑

本包在 QMS 轴下的共同对象是面向终端客户的商品选购、交易、交付、退换、售后响应和客户体验控制。质量管理体系审核关注的核心不是商品名称或服务名称是否完全相同，而是客户需求如何被识别和转化，商品或服务对象如何受控，交易、工单或订单过程如何记录，交付前后如何检验或确认，客户反馈如何形成闭环。

本包可概括的共同质量形成链为：客户需求或购买意向 -> 商品或服务信息展示 -> 商品适配和库存确认 -> 价格、数量、效期、规格或配置复核 -> 交易结算 -> 交付或配送 -> 退换、投诉和售后闭环。该链条决定了本包共享的专业能力基础，即审核员应能够围绕客户要求、商品或服务对象、过程记录、输出验证、交付确认和反馈闭环建立审核证据链。

组内差异主要表现为商品属性、交付渠道和外部接口不同：车辆销售强调高价值配置和交付文件；食品、烟草、药品、医疗器械、燃料、危险化学品强调特殊商品边界；ICT、电器和音像设备强调功能兼容和售后；摊位市场和非店铺零售强调现场或远程交易记录、页面信息和仓配退换。这些差异不否定设组，但要求本包不能按无差别能力包使用，应通过分支标注、专项确认、条件扩展和抽样控制加以处理。

  • 本体系核心控制要求

本组所称关键质量特性，是指商品或服务输出中影响客户可接受性的适配性、真实性、完整性、及时性、一致性、可追溯性、功能状态、数量准确性和售后响应。商业服务场景中的检验和放行，通常表现为订单复核、商品验收、库存盘点、称量计量、温度或效期检查、工单复核、交付签收、客户确认、主管抽查或质检记录。审核员应把这些复核和确认活动作为服务结果进入客户使用前的质量控制证据。

第一，应确认组织是否把终端客户需求转化为可验证的商品或服务要求。车辆销售需核对配置、交付时间、随车文件、金融保险接口和售后承诺；普通商品零售需核对规格、数量、价格、标签、促销口径和退换规则；线上零售需核对页面描述、库存同步、配送承诺和客服口径。

第二，应评价商品信息和实物一致性。审核样本应覆盖至少一项实物商品、相应价签或页面描述、采购或入库记录、库存记录、交付或销售记录和客户反馈。对于食品、药品、医疗器械、烟草、燃料、危险化学品、珠宝、旧货和软件授权，应核对批号、效期、证书、许可类别、用途说明或瑕疵披露等证据。

第三，应追溯库存、陈列和防护控制。生鲜食品关注温度、鲜度、称重和短保周转；服装鞋类关注尺码、色号和试穿退换；电器和 ICT 关注型号、序列号、安装和兼容；五金油漆玻璃关注规格、色号、裁配和危险属性；旧货关注来源、成色、瑕疵和功能状态。

第四，应核查交易、交付和放行记录。车辆交付应能追到合同、配置、交车检查和客户签收；燃料零售应能追到储罐或加注、计量、结算和异常处理；非店铺零售应能追到订单、支付、拣货、发运、签收和退换。放行不是简单收款，应体现客户可接受性的确认。

第五，应评价退换、投诉和纠正闭环。典型问题包括商品与描述不一致、效期或温控失控、车型或配件适配错误、称重计量差异、页面宣传偏差、配送破损、售后响应超时、旧货瑕疵未披露和特殊商品边界识别不足。审核应追溯问题登记、原因分析、客户沟通、补救和防止再发生措施。

  • 分组合理性论证结论

本组可以设立的理由在于，组内活动均围绕终端客户购买和服务体验形成质量，均需要控制客户需求识别、商品信息、库存防护、交易交付、售后响应和反馈闭环。差异主要来自商品属性和渠道形态，可通过分支能力标注、特殊商品专项确认和抽样策略控制。

因此，QG29-1 可以作为质量管理体系技术领域包使用，但其使用方式应为“统一零售领域包 + 商品分支标注 + 特殊商品专项确认 + 渠道边界控制 + 条件扩展”。审核员授权、项目匹配和能力扩展均应体现分支差异，不得把同包经历理解为跨全部小类的充分证明。
