  • 文件定位说明

本文件用于环境管理体系（EMS）认证中 EG35-2 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦建筑物一般清洁、建筑专项清洗、工业清洗及其他清洁服务在本体系轴下的清洁剂、废水、废气、固体废物、污泥、残液、消杀药剂、外包处置和环境合规接口，不承担行业百科说明功能，基础行业事实由对应专业小类基础卡承载。

本组采用“统一领域包 + 一般清洁分支 + 建筑专项清洗分支 + 工业清洗专项确认 + 其他清洁路线限定”的使用口径。组内小类可以共享本体系的基础判断方法，但不得把某一分支经历等同于另一分支完整能力；对现场性强、外部合规接口明显、污染源或危险源发生实质变化的情形，应在授权和项目匹配阶段追加分支确认。

  • 技术领域包构成
小类编码小类名称纳入本包的活动范围主要内部路线特殊边界
35.16.01建筑物的一般清洁办公室、住宅、商店、工厂、研究所等建筑日常清洁。日常保洁、公共区域清洁、卫生间、地面、垃圾收集。清洁剂、废水、固体废物、消杀药剂、外包处置和客户场所排放接口应按路线确认。
35.16.02其他建筑及工业清洗活动建筑外墙、窗户、烟囱、通风管、锅炉、工业机械等专项清洗。建筑专项清洗、工业设备清洗、管道清洗和炉膛系统清洗。清洁剂、废水、固体废物、消杀药剂、外包处置和客户场所排放接口应按路线确认。
35.16.02a工业清洗活动工业设备、管道、储罐、换热器、生产设施和特殊介质系统清洗。化学清洗、高压水射流、机械清洗、停机清洗和设备复位。工业残液、含污染物废水、清洗剂、污泥、废包装和客户设备内残留介质为重点边界。
35.16.02b其他建筑清洗活动外墙、玻璃、烟囱、通风管、炉灶、锅炉和排气装置等建筑专项清洗。外墙玻璃、烟道、通风管、屋面和立面清洗。清洁剂、废水、固体废物、消杀药剂、外包处置和客户场所排放接口应按路线确认。
35.16.03其他清洁活动游泳池、交通工具、罐体、消毒灭杀、洗瓶、道路清扫和除雪等。交通工具清洁、消杀、罐体内部清洗、道路保洁、洗瓶和除雪。清洁剂、废水、固体废物、消杀药剂、外包处置和客户场所排放接口应按路线确认。
  • 分组设立的基本逻辑

本包在本体系轴下的共同对象是清洁对象表面、建筑设施、工业设备、交通工具、罐体、道路和公共场所清洁过程中形成的清洁剂投入、污染物转移和废物流。分组判断的核心不是服务名称是否相同，而是环境因素、污染源、污染物、废水、废气、固体废物、外包处置、监测和合规义务的形成机理和控制路径是否足够接近。

本包可概括的共同证据链为：清洁对象和污染物识别 -> 清洗方案和药剂选择 -> 用水、清洁剂、设备和人员投入 -> 清洗作业和污染物剥离 -> 废水、废气、污泥、残渣、废包装收集 -> 暂存、转移、处置、监测和客户验收 -> 异常改进。该链条决定了本包共享的专业能力基础，审核员应能够围绕源头识别、过程控制、记录追溯、异常处置和改进闭环建立审核证据。

一般建筑清洁以低浓度废水和一般固体废物为主；建筑专项清洗会增加高处表面污染物、烟道油污、通风管积尘等废物流；工业清洗涉及设备残留介质、清洗废液、污泥和化学品，是本组环境边界最重的路线。这些差异不否定设组，但要求本包不能按无差别能力包使用，应通过分支标注、专项确认、条件扩展和抽样控制加以处理。

  • 专业小类关系类型与授权后果
关系类型含义授权后果典型控制方式
共同基础关系均以服务场所、办公资源、电子设备、客户现场、外包服务或轻量物料为主要环境因素载体。可简化办公型服务和一般商业支持服务的 EMS 基础评价，但仍需确认目标分支的污染源、废物流和合规接口。资料评审、现场访谈、环境因素清单和废物流追溯。
并列分支关系同属本环境领域包，但资源消耗、废物类别、客户现场或外包链不同。应记录实际分支能力，不把同包经历理解为全分支能力。分支标注、限定使用、项目技术支持。
条件扩展关系已具备相邻服务环境因素识别能力，但目标路线存在专门污染源或废物链。完成补充培训、案例评审、专业面谈或见证审核后方可扩展。培训考核、案例评审、见证审核。
专项确认关系涉及化学品、清洗废液、消杀、电子废弃物、展会大量废弃物、车辆或客户现场复杂边界。项目使用前应专项确认，必要时配置技术专家支持。专项面谈、技术专家评审、项目匹配确认。
不可直接替代关系普通办公型服务经验不足以证明专项现场、清洗、绿化、安防安装或包装物料环境控制能力。不得作为目标能力的单独授权依据。补充目标案例或限定项目类型。
边界受控关系客户现场、外包处置、法定许可、废弃物转移、个人服务设施或化学品使用改变环境边界。授权记录应写明边界，项目匹配时按实际活动确认。授权备注、合规类别清单、技术支持。
一般清洁与建筑专项清洗均共享清洁剂、用水、废水、废物和客户现场接口。可共享清洁服务基础能力，建筑专项应补充材质、烟道、通风管和现场废物流案例。专项项目案例、废物收集和客户验收记录。
一般清洁与工业清洗仅共享清洁活动基础，污染物强度和处置要求差异明显。不得以一般清洁经历替代工业清洗 EMS 能力。工业清洗专项培训、案例评审和见证审核。
35.16.03集合路线交通工具、罐体、消杀、道路和除雪等路线均属清洁服务但环境因素不同。应按实际清洁对象限定授权。合同对象、药剂、废物、客户场所和处置记录确认。
  • 本体系共同能力基础
共同能力维度本包共同基础可共享的审核判断不能共享的边界
污染源识别均需识别清洁对象表面污染物、药剂、用水、工具设备、废水、固体废物和客户现场排放接口。可共享清洁活动环境因素和污染源识别方法。工业残留介质、罐体、消杀和烟道油污需专项确认。
物料和药剂控制均可能使用清洁剂、消毒剂、除油剂、除垢剂、吸附材料和包装容器。可共享采购、储存、配比、领用、剩余物和废包装控制判断。酸碱、溶剂、强氧化或专用工业药剂需更高粒度确认。
废物流和污染物控制均可能形成废水、残渣、污泥、废包装、废抹布、过滤物和客户现场垃圾。可共享收集、暂存、转移、处置和台账判断。工业废液、含油污泥、消杀残液和罐体清洗残留不宜与一般废水混同。
监测和客户接口均需确认客户场所排水、废物交接、外包处置、现场保护和验收要求。可共享监测需求识别、交接记录和验收证据判断。客户生产设备、地下管网、雨污分流和特殊设施接口需专项确认。
  • 本体系核心控制要求

EMS 审核应围绕环境因素、污染源、污染物、废水、废气、固体废物、危险废物类别识别、外包处置、监测和合规义务展开。服务业组织不宜仅因生产污染较少而简化判断；办公资源、客户现场、外包服务、活动物料、电子设备、药剂和废物流同样需要形成可追溯控制。

第一，应从清洁对象而不是服务名称识别环境因素。地面保洁、外墙清洗、通风管清洗、工业设备清洗、交通工具清洁、罐体内部清洗、消杀和道路除雪的污染物来源、废物流和客户接口均不相同。

第二，应核查清洁剂和物料控制。审核应追溯药剂选择依据、配比、领用、现场存放、剩余物回收、废包装处置和替代减量措施。工业清洗还应确认清洗介质、设备残留物、置换液、冲洗水和污泥的识别与控制。

第三，应核查废水、废气、固体废物和特殊废物流。一般清洁废水不得简单等同于工业清洗废液；烟道和通风管可能产生含油或含尘废物；消杀和泳池维护可能涉及残余药剂；道路除雪可能涉及融雪物和路面残渣。

第四，应评价监测、转移和异常处置。清洗废液去向、客户排水接口、现场泄漏、药剂误用、异味投诉、清洗残留、污泥暂存和外包处置记录应形成闭环。审核员应从一个清洗项目追溯到废物流最终交接证据。

  • 分小类或内部路线差异分析
小类/路线与本包共同基础主要差异差异对能力授权的影响控制方式
35.16.01 建筑物一般清洁共享清洁剂、用水、生活垃圾、废包装和客户场所排放接口。以日常保洁为主，污染物浓度通常较低，重点在药剂用量、废水去向和垃圾分类。可作为清洁基础分支，不覆盖工业清洗。抽取日常保洁样本，追溯药剂领用、废水排放接口、垃圾分类和客户巡检。
35.16.02 建筑及工业清洗共享专项清洗对象、药剂、废水、污泥和客户验收基础。内部包含建筑专项和工业设备清洗，污染源差异大。应按35.16.02a或35.16.02b细化授权。抽取专项项目，确认清洗对象、污染物类别、收集和处置路径。
35.16.02a 工业清洗共享清洗作业和客户验收基础。废液、油污、酸碱清洗剂、含污染物污泥、残留介质和设备排空置换突出。属 EMS 重点专项路线，不以一般清洁经历替代。追溯工业清洗方案、介质识别、废液收集、暂存、转移和复位验收。
35.16.02b 建筑专项清洗共享清洁剂、废水、固体废物和客户现场接口。外墙、玻璃、烟道、通风管和锅炉等对象材质与污染物不同。需确认建筑专项清洗能力，尤其是烟道、通风管和锅炉积垢处置。抽取外墙或烟道项目，追溯试清洁、废物收集、现场保护和客户验收。
35.16.03 其他清洁共享清洁服务、药剂、废水、废物和客户验收基础。交通工具、游泳池、罐体、消杀、洗瓶、道路清扫和除雪差异明显。应按实际路线限定授权；罐体、消杀和道路清扫需专项确认。抽取具体服务合同，确认药剂、废水、残渣、道路撒布物和处置记录。
  • 分组合理性论证结论

EG35-2 可以设立为 EMS 清洁活动技术领域包。五个小类均围绕清洁对象、清洁剂投入、污染物剥离、废水和固体废物控制、外包处置和客户验收形成环境管理逻辑。组内差异主要由清洁对象和污染物强度决定，其中工业清洗、罐体清洗、消杀和烟道通风管清洗应作为专项或边界受控路线。

  • 审核关键要点与抽样方法
抽样场景现场必看记录必查纵向追溯路径追问方向
一般建筑清洁保洁区域、药剂间、工具间、垃圾分类点、客户排水接口。药剂领用、配比、作业记录、巡检、垃圾交接、客户反馈。区域 -> 药剂 -> 作业 -> 废水/废物 -> 客户确认。废水排向何处；药剂是否按要求配比和回收。
工业清洗设备、管道、储罐、隔离点、药剂、废液收集容器和暂存点。清洗方案、介质识别、药剂记录、废液污泥、转移交接、验收复位。对象识别 -> 清洗方案 -> 作业 -> 废液收集 -> 处置 -> 验收。污染物类别如何识别；废液和污泥去向如何证明。
建筑专项清洗外墙、玻璃、烟道、通风管、现场保护和废物收集点。勘查、试清洁、药剂、废物收集、现场清理、客户验收。勘查 -> 方案 -> 作业 -> 废物收集 -> 验收。烟道油污和通风管积尘如何收集。
消杀或泳池清洁药剂储存、投加点、作业区域、客户提示和残液处理点。药剂领用、配比、作业记录、残留确认、客户反馈。对象 -> 药剂 -> 作业 -> 残留 -> 客户确认。药剂残留和废包装如何控制。
道路或交通工具清洁车辆、路面、清扫设备、冲洗水和收集物。作业计划、设备维护、收集物、道路投诉、客户验收。路线 -> 作业 -> 收集 -> 转运 -> 反馈。路面残渣和冲洗水如何管理。
  • 能力扩展与条件授权
起点能力目标能力可扩展依据必须补充确认授权限制
一般清洁建筑专项清洗共享清洁剂、用水、作业记录和客户验收基础。外墙、烟道、通风管、材质保护、污染物收集和现场废物流案例。未确认前仅限一般清洁。
一般或建筑清洁工业清洗仅共享清洁活动基础。工业介质、清洗废液、污泥、残液、置换、暂存和转移案例。工业清洗应专项确认。
一般清洁消杀或泳池清洁共享药剂和客户场所基础。消杀药剂、残留控制、泳池水处理和客户告知案例。按具体对象限定。
建筑专项清洗35.16.03罐体或交通工具清洁共享专项清洗方案和客户验收基础。罐体残留、交通工具污物、废水收集和外包处置案例。按实际清洁对象限定。
  • 培训、考核与作业指导书需求

本组应建立清洁活动 EMS 专业培训，内容包括清洁对象和污染源识别、清洁剂和消杀药剂控制、用水和排水接口、废水废气固体废物控制、污泥和残液收集、工业清洗废液、烟道和通风管废物、罐体和交通工具清洗、道路清扫和除雪、外包处置和客户现场环境边界。考核应要求审核员完成一般清洁、工业清洗、建筑专项和其他清洁的废物流追溯。

  • 常见合规义务类别与标准适用提示

本组可能涉及清洁药剂、消毒灭杀、废水排放接口、污泥和残液、一般固体废物、危险废物类别识别、外包处置、道路清扫、车辆清洗、泳池水处理、客户场所环境要求和化学品管理等类别。文件不列具体标准编号和年份；适用性应使用机构受控的有效清单、客户合同、服务对象和所在地要求确认。

  • 分组使用限制和法定边界

本分组仅用于 EMS 认证中的技术领域包论证和审核员能力控制，不替代排污许可、危险废物认定、化学品许可、环境监测法定结论、行政执法、客户设备验收或外包处置单位资质审查。涉及工业清洗、罐体清洗、消杀、烟道通风管清洗、客户生产设备、特殊化学介质或大量废液污泥时，应进行专项能力确认。

  • 分组结论与使用口径

EG35-2 可作为环境管理体系清洁活动技术领域包使用。授权时应记录一般清洁、建筑专项清洗、工业清洗、消杀/泳池/交通工具/道路等其他清洁路线的实际能力。文件维护触发条件包括：清洁对象、药剂、废水去向、污泥残液处置、客户排放接口、外包处置方式或工业清洗路线发生实质变化。
