  • 文件定位说明

本文件用于职业健康安全管理体系认证中 SG29-2 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦汽车与摩托车保养维修服务在职业健康安全管理体系轴下的车辆维修危险源、举升和试车、钣喷和化学品暴露、触电、机械伤害、职业健康和应急，不承担行业百科说明功能；基础行业事实由对应专业小类基础卡承载。

本组采用“维修专项领域 + 条件授权 + 分支限定”的使用口径。组内小类可以共享本体系轴下的基础判断方法，但不得把某一分支经历等同于另一分支完整能力。对污染源、危险源、外部合规接口、客户现场或外包链条发生实质变化的情形，应在授权和项目匹配阶段追加分支确认。

  • 技术领域包构成

本技术领域包包括 2 个专业小类。下表仅列示本组在本体系轴下的调用范围和分组边界，专业小类的完整定义、产业链、术语和基础工艺知识由基础卡提供。

小类代码小类名称主导活动类型主要危险源载体分组边界提示
29.02.00汽车的保养和修理汽车维修车辆举升、底盘作业、电气检测、轮胎拆装、钣喷、清洗、试车、压缩空气和危化品使用。举升设备、动火、喷涂、蓄电池和新能源高压系统应按专项能力确认。
29.04.00摩托车的销售、保养、维修及零部件和配件的销售摩托车复合服务整车展示、配件销售、保养维修、试车、举升支撑、燃油系统、电瓶和小型工具。与汽车维修共享工单和维修安全逻辑，但车型结构、试车场景和骑行安全边界不同。
  • 分组设立的基本逻辑

本组在本体系轴下的共同对象是车辆和摩托车维修服务中的接车、诊断、举升、拆装、钣喷、清洗、试车和交付活动。分组判断的核心不是小类名称是否相近，而是危险源、伤害机制、人员暴露、职业健康、高风险作业、事件记录、承包方和应急响应的形成机理、控制路径和审核证据是否足够接近。

本组可概括的共同证据链为：接车诊断 -> 工单和风险告知 -> 举升或支撑 -> 拆装维修 -> 钣喷清洗或电气检测 -> 修后测试试车 -> 废旧件处理 -> 交付和事件改进。该链条决定了审核员可以共用的专业能力基础，也决定了现场抽样时应从源头识别、过程控制、记录追溯、异常处置和改进闭环几个方向建立证据。

汽车维修在举升、钣喷、新能源高压系统和大型车辆方面更突出；摩托车维修在小型车辆支撑、试车和燃油系统方面更突出。这些差异不否定设组，但要求本组按条件授权和边界受控方式使用。

  • 组内关系结构与授权后果
关系类型含义授权后果典型控制方式
共同基础关系组内活动均需要识别危险源、伤害机制、人员暴露、职业健康、场所设施、外部交通、承包方和应急响应。可共享基础 OHSMS 审核能力，但应确认具体作业场景和人员暴露。危险源清单复核、现场走查、事件记录追溯、人员访谈。
并列分支关系同属本职业健康安全领域包，但商品属性、作业强度、客户现场、仓储装卸、高风险作业或人员接触不同。授权应保留分支标注，不把单一分支经历理解为全分支能力。分支面谈、样本追溯、项目匹配备注。
条件扩展关系相邻分支具备相同安全管理基础，但目标分支存在专门设备、化学品、车辆、维修、冷库或人员暴露。完成补充培训、案例评审、专业面谈或见证审核后方可扩展。培训考核、案例评审、见证审核。
专项确认关系涉及燃料、危险化学品、车辆维修、举升、喷涂、高压电、叉车、大件装卸、夜间或外部现场作业。项目使用前应确认作业活动、人员暴露和应急边界，必要时配置技术支持。专项问询、作业清单确认、应急记录复核。
不可替代关系普通办公室、普通门店或纯代理经历不能证明维修、燃料、化学品或高装卸强度活动的 OHSMS 审核能力。不得作为目标分支能力的单独依据。补充目标经历或限定项目类型。
边界受控关系客户现场、承包方、仓储物流、维修拆解、加注、冷库或异常工况会改变危险源边界。授权和项目匹配应按实际活动边界使用。授权备注、作业边界确认、承包方接口核验。
车辆维修专项关系汽车和摩托车共享维修服务安全链条，但车辆结构、举升方式、试车场景和高压系统不同。授权应标注汽车、摩托车、钣喷、新能源或大型车辆等分支。维修现场见证、设备点检、工单追溯和事件记录。
  • 共同过程与专业机制分析

本组的危险源不是一般门店风险，而是车辆维修作业风险。举升设备、千斤顶、轮胎拆装、压缩空气、电焊切割、喷涂、清洗、燃油系统、电气系统、高压电池、试车道路和客户车辆交接均可能造成严重伤害。职业健康方面，应关注噪声、有机溶剂、尾气、粉尘和长期弯腰姿势。OHSMS 审核应从一张维修工单出发，把人员、设备、作业方法、个人防护、异常处置和应急响应串起来。

过程环节危险源和人员暴露形成机制审核关注的证据
接车诊断识别车辆状态、维修项目、试车需求、燃油和电气系统风险。接车单、工单、风险告知、客户确认。
举升拆装车辆举升、底盘作业、轮胎拆装、发动机和传动系统维修形成夹挤砸伤。举升机点检、作业指导、维修记录。
钣喷清洗动火、喷涂、有机溶剂、粉尘、噪声和清洗药剂形成职业健康暴露。通风、个人防护、材料清单、培训记录。
试车交付道路试车、制动转向验证、客户区域车辆移动形成交通和碰撞风险。试车记录、交付确认、事件和投诉。
  • 本体系核心控制要求

第一，应把车辆举升和支撑作为必抽样对象。审核员应观察举升机、支撑点、限位、防滑、载荷、维修人员站位和车辆锁止，核对设备点检、维修记录和人员培训。

第二，应确认钣喷、清洗和化学品暴露。喷漆房、调漆区、打磨区、清洗区、废漆和溶剂存放点应纳入现场走查，重点确认通风、个人防护、火源控制、职业健康沟通和异常处置。

第三，应对新能源车和电气维修进行专项确认。涉及高压电池、充电系统、电气诊断和事故车维修时，普通机修经验不足以证明能力，应确认断电、隔离、警示、专用工具和应急措施。

第四，应关注摩托车维修的试车和燃油边界。摩托车试车常与门店周边道路、客户区域和小型维修工位交叉，审核员应检查试车路线、人员防护、燃油系统维修和客户交付控制。

  • 差异分析与可接受性判断

本章用于说明组内小类为什么能够设为同一技术领域包，同时说明哪些差异需要通过授权备注、专项确认或现场抽样补足。差异分析不用于弱化专业能力要求，而是用于把能力边界写清楚。

小类共同基础主要差异边界控制可接受理由抽样落点
29.02.00 汽车的保养和修理均通过人员活动、场所设施、客户接触、仓储搬运、外部交通和异常处置形成危险源识别证据。夹挤砸伤、车辆滑落、火灾爆炸、触电、噪声、有机溶剂暴露、尾气和试车道路伤害是主要伤害机制。举升设备、动火、喷涂、蓄电池和新能源高压系统应按专项能力确认。可共用危险源识别、人员暴露评价、事件追溯、培训沟通和应急响应审核方法。抽取 汽车维修 样本，追溯危险源、伤害机制、职业健康暴露、高风险作业和应急记录。
29.04.00 摩托车的销售、保养、维修及零部件和配件的销售均通过人员活动、场所设施、客户接触、仓储搬运、外部交通和异常处置形成危险源识别证据。机械夹伤、烫伤、燃油火灾、试车摔伤、噪声和客户区域交叉作业是主要危险源。与汽车维修共享工单和维修安全逻辑，但车型结构、试车场景和骑行安全边界不同。可共用危险源识别、人员暴露评价、事件追溯、培训沟通和应急响应审核方法。抽取 摩托车复合服务 样本，追溯危险源、伤害机制、职业健康暴露、高风险作业和应急记录。
  • 分组结论

SG29-2 组内小类均以车辆保养维修为危险源形成核心，主要伤害机制集中在举升坠落、机械夹挤、钣喷火灾、化学品暴露、触电、噪声、尾气和试车交通。汽车与摩托车维修对象不同，但工单驱动、设备工具、维修实施、修后验证、人员培训和应急处置证据链一致，因此可以设为同一 OHSMS 技术领域包，并按具体维修分支控制授权。

因此，SG29-2 可以作为职业健康安全管理体系技术领域包使用，使用方式为“维修专项领域 + 条件授权 + 分支限定”。审核员授权、项目匹配和能力扩展均应体现分支差异，不得把同包经历理解为跨全部小类的充分证明。

  • 审核员共同能力评价与条件授权

本章用于界定本技术领域包可共享的共同能力，以及不同分支在授权、项目匹配和能力扩展时需要追加确认的内容。

能力要素评价内容可接受证据授权控制
危险源识别识别服务场所、仓储搬运、客户现场、车辆、维修工具、化学品、燃料和外部交通中的危险源。危险源清单、现场走查、作业活动清单、事件记录。按分支标注；高风险作业需专项确认。
伤害机制判断判断滑倒跌倒、搬运扭伤、车辆碰撞、夹挤砸伤、触电、火灾爆炸、中毒和职业健康暴露。岗位观察、设备点检、培训记录、职业健康沟通和事故事件记录。维修、燃料、化工和大件装卸需目标经历或专家支持。
人员暴露与职业健康识别岗位、班次、顾客接触、夜间作业、噪声、粉尘、有机溶剂、低温和心理压力。岗位清单、排班、个人防护、体检或健康沟通记录。职业健康判断应与实际暴露相匹配。
运行控制与应急检查现场隔离、举升、装卸、库区交通、化学品泄漏、火灾、客户冲突和异常处置。作业规程、点检、演练、事件调查、承包方记录。按实际作业抽样，不能用普通门店经历替代特殊现场。
沟通参与与改进评价员工参与、承包方沟通、事件报告、纠正措施和管理评审。访谈记录、会议记录、整改关闭和绩效趋势。证据应能追溯到具体岗位或服务样本。

能力扩展应采用“基础经历确认、目标分支差异培训、案例评审或专业面谈、必要时见证审核、授权记录标注”的路径。对燃料、危险化学品、车辆维修、个人家庭用品维修、冷链、废旧材料和含客户现场复杂接口的项目，应在项目匹配阶段再次确认适用边界。

  • 审核关键要点与抽样路径

本组抽样应覆盖一个举升或拆装工位、一个钣喷或清洗场景、一个试车交付样本；若涉及新能源车、大型车、事故车或摩托车试车，应追加专项样本。

  • 培训、考核与作业指导书需求

培训应覆盖车辆维修危险源识别、举升设备、钣喷和有机溶剂、燃油系统、电气和新能源高压系统、试车安全、职业健康暴露、事件调查和应急响应。对只有一般商贸审核经历的人员，应通过维修现场见证确认能力。

考核宜采用场景题、案例追溯题和边界判断题，要求审核员能够从一个真实或模拟项目出发，说明本体系轴下的识别、评价、控制、记录、异常处置和改进之间的证据关系。作业指导书应提供分支化抽样路径、记录清单、访谈问题和授权边界提示。

  • 常见合规义务类别与标准适用提示

常见合规义务类别包括机动车维修经营管理、消防、职业健康、特种设备或起重举升边界、危险化学品使用和储存、个人防护、道路试车、承包方和客户场所要求。本文件不列入具体标准编号和年份；适用性应使用机构受控的有效清单、客户合同、服务目录、项目范围和所在地监管要求确认。上述类别用于识别外部要求如何转化为管理体系控制，不替代政府许可、法定检验、行政执法或客户专项验收。

  • 使用限制和法定边界

本组不覆盖汽车制造、零部件制造、燃料零售加注、报废机动车拆解或危险化学品经营。若维修组织实际开展上述活动，应另行确认对应技术领域能力。

管理体系审核仅用于评价组织是否在其服务范围内建立并实施相应管理控制，不替代行政许可、法定检验、行政执法、政府监管、司法判断或强制性专项评价。涉及受监管资质、特种商品、危险化学品、燃料、药品、医疗器械、个人信息、资金信用、道路运输、客户现场和外包服务时，应在项目匹配阶段确认审核员分支能力和必要的技术支持。
