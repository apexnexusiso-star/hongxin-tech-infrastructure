  • 文件定位说明

本文件用于环境管理体系认证中 EG29-1 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦一般批发零售、销售代理与商贸服务在环境管理体系轴下的环境因素、一般污染源、商品流通废弃物、仓储配送、外包运输和合规义务转化，不承担行业百科说明功能；基础行业事实由对应专业小类基础卡承载。

本组采用“共同基础 + 多分支边界控制 + 特殊商品专项确认”的使用口径。组内小类可以共享本体系轴下的基础判断方法，但不得把某一分支经历等同于另一分支完整能力。对污染源、危险源、外部合规接口、客户现场或外包链条发生实质变化的情形，应在授权和项目匹配阶段追加分支确认。

  • 分组设立的基本逻辑

本组在本体系轴下的共同对象是以商品流通、代理撮合、门店或仓储交付为主的商贸服务活动。分组判断的核心不是小类名称是否相近，而是环境因素、污染源、污染物、废水、废气、固体废物、监测、外包处置和合规义务的形成机理、控制路径和审核证据是否足够接近。

本组可概括的共同证据链为：客户需求或订单识别 -> 采购或代理撮合 -> 收货验收 -> 仓储陈列或信息发布 -> 分拣配送或顾客交付 -> 退换货和废弃物处理 -> 投诉、异常和改进。该链条决定了审核员可以共用的专业能力基础，也决定了现场抽样时应从源头识别、过程控制、记录追溯、异常处置和改进闭环几个方向建立证据。

组内差异集中在商品属性、仓储条件、冷链要求、包装废物、过期报废、外包配送和少量特殊商品暂存。这些差异不否定设组，但要求本组按条件授权和边界受控方式使用。

  • 共同过程与专业机制分析

本组的环境管理机制不是生产排放型，而是商贸流通型。环境因素主要沿商品和服务链条形成：一部分来自组织自身的门店、库房、冷柜、办公、运输和包装；一部分来自组织对供应商、承运方、市场管理方、平台仓配和退换货处置方的控制接口。审核重点在于组织是否能够把实际经营商品的环境边界识别出来，并转化为可执行的仓储、运输、废弃物和异常处置控制。

  • 本体系核心控制要求

第一，应确认组织实际经营商品和场所边界。一般批发零售名称覆盖面很宽，同一门店或仓库可能同时存在食品、日化、电子、电器、建材、旧货、医疗器械和平台仓配。审核员应从商品清单、仓库分区、退货区、临期区和外包配送接口入手，确认环境因素是否按实际经营内容识别，而不是按营业执照或行业名称笼统识别。

第二，应追溯废弃物流向。废包装、过期食品、破损商品、废旧电子产品、废电池、清洁材料包装、废旧材料夹杂物和退货报废物是本组最常见的固体废物证据链。审核员应抽取至少一个收货样本、一个退货或报废样本、一个外包处置样本，核对台账、现场暂存和处置凭证是否一致。

第三，应关注冷链、清洁、异味和泄漏等现场性环境因素。食品批发零售、花卉宠物、清洁材料、化妆品、药品和含特殊商品的综合门店不能只看办公室资料，应到库房、冷柜、收货区、垃圾暂存点、清洁用品存放点和退货区验证控制措施。

第四，应评价外包运输、市场管理方和平台仓配接口。商贸组织常把仓储、配送、冷链、废物处置和门店物业管理外包，EMS 审核不能因为活动外包而中断证据链，应确认组织如何规定外包方要求、如何检查执行、如何处理环境异常。

  • 分组结论

EG29-1 组内小类虽然商品类型多、经营模式多，但在环境管理体系轴下具有共同的商贸流通环境因素形成逻辑：以门店或仓储场所为载体，以商品收发、陈列、配送、退换货、废弃物和外包接口为主线，以废包装、过期或破损商品、冷链能耗、清洁废水、一般固体废物和特殊商品边界为审核证据。因此可设为同一环境管理体系技术领域包。

因此，EG29-1 可以作为环境管理体系技术领域包使用，使用方式为“共同基础 + 多分支边界控制 + 特殊商品专项确认”。审核员授权、项目匹配和能力扩展均应体现分支差异，不得把同包经历理解为跨全部小类的充分证明。

本章用于界定本技术领域包可共享的共同能力，以及不同分支在授权、项目匹配和能力扩展时需要追加确认的内容。

  • 培训、考核与作业指导书需求

培训应覆盖商贸流通型 EMS 审核逻辑、商品属性识别、废包装和退换货去向、冷链和清洁控制、外包运输与废物处置接口、特殊商品边界判断。对未接触过商贸仓储或多品类零售的审核员，应通过案例评审确认其能够把环境因素从商品流转链条中抽取出来。

考核宜采用场景题、案例追溯题和边界判断题，要求审核员能够从一个真实或模拟项目出发，说明本体系轴下的识别、评价、控制、记录、异常处置和改进之间的证据关系。作业指导书应提供分支化抽样路径、记录清单、访谈问题和授权边界提示。

  • 使用限制和法定边界

本组不覆盖车辆维修、个人家庭用品维修、燃料加注或燃料储运专项环境控制；若商贸组织实际开展清洗、维修、拆解、翻新、加注、危险化学品实体仓储或废旧物深度加工，应转入对应技术领域或追加专项能力确认。

管理体系审核仅用于评价组织是否在其服务范围内建立并实施相应管理控制，不替代行政许可、法定检验、行政执法、政府监管、司法判断或强制性专项评价。涉及受监管资质、特种商品、危险化学品、燃料、药品、医疗器械、个人信息、资金信用、道路运输、客户现场和外包服务时，应在项目匹配阶段确认审核员分支能力和必要的技术支持。
