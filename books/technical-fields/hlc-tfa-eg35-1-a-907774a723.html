  • 文件定位说明

本文件用于环境管理体系（EMS）认证中 EG35-1 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦办公型、专业服务、客户支持、安保安防、设施支持、景观、会展、包装及一般商业支持服务在本体系轴下的环境因素、资源消耗、废物流、外包处置、客户现场环境边界和合规义务，不承担行业百科说明功能，基础行业事实由对应专业小类基础卡承载。

本组采用“统一领域包 + 办公型服务分支 + 现场活动分支 + 安保安防分支 + 景观包装分支 + 条件扩展”的使用口径。组内小类可以共享本体系的基础判断方法，但不得把某一分支经历等同于另一分支完整能力；对现场性强、外部合规接口明显、污染源或危险源发生实质变化的情形，应在授权和项目匹配阶段追加分支确认。

  • 分组设立的基本逻辑

本包在本体系轴下的共同对象是服务业组织在办公场所、客户现场、活动场所、安保安防点位、景观区域、包装现场和外包服务中形成的资源消耗与废物流。分组判断的核心不是服务名称是否相同，而是环境因素、污染源、污染物、废水、废气、固体废物、外包处置、监测和合规义务的形成机理和控制路径是否足够接近。

本包可概括的共同证据链为：活动和场所边界识别 -> 资源投入和外包接口确认 -> 环境因素与污染源识别 -> 废水、废气、固体废物或特殊废物流分类控制 -> 监测、转移、台账和客户接口记录 -> 异常处置和改进。该链条决定了本包共享的专业能力基础，审核员应能够围绕源头识别、过程控制、记录追溯、异常处置和改进闭环建立审核证据。

本组多数小类以办公资源、电子设备、纸张、差旅和一般固体废物为主，但广告摄影、会展、安防安装、设施支持、景观、包装和部分外出服务会明显改变物料流、废物流或客户现场边界。这些差异不否定设组，但要求本包不能按无差别能力包使用，应通过分支标注、专项确认、条件扩展和抽样控制加以处理。

  • 专业小类关系类型与授权后果
关系类型含义授权后果典型控制方式
共同基础关系均以服务场所、办公资源、电子设备、客户现场、外包服务或轻量物料为主要环境因素载体。可简化办公型服务和一般商业支持服务的 EMS 基础评价，但仍需确认目标分支的污染源、废物流和合规接口。资料评审、现场访谈、环境因素清单和废物流追溯。
并列分支关系同属本环境领域包，但资源消耗、废物类别、客户现场或外包链不同。应记录实际分支能力，不把同包经历理解为全分支能力。分支标注、限定使用、项目技术支持。
条件扩展关系已具备相邻服务环境因素识别能力，但目标路线存在专门污染源或废物链。完成补充培训、案例评审、专业面谈或见证审核后方可扩展。培训考核、案例评审、见证审核。
专项确认关系涉及化学品、清洗废液、消杀、电子废弃物、展会大量废弃物、车辆或客户现场复杂边界。项目使用前应专项确认，必要时配置技术专家支持。专项面谈、技术专家评审、项目匹配确认。
不可直接替代关系普通办公型服务经验不足以证明专项现场、清洗、绿化、安防安装或包装物料环境控制能力。不得作为目标能力的单独授权依据。补充目标案例或限定项目类型。
边界受控关系客户现场、外包处置、法定许可、废弃物转移、个人服务设施或化学品使用改变环境边界。授权记录应写明边界，项目匹配时按实际活动确认。授权备注、合规类别清单、技术支持。
办公型专业服务之间法律、会计、咨询、翻译、调查、HR和征信等主要共享办公资源、电子资料、差旅和纸张耗材环境因素。可共享办公型 EMS 基础能力，但不覆盖现场活动、包装、景观和安防安装。办公现场、差旅、纸电耗材、电子设备和资料处置抽样。
办公型服务与现场活动广告、摄影、会展、市场调查和公关可能进入客户现场或临时活动场所。扩展时应确认活动物料、场馆废物、供应商和客户现场边界。活动案例、供应商记录、废物清理和客户确认抽样。
办公型服务与景观包装景观和包装的物料、水肥、药剂、包装材料和固体废物显著高于一般办公型服务。不得以普通办公型服务经历替代景观或包装现场能力。景观养护、包装订单、物料废弃和外包处置专项确认。
安保安防路线安保车辆、夜间巡逻、监控中心、安防设备、电池、线缆和废旧电子设备形成独立环境边界。应记录安保或安防分支能力。车辆、设备、废旧部件、监控中心和客户现场维护记录抽样。
  • 本体系共同能力基础
共同能力维度本包共同基础可共享的审核判断不能共享的边界
环境因素识别均需从办公室、客户现场、差旅、活动、外包方、电子设备、物料和废弃物识别环境因素。可共享服务活动边界识别和环境因素清单适宜性判断。工业清洗、化学清洗和高污染废液不在本包内，应由EG35-2专项控制。
资源能源消耗均可能涉及电力、纸张、办公耗材、电子设备、交通差旅、包装物料或外包服务。可共享资源消耗统计、节约措施和外包资源边界判断。景观用水、包装材料、活动搭建和安防设备需分支确认。
废物流控制均可能产生废纸、包装物、废旧电子设备、墨粉硒鼓、绿化废弃物、活动废弃物或一般固体废物。可共享分类收集、暂存、回收、外包处置和台账判断。电池、安防设备、包装废料、绿废和活动大量废弃物需提高抽样粒度。
客户现场和外包接口多数服务存在客户现场、场馆、外包云服务、供应商、物业、回收方或外包制作方接口。可共享外包方环境要求、客户边界确认和交接记录判断。客户生产现场、清洗现场和法定排放接口不得仅凭办公型能力覆盖。
监测和合规义务一般以资源统计、废物转移、供应商记录、客户场所要求和合规义务类别识别为主。可共享监测需求识别和合规义务转化判断。具体排放监测、危险废物处置和清洗废液处理由专项路线确认。
  • 本体系核心控制要求

EMS 审核应围绕环境因素、污染源、污染物、废水、废气、固体废物、危险废物类别识别、外包处置、监测和合规义务展开。服务业组织不宜仅因生产污染较少而简化判断；办公资源、客户现场、外包服务、活动物料、电子设备、药剂和废物流同样需要形成可追溯控制。

第一，应确认组织是否按照服务场所、客户现场、临时活动、外包方和服务对象识别环境因素。仅把本组写成办公室用电用纸是不充分的；广告会展、摄影、安防安装、景观和包装活动都会带来额外物料流和废物流。

第二，应核对资源投入和废物流闭环。办公型服务应关注电力、空调、纸张、墨粉、硒鼓、电子设备和差旅；活动型服务应关注宣传材料、场馆废物、外包搭建和撤场清理；景观服务应关注用水、肥料、药剂和绿化废弃物；包装活动应关注包装材料、标签、边角料和废包装。

第三，应评价外包方和客户现场环境接口。广告制作、摄影棚、会展搭建、安防安装、电子设备回收、绿化养护和包装物流可能由外部组织完成。审核员应追溯外包要求、交接记录、处置去向、客户现场规则和异常反馈。

第四，应评价异常和改进。典型异常包括资料大量打印、废旧电子设备处置不清、活动撤场废物未清理、包装错料导致废弃、景观药剂使用记录缺失、安防废旧电池无去向、客户现场环境要求未识别等。审核应追溯原因分析、纠正、预防和改进证据。

  • 分小类或内部路线差异分析
小类/路线与本包共同基础主要差异差异对能力授权的影响控制方式
35.01.00 法律活动共享办公室、纸张、电子资料、差旅和客户会谈环境因素。案卷纸质资料、外出开庭和档案保存较突出。可按办公型专业服务授权；大量档案或外出调查需确认。抽取案卷、纸张消耗、电子化交付、差旅和档案处置记录。
35.02.00 会计税务服务共享办公、电子资料、客户资料和差旅因素。客户财务资料、纸质凭证、档案保存和客户现场盘点可能增加资源消耗。可共享办公型能力；长期驻场或大量纸质档案需确认。追溯凭证资料接收、电子化、纸张耗材和档案处置。
35.03.00 公司总部共享总部办公、会议、差旅、供应商和共享服务因素。总部可能通过采购和供应商要求影响下属单位环境绩效。应确认总部管控边界，不把办公室审核扩大到下属生产场所。抽取总部环境目标、供应商控制、差旅会议和办公废物记录。
35.04.01 公共关系共享办公、活动沟通、资料制作和差旅因素。媒体活动、宣传品、外部活动和临时场所废物更突出。活动型公关需确认活动现场环境因素识别能力。抽取传播活动，追溯物料制作、现场废物和供应商要求。
35.04.02 管理咨询共享办公、客户现场、差旅和电子资料因素。驻场咨询和频繁差旅可能改变能源、交通和客户现场边界。可共享办公型能力；长期驻场需确认客户现场边界。追溯项目计划、差旅、客户现场活动和电子化交付。
35.05.01 广告机构共享办公、创意制作、外包供应商和客户活动因素。实物宣传品、拍摄、户外安装和废弃广告材料可能突出。广告制作和户外执行需专项确认。抽取广告项目，追溯物料、外包制作、废弃物和客户交付。
35.05.02 媒体代理共享办公、电子平台和客户沟通因素。主要环境因素较轻，集中在办公资源、电子设备和差旅。可作为办公型服务基础能力。抽取媒体投放项目，核对办公耗材、电子化资料和供应商边界。
35.06.00 市场调查共享办公、电话访问、线上问卷、外出访问和资料处理因素。现场调查差旅、纸质问卷和临时活动垃圾可能增加。外出大样本调查需确认现场和交通边界。抽取调查项目，追溯问卷材料、访问路线和资料处置。
35.07.00 摄影活动共享办公、电子设备、外景活动和客户交付因素。摄影灯光、电池、耗材、外景交通、布景和后期设备更突出。摄影棚或大型外景需分支确认。追溯拍摄项目的设备电池、布景材料、废弃物和外包场地。
35.08.00 翻译口译共享办公、电子资料、会议和差旅因素。现场口译涉及会议场所和差旅；笔译以电子资料为主。可共享办公型能力；大型会议口译需确认活动边界。抽取翻译项目，核对电子化交付、会议现场和差旅记录。
35.09.00 就业安置共享办公、面试、差旅和电子资料因素。线下招聘会和大批量面试可能产生场地和宣传物料废物。招聘会路线需专项确认。抽取招聘项目，追溯面试场所、宣传材料和资料处置。
35.10.00 临时就业代理共享办公、派出人员管理和客户现场接口因素。派出人员实际环境因素通常在客户现场形成，边界需界定。应确认派出服务是否控制客户现场环境因素。追溯派出协议、客户现场边界和人员沟通记录。
35.11.00 HR提供共享办公、员工资料、客户接口和电子系统因素。长期员工记录和客户现场服务边界突出。可共享HR服务基础；长期驻场需确认客户现场边界。抽取员工服务样本，核对电子资料、档案和客户现场活动。
35.12.00 私人保安共享办公、巡逻、车辆、制服装备和客户场所因素。巡逻车辆、夜间照明、废旧装备和信息销毁更突出。安保现场和车辆路线需分支确认。抽取巡逻或护送项目，追溯车辆燃料、装备和客户场所废物。
35.13.00 安防系统服务共享办公、监控中心、电子设备和客户现场因素。设备安装维护、废旧电子设备、电池、线缆和包装物突出。安防安装维护需专项确认。抽取安装维护项目，追溯设备包装、废旧部件和客户现场清理。
35.14.00 调查活动共享办公、资料处理、外出访问和差旅因素。外出调查路线、车辆和纸质证据保存可能突出。现场调查需确认交通和客户现场边界。追溯调查项目的外出记录、资料保存和废弃资料处置。
35.15.00 设施综合支持共享客户设施、驻场服务、外包方和一般废物流因素。可能包含垃圾清理、接待、邮件、洗衣、安保和维护等多接口。设施组合服务需确认实际模块，不得覆盖未确认清洁或维修。抽取月度设施服务，追溯垃圾分类、外包方和客户现场记录。
35.17.00 景观服务共享客户场所维护、外包作业和废弃物收集基础。水肥、修剪废弃物、药剂、苗木包装和季节性作业突出。景观路线需专项确认，不以普通办公服务替代。追溯养护计划、用水、药剂、绿废收集和客户验收。
35.18.01 办公室管理共享客户办公场所、邮件、档案、接待和行政耗材因素。客户现场驻场和邮件包装物可能突出。可共享办公型能力；驻场服务需确认客户现场边界。抽取办公室服务工单，追溯耗材、邮件包装和废物分类。
35.18.02 文档支持共享纸张、复印、墨粉、装订、邮寄和保密销毁因素。纸张、墨粉硒鼓、废纸和保密销毁突出。文档支持需确认耗材和废弃物处置能力。追溯复印任务、耗材领用、废纸和硒鼓回收。
35.19.00 呼叫中心共享办公、坐席设备、用电和电子资料因素。高密度坐席带来用电、空调、电子设备和废旧耳机耗材。可共享办公型能力；大型坐席中心需确认资源消耗和废弃物。抽取坐席区用电设备、耗材、更换记录和办公废物。
35.20.00 会展组织共享活动策划、场馆、物料、供应商和现场废物因素。搭建材料、宣传品、餐饮包装、观众废物和运输更突出。会展现场属专项确认路线。抽取会展项目，追溯物料、场馆废物、供应商和撤展清理。
35.21.01 收款征信共享办公、电子资料、电话沟通和客户信息系统因素。环境因素较轻，主要为办公资源和电子设备。可共享办公型能力；大量外访催收需确认差旅边界。抽取服务样本，核对办公耗材、差旅和资料处置。
35.21.02 包装活动共享受托服务、物料、作业现场和客户交付因素。纸塑包装、标签、边角料、废包装、装瓶或固体包装物料突出。包装服务不得以普通办公型经历替代。抽取包装订单，追溯物料、废包装、标签废弃和外包处置。
35.21.03 其他商业支持共享办公处理、资料服务、活动支持和客户接口因素。速记字幕偏办公，募捐、拍卖、收回和会员计划可能涉及现场活动或物料。集合类按实际服务路线限定。抽取实际合同，确认环境因素、废物流和外包接口。
  • 分组合理性论证结论

EG35-1 可以设立为 EMS 技术领域包。组内小类虽服务对象差异较大，但多数环境因素集中在办公资源、电子设备、差旅、纸张耗材、客户现场、外包服务和一般固体废物；现场活动、安防安装、景观和包装路线的差异可以通过分支标注、专项确认和抽样控制处理。本组不覆盖35.16清洁专项路线，清洁剂、清洗废液和工业清洗污染源应由EG35-2控制。

抽样场景现场必看记录必查纵向追溯路径追问方向
办公型专业服务办公室、档案区、打印复印区、电子设备和废物分类点。环境因素清单、资源统计、耗材领用、废纸硒鼓、电子设备处置、差旅记录。服务活动 -> 资源消耗 -> 废物流 -> 处置记录 -> 改进。是否识别客户现场和外包云服务边界；电子化是否减少纸张。
广告摄影或会展活动场馆、拍摄现场、物料区、供应商和撤场区域。活动方案、物料清单、供应商要求、废物清理、客户确认和异常记录。活动目标 -> 物料投入 -> 现场执行 -> 废物清理 -> 总结改进。宣传品和搭建材料如何减少；撤场废物如何交接。
安保或安防服务监控中心、巡逻车辆、设备仓库、安装维护现场。车辆记录、设备领用、废旧部件、电池线缆、客户现场清理和外包处置。服务点位 -> 设备或车辆使用 -> 废旧部件 -> 回收处置。废旧电子设备和电池去向如何控制。
景观服务绿地、药剂和肥料库、工具、绿废暂存点。养护计划、用水、药剂肥料、修剪废弃物、客户验收。养护计划 -> 资源投入 -> 作业 -> 绿废收集 -> 改进。药剂用量和绿废去向如何记录。
包装或商业支持现场包装作业区、物料、标签、废料、成品区。订单、物料领用、废包装、返工废弃、外包回收和客户验收。订单 -> 物料 -> 作业 -> 废料 -> 回收处置。错料造成的废弃如何统计和预防。

  • 培训、考核与作业指导书需求

本组应建立服务业 EMS 专业培训，内容包括办公型环境因素识别、资源能源消耗、纸张和电子设备管理、差旅和客户现场边界、外包方环境控制、活动物料和场馆废物、安保安防设备废弃物、景观用水药剂和绿废、包装材料和废包装、环境异常和合规义务类别识别。考核应要求审核员分别完成办公型服务、活动型服务、安防设备、景观养护和包装现场的环境因素追溯。

  • 常见合规义务类别与标准适用提示

本组可能涉及一般固体废物、废旧电子设备、废电池、办公耗材回收、节约资源、绿色办公、客户场所环境要求、广告和会展活动场地管理、绿化养护药剂、包装材料、外包处置、车辆使用、个人信息载体销毁和客户行业专门环境要求等类别。文件不列具体标准编号和年份；适用性应使用机构受控的有效清单、客户合同、服务范围和所在地要求确认。

  • 分组使用限制和法定边界

本分组仅用于 EMS 认证中的技术领域包论证和审核员能力控制，不替代排污许可、危险废物经营或转移审批、环境监测法定结论、政府监管、行政执法、客户专项验收或外包处置单位资质审查。涉及清洁剂和清洗废液、工业清洗、消杀、客户生产现场污染源、数据中心大型能源设施或其他实质污染源时，应转入对应专项路线确认。

  • 分组结论与使用口径

EG35-1 可作为环境管理体系办公型、专业服务及一般商业支持服务技术领域包使用。授权时应记录审核员在办公型服务、现场活动、安保安防、设施支持、景观、包装和集合类商业支持等分支上的实际能力。文件维护触发条件包括：服务活动由办公室转向现场执行，外包处置方式、物料使用、安防设备、景观药剂、包装材料、活动场馆或客户环境边界发生实质变化。
