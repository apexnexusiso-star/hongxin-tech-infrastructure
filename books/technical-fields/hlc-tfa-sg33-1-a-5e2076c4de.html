  • 文件定位说明

本文件用于职业健康安全管理体系认证中 SG33-1 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。本文件围绕 OHSMS 轴的危险源、伤害机理、职业健康、高风险作业、人员暴露、异常工况和应急响应展开，不承担软件和信息技术行业百科说明功能。

本组采用“统一领域包 + 办公研发服务分支 + 机房/运维分支 + 客户现场集成分支 + 条件扩展 + 专项边界控制”的使用口径。普通办公型 IT 服务、数据中心运维和客户现场安装的危险源强度不同，授权时应记录实际分支能力。

  • 技术领域包构成
小类编码小类名称纳入本包的活动范围主要内部路线特殊边界
33.01.01电脑游戏发行游戏版本发行、渠道交付、补丁、账号和用户服务接口。游戏发行、平台发行、联网游戏发行、持续运营型发行。环境和安全重点不在代码内容本身，而在办公场所、服务器资源、外包云服务、用户服务和可能的机房/运营支撑。
33.01.02其他软件发行现成软件、企业软件、工具软件、云订阅软件、许可和版本发布。传统安装包发行、企业批量授权、云订阅发行、开源商业发行。关注办公和研发支撑、软件交付介质、客户部署支持、外包云服务和电子资料管理。
33.02.01计算机编程活动需求、设计、编码、测试、构建、部署准备和维护性开发。前端、后端、移动端、接口、数据库、脚本、低代码、维护性开发。长期伏案和视屏作业明显；若进入客户现场部署或机房调试，边界发生变化。
33.02.02计算机咨询活动IT 规划、架构设计、选型、可行性研究、项目管理咨询和技术尽调。规划咨询、架构咨询、选型咨询、云咨询、数据咨询。通常以办公、差旅、客户现场访谈和资料处理为主；不等同于现场施工或运维。
33.02.03计算机设备管理活动终端、服务器、网络、账号、配置、补丁、备份、事件、变更和服务台管理。桌面外包、服务器运维、网络运维、驻场管理、远程运维中心。机房、弱电间、夜间值守、备份设备、UPS、电气和搬运边界更突出。
33.02.04其他信息技术及计算机服务活动，特别是系统集成软硬件部署、网络联通、软件安装、数据迁移、灾难恢复、系统联调和验收移交。基础设施集成、应用集成、弱电信息系统集成、云迁移实施、灾难恢复服务。客户现场安装、登高、布线、搬运、临时用电、割接和承包方接口需要专项控制。
33.03.01数据处理、托管及相关活动数据中心、服务器托管、云资源、数据库托管、数据处理、备份、灾备和运行支撑。物理托管、云托管、数据库托管、批量数据处理、备份灾备。数据中心和机房环境可显著改变环境因素和危险源，应作为重点分支。
33.03.02门户网站综合门户、垂直门户、企业门户、搜索导航、内容聚合、用户账号和访问统计。综合门户、行业门户、企业门户、搜索导航、社区内容门户。通常为办公和平台运行；若自建机房、演播采编或线下活动，需按实际边界确认。
  • 分组设立的基本逻辑

本包的共同对象是软件和信息技术服务中的人员、计算设备、服务器机房、客户现场、外包服务和运行支撑活动。OHSMS 关注的不是软件功能质量，也不是环境排放，而是人员在办公、研发、运维、机房、客户现场安装、夜间值守和应急处置中的伤害和健康损害风险。

本包共同危险源链可概括为：工作活动和场所识别 → 视屏作业、久坐、用电、设备搬运、机房巡检、客户现场安装、值守和差旅 → 人员暴露于肌肉骨骼负荷、视疲劳、心理压力、电气、火灾、噪声、热环境、搬运伤害、高处或临边、临时用电、承包方交叉作业等危险源 → 工程控制、作业程序、培训、个体防护、应急和事件学习。

八个小类均属于 IT 服务活动，办公和视屏作业职业健康基础高度相似；但设备管理、系统集成、数据中心和灾难恢复服务可能带来电气、搬运、夜间值守、机房消防、登高布线、客户现场施工和应急切换等更强危险源。该差异不否定设组，但必须通过分支标注和专项确认控制。

  • 专业小类关系类型与授权后果
关系类型含义授权后果典型控制方式
共同基础关系共享信息技术服务的需求识别、资源配置、运行记录、外包接口和合规义务识别基础。可简化基础专业面谈，但仍应确认目标体系、目标小类和目标路线的实际经历。资料评审、专业面谈、案例判断。
并列分支关系同属本包但服务对象、现场条件、环境因素或危险源不同。应记录实际分支能力，不把同包经历理解为全分支能力。分支标注、限定使用、项目技术支持。
条件扩展关系已具备相邻分支能力，具备扩展基础，但目标分支仍有专门证据要求。完成补充培训、案例评审、专业面谈或见证审核后方可扩展。培训考核、案例评审、见证审核。
专项确认关系涉及数据中心、机房工程、客户现场安装、灾备、备用电源、强内容平台或复杂外包链。项目使用前应专项确认，必要时配置技术专家支持。专项面谈、技术专家评审、项目前确认。
不可直接替代关系相关 IT 经历不足以证明目标环境或职业健康安全能力。不得作为目标能力的单独授权依据。重新评价、补充经历或限定项目类型。
边界受控关系法定许可、客户现场、数据中心、外包处置、内容服务或特殊作业改变使用边界。授权记录应写明边界，项目匹配时按实际活动确认。授权备注、合规类别清单、技术支持。
办公研发型小类之间软件发行、编程、咨询和门户运营共享视屏作业、久坐、用电、办公消防和心理负荷基础。可共享办公型 IT 服务 OHSMS 基础评价。办公场所、工位、用电、消防、工作时长和参与协商样本追溯。
办公研发到机房运维机房运维增加电气、UPS、电池、消防系统、搬运、噪声、温湿度和夜间值守。不得凭普通办公经历承担复杂机房或托管运维项目。机房巡检、能量隔离、应急和设备搬运案例确认。
软件服务到系统集成现场客户现场集成增加登高、布线、临时用电、搬运、交叉作业和承包方控制。应确认现场作业和客户场所协调能力。项目现场、作业许可、承包方和应急记录评审。
  • 本体系共同能力基础
共同能力维度本包共同基础可共享的审核判断不能共享的边界
危险源识别均需识别办公、视屏、用电、消防、差旅、客户现场、机房和外包活动中的危险源。能判断危险源识别是否覆盖人员、场所、设备、活动和异常状态。数据中心、UPS、电池、客户现场安装、登高布线和应急切换需单独确认。
职业健康均存在长时间视屏、久坐、重复键鼠操作、工作强度和心理压力。能判断工位、视屏作业、工时、休息、健康沟通和人员参与是否受控。夜班值守、高强度上线、长期驻场和客户现场压力需分支确认。
设备和电气安全均使用计算机、服务器、网络设备、电源插排、机柜和办公设备。能判断用电、线缆、消防、设备摆放和巡检是否受控。机房强电接口、UPS、电池、发电机和配电柜不得按普通办公判断。
作业活动控制均涉及安装、调试、巡检、搬运、远程操作、现场沟通或服务响应。能判断人员能力、作业步骤、工具、异常处置和外包方接口。高风险作业、客户现场交叉作业和临时用电需专项控制。
应急响应均需关注火灾、触电、设备故障、数据中心异常、客户现场事故和人员健康事件。能判断应急场景、报警、疏散、联络、演练和事件学习是否适配。机房气体灭火、UPS 电池热失控、灾备切换和夜间值守应专项确认。
  • 本体系核心控制要求

OHSMS 审核应围绕“危险源识别、人员暴露、控制措施、职业健康、应急、承包方和事件学习”展开。第一，应核对组织是否按办公研发、远程工作、机房运维、客户现场、差旅和值守活动识别危险源。第二，应核对视屏作业、久坐、键鼠重复操作、工时、夜班和心理负荷相关的职业健康控制。第三，应核对电气、线缆、插排、机柜、服务器、UPS、电池、制冷、消防和设备搬运控制。第四，应核对系统集成和设备安装中的登高、布线、临时用电、搬运、客户现场交叉作业和承包方控制。第五，应核对应急预案、疏散、火灾、触电、气体灭火误入、机房停电、灾备切换和人员突发健康事件的响应安排。

普通软件和咨询组织可重点抽样办公工位、视屏作业、用电消防、工作时间和差旅；设备管理和托管组织应增加机房巡检、设备搬运、UPS、电池、夜间值守和应急；系统集成组织应增加客户现场作业许可、登高布线、临时用电、承包方和交叉作业。

  • 分小类或内部路线差异分析
小类/路线与本包共同基础主要差异差异对能力授权的影响控制方式
33.01.01 电脑游戏发行共享办公、视屏、用户服务和平台运营危险源。上线周期、运营值班、用户服务压力和服务器运营接口突出。可按办公平台运营分支授权；自建机房或夜间值守需确认。工位、工时、值班、外包云和应急记录抽样。
33.01.02 其他软件发行共享办公、用电、视屏作业和客户支持基础。企业客户部署支持可能进入客户现场。普通发行可共享；现场部署支持需补充确认。客户现场、设备搬运和用电边界抽样。
33.02.01 计算机编程共享视屏作业、久坐、键鼠重复操作和高强度项目周期。开发测试、上线窗口和远程协同压力突出。可作为办公研发型基础经历。工位、工时、健康沟通、上线值守和远程办公抽样。
33.02.02 计算机咨询共享办公、差旅、客户现场访谈和资料处理基础。差旅、驻场、客户现场沟通和会议强度突出。可共享办公型能力；长期驻场需确认客户场所危险源。差旅、驻场、会议场所和客户现场沟通记录抽样。
33.02.03 计算机设备管理共享设备、机房、服务台、值守和运行响应基础。服务器、网络设备、UPS、电池、机柜搬运、夜间值守和故障抢修突出。应标注设备管理/运维分支。巡检、工单、搬运、能量隔离、夜班和应急记录追溯。
33.02.04 系统集成及其他 IT 服务共享客户现场、设备安装、配置和联调基础。登高、布线、临时用电、搬运、交叉作业、承包方和割接压力突出。应标注系统集成分支；弱电施工或大规模改造专项确认。项目现场、作业许可、承包方、工具和应急记录抽样。
33.03.01 数据处理托管共享机房、平台运行、值守和应急基础。数据中心、电气、制冷、UPS、电池、气体灭火、噪声和夜间值守突出。属于本包 OHSMS 重点分支，应专项确认。机房巡检、配电、UPS、电池、消防、值守和演练追溯。
33.03.02 门户网站共享办公运营、内容平台、服务响应和视屏作业基础。内容值班、突发事件响应、用户互动压力和流量异常处理突出。可按平台运营分支授权；自建机房或演播活动需确认。值班、工时、用户反馈、远程办公和应急沟通抽样。
  • 分组合理性论证结论

SG33-1 可以作为 OHSMS 技术领域包设立。八个小类均属于软件和信息技术服务活动，共享办公视屏作业、用电消防、设备使用、客户沟通、外包服务、服务响应和人员参与协商等职业健康安全基础。审核员掌握该基础后，能够识别本包内多数普通办公型 IT 服务的危险源和控制逻辑。

本组不能把信息技术行业简单视为低危险办公活动。机房运维、数据中心、系统集成现场、设备搬运、UPS 电池、气体灭火、夜间值守、客户现场作业和灾备切换会显著改变伤害机理和人员暴露。机构应采用“统一领域包 + 分支能力标注 + 条件扩展 + 专项边界控制”的使用口径。

抽样场景现场必看记录必查纵向追溯路径追问方向
办公研发场所工位、显示器、座椅、照明、线缆、插排、消防通道。危险源清单、职业健康沟通、工时记录、培训、消防检查、事件记录。岗位活动 → 人员暴露 → 控制措施 → 参与协商 → 事件和改进。久坐、视屏、键鼠、用电和工时如何控制。

机房或数据中心巡检机柜、配电、UPS、电池、制冷、气体灭火、通道和警示。巡检记录、配电操作、设备搬运、消防演练、应急预案、培训记录。机房任务 → 危险源识别 → 作业控制 → 异常处置 → 演练改进。触电、火灾、搬运、气体灭火和夜间单独作业如何控制。
系统集成客户现场布线区域、梯具、临时用电、工具、材料、承包方作业区。项目计划、现场交底、作业许可、承包方记录、事故或未遂事件记录。项目任务 → 现场危险源 → 控制措施 → 承包方协调 → 客户确认。交叉作业、高处、临时用电和搬运如何受控。
设备搬运上架机柜、搬运路线、工具、人员配合、地面和空间条件。搬运计划、人员培训、工具检查、上架记录、异常处理。设备到货 → 搬运 → 上架 → 接线 → 验证 → 事件复盘。大件设备、重心、夹挤和线缆绊倒如何预防。

  • 培训、考核与作业指导书需求

本组应建立 IT 服务 OHSMS 专业培训，内容包括视屏作业和工效学、久坐和肌肉骨骼负荷、心理压力和工作时间、办公用电和消防、远程办公、差旅和驻场、机房巡检、服务器上架、UPS 和电池、气体灭火、夜间值守、客户现场系统集成、登高布线、临时用电、搬运、承包方控制和应急响应。

考核应采用场景式题目，要求审核员分别完成办公研发场所、上线值班、机房巡检、系统集成现场、设备搬运和灾难恢复演练的危险源追溯。作业指导书应提供办公型 IT 服务、机房运维、系统集成现场和数据中心应急四类抽样路径。

  • 常见合规义务类别与标准适用提示

本组可能涉及劳动用工、工作时间、职业健康、消防安全、用电安全、承包方管理、特种作业、高处作业、有限空间类似受限场景识别、设备搬运、机房管理、应急管理、女职工和未成年工保护、社会保险、客户现场安全规则和外包服务管理等类别。文件不列具体标准编号和年份；适用性应使用机构受控的现行有效清单、客户合同、场所边界和项目作业活动确认。

上述类别用于识别外部要求如何转化为危险源识别、运行控制、培训、作业许可、个体防护、事件调查和应急演练，不替代政府许可、安全评价、职业病危害评价、消防验收、行政执法或客户专门验收。

  • 分组使用限制和法定边界

本分组仅用于 OHSMS 认证中的技术领域包论证和审核员专业能力控制。管理体系审核不替代政府许可、安全评价、职业病危害评价、消防验收、特种作业资格审查、行政执法、工伤认定、社会保险缴纳法定审查或客户专项安全验收。

当项目涉及大型数据中心、复杂配电和 UPS、电池系统、气体灭火、夜间单独值守、客户现场弱电施工、高处布线、临时用电、重型服务器搬运、重大割接或灾难恢复演练时，应在项目匹配阶段追加专项确认或技术专家支持。

  • 分组结论与使用口径

SG33-1 可作为职业健康安全管理体系软件、信息技术、数据处理及门户网站技术领域包使用。授权时应记录审核员在办公研发型 IT 服务、软件发行、编程咨询、设备管理、系统集成现场、数据中心托管、门户运营、夜间值守和灾难恢复等分支上的实际能力。组内扩展应通过培训、案例评审、专业面谈、见证审核或技术支持控制。

文件维护触发条件包括：数据中心运维方式、系统集成现场作业方式、远程和夜间值守模式、工效学和职业健康要求、承包方管理、机房消防和应急要求发生实质变化，或上层分组使用中出现能力匹配争议。
