29.03.01 汽车零部件及配件的批发 专业小类基础卡

> 本卡为技术领域分组底层知识卡，记录不依附于特定管理体系的行业事实、过程边界、术语、产品或服务、过程技术、产业链、法规标准类别、检验计量手段和维护信息。凡涉及具体管理体系下的人员能力、样本选择、合格评定结论或体系风险分级的内容，应在上层分组论证文件中展开。

A2 定义与范围界定

本小类包括面向维修企业、经销商、车队、零售门店、区域分销商和电商渠道批量供应汽车零部件及配件的批发活动。典型对象包括发动机和底盘件、电气电子件、车身件、易损件、油液耗材、轮胎、电瓶、灯具、滤清器、制动件、传动件、附件和维修材料。 本小类的核心不是制造零部件，也不是终端门店安装服务，而是把大量车型、品牌、年款、零件号、替代件和库存周转信息组织成可识别、可适配、可配送、可追溯的流通网络。批发业务通常具有 SKU 多、车型覆盖广、周转快、退换货频繁、价格层级复杂和区域配送密集的特点。 汽车零部件批发的专业性集中在配件目录、车型适配、批次和来源识别、仓储条件、库存准确性、物流包装、渠道价格、退货判定和售后索赔接口。其交付结果是面向组织客户的配件供应服务，而不是车辆维修结果。

A3 边界说明、相邻小类区分点和排除项

相邻活动容易混淆的原因主要区分依据本卡处理原则
29.03.02 汽车零部件及配件的零售均销售汽车零部件和配件客户对象、交易批量、库存深度和服务方式面向维修厂、车队、经销商和分销商的批量供货归入本卡；面向个人车主和终端消费者的门店或平台零售归入 29.03.02。
29.02.00 汽车的保养和修理批发商可能提供技术咨询或配送到维修工位是否承担车辆诊断、拆装和维修结果仅供应配件和适配信息归入本卡；实际维修服务归入 29.02.00。
汽车零部件制造批发商可能自有品牌或委托生产主导活动是否为制造加工还是流通分销自有品牌但主要从事采购和批发的可按本卡识别；实际制造过程另行识别。
29.10 机械设备批发部分维修设备、工具和工装也面向汽车维修企业销售交易对象是否为汽车零部件配件，还是设备工具零部件、耗材和车辆附件归入本卡；举升机、检测线、机床等设备批发另行识别。
废旧材料批发旧件、拆车件和再制造件可能进入流通是否作为可使用汽车配件销售，还是废旧材料回收可作为配件销售并有适配信息的纳入本卡；废金属、废塑料或报废件回收归入废旧材料批发。
电商平台服务配件批发可通过平台完成企业是否自己经营配件采购、库存和销售，还是提供平台撮合服务自营配件批发归入本卡；仅提供平台信息和交易撮合另行识别。

明确排除项：

  • 汽车零部件、轮胎、油液、电瓶、电子件和附件的制造活动。
  • 面向个人消费者的终端配件零售和安装服务。
  • 汽车维修、保养、钣喷和车辆检测服务。
  • 仅销售维修设备、检测设备、机床和一般机械工具的批发活动。
  • 废旧汽车、报废件和拆解材料的回收处置活动。

A4 分组特征摘要

维度本小类特征上层分组调用提示
主导活动类型汽车零部件及配件 B2B 批发分销服务上层调用时应识别其对象是配件供应链，不是车辆维修过程。
核心过程性质车型覆盖和零件号管理、采购验收、仓储库位、批次追溯、适配查询、订单拣配、区域配送、退换货和索赔接口其技术命脉在多车型多 SKU 适配和批发库存追溯。
主要技术基础零件目录、OE号、替代关系、易损件周期、仓储保管、条码批次、物流包装、配件真伪识别和售后索赔资料普通批发经验不足以覆盖汽车配件适配链。
产业链段位上接零部件制造商、品牌总代、拆车件和再制造件渠道，下接维修厂、经销商、车队、零售店和电商经营者处在汽车后市场供给链中间段。
典型规模跨度从区域配件批发市场商户到全国型供应链平台和品牌分销仓均存在规模差异主要体现在库存深度、目录系统、仓储配送和索赔能力。
主要分型轴按原厂件/品牌件/同质件/再制造件、易损件/总成件/车身件、线下批发/平台批发、现货仓/调拨分销分型分型改变验收、仓储和适配方式。
分组比较提示与 29.03.02 共享配件识别和客户咨询基础，但本卡更强调 B2B 批量供货、库存周转、批次来源和渠道索赔如与零售共组，应区分批发客户的专业性和终端客户的适配沟通差异。
分组敏感边界自有品牌、拆车件、再制造件和平台交易容易使制造、回收、零售和批发边界混合应以主导活动是否为配件批量流通和供应链服务为判据。

B. 术语与概念

B1 专业术语和行业常用表达

术语解释本小类中的使用语境
OE号整车厂或配套体系用于识别零部件的编号类别。用于配件适配和替代关系判断。
副厂件非整车厂原品牌渠道供应的替代配件的行业俗称。批发渠道中常用于区分来源和价格。
同质配件与原装配件在功能和适配上具有可替代关系的配件类别。维修市场中用于多渠道选择。
易损件使用中消耗或磨损较快的配件，如滤芯、刹车片、雨刮等。批发频率高、库存周转快。
总成件由多个零件组成并可整体更换的部件，如发电机、起动机、压缩机等。涉及旧件返还和索赔接口。
拆车件从报废或事故车辆拆出的可再用部件。来源、状态和适配说明更敏感。
再制造件对旧件进行拆解、清洗、更换、装配和测试后形成的可用件。需要与简单旧件、修复件区分。
适配确认配件与车型、年款、发动机、配置和接口匹配。是汽车配件批发的核心专业动作。
替代关系不同品牌或编号配件之间可互换使用的关系。影响库存推荐和客户选择。
批次追溯通过批号、条码、入库记录和供应商信息追踪配件来源。用于退换货和索赔。
库位仓库中存放配件的具体位置编码。影响拣货效率和库存准确性。
索赔因配件问题、运输损坏或适配异常向供应商或客户处理的商业服务过程。批发业务售后接口。
旧件返还更换总成件时将旧件回收给供应商或再制造渠道。常见于发电机、压缩机和方向机等总成。
滞销件长期未销售或适配车型减少的库存配件。影响库存结构和资金占用。

缩略语或代号含义使用语境

B3 关键技术概念说明

汽车配件批发的核心难度来自车型复杂度。相同零件名称可能因车型、年款、发动机、排量、底盘号、配置和生产批次不同而不可互换，批发服务必须依赖目录和适配逻辑。 批发库存不是简单堆货。高频易损件要求周转速度，总成件要求来源和旧件返还，车身覆盖件要求防变形和防划伤，电子件要求防静电和防潮，油液和化学耗材要求保存条件。 渠道层级和价格层级是本小类的重要商业特征。总代、区域仓、二级批发、维修厂、连锁门店和平台店之间的价格、账期、配送和退货条件不同。 自有品牌或贴牌配件并不必然改变本小类属性。只有当企业主导活动转为配件制造、装配或加工时，才应上移到制造类小类；若主导活动仍是采购和批发分销，则保持本卡边界。

D. 过程与技术

D1 主要过程流程：从投入到产出的完整链路

本小类过程链通常从市场需求、车型覆盖规划和供应商选择开始，经配件目录建立、采购下单、到货验收、入库上架、批次和库位管理、客户询价、车型和零件号适配、订单确认、拣货复核、包装配送、签收、退换货、索赔和库存结构维护完成。 汽车配件批发的服务结果是把复杂的配件供应链转化为维修企业和渠道客户可快速使用的供货能力。目录准确、库存准确、适配准确和配送及时共同决定服务有效性。 与零售相比，批发更强调库存深度、价格层级、账期、批量配送、渠道索赔和供应链周转；与维修相比，批发不承担车辆状态恢复结果，但必须提供足够的适配信息和来源资料。

通用链路可表示为：

`text 客户或市场需求 → 对象识别 → 技术或规格匹配 → 商务确认 → 资源准备 → 交付或服务作业 → 状态确认 → 文件和售后接口 → 反馈与维护 `

配送车辆或物流接口同城和跨区配送影响时效和签收。
油液和化学品存放区机油、制动液、冷媒、清洗剂等需要按类别保管。
电气件防静电资源电子模块、传感器和控制单元存放减少静电和潮湿影响。
盘点工具库存核对、差异分析和库龄管理支撑库存准确。
退货检视区识别错配、损伤、使用痕迹和旧件返还售后处理资源。

D3 与 G 段的分工：D3 写资源和工具本身，G 段写这些资源用于确认哪些参数、状态或事实。

D4 主要投入：物料、资料、客户财产和数据

投入类别典型内容作用
汽车零部件易损件、总成件、车身件、电气件、轮胎和油液核心流通对象。
配件目录和技术资料零件号、适配表、替代关系、车型信息适配和报价依据。
供应商资料品牌、授权、价格、交期和售后条件采购和索赔基础。
客户订单资料询价、VIN、车型、数量、配送和账期订单处理输入。
包装材料纸箱、缓冲材料、防潮袋、防静电袋、托盘保护配件运输。
物流资源快递、同城配送、零担和干线物流配送能力输入。
库存数据库位、批次、数量、库龄、周转库存控制基础。
旧件和退货件总成旧件、错配件、损伤件和索赔件售后处理对象。

D5 常见工艺路线、服务模式和规模差异

类型典型特征差异影响
区域传统批发商依托汽配城和本地配送客户熟、反应快，但系统化程度差异大。
品牌总代经营单一或少数品牌，来源稳定价格政策和授权资料较清楚。
平台化供应链线上下单、云仓和多地配送信息系统和库存准确性更关键。
专营系统件批发专注制动、底盘、电气、油液或轮胎专业适配深度较高。
再制造和拆车件渠道价格敏感、来源多样状态识别和说明更敏感。
车队定向供应按车队车型配置常用件库存结构和响应时效更突出。
小型批发门店人员少、库存有限、外调件多依赖上游目录和调拨效率。

D6 常见过程文件和记录载体

文件或记录典型内容作用

售后和反馈记录退换货、返修、投诉、索赔和回访支撑问题闭环和经验积累。

D7 汽车配件批发的车型适配、库存追溯和渠道索赔链条深化说明

汽车配件批发的深水区在多车型、多零件号、多供应来源之间保持可识别和可追溯。客户往往只说车型或故障部位，批发商需要把这些信息转化为准确零件号、替代关系和库存位置。 库存追溯是批发区别于普通贸易的重要环节。油液有保存期限，电子件有防潮防静电要求，车身件容易运输损伤，总成件涉及旧件返还，轮胎和电瓶有规格、批次和状态差异。 渠道索赔把客户、批发商和供应商连接起来。配件不适配、运输损坏、疑似故障、旧件未返、批次争议等都要依赖订单、批次、包装、图片、检测和退货条件进行处理。

链条典型要素客观作用
车型识别链VIN、车型、年款、发动机、配置确定适配入口。
零件编号链OE号、品牌号、替代号、批次号确定可供应对象。
库存链库位、数量、批次、库龄、盘点支撑快速准确拣货。
保管链防潮、防压、防静电、防泄漏、防划伤维持配件流通过程状态。
订单链客户、价格、数量、账期、配送形成批发交易结果。
配送链包装、承运、签收、异常反馈把配件送达客户。
退换链错配、损坏、使用痕迹、时限形成售后处理边界。
索赔链客户证据、供应商条件、旧件返还、批次追溯闭合渠道责任。

D8 本小类与上层分组文件的接口提示

接口维度底层可提供的事实上层文件需要另行形成的判断
共性判断活动对象、过程链、技术基础、产业链段位是否能够与相邻小类组成同一技术领域组。
差异判断内部分型、设备资源、专属术语、敏感边界差异是否可通过补充能力、培训或限定授权处理。
边界判断A3 排除项和易混活动具体项目归属和人员授权边界。
能力接口D2 过程、D3 资源、G 段方法和 H3 敏感点不同管理体系下的人员能力要求。
维护接口F 段类别指针、I 段资料线索和待更新事项法规标准或行业变化后的联动更新。

E. 产业链与边界

E1 上游供应

上游来源提供内容对本小类的影响
零部件制造商提供原厂件、品牌件和售后件决定配件来源和技术资料。
品牌总代理提供区域供货和价格政策影响供货稳定性。
再制造和拆车渠道提供价格敏感类总成和旧件影响状态识别和说明。
物流服务商承担跨区运输和同城配送影响时效和损伤率。
目录和数据服务商提供车型适配和零件号资料影响适配准确性。
包装材料供应商提供防护包装和标签材料影响配送保护。

E2 下游应用或客户

下游对象使用或需求场景对服务的影响
汽车维修厂高频采购易损件和故障维修件需要适配准确和送达及时。
品牌服务站补充非常用件或区域调拨关注来源和交期。
车队客户按保有车型批量备件关注稳定供应和成本。
零售门店从批发商进货后面向消费者销售关注价格和库存齐全。
电商经营者线上销售配件和附件关注包装、库存和发货速度。
二级批发商区域分销和下沉市场覆盖关注价格层级和账期。

E3 本小类在产业链中的位置

本小类位于流通和服务产业链中，不改变车辆或商品的基本制造属性，而是通过信息匹配、资源组织、交易安排、状态确认和服务接口，把上游车辆、配件或资料转化为客户可接收、可使用或可继续处理的服务结果。

对于 29 大类而言，产业链位置判断尤其依赖主导活动：同一组织可能同时存在销售、维修、配件、金融、保险、平台和外包接口，但分类时应识别哪一类活动构成主要服务输出。

E4 常见委外和外部接口

外部接口常见内容边界提示
仓储外包第三方仓库或云仓保管配件库存准确和发货接口。
物流配送快递、零担、同城配送包装保护和签收。
目录数据维护外部数据商提供适配信息车型资料更新接口。
退货检测高价值总成或电子件可能外部检测索赔依据。
包装加工贴标、组合包、重新包装品牌和追溯信息。
旧件回收总成旧件返还或再制造渠道回收交接和状态确认。

F. 适用法规与技术标准

G. 检验、检测与计量手段

G1 行业常用检测、核验和计量方法

方法或手段对象用途
身份核验VIN、证件、随车文件、零件号确认实物和资料一致。
外观检查整车、车身件、配件包装、装备外观发现损伤、变形、划痕和包装异常。
功能检查灯光、电气、上装动作、车载电子、车辆基本功能确认交付或维修后的功能状态。
诊断仪检测车辆电子控制系统和故障码读取数据流、故障码和系统状态。
尺寸和规格核对轮胎、电瓶、配件接口、车身件尺寸确认适配和可安装性。
库存盘点车辆、配件、商品和库位确认账实一致和周转状态。
包装和标签核对配件、油液、用品、装备确认商品信息和使用说明。
试车或试骑车辆维修后或销售体验车辆确认行驶、制动、转向、异响和功能状态。
扭矩或紧固确认轮胎、制动、底盘、摩托车链条和关键连接确认安装和拆装状态。
客户签收和交接确认车辆、配件、文件、服务结果确认服务结果已移交。

参数或事实常用方法或工具说明

配置或规格一致性配置表、实物标签、零件目录、包装参数用于车辆和配件适配。
车辆交付状态PDI清单、外观检查、油液检查、功能检查用于销售交付。

电瓶状态电压、容量类别、冷启动能力语境、外观和极柱检查用于电瓶销售更换。
油液状态规格类别、包装、颜色、液位、泄漏观察用于保养和商品销售。

H. 行业本底特征

H1 技术复杂度、自动化和人工依赖程度

维度本底特征说明
技术复杂度车辆和配件涉及机械、电气、电子、软件、材料和使用场景不同小类复杂度来源不同。
信息依赖车型、VIN、零件号、配置、库存和客户资料高度重要信息错误会直接传导到交付或服务结果。
人工经验销售说明、适配判断、诊断和客户沟通仍大量依赖人员经验系统工具不能完全替代专业判断。
自动化程度库存、订单、目录和平台系统逐步提高自动化现场交付、维修和客户解释仍需人工完成。
规模跨度从小型门店到连锁平台、品牌经销和区域仓均存在组织形态跨度大。

H2 典型组织形态

组织形态典型特点说明
品牌授权经销或服务站厂家资源、资料和服务接口较完整常见于整车销售和维修。
独立门店经营灵活、人员复合、外部接口多常见于配件零售和维修。
区域批发商或仓配平台库存深、SKU多、配送范围广常见于配件批发。
线上平台店远程获客、系统订单、物流交付适配说明和退换货突出。
综合复合门店销售、维修、配件、精品和外部服务交织边界识别需要看主导活动。

H3 客观存在的易出问题环节和技术敏感点

敏感点客观表现客观影响链
适配信息错误车型、年款或零件号判断错误适配错误 → 客户无法安装 → 退换货和停工。
库存账实不符系统数量与实物不一致库存不准 → 承诺失实 → 订单延误。
来源信息不清品牌、批次或供应商记录不完整来源不清 → 索赔困难 → 渠道信任下降。
电气件保管不当潮湿、静电或挤压保管不当 → 隐性损伤 → 装车后故障。
油液和耗材过期保质期限或存放条件失控状态退化 → 使用风险增加 → 退货或投诉。
车身件运输损伤大件覆盖件防护不足包装不足 → 划伤变形 → 返运和赔付。
替代关系误判不同品牌件不可完全互换替代误判 → 安装偏差 → 客户返工。
旧件返还混乱总成件旧件未按条件返还旧件链断裂 → 供应商索赔失败 → 成本增加。
渠道价格口径混乱同一客户不同政策和账期价格不清 → 账务争议 → 客户流失。
平台库存同步延迟多渠道销售库存未实时更新库存超卖 → 履约延迟 → 退单。

H3 仅写事实因果链，不把这些敏感点预先归入任何特定管理体系视角。
