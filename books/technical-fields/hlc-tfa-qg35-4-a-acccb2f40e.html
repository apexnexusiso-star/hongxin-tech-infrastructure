  • 文件定位说明

本文件用于质量管理体系认证中 QG35-4 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦 就业安置、临时就业代理和其他人力资源提供服务 在 QMS 轴下的质量形成链、客户要求转化、服务过程控制、输出验证、记录追溯、投诉反馈和改进闭环。本文件不承担行业百科说明功能，基础行业事实由对应专业小类基础卡承载。

本组采用“统一领域包 + 招聘安置分支 + 临时派遣分支 + 人力资源外包分支 + 用工边界控制 + 条件扩展”的使用口径。组内小类可以共享通用服务质量管理判断方法，但不得把某一分支经历等同于另一分支完整能力；对专业责任强、客户损失后果高、现场活动复杂或外部合规接口明显的情形，应在授权和项目匹配阶段追加分支确认。

  • 技术领域包构成
小类编码小类名称纳入本包的活动范围主要内部路线特殊边界
35.09.00就业安置代理机构的活动人员物色、选择推荐、安置、高级管理人员寻访、角色选派和网上招聘代理。普通招聘、猎头、高管寻访、线上招聘、角色选派。候选人真实性、岗位匹配、推荐过程、客户录用反馈和个人信息边界需确认。
35.10.00临时就业代理活动在限定时间内为客户替代或补充劳动力而提供工人，人员为临时服务单位雇员。临时派遣、短期替岗、季节性用工、项目性用工。劳动关系、派出人员、客户现场、工时结算和现场监督边界需专项确认。
35.11.00其他人力资源的提供为客户企业提供长期或持续人力资源，并代表雇主处理工资、税务及人力资源记录等事项。人力资源外包、员工记录、薪酬福利接口、雇主记录服务、长期人员提供。长期用工、薪酬社保、员工资料、客户管理责任和指导监督边界需专项确认。
  • 分组设立的基本逻辑

本包在 QMS 轴下的共同对象是围绕客户岗位、人员供给、候选人或派出人员管理形成的人力资源服务过程。质量管理体系审核关注的核心不是服务名称是否相同，而是客户需求如何被识别和转化，服务资源如何配置，服务实施过程如何受控，服务输出如何被复核或验收，客户反馈如何形成纠正和改进。

本包可概括的共同质量形成链为：客户岗位或用工需求 -> 岗位画像和服务协议 -> 候选人或人员资源识别 -> 资格、经历和匹配核验 -> 推荐、派出或持续人力资源服务 -> 客户确认、人员反馈、工时薪酬或服务报告 -> 投诉、替换和改进闭环。该链条决定了本包共享的专业能力基础，即审核员应能够围绕客户要求、人员能力、服务方案、过程记录、输出验证、交付确认和反馈闭环建立审核证据链。

组内差异主要表现为服务交付结果不同：就业安置重在候选人推荐和录用匹配，临时就业代理重在短期人员派出和工时结算，其他人力资源提供重在持续人员管理、薪酬福利接口和雇主记录。这些差异不否定设组，但要求本包不能按无差别能力包使用，应通过分支标注、专项确认、条件扩展和抽样控制加以处理。

  • 专业小类关系类型与授权后果
关系类型含义授权后果典型控制方式
共同基础关系同属以合同、委托、项目任务或服务订单为输入的专业服务活动，均需识别客户要求、配置人员和资源、形成服务输出、保存服务证据并处理反馈。可简化通用服务过程、客户沟通、记录控制和服务评价等基础能力评价，但仍需确认目标小类或目标分支的实际经历。资料评审、案例判断、专业面谈、服务证据追溯。
并列分支关系同属本技术领域包，但服务对象、交付物、专业责任、现场条件或客户验收方式不同。应记录实际分支能力，不把同包经历理解为全分支能力。分支标注、限定使用、项目技术支持。
条件扩展关系已具备相邻分支能力，具有扩展基础，但目标分支仍存在专门知识、证据链或法规边界。完成补充培训、案例评审、专业面谈、见证审核或技术支持后方可扩展。培训考核、案例评审、见证审核、专家确认。
专项确认关系涉及强执业属性、高保密数据、高客户损失后果、特殊现场作业或复杂外包链。项目使用前应开展专项确认，必要时配置技术专家支持。专项面谈、技术专家评审、项目匹配确认。
不可直接替代关系相关服务经验不足以证明目标小类的质量形成链能力。不得作为目标能力的单独授权依据，应补充目标经历或限定项目类型。重新评价、补充经历、限定项目类型。
边界受控关系当执业资格、客户行业要求、个人信息、资金信用、现场安全、外包生产或法定接口改变服务边界时，统一包内授权应增加边界说明。授权记录应写明适用边界，项目匹配时按实际服务内容确认。授权备注、合规类别清单、技术支持。
就业安置与临时就业代理均从客户岗位需求出发进行人员匹配，但前者通常以推荐录用为结果，后者以派出人员持续服务为结果。可共享岗位画像和人员筛选基础，临时派遣需确认劳动关系和派出管理能力。岗位需求、候选人核验、派出协议、工时和反馈记录追溯。
临时就业代理与HR提供均涉及人员持续服务、客户接口和员工记录。长期人力资源提供的薪酬、税务、人事记录和雇主责任边界需专项确认。员工档案、薪酬福利接口、客户反馈和人员变更记录抽样。
招聘代理与HR外包均依赖候选人或员工信息和客户岗位要求。从一次性推荐扩展到长期人员管理，应补充服务周期和员工记录控制能力。服务合同、人员档案、变更、投诉和结算记录评价。
  • 本体系共同能力基础
共同能力维度本包共同基础可共享的审核判断不能共享的边界
客户岗位需求识别均需识别客户岗位职责、任职资格、人数、期限、工作地点、薪酬范围和服务结果。判断服务协议、岗位画像、筛选标准和客户确认是否一致。临时派遣和长期HR提供的劳动关系与客户现场边界需专项确认。
人员资源和信息控制均需收集、核验、保存和更新候选人或员工资料。可共享身份、经历、资质、面试、背调、资料保密和个人信息控制判断。特殊岗位、敏感背景核验和员工薪酬资料不能用一般招聘经历替代。
匹配和推荐过程均需按岗位要求进行筛选、评估、推荐或派出。可共享匹配逻辑、面试评价、客户反馈和不合格候选人处理判断。现场派出人员的持续绩效、纪律和工时管理需分支确认。
服务交付和持续跟踪均需跟踪录用、到岗、派出、替换、投诉和服务报告。可共享客户满意、投诉处理、替换机制和纠正措施判断。薪酬税务、人事记录、工伤和客户现场管理接口需专项确认。
  • 本体系核心控制要求

本组所称关键质量特性，是指服务输出中影响客户可接受性的准确性、完整性、及时性、一致性、可追溯性、响应性和交付符合性。在服务业场景中，检验和放行通常表现为主管复核、质检抽查、客户确认、验收签收、报告批准、脚本质检、现场巡检或交付前复核；审核员应把这些复核和确认活动作为服务结果进入客户使用前的质量控制证据。

QMS 审核应首先确认客户岗位和用工需求如何被识别。岗位职责、任职资格、人数、期限、地点、薪酬或费用、服务级别、替换条件和验收方式应在合同、岗位说明、服务订单或客户确认记录中体现。需求识别不充分会直接导致推荐不匹配、派出人员不合格、客户投诉和结算争议。

第二，应追溯候选人或派出人员的信息控制。人员身份、学历、资格、经历、背景、面试评价、客户反馈、到岗状态和变更记录均影响服务质量。审核员应确认资料收集有授权，核验方法有记录，信息更新和访问权限受控，未录用或离职人员资料有处置规则。

第三，应评价匹配、推荐、派出和持续服务过程。就业安置应关注岗位画像、筛选、面试、推荐理由和录用反馈；临时就业代理应关注派出协议、入职培训、到岗、工时、替换和客户现场反馈；其他人力资源提供应关注员工记录、薪酬福利接口、人员变动、客户沟通和服务报告。

第四，应核查投诉和纠正闭环。典型问题包括候选人资料不实、岗位匹配偏差、到岗延迟、派出人员流失、工时记录争议、薪酬福利数据错误、客户投诉未及时响应和个人信息泄露。审核应追溯问题登记、原因分析、补救、客户沟通和制度改进。

  • 分小类或内部路线差异分析
小类/路线与本包共同基础主要差异差异对能力授权的影响控制方式
35.09.00 就业安置代理共享岗位需求、人员筛选、客户反馈和记录控制基础。服务结果通常是推荐和录用，重点在候选人真实性、匹配度和推荐过程。可作为人力资源服务基础分支，但不覆盖派出和长期HR外包。抽取招聘项目，追溯岗位画像、候选人筛选、面试、推荐和录用反馈。
35.10.00 临时就业代理共享岗位需求、人员资源、客户反馈和替换机制基础。人员为临时服务单位雇员，持续派出、工时、替换、客户现场反馈和结算突出。属专项确认路线，应确认派出人员管理和客户现场接口。抽取派出人员样本，追溯协议、到岗、工时、客户反馈、替换和结算。
35.11.00 其他人力资源提供共享人员资料、客户服务和持续跟踪基础。长期或持续人力资源提供，薪酬税务、人事记录、员工变更和雇主责任边界突出。应标注HR外包或长期人员提供分支。抽取员工服务样本，追溯员工档案、薪酬福利接口、变更、投诉和服务报告。
高管寻访或特殊岗位招聘共享岗位需求和候选人筛选基础。保密、候选人来源、背景核验、客户决策链和高价值岗位匹配突出。从普通招聘扩展到高管或特殊岗位需专项确认。高管寻访案例、候选人沟通、背调和客户反馈记录。
线上招聘平台服务共享岗位发布、候选人信息和客户反馈基础。平台规则、简历库、算法筛选、账号权限和数据处理突出。需确认平台型招聘和个人信息处理能力。岗位发布、简历筛选、账号权限、投诉和数据记录抽样。
  • 分组合理性论证结论

本组可以设立的理由在于，三个小类均以客户岗位或用工需求为起点，通过人员资源识别、资格经历核验、匹配推荐、派出或持续服务、客户反馈和替换改进形成服务质量。QMS 审核可共享岗位需求识别、人员资料控制、候选人或员工匹配、服务交付、客户反馈和投诉闭环的判断方法。

因此，QG35-4 可以作为质量管理体系技术领域包使用，但其使用方式应为“统一领域包 + 招聘安置分支 + 临时派遣分支 + 人力资源外包分支 + 用工边界控制 + 条件扩展”。审核员授权、项目匹配和能力扩展均应体现分支差异，不得把同包经历理解为跨全部小类的充分证明。

  • 审核关键要点与抽样方法
抽样场景现场必看记录必查纵向追溯路径追问方向
招聘安置项目招聘系统、候选人库、面试记录、客户沟通记录。岗位需求、筛选标准、候选人资料、面试评价、推荐记录、录用反馈。客户岗位 -> 候选人筛选 -> 面试评估 -> 推荐 -> 客户反馈。候选人真实性如何核验；推荐理由是否符合岗位要求。
高管或特殊岗位寻访项目保密区、候选人长名单、背调资料。委托协议、岗位画像、寻访记录、背调、客户面谈、候选人反馈。委托 -> 岗位画像 -> 寻访 -> 背调 -> 推荐 -> 决策反馈。保密和利益冲突如何控制；背调异常如何处理。
临时人员派出派出人员名册、客户现场接口、工时记录。派出协议、入职资料、培训、到岗、工时、客户评价、替换和结算。客户用工需求 -> 人员匹配 -> 派出 -> 工时确认 -> 客户评价 -> 结算。现场监督边界如何划分；人员不适配如何替换。
长期HR外包服务员工档案、薪酬福利接口、客户服务台。服务协议、员工资料、变更记录、薪酬福利数据、服务报告、投诉。客户需求 -> 员工记录 -> 服务处理 -> 客户确认 -> 报告。数据错误如何纠正；客户和雇主责任边界如何确认。
线上招聘代理职位发布后台、简历筛选规则、客户账号。岗位发布、简历来源、筛选记录、客户反馈、投诉和账号权限记录。岗位 -> 发布 -> 简历 -> 筛选 -> 客户反馈。简历来源和个人信息授权如何确认。
  • 能力扩展与条件授权
起点能力目标能力可扩展依据必须补充确认授权限制
招聘安置临时就业代理共享岗位需求、候选人筛选和客户反馈基础。派出协议、临时人员入职、工时、客户现场反馈、替换和结算案例。未确认前不用于派遣或临时用工项目。
临时就业代理招聘安置共享岗位识别和人员匹配基础。候选人推荐、面试评价、客户录用反馈和招聘项目案例。可简化基础评价，仍需确认招聘过程能力。
临时就业代理其他HR提供共享人员持续服务、客户接口和记录控制基础。长期员工资料、薪酬福利、税务接口、变更和服务报告案例。未确认前不用于长期HR外包项目。
HR外包临时就业代理共享员工资料和客户服务基础。临时派出、到岗、工时、客户现场反馈和替换机制案例。按确认派出服务路线使用。
普通招聘高管寻访或特殊岗位共享岗位画像和候选人筛选基础。保密、候选人来源、背调、客户决策链和高价值岗位案例。高管和特殊岗位需专项确认。
  • 培训、考核与作业指导书需求

本组应建立人力资源服务 QMS 培训，内容包括岗位需求识别、候选人资料核验、个人信息控制、面试和评价记录、岗位匹配逻辑、客户反馈、派出人员管理、工时和结算、长期HR外包员工记录、薪酬福利接口、投诉替换机制、高管寻访和线上招聘平台边界。
