A2 定义与范围界定

本小类包括其他具有明确用途、专业规格、客户群体或渠道要求的特定产品销售代理活动。它不是普通杂项代理，而是针对特定产品族进行持续代理、资料整理、客户开发和交易协调的服务。

销售代理的服务结果通常不是商品实物的制造、加工或自营销售，而是围绕委托授权形成客户线索、询盘响应、规格澄清、报价传递、交易条件协调、订单跟踪、交付资料传递、售后问题协调和佣金结算。代理机构是否实际接触样品、是否代收代付、是否协助运输或是否参与合同签署，应根据委托权限逐项识别。

本小类的专业性集中在产品主属性识别、专用规格、客户用途、样品资料、行业证明、售后接口和相邻类别调用边界。同为销售代理，商品对象不同会显著改变术语、资料、样品、交付和外部接口，不能用一般商业中介服务替代本小类的专业描述。

A3 边界说明、相邻小类区分点和排除项

相邻活动容易混淆的原因主要区分依据本卡处理原则
自营批发贸易代理和批发都促成商品成交，且可能使用相同客户渠道是否取得货权、是否以买卖差价为主、是否承担库存和货物处分责任受托撮合、传递信息并以佣金或服务费为主的归入本卡；自购自销并承担库存货权的归入相应批发小类。
商品零售代理机构可能面对终端客户并展示样品交易对象是代理服务还是终端商品零售面向委托方提供销售代理服务的归入本卡；以门店或平台直接向终端销售商品为主的归入相应零售小类。
生产制造或初加工代理对象可能来自生产企业，代理人员熟悉产品技术是否进行制造、加工、分装、改性或实物生产只做销售代理和交易协调归入本卡；主导生产加工活动按制造或加工小类识别。
经纪、拍卖和平台撮合均可能撮合买卖双方并不持有货物是否为特定商品或委托方持续开发销售渠道，还是提供公开交易平台或拍卖程序长期受托代理特定商品或委托方归入本卡；公开平台、拍卖和一般经纪按主导活动另行识别。
物流、仓储和货运代理代理业务常协调运输、仓储、装卸和交付资料主导服务结果是销售成交还是物流履约交付接口协调属于本卡；以运输、仓储或货运代理为主的活动不纳入本卡。
进出口代理部分代理涉及进口货源、报关单证和国际结算主导活动是商品销售代理还是进出口手续代理围绕商品销售渠道开发归入本卡；以报关、单证和进出口服务为主另行识别。

明确排除项：

  • 取得货权并以自营差价为主的批发或零售活动。
  • 商品制造、加工、分装、维修、安装和实物处置活动。
  • 以仓储、运输、货运代理、报关或供应链金融为主的活动。
  • 公开拍卖、一般平台撮合和不针对特定商品的广告推广活动。
  • 超出委托权限直接承诺价格、质量、交付或售后责任的活动。

分组敏感边界代理对象跨度较大，需用商品属性、客户用途和货权边界防止与批发零售混淆使用本卡时应以委托权限、货权归属、主导服务结果和商品属性共同判断。

B. 术语与概念

B1 专业术语和行业常用表达

术语解释本小类中的使用语境
销售代理受委托方委托，为特定商品或客户撮合交易、开发客户、传递信息并获取佣金或服务报酬的商业活动。用于区分代理服务与自营批发零售。
委托方授权代理机构开展市场开发、客户沟通或交易协调的一方。通常是生产商、供应商、进口商或品牌方。
代理权限代理机构可开展的区域、客户、品类、价格、合同签署和售后协调权限范围。决定代理服务边界。
货权商品所有权或处分权归属。判断代理与自营贸易边界的重要概念。
佣金代理机构根据成交、销售额、服务量或约定条件取得的报酬。销售代理的典型收益方式。
询盘潜在客户对商品、价格、交期、规格或服务条件提出的需求信息。代理服务链的入口之一。
报价围绕商品、数量、价格、交期、付款和服务条件形成的交易表达。代理机构常负责传递或协助形成。
客户开发识别、接触、筛选和维护潜在买方或渠道客户的活动。代理服务的核心过程。
样品或样本用于客户确认规格、外观、性能、产地或等级的代表性实物或资料。不同商品的样品形态差异很大。
交易条件价格、数量、账期、交付地点、运输、包装、索赔和售后等约定。代理机构沟通的主要内容。
信用额度供应方给予客户或渠道的赊销限额或账期控制条件。代理业务常涉及但不等同于金融服务。
售后协调代理机构协助处理交付、退换、投诉、索赔或技术问题的活动。通常不直接替代生产商或卖方责任。
主属性决定产品归属和技术理解的主要属性。本小类代理沟通和资料整理中常见。
专用规格面向特定用途形成的规格参数。本小类代理沟通和资料整理中常见。
适用场景产品被客户使用的专业场合。本小类代理沟通和资料整理中常见。
替代类别可被相邻小类覆盖的产品类别。本小类代理沟通和资料整理中常见。
集合类内部包含多个不同产品族的分类。本小类代理沟通和资料整理中常见。

B3 关键技术概念说明

销售代理首先要区分代理服务和商品买卖。代理机构可能掌握客户、样品、报价和交付信息，但不必然拥有货物所有权，也不必然承担制造者、卖方、仓储方或承运方责任。

理解本小类必须理解代理对象自身的商品属性。未列入前述细分但具有明确专业属性的特定产品的规格、等级、证明资料、样品、包装、交付和客户用途具有专门含义，代理机构的信息传递如果偏差，会直接改变交易判断。

委托权限是本小类最重要的边界概念。代理机构可以被授权寻找客户、传递报价、协助谈判或跟踪履约，但能否签约、能否承诺价格、能否代收款、能否处理索赔，必须由委托关系决定。

代理服务的价值通常体现在信息不对称的降低。商品越专业、交易越跨区域、客户用途越复杂，代理机构越需要把技术资料、交易条件和交付接口翻译成供需双方都能理解的语言。

D. 过程与技术

D1 主要过程流程：从投入到产出的完整链路

销售代理过程通常从委托关系建立开始，经代理商品和权限确认、目标客户识别、市场信息收集、商品资料整理、客户询盘、规格或用途澄清、样品或资料传递、报价和交易条件协调、合同或订单形成、交付跟踪、售后反馈协调和佣金结算完成。

本小类的具体过程链围绕未列入前述细分但具有明确专业属性的特定产品展开。代理人员既要理解代理服务的一般商务逻辑，也要理解该类商品的等级、规格、证明、包装、储运和客户用途，否则容易把客户真正关心的技术条件遗漏在报价之外。

与批发零售不同，代理过程的关键不在自有库存周转，而在委托权限、客户信息、交易条件和货权责任边界。代理机构可以参与很多交付接口，但是否承担实物责任必须回到合同和委托关系识别。

通用链路可表示为：

`text 委托授权 → 商品和资料识别 → 市场与客户开发 → 询盘澄清 → 报价协调 → 样品或证明资料传递 → 合同订单协调 → 交付接口跟踪 → 售后协调 → 佣金结算 `

D7 其他特定产品专业代理的主属性识别和相邻类别调用链条深化说明

本小类的深水区在于不能把未列入前述细分但具有明确专业属性的特定产品写成普通商品代理。代理服务必须把商品对象的规格、用途、样品、证明资料和交付接口转化为客户可理解的交易条件。 代理机构不一定持有货物，但它传递的信息会影响客户判断。样品是否代表大货、报价是否包含运费和税费、交付和售后由谁承担，都会影响交易事实。 如果代理对象内部跨度大，基础卡应把分型差异前置给上层文件，而不是用一个笼统的商业服务描述抹平。

链条典型要素客观作用
对象识别链品类、型号、等级、用途确定代理对象。
样品资料链样品、图片、目录、证明资料支撑客户判断。
客户用途链生产、零售、工程、消费或专业使用匹配客户需求。
价格条件链报价、折扣、账期、运费、佣金形成交易条件。
货权边界链委托方、供应方、客户、代理权限明确责任主体。
交付接口链包装、发货、物流、签收支撑履约。
售后协调链退换、索赔、投诉和资料补充闭合客户反馈。
维护更新链商品变化、客户变化、渠道变化保持代理服务有效。

D8 本小类与上层分组文件的接口提示

接口维度底层可提供的事实上层文件需要另行形成的判断
共性判断代理服务、委托权限、客户开发、交易撮合和佣金结算是否可与其他销售代理小类组成同一技术领域组。
差异判断商品对象、技术指标、样品资料、外部许可类别和交付接口差异是否需通过限定授权或补充能力处理。
边界判断货权、自营贸易、制造加工、物流仓储和平台撮合边界具体项目归属和人员授权边界。
能力接口D2 过程、D3 资源、G 段方法和 H3 敏感点不同管理体系下的人员能力要求。
维护接口F 段类别指针、I 段资料线索和待更新事项法规标准或行业变化后的联动更新。

E1 上游供应

批发商和渠道商提供货源和库存信息影响交付能力。
展会和市场平台提供客户和展示机会影响获客方式。

E2 下游应用或客户

下游对象使用或需求场景对服务的影响

批发和零售客户用于渠道转售关注价格和供货。

品牌客户采购指定品牌或规格关注授权和真实性。

E3 本小类在产业链中的位置

本小类位于商品生产供应方和购买使用方之间，是以客户、信息、渠道和交易条件为主要资源的服务环节。代理机构不必然持有货物，也不必然直接承担仓储运输责任，但会影响供需双方对商品规格、价格、交付和售后接口的理解。

在 29.05 销售代理族中，本卡的产业链位置由未列入前述细分但具有明确专业属性的特定产品的专业属性进一步限定。商品对象越专业、证明资料越复杂、交付接口越多，代理机构对资料准确性和边界表达的依赖越高。

E4 常见委外和外部接口

外部接口常见内容边界提示
物流配送发货、运输、签收和异常反馈代理协调但不必然承运。
检测证明商品检测、证明和标签资料资料对应性重要。
展会展示展位、样品和客户接触获客接口。
平台运营线上页面、客服和交易记录责任边界。
售后服务退换货、索赔和维修接口主体责任需区分。
结算服务代收代付、佣金和账期货款与佣金边界。

F. 适用法规与技术标准

F1 行业准入、资质和许可类别

类别可能涉及的事项底层卡处理原则
经营主体登记销售代理、贸易代理、商务服务、批发代理等经营范围表达只记录类别，不判断具体组织适用性。
合同和代理关系规则类别委托、授权、佣金、代理权限、违约和保密等作为代理活动通用法律主体。
广告、价格和反不正当竞争类别报价、宣传、渠道竞争和商业承诺只作为通用类别指针。
商品特殊规则接口食品、烟草、活体动物、危险化学品、木材、设备、进出口等可能涉及按商品对象保留类别指针。
网络交易和平台服务规则类别线上撮合、直播、平台店铺和电子合同适用于线上代理模式。

F2 强制性产品要求和主要技术标准类别

标准或要求类别典型对象检索方向
商品分类和规格等级标准类别未列入前述细分但具有明确专业属性的特定产品按具体商品类别检索现行有效标准。
标识、标签和包装要求类别商品标签、包装、说明资料、警示和批次信息按商品属性检索。
检测、计量和取样方法类别样品、指标、重量、数量、成分和状态用于交易确认和争议处理。
仓储和运输技术条件类别温控、防潮、防混、禁配、装卸和包装保护按商品储运属性检索。
进出口和单证资料类别进口商品、原产地、检疫、报关和检验证明只作为外部资料线索。
电子交易和数据记录类别平台订单、电子合同、客户资料和交易记录适用于线上代理服务。

F3 通用法律法规主体

法规主体类别与本小类的关系处理原则
民事代理和合同委托代理、权限、佣金、违约和责任边界底层卡只写主体类别。
市场交易秩序广告宣传、价格表达、商业贿赂和不正当竞争具体适用条款不在本卡展开。
产品责任和消费者权益商品说明、售后协调和责任主体识别按商品是否面向终端客户另行判断。
个人信息和商业秘密客户资料、报价、供应商信息和交易数据作为资料处理规则类别记录。
特殊商品和外部许可不同商品可能涉及检疫、许可、专卖、危险属性或资质类别具体清单交由对应上层或专项文件处理。

G. 检验、检测与计量手段

G1 行业常用检测、核验和计量方法

方法或手段对象用途
委托权限核验授权书、协议、区域和客户范围确认代理边界。
商品规格核对规格表、等级、牌号、型号、批次和包装确认交易对象。
样品或样本确认实物样品、照片、视频、封样和留样支撑远程或异地交易。
证明资料核验产地、检疫、检测、标签、许可和单证资料类别确认资料是否与商品对应。
价格口径核对报价、价格公式、运费、账期和有效期确认交易条件。
数量和重量核对过磅、点数、包装数量、仓单和签收确认交付数量。
客户用途核对客户工艺、销售场景、使用需求和交货条件确认商品匹配。
交付节点核对发运、到货、签收、仓储和运输状态跟踪履约接口。
售后反馈核对退换、索赔、投诉、质量争议和短重差异支撑协调处理。
佣金结算核对成交、发货、验收、回款和服务节点确认代理报酬。

G2 关键参数与对应方法

参数或事实常用方法或工具说明
代理权限委托协议、授权书、往来确认判断是否可代表委托方沟通。
商品身份品名、型号、牌号、批次、包装和照片避免交易对象错配。
商品指标检测报告、等级证明、样品比对和客户确认不同商品指标不同。
客户需求询盘记录、用途说明、采购计划和技术澄清形成匹配依据。
报价有效性报价单、行情资料、价格公式和确认时间避免过期或口径不一。
货权节点仓单、提单、出库单、签收和合同条款识别责任边界。
交付状态物流跟踪、到货照片、签收和验收反馈确认履约进度。
证明资料对应性资料编号、批次、品名、数量和客户要求比对减少资料错配。
异常事实照片、检测、签收备注、往来记录支撑售后协调。
佣金基础成交金额、回款、发货、验收和服务范围形成结算依据。

H. 行业本底特征

H1 技术复杂度、自动化和人工依赖程度

维度本底特征说明
技术复杂度取决于代理对象的专业属性、证明资料、交易规模和交付接口商品越专业，代理服务越依赖技术资料理解。
信息依赖委托权限、客户资料、商品规格、价格和交付信息高度关键信息偏差会直接传导到交易判断。
人工经验客户开发、商务谈判、商品解释和异常协调仍高度依赖人员经验系统只能辅助记录和匹配。
自动化程度客户关系、报价、合同和订单系统逐步普及样品、看货和现场协调仍需人工参与。
规模跨度个人代理、小团队、区域代理和全国渠道代理并存内部能力差异较大。

H2 典型组织形态

组织形态典型特点说明
个人或小团队代理依靠客户资源和行业经验资料管理和权限边界容易薄弱。
区域代理商负责特定区域客户开发和售后协调渠道维护能力突出。
品牌或厂家代理机构受供应方长期委托产品资料和价格政策较稳定。
采购代理机构受买方委托寻找货源需求识别和供应商比较突出。
平台化代理服务商通过线上工具撮合和跟踪数据和责任边界突出。
项目型代理机构围绕工程、设备或大宗采购技术澄清和合同节点复杂。

H3 客观存在的易出问题环节和技术敏感点

敏感点客观表现客观影响链
主属性判断错误本应归入更具体小类的产品被放入本卡归类错误 → 上层调用偏差 → 分组依据变弱。
相邻类别排除不足未说明为何不属于设备、化工、建材或食品等类别排除不足 → 边界被追问 → 文件维护困难。
专用规格表达不清型号、接口或使用条件描述不足规格不清 → 客户误用 → 退换货。
样品试用条件不明试用期限、损耗或归还条件不清条件不明 → 样品争议 → 成本增加。
行业证明资料不足客户需要的检测或合格资料类别未传递资料不足 → 接收延迟 → 成交受阻。
售后接口不清安装、维修、耗材和技术支持主体未说明接口不清 → 使用问题无人承接 → 客户流失。
替代型号误导停产或升级产品替代关系未确认替代误判 → 兼容异常 → 客户投诉。
进口资料翻译偏差外文说明和中文沟通不一致资料偏差 → 使用理解错误 → 售后争议。
集合类滥用过多无关产品被装入同一代理范围范围过宽 → 专业描述空心 → 调用价值下降。
佣金口径随产品变化附件、耗材和服务项是否计佣不清口径不清 → 结算争议 → 关系受损。

H3 仅写事实因果链，不把这些敏感点预先归入任何特定管理体系视角。
