17.13.00 金属加工制品的维修 专业小类基础卡

A. 标识与定位

A1 小类名称、分类代码、在分类体系中的位置

字段内容
专业小类代码17.13.00
专业小类名称金属加工制品的维修
所属大类17 金属制品制造及金属材料加工相关活动
所属中类17.13 金属加工制品维修服务
本卡定位描述对既有金属加工制品进行状态检查、损伤诊断、拆解、清理、校正、补焊、机加工修复、部件更换、表面恢复、密封或功能确认和交付的行业事实。
与上层文件关系本卡只记录底层行业事实和技术边界，不记录任何上层视图判断。

A2 定义与范围界定

本小类是指对已经制造完成并投入储存、运输、安装、使用或待再利用状态的金属加工制品进行维修、修复、翻新、恢复、局部更换和状态确认的活动。其核心对象不是全新金属制品制造，而是对既有金属制品因磨损、腐蚀、变形、裂纹、泄漏、连接松动、表面损伤、配合失效或使用状态下降所进行的修复服务。

本小类可能涉及的维修对象包括金属结构件、金属门窗和金属围护件、金属容器、箱槽罐仓、钢桶和金属包装容器、金属工具、锁具和铰链、金属丝制品、链条、弹簧、紧固件、金属托架、金属支架、金属外壳、金属框架、杂项金属制品及其部件。若涉及承压容器、锅炉、蒸汽发生器、危险货物包装容器、防火门窗或其他具有专项监管属性的产品，其维修边界、许可、检验和资料要求应按产品类别和机构受控分类表核实。

维修活动通常包括受理和识别、状态检查、拆卸清洗、损伤评估、维修方案确定、材料和备件准备、焊接补强、校直校形、孔位和螺纹修复、密封面修整、涂层或镀层恢复、部件更换、重新装配、试漏或功能检查、表面保护、记录和交付。与制造相比，维修的输入状态更不确定，需要先确认损伤范围、原始材料、使用环境、剩余尺寸和可修复性。

本小类不包括通用机械设备维修、电气设备维修、机动车维修、船舶和航空器维修、建筑工程安装和维护、金属制品全新制造、单纯机加工服务、单纯表面处理服务、废旧金属回收拆解、贸易和单纯清洗保养服务。若维修对象已经属于机械、电气、车辆、船舶或建筑工程系统的一部分，应按主导维修对象和合同服务边界另行识别。

A4 分组特征摘要

受控维度本小类特征摘要
主导活动类型金属加工制品维修服务，具有状态诊断、修复方案、拆装清理、补焊校正、表面恢复和功能确认特征。
核心过程性质对既有金属制品进行识别、损伤检查、可修复性判断、维修实施、部件更换、恢复性检测和交付。
主要技术基础金属材料识别、损伤机理、腐蚀和磨损、焊接修补、变形校正、螺纹和孔位修复、密封恢复、防腐恢复和维修后确认。
产业链段位位于金属制品使用端、维护端和再利用端之间，服务于制造后阶段的寿命延长、功能恢复和周转再使用。
典型规模跨度覆盖小型金属维修店、容器和门窗维修企业、工业金属件修复企业、钢桶翻新企业、工具和五金维修企业以及具备焊接和检测资源的专业维修组织。
主要分型轴按对象分为结构件、门窗、容器、包装容器、工具五金、链条弹簧和杂项金属件维修；按方式分为现场维修、工厂返修、翻新再利用和部件更换。
分组比较提示本小类与前述制造小类共享材料、焊接、机加工和表面处理技术，但调用抓手应放在既有制品状态不确定、损伤诊断、可修复性判断、维修边界和维修后确认上；不宜把它简单等同于某一个制造小类。

B3 关键技术概念说明

维修与制造的根本差异在于输入状态。制造通常从材料、零件和图纸出发，维修则从已经使用、损伤或退化的制品出发。维修对象可能存在原材料不明、历史维修不明、腐蚀范围不均、局部变形、残余应力、表面污染、旧涂层覆盖、隐蔽裂纹和配件缺失等情况，因此状态检查和可修复性判断是维修过程的前置基础。

维修方案不是简单选择一种加工方法，而是把损伤类型、制品原功能、剩余材料状态、使用环境、维修后验证方式和交付边界组合起来。裂纹可能需要开槽、止裂、补焊和探伤；腐蚀减薄可能需要补板、堆焊、局部更换或报废；变形可能需要冷校、热校或更换；表面失效可能需要去旧涂层、重新前处理和防腐恢复。

维修后确认体现了本小类的服务结果。金属容器可能需要试漏、壁厚或密封检查；门窗和锁铰链可能需要启闭、锁止和间隙确认；结构件可能需要尺寸、焊缝和连接状态确认；工具、链条和弹簧可能需要硬度、载荷、变形或外观确认。

C2 主要功能、性能维度

本小类服务结果的客观维度包括维修对象识别、损伤范围、剩余壁厚、裂纹状态、腐蚀状态、变形量、焊缝状态、补强状态、尺寸恢复、孔位和螺纹恢复、密封面状态、涂层或镀层恢复、启闭状态、锁止状态、承载或支承状态、试漏状态、表面外观、包装防护、维修记录和交付标识。

维修结果不一定等同于新品状态。不同维修合同可能约定恢复原设计状态、恢复可使用状态、临时修复、局部修复、翻新再利用或更换部件后交付。因此 C2 的性能维度应与维修对象、合同边界和产品类别配套理解。

D. 过程与技术

D1 主要工艺/过程流程

`mermaid flowchart LR A["维修委托/对象识别"] --> B["状态检查和损伤评估"] B --> C["维修方案和边界确认"] C --> D["拆解、清洗、去旧涂层"] D --> E["补焊、校正、机加工或部件更换"] E --> F["表面恢复和重新装配"] F --> G["试漏、尺寸、功能或外观确认"] G --> H["记录、标识、包装和交付"] `

维修流程从对象识别开始。维修企业通常需要确认制品名称、材质、用途、损伤位置、历史维修、客户要求、可拆卸性、现场条件和交付状态。对于金属容器、承压边界产品或特殊功能制品，还需要确认铭牌、图纸、运行条件、介质和必要资料。

状态检查可能包括目视、测厚、裂纹检测、尺寸测量、试漏、启闭测试、硬度检测、连接检查和表面状态检查。维修方案确定后，再进行拆解清洗、去除旧涂层、坡口或开槽、焊接修补、堆焊、校正、局部更换、孔位螺纹修复、密封面研磨、表面处理和重新装配。

维修后确认根据对象不同而变化。容器类关注泄漏、壁厚、接管和涂层；结构件关注变形、焊缝、连接和尺寸；门窗锁铰链关注启闭、间隙、锁止和滑动；链条弹簧关注载荷、伸长、弹性和疲劳相关状态；包装容器关注清洁、密封、外观和标识。

E. 产业链与边界

E1 上游供应

本小类上游既包括待修金属制品来源，也包括维修材料、备件、焊材、密封件、紧固件、涂料、防腐材料、检测设备和外部专业服务。与制造不同，待修制品本身就是最重要的输入，其历史使用、材料、损伤、污染、旧涂层和拆装条件会直接影响维修方案。

备件和材料供应的适配性在本小类中较突出。旧制品可能型号停产、材料不明、图纸缺失或接口磨损，维修企业常需要通过测绘、材料识别、试配、替代件加工或局部改制来恢复状态。

E2 下游应用/客户

下游包括工业企业、建筑物业、设备使用单位、仓储物流、包装周转企业、门窗使用单位、五金工具使用者、工程维护单位、金属制品制造企业售后部门和再利用组织。客户需求通常表现为减少停用时间、恢复使用状态、延长寿命、降低更换成本或满足再流通条件。

E3 本小类在产业链中的位置

本小类位于金属制品制造之后和报废回收之前，是金属制品使用期内的维护恢复环节。它既不同于前端制造，也不同于后端废料回收；其价值在于通过诊断和修复延长既有制品的使用周期。

本小类常与制造企业售后、现场服务、外协加工、检测机构和备件供应商共同形成服务链。对某些产品，维修活动可能发生在制造企业内部售后部门；对另一些产品，则由独立维修组织或现场维护队伍承担。

E4 常见委外/外包环节

委外/外包环节行业常见原因边界提示
无损检测和材料识别裂纹、壁厚、焊缝或材质确认需要专门设备外部检测结果作为维修方案和结果确认输入。
热处理部分补焊、堆焊或工具修复后需要热处理外协热处理仍服务于维修结果。
表面处理镀层、喷涂、阳极氧化、防腐需要专业设施独立处理企业按 17.10.01 识别，维修企业作为外部接口调用。
备件加工旧件停产或非标部件需定制可通过机加工或成形加工外协实现。
专项试验压力、泄漏、载荷、寿命等设备资源有限外部试验资源作为维修后确认方法。
现场吊装和运输维修对象体积大或现场受限作为维修服务配套接口，不等同于制造。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类的技术复杂度来自维修对象的不确定性。制造过程面对的是相对明确的材料和图纸，而维修过程面对的是已经使用、老化、损伤或缺失信息的金属制品。即使维修工具和工艺看似常规，损伤判断、材料识别、可修复性、现场限制、旧件拆解和维修后确认都会增加复杂度。

行业自动化程度通常低于标准化制造。小型维修组织多依赖人工拆装、焊接、打磨、校正和经验判断；专业维修企业可能配备便携检测设备、焊接修复设备、压力试验设施、机加工资源和表面恢复能力。维修活动常受现场空间、停用时间、旧件状态、备件供应和客户交付期限制。

本小类具有较强的对象差异性。维修金属门窗、维修钢桶、维修容器、维修链条弹簧和维修结构件所需技术基础并不完全相同，因此基础卡只建立维修服务共性；具体对象的专项知识应与相应制造基础卡交叉调用。

H2 典型组织形态

组织形态典型特征常见资源配置

容器和钢桶翻新企业以清洗、补焊、检漏、防腐和标识恢复为主清洗设施、焊接、试漏、喷涂和包装资源。

H3 客观存在的易出问题环节/技术敏感点

敏感点客观影响链
维修对象身份不清铭牌、图纸、材质或用途信息缺失 → 维修方案依据不足 → 材料、工艺或检测选择偏移。
隐蔽损伤未识别旧涂层、污垢或装配遮挡裂纹和腐蚀 → 损伤范围判断不足 → 修复后局部缺陷继续存在。
材料匹配不当母材牌号、强度或腐蚀状态识别不足 → 焊材或备件选择偏移 → 焊缝、连接或使用状态波动。
补焊热输入控制不稳局部热输入过大或焊接顺序不当 → 变形、硬化、裂纹或残余应力增加 → 修复部位状态不稳定。
校正过程过量机械力或热校正过度 → 局部屈曲、裂纹扩展或尺寸反向偏移 → 装配接口受扰动。
密封面修复不足划伤、腐蚀坑或平面度未恢复 → 垫片压缩不均 → 泄漏路径保留。
旧涂层和污染物清理不足油污、锈蚀、盐分或旧涂层残留 → 新防腐层结合受阻 → 起泡、脱落或腐蚀路径形成。
备件规格不匹配停产件、代用件或非标件尺寸偏差 → 装配间隙和运动路径变化 → 卡滞、松动或磨损增加。
维修后确认项目不足只完成外观修复而未确认尺寸、泄漏、载荷或功能 → 隐性异常未显现 → 投用后状态波动。
维修记录不完整维修前状态、材料、过程和检测信息缺失 → 后续追溯困难 → 再维修或报废判断依据不足。
现场维修条件受限空间、吊装、电源、清洁和天气条件限制 → 工艺窗口变窄 → 焊接、涂覆或装配状态受扰动。

H3 只记录行业中客观存在的敏感点及事实因果链，不对其在任何上层视图中的重要性作判断。
