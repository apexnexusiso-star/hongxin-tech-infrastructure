  • 文件定位说明

本文件用于职业健康安全管理体系认证中 SG29-3 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦非汽车用燃料及非危险化学品化工产品批发在职业健康安全管理体系轴下的中间产品仓储批发中的装卸搬运、粉尘、一般化学品或燃料边界、客户交付、人员暴露和应急，不承担行业百科说明功能；基础行业事实由对应专业小类基础卡承载。

本组采用“中等现场边界 + 条件授权 + 介质限定”的使用口径。组内小类可以共享本体系轴下的基础判断方法，但不得把某一分支经历等同于另一分支完整能力。对污染源、危险源、外部合规接口、客户现场或外包链条发生实质变化的情形，应在授权和项目匹配阶段追加分支确认。

  • 技术领域包构成

本技术领域包包括 2 个专业小类。下表仅列示本组在本体系轴下的调用范围和分组边界，专业小类的完整定义、产业链、术语和基础工艺知识由基础卡提供。

  • 分组设立的基本逻辑

本组在本体系轴下的共同对象是不含汽车用燃料的燃料批发和不含危险化学品的化工产品批发活动。分组判断的核心不是小类名称是否相近，而是危险源、伤害机制、人员暴露、职业健康、高风险作业、事件记录、承包方和应急响应的形成机理、控制路径和审核证据是否足够接近。

本组可概括的共同证据链为：客户订单 -> 商品确认 -> 收货或外包仓储 -> 装卸搬运 -> 分区暂存 -> 配送交付 -> 异常和事件反馈。该链条决定了审核员可以共用的专业能力基础，也决定了现场抽样时应从源头识别、过程控制、记录追溯、异常处置和改进闭环几个方向建立证据。

非汽车用燃料和非危险化学品化工产品在介质形态、包装、粉尘或刺激性、装卸方式和外包储运责任上存在差异。这些差异不否定设组，但要求本组按条件授权和边界受控方式使用。

  • 共同过程与专业机制分析

SG29-3 位于普通商贸和高边界燃料化学品之间。组织通常从事批发交易、仓储、装卸和配送，危险源高于普通门店，但低于含危险化学品储运或汽车燃料加注。OHSMS 审核重点在于确认实际商品是否符合边界，仓储装卸是否识别粉尘、包装破损、滑倒、叉车、货物坠落、交通和一般化学品接触，以及外包储运是否纳入控制。

过程环节危险源和人员暴露形成机制审核关注的证据
商品边界确认确认燃料或化工产品不进入高边界危化品和汽车燃料加注场景。商品清单、合同评审、供应商资料。
仓储装卸堆码、叉车、托盘车、包装破损、粉尘或异味形成危险源。现场分区、装卸记录、设备点检。
配送交付车辆进出、承运方、客户现场交接形成交通和外部场所暴露。运输协议、交付记录、异常反馈。
应急处理包装破损、洒漏、人员接触、火灾或跌倒等异常需要应急响应。应急物资、演练、事件记录。
  • 本体系核心控制要求

第一，应先确认边界而后判断能力。SG29-3 的成立基础在于不进入含危险化学品高边界和汽车燃料加注场景，审核员应核对商品清单、合同、仓储安排和客户交付方式，确认实际业务没有越界。

第二，应关注装卸搬运和仓储交通。即便不属于高边界商品，燃料类和化工类批发仍可能存在大包装、托盘、桶装、袋装、粉尘、滑倒、叉车碰撞和货物坠落风险，应通过现场观察和记录追溯验证控制。

第三，应评价一般化学品或燃料接触。非危险化学品并不意味着无人员暴露，审核员应确认容器破损、粉尘、异味、皮肤接触、清理和个人防护是否被识别。

第四，应检查外包储运控制。批发企业常以票据和订单管理为主，但若组织选择承运方、安排仓库或负责客户交付，应确认承运方和仓储方的 OHSMS 接口。

小类共同基础主要差异边界控制可接受理由抽样落点

  • 分组结论

SG29-3 组内小类均属于不进入高边界危险化学品或汽车燃料加注场景的中间产品批发，危险源主要集中在仓储装卸、包装破损、粉尘或一般化学品接触、车辆进出、外包储运和客户交付。它们高于普通商贸服务但低于 SG29-4 的高边界经营，因此可以设为独立 OHSMS 技术领域包，并以介质和商品边界限定授权。

因此，SG29-3 可以作为职业健康安全管理体系技术领域包使用，使用方式为“中等现场边界 + 条件授权 + 介质限定”。审核员授权、项目匹配和能力扩展均应体现分支差异，不得把同包经历理解为跨全部小类的充分证明。

本章用于界定本技术领域包可共享的共同能力，以及不同分支在授权、项目匹配和能力扩展时需要追加确认的内容。

能力要素评价内容可接受证据授权控制
危险源识别识别服务场所、仓储搬运、客户现场、车辆、维修工具、化学品、燃料和外部交通中的危险源。危险源清单、现场走查、作业活动清单、事件记录。按分支标注；高风险作业需专项确认。

运行控制与应急检查现场隔离、举升、装卸、库区交通、化学品泄漏、火灾、客户冲突和异常处置。作业规程、点检、演练、事件调查、承包方记录。按实际作业抽样，不能用普通门店经历替代特殊现场。

能力扩展应采用“基础经历确认、目标分支差异培训、案例评审或专业面谈、必要时见证审核、授权记录标注”的路径。对燃料、危险化学品、车辆维修、个人家庭用品维修、冷链、废旧材料和含客户现场复杂接口的项目，应在项目匹配阶段再次确认适用边界。

  • 审核关键要点与抽样路径

本组抽样应从商品清单和合同边界开始，再进入仓库或外包储运接口验证装卸、包装、人员暴露和应急。若发现实际商品属于高边界危险化学品或汽车燃料加注，应转入 SG29-4。

抽样场景必看现场或活动必查记录追溯路径访谈对象
燃料批发边界仓库或外包储运接口、装卸点。商品清单、收发货、承运方、事件记录。订单 -> 仓储 -> 装卸 -> 交付 -> 异常。业务、仓储、物流、合规人员。

  • 培训、考核与作业指导书需求

培训应覆盖非高边界燃料和化工批发的介质确认、仓储装卸、粉尘和一般化学品接触、车辆物流、承包方控制和越界识别。审核员应能区分 SG29-1 普通商贸、SG29-3 中间产品批发和 SG29-4 高边界经营。

考核宜采用场景题、案例追溯题和边界判断题，要求审核员能够从一个真实或模拟项目出发，说明本体系轴下的识别、评价、控制、记录、异常处置和改进之间的证据关系。作业指导书应提供分支化抽样路径、记录清单、访谈问题和授权边界提示。

  • 常见合规义务类别与标准适用提示

常见合规义务类别包括仓储安全、消防、一般化学品或燃料储存要求、劳动防护、装卸和物流、承包方控制、客户交付要求和所在地场所管理要求。本文件不列入具体标准编号和年份；适用性应使用机构受控的有效清单、客户合同、服务目录、项目范围和所在地监管要求确认。上述类别用于识别外部要求如何转化为管理体系控制，不替代政府许可、法定检验、行政执法或客户专项验收。

  • 使用限制和法定边界

本组不覆盖含危险化学品经营、汽车燃料加注、燃料生产、化工生产、危险货物运输经营、化学品使用性生产或危险废物经营。出现上述活动时应转入相应技术领域或进行专项能力确认。

管理体系审核仅用于评价组织是否在其服务范围内建立并实施相应管理控制，不替代行政许可、法定检验、行政执法、政府监管、司法判断或强制性专项评价。涉及受监管资质、特种商品、危险化学品、燃料、药品、医疗器械、个人信息、资金信用、道路运输、客户现场和外包服务时，应在项目匹配阶段确认审核员分支能力和必要的技术支持。
