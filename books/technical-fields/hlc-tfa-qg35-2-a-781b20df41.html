  • 文件定位说明

本文件用于质量管理体系认证中 QG35-2 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦 广告策划制作、媒体代理、摄影影像和会议展览组织服务 在 QMS 轴下的质量形成链、客户要求转化、服务过程控制、输出验证、记录追溯、投诉反馈和改进闭环。本文件不承担行业百科说明功能，基础行业事实由对应专业小类基础卡承载。

本组采用“统一领域包 + 创意制作分支 + 媒体投放分支 + 影像制作分支 + 会展执行分支 + 条件扩展”的使用口径。组内小类可以共享通用服务质量管理判断方法，但不得把某一分支经历等同于另一分支完整能力；对专业责任强、客户损失后果高、现场活动复杂或外部合规接口明显的情形，应在授权和项目匹配阶段追加分支确认。

  • 技术领域包构成
小类编码小类名称纳入本包的活动范围主要内部路线特殊边界
35.05.01广告机构广告策划、创意、素材制作、广告活动执行、营销推广和广告材料提供。整合广告、品牌创意、数字营销、户外广告、直邮和销售点营销。创意版权、客户审批、发布内容、外包制作和投放效果边界应确认。
35.05.02媒体代理媒体时段、版面、空间或数字流量的采购、销售、转售、排期和投放管理。电视广播、报刊、户外、互联网、社交媒体、程序化投放。媒体资源真实性、排期、监测、结算和第三方平台数据边界应确认。
35.07.00摄影活动商业、人像、出版、房地产、旅游、航空、活动影像、胶片或数字后期等摄影服务。棚拍、外景、活动摄录、商业产品摄影、后期修图、影像修复。肖像授权、现场条件、原片管理、后期版本和版权使用边界应确认。
35.20.00大会和贸易展览的组织会议、贸易展览、谈判、集会和大型活动的组织、宣传、管理和现场运营。会议组织、展览主办、展台管理、论坛活动、招商招展、现场执行。场馆、搭建、参展商、现场人流、供应商和设施操作边界应专项确认。
  • 分组设立的基本逻辑

本包在 QMS 轴下的共同对象是以传播、展示、影像或活动为载体的客户营销沟通服务输出。质量管理体系审核关注的核心不是服务名称是否相同，而是客户需求如何被识别和转化，服务资源如何配置，服务实施过程如何受控，服务输出如何被复核或验收，客户反馈如何形成纠正和改进。

本包可概括的共同质量形成链为：客户brief或活动目标 -> 创意、媒体、影像或会展方案 -> 资源和供应商配置 -> 内容制作、排期或现场筹备 -> 客户审批和过程复核 -> 发布、拍摄或活动执行 -> 监测、交付、结算和反馈闭环。该链条决定了本包共享的专业能力基础，即审核员应能够围绕客户要求、人员能力、服务方案、过程记录、输出验证、交付确认和反馈闭环建立审核证据链。

组内差异表现为输出载体不同：广告机构重在创意与内容制作，媒体代理重在资源采购和投放数据，摄影重在现场拍摄和影像交付，会展重在活动组织和现场协同。这些差异不否定设组，但要求本包不能按无差别能力包使用，应通过分支标注、专项确认、条件扩展和抽样控制加以处理。

  • 专业小类关系类型与授权后果
关系类型含义授权后果典型控制方式
共同基础关系同属以合同、委托、项目任务或服务订单为输入的专业服务活动，均需识别客户要求、配置人员和资源、形成服务输出、保存服务证据并处理反馈。可简化通用服务过程、客户沟通、记录控制和服务评价等基础能力评价，但仍需确认目标小类或目标分支的实际经历。资料评审、案例判断、专业面谈、服务证据追溯。
并列分支关系同属本技术领域包，但服务对象、交付物、专业责任、现场条件或客户验收方式不同。应记录实际分支能力，不把同包经历理解为全分支能力。分支标注、限定使用、项目技术支持。
条件扩展关系已具备相邻分支能力，具有扩展基础，但目标分支仍存在专门知识、证据链或法规边界。完成补充培训、案例评审、专业面谈、见证审核或技术支持后方可扩展。培训考核、案例评审、见证审核、专家确认。
专项确认关系涉及强执业属性、高保密数据、高客户损失后果、特殊现场作业或复杂外包链。项目使用前应开展专项确认，必要时配置技术专家支持。专项面谈、技术专家评审、项目匹配确认。
不可直接替代关系相关服务经验不足以证明目标小类的质量形成链能力。不得作为目标能力的单独授权依据，应补充目标经历或限定项目类型。重新评价、补充经历、限定项目类型。
边界受控关系当执业资格、客户行业要求、个人信息、资金信用、现场安全、外包生产或法定接口改变服务边界时，统一包内授权应增加边界说明。授权记录应写明适用边界，项目匹配时按实际服务内容确认。授权备注、合规类别清单、技术支持。
广告机构与媒体代理广告策划和媒体投放均服务于客户传播目标，但一个偏内容生成，一个偏渠道和排期。可共享传播项目基础能力；跨创意和媒介扩展应确认对应案例。创意作品、媒体排期、监测报告和结算记录追溯。
摄影与广告创意摄影可作为广告内容生产的重要环节，但影像制作有独立现场和后期控制。广告经历不能替代摄影现场和影像交付能力。拍摄计划、授权、原片、后期和客户选片记录评价。
会展与广告传播会展包含宣传、招商、现场视觉和客户体验，与广告传播有共同目标。会展现场运营、搭建和供应商协同需专项确认。场馆、搭建、展位、现场执行和供应商记录抽样。
  • 本体系共同能力基础
共同能力维度本包共同基础可共享的审核判断不能共享的边界
客户brief转化均需将客户品牌、产品、受众、预算、期限和效果目标转化为方案。判断brief、方案、排期、拍摄脚本或活动计划是否一致。媒体采购指标、摄影画面要求和会展现场计划不能互相替代。
内容与资源配置均依赖创意人员、摄影人员、媒介资源、场馆、供应商和项目管理资源。可共享供应商评价、资源排期、外包控制和项目责任判断。摄影设备、媒体平台和会展搭建供应商差异需分支确认。
过程复核和客户审批均需通过提案、设计稿、脚本、排期、样片、展位图或执行方案获得客户确认。可共享版本、审批、变更和客户确认判断。公开发布内容和现场活动变更需更高粒度追溯。
输出交付和效果验证均需交付广告素材、投放报告、影像成品、活动总结或结算资料。可共享交付验收、数据报告、客户反馈和纠正措施判断。媒体监测真实性、影像版权和会展现场投诉需专项抽样。
  • 本体系核心控制要求

本组所称关键质量特性，是指服务输出中影响客户可接受性的准确性、完整性、及时性、一致性、可追溯性、响应性和交付符合性。在服务业场景中，检验和放行通常表现为主管复核、质检抽查、客户确认、验收签收、报告批准、脚本质检、现场巡检或交付前复核；审核员应把这些复核和确认活动作为服务结果进入客户使用前的质量控制证据。

QMS 审核应围绕客户传播目标到最终传播或活动输出的链条展开。首先应核对客户brief、合同、预算、目标受众、品牌规范、活动目标和验收要求是否明确，并确认这些要求如何转化为创意方案、媒体计划、拍摄方案或会展执行计划。

第二，应关注内容、资源和供应商控制。广告素材、摄影作品、展会搭建和媒体投放往往依赖外部设计、制作、摄影棚、场馆、搭建商、媒体平台和监测机构。审核员应追溯供应商选择、任务书、交付标准、过程沟通和验收记录。

第三，应核查客户审批与变更控制。传播类服务容易发生口径变更、素材修改、排期调整、拍摄重拍、展位变更和现场追加需求。审核应确认版本、审批、变更影响、费用和交付期限是否受控。

第四，应评价交付验证和效果反馈。广告机构应有素材验收和发布证明；媒体代理应有排期、投放、监测和结算证据；摄影服务应有原片、精选、后期、交付和授权证据；会展组织应有现场执行、参展商反馈、观众数据、问题处置和总结记录。

  • 分小类或内部路线差异分析
小类/路线与本包共同基础主要差异差异对能力授权的影响控制方式
35.05.01 广告机构共享客户传播目标、方案、资源配置、审批和交付基础。创意策略、文案视觉、素材制作、外包制作和客户主观评价突出。应标注广告创意或整合营销分支。抽取广告项目，追溯brief、创意方案、素材版本、客户审批和发布证明。
35.05.02 媒体代理共享传播目标、客户审批和效果反馈基础。媒体资源、排期、价格、投放监测、流量数据和结算准确性突出。从广告创意扩展到媒体代理需确认媒介计划和数据报告能力。抽取投放订单，追溯排期、合同、监测截图或报告、结算。
35.07.00 摄影活动共享客户需求、方案、输出交付和客户反馈基础。拍摄现场、设备、灯光、模特或授权、原片、后期和成片质量突出。应标注摄影或影像制作分支；商业摄影和活动摄录需分开确认。抽取拍摄项目，追溯拍摄计划、授权、原片、选片、后期和交付。
35.20.00 会展组织共享传播目标、客户确认、供应商控制和现场反馈基础。场馆、展位、搭建、参展商、观众流线、现场协调和应急处置突出。会展现场执行属专项确认路线，不以广告或摄影经历替代。抽取会展项目，追溯招商、场馆、展位图、供应商、现场问题和总结。
  • 分组合理性论证结论

本组可以设立的理由在于，四个小类均以客户传播、展示或营销沟通目标为起点，均通过方案策划、资源组织、内容或现场实现、客户审批、发布执行和反馈评价形成服务质量。QMS 审核可共享客户brief转化、项目计划、外包控制、版本审批、交付验证和客户反馈闭环的判断方法。

因此，QG35-2 可以作为质量管理体系技术领域包使用，但其使用方式应为“统一领域包 + 创意制作分支 + 媒体投放分支 + 影像制作分支 + 会展执行分支 + 条件扩展”。审核员授权、项目匹配和能力扩展均应体现分支差异，不得把同包经历理解为跨全部小类的充分证明。

  • 培训、考核与作业指导书需求

本组应建立营销传播服务 QMS 培训，内容包括客户brief识别、创意与媒介方案控制、影像制作流程、会展项目计划、供应商和外包控制、客户审批、版本变更、公开发布证明、监测报告、现场问题处置、版权和授权边界、不合格服务纠正。广告、媒体、摄影和会展应分别设置案例。

考核宜采用场景式题目和案例追溯题，要求审核员能够从一个真实或模拟服务订单出发，说明客户要求识别、资源配置、关键过程控制、输出复核、交付验收、投诉反馈和纠正措施之间的证据关系。作业指导书宜提供分支化抽样路径、典型记录清单、访谈问题库和授权边界提示。

  • 常见合规义务类别与标准适用提示

本组可能涉及广告发布、知识产权、肖像权和版权、消费者权益、互联网广告、户外广告、个人信息、商业秘密、场馆管理、合同履约、发票结算、活动组织、展览搭建、消防和客户行业专门要求等类别。文件不列具体标准编号和年份；适用性应使用机构受控的有效清单、客户合同、服务目录、项目范围和所在地监管要求确认。上述类别用于识别外部要求如何转化为服务过程控制、人员资质确认、记录保存、客户沟通和输出复核，不替代政府许可、行政执法或客户专项验收。

  • 分组使用限制和法定边界

本组的 QMS 分组不替代广告发布监管、媒体资源真实性法定认定、知识产权权属判断、场馆许可、消防验收、活动审批、演员或模特授权审查、第三方监测认证或客户专项验收。涉及大型公众活动、复杂展览搭建、高额媒体投放、敏感广告内容或大规模人员现场活动时，应进行专项能力确认。

管理体系审核仅用于评价组织是否在其服务范围内建立并实施质量管理控制，不替代行政许可、司法判断、法定鉴证、执业资格审查、政府监管、行政处罚、强制检测、客户专项验收或其他法定结论。涉及受监管资质、敏感数据、资金信用、现场作业和第三方外包时，应在项目匹配阶段确认审核员分支能力和必要的技术支持。

  • 分组结论与使用口径

QG35-2 可作为质量管理体系广告、媒体、摄影及会展服务技术领域包使用。授权时应记录广告创意、媒体代理、摄影影像和会展组织分支能力。文件维护触发条件包括：主要媒体渠道、监测方式、摄影交付技术、会展活动模式、外包供应商结构或公开传播合规类别发生实质变化，或项目匹配中出现分支能力争议。
