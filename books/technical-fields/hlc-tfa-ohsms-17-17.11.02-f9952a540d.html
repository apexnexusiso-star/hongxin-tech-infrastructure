A2 定义与范围界定

本小类是指制造用于门、窗、柜、箱、车辆、设备、家具或其他可开启部件的锁止、启闭、转动连接和位置保持装置的活动。其核心对象包括机械锁具、锁芯、锁体、钥匙、挂锁、门锁、柜锁、抽屉锁、工业锁、合页、铰链、暗铰链、重型铰链、门控连接件及类似五金。

本小类的核心技术在于锁止机构、钥匙或编码配合、弹子/叶片/插芯结构、锁舌运动、铰链转动副、承载和耐久、装配配合、表面防护以及门窗或箱柜接口。若智能锁、电子锁或电控锁以金属锁体、锁芯、锁舌和机械启闭机构为主体，可在本小类事实框架下描述电子控制部件作为配套；若主导为电子安防系统、门禁控制或软件平台，应另行识别。

本小类不包括金属门窗制造、家具制造、汽车整车或车锁系统集成、电子门禁系统、安防报警系统、单纯五金贸易、锁具安装开锁服务和门窗维修服务。

B3 关键技术概念说明

锁具制造的核心是“可控开启”。钥匙、密码、电子识别或机械结构使锁舌在规定条件下运动，在非规定条件下保持锁止。锁芯编码、弹子高度、钥匙齿形、锁舌行程、弹簧力和外壳配合共同决定机构状态。

铰链制造的核心是“可靠转动连接”。两片或多片叶片通过销轴、轴套、滚珠、垫片或限位结构形成转动副。承载、间隙、同轴度、摩擦、表面处理和安装孔位决定启闭状态。

表面防护和装饰在锁铰链中很重要。镀层、喷涂、抛光、拉丝和氧化既影响外观，也影响耐腐蚀、耐磨和手感。

C4 典型产品族专业差异补充

锁和铰链同属建筑及配套五金，但二者的专业差异并不只在外形。锁具更强调编码、传动、锁闭和启闭状态；铰链更强调转动副、承载、同轴和摩擦状态。智能锁机械部分还叠加离合机构、方杆传动和电子模块安装接口，底层识别时应把机械件和电子控制件的边界说清。

产品族过程差异对底层识别有价值的专业信息
插芯门锁和锁体冲压壳体、锁舌组件、弹簧、拨叉、方杆孔和盖板装配共同形成。锁舌行程、斜舌回弹、拨动顺畅和安装尺寸是识别重点。
锁芯和钥匙系统锁芯车铣、弹子或叶片配组、钥匙齿形加工和编码装配突出。互开状态、钥匙匹配、旋转力矩和编码批次需要单独识别。
挂锁、柜锁和箱包锁小型压铸、冲压、铆接、弹簧装配和外观表面处理占比高。产品体积小、规格多，零件混装和表面外观常与交付状态相连。
配电柜锁和工业柜锁锁体、连杆、拉手、限位、密封和柜体安装孔位相互配合。安装接口、开闭角度、锁舌长度和防护结构是底层描述抓手。
普通合页和建筑铰链冲压开片、卷圆、穿轴、铆接、打孔和表面处理构成主线。叶片平面度、孔位、销轴状态和启闭间隙体现其转动连接特征。
重型、隐藏和阻尼铰链多轴连接、滚珠或轴套、阻尼件、调节螺钉和承载结构更复杂。承载、同轴、转动阻力、调节范围和安装基准应与普通合页区分。
智能锁机械总成锁体、离合器、方杆、锁芯、应急开启和电子模块接口协同形成。本卡只描述机械结构与接口，电子识别和软件控制不在本小类展开。

D. 过程与技术

D1 主要工艺/过程流程

`mermaid flowchart LR A["产品设计/零件图纸"] --> B["材料和零件成形"] B --> C["机加工、冲压或压铸"] C --> D["热处理、抛光或表面处理"] D --> E["锁芯/锁体/铰链装配"] E --> F["钥匙编码或机构调试"] F --> G["启闭、寿命和外观检测"] G --> H["包装、标识、交付"] `

锁具制造通常包含锁体冲压或压铸、锁芯机加工、弹子和弹簧装配、钥匙切削、锁舌和传动机构装配、表面处理和启闭检测。铰链制造通常包含板材冲压、折弯、卷圆、销轴加工、铆接或压装、抛光、镀覆和转动检测。

D1.1 机械锁具的机构形成过程

机械锁具的制造重点在锁芯编码、锁体传动和锁舌运动。弹子锁芯通常需要对锁芯、锁壳、弹子孔、钥匙槽、拨轮或尾片进行精密加工，再按编码装入不同高度的弹子、弹簧和封片。钥匙加工需要保持齿深、齿距、槽形和毛刺状态与锁芯编码匹配。若弹子孔偏斜、钥匙齿形毛刺或弹簧弹力不一致，锁芯转动状态会立即受到影响。

插芯门锁和建筑门锁还包括锁体壳、斜舌、方舌、拨叉、执手方孔、反锁机构、导向板和面板等部件。冲压件毛刺、压铸件缩孔、锁舌行程、执手回弹、拨叉间隙和铆接状态，会共同影响开启、闭合、锁止和手感。多舌锁体还需要关注天地杆接口、锁点同步和安装方向。

D1.2 铰链和合页的转动副过程

铰链制造看似简单，实质上围绕“叶片、卷圆、销轴、轴套和安装孔”形成转动副。普通合页通常由板材冲压、孔位加工、卷圆、穿销、铆头、表面处理和转动检查组成；重型铰链可能使用厚板、锻件或机加工件，并增加轴套、滚珠、油槽或限位结构。隐藏铰链、多轴铰链和家具铰链还涉及多连杆、弹簧、阻尼器和开合角度。

铰链的专业敏感点在同轴度、间隙和表面。卷圆不均会造成转动阻力和旷量，销轴硬度或表面粗糙度不匹配会造成磨损，安装孔位偏差会使门扇下垂或闭合干涉。表面镀层过厚或孔内镀层堆积也可能改变转动间隙。

D1.3 智能锁机械模块的边界

智能锁并不等于纯电子产品。其机械部分仍包括锁体、锁芯、离合机构、电机传动、方杆、锁舌、把手结构、应急钥匙通道和安装接口。制造中需要把电子模块的运动输出转化为可靠的机械锁止动作，因此电机行程、离合间隙、齿轮啮合、传感器位置和机械应急开启结构需要与锁体配合。若企业仅制造识别模块、控制板或门禁系统，而不形成机械锁体，则不宜按本小类理解。

铰链合页合页厂、门窗五金厂冲压、卷圆、销轴、铆接和承载突出。
智能锁机械件智能门锁配套企业机械机构、电机接口、锁体装配和外观突出。
工业锁铰链机柜和设备门五金企业防护等级、耐腐蚀、承载和专用接口突出。

D6 典型工艺路线识别提示

锁和铰链制造的路线差异主要来自机构复杂度和转动连接方式。底层识别时，应把锁芯编码、锁体联动、铰链转动副和智能锁机械接口分开描述。

路线类型典型识别信息与其他路线的差异
锁芯钥匙路线锁芯加工、弹子或叶片配组、钥匙齿形、编码和试开。机械编码和互开状态是独有识别点。
锁体装配路线冲压壳体、锁舌、拨叉、弹簧、方杆孔和盖板装配。多件联动和锁舌行程形成主线。
压铸外观件路线锌合金或铝合金压铸、去披锋、抛光、表面处理和装配。外观表面和装配孔位同时突出。
普通合页路线冲压开片、卷圆、穿轴、铆接、打孔和表面处理。转动副和安装孔位是主要信息。
重型或隐藏铰链路线多轴件加工、滚珠或轴套、阻尼件、调节件和承载试验。承载、同轴和调节结构明显高于普通合页。
智能锁机械路线锁体、离合器、方杆、应急开启和电子模块安装接口。机械传动与电子配套边界需要说清。

E3 本小类在产业链中的位置

本小类位于金属零件加工和门窗家具设备成品之间，是启闭、锁止和铰接功能的专门五金环节。其产品通常作为成套产品的配件或独立五金进入市场。

寿命和耐蚀检测设备投入较大可由外部检测资源完成。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类属于小型机构五金制造，产品零件多、装配配合细、外观要求高。普通合页制造技术复杂度中等，锁芯、智能锁机械件和高耐久工业铰链复杂度较高。自动化程度从人工装配到自动铆接、自动钥匙加工和寿命检测均有分布。

H2 典型组织形态

组织形态典型特征常见资源配置
小型合页厂冲压卷圆和铆接为主冲床、卷圆、铆接、抛光和外协电镀。
锁芯锁体厂精密小件和装配为主CNC、钥匙机、弹子装配和功能检测。
建筑五金企业锁、执手、合页成套压铸、机加工、表面和装配资源。
智能锁配套企业机械机构和电子部件配套锁体装配、电机接口和功能检测。
工业锁铰链企业机柜、车辆和设备配套防护、承载、耐蚀和专用接口资源。

H4 典型组织形态差异补充

锁铰链行业存在小型合页厂、专业锁芯厂、成套建筑五金企业和智能锁机械配套企业。不同组织的设备、检测和装配能力差异较明显。

组织形态典型表现技术识别提示
小型合页厂冲压、卷圆、穿轴、铆接和外协表面处理为主。孔位、销轴间隙和外协镀覆信息突出。
锁芯锁体企业精密小件加工、钥匙编码和机构装配较多。编码、互开和锁舌行程信息突出。
建筑五金企业锁、执手、合页和门控件成套供应。配套完整性和安装接口信息较多。
工业柜锁企业柜锁、连杆、拉手和密封配套较多。柜体安装和联动机构状态突出。
智能锁机械配套企业锁体、离合、方杆和电子模块安装接口较多。机械边界和电子配套接口需要明确。
外观装饰型企业压铸、抛光、拉丝和表面处理资源较强。外观面和膜层状态比机构复杂度更突出。

H3 客观存在的易出问题环节/技术敏感点

敏感点客观影响链
锁芯编码加工偏差齿形、弹子或槽位偏差 → 钥匙配合状态变化 → 开启卡滞或互开路径形成。
冲压压铸毛刺残留边缘毛刺或飞边未清除 → 装配间隙和运动路径受扰动 → 卡滞、噪声或表面划伤。
弹簧和小件混料小件规格或弹力不一致 → 锁止和复位状态变化 → 启闭不稳定。
铰链销轴同轴度不足卷圆、压装或铆接偏差 → 转动阻力和间隙变化 → 下垂、异响或磨损加剧。
表面镀层不连续前处理或镀覆状态异常 → 局部露底或薄层 → 锈蚀或外观变化路径形成。
润滑和包装不足运动副干摩擦或运输碰撞 → 卡滞、划伤或零件脱落路径形成。
锁舌行程和导向板位置偏差锁体内部传动或面板孔位异常 → 锁舌伸缩路径偏移 → 闭门干涉、锁闭不到位或手感异常。
智能锁离合机构间隙异常电机、齿轮、离合销或方杆配合偏差 → 机械输出不能稳定传递 → 空转、卡滞或应急开启状态异常。
铰链镀层堆积或孔内毛刺孔壁和销轴接触面状态异常 → 转动副摩擦和间隙变化 → 启闭阻滞或磨损路径形成。
