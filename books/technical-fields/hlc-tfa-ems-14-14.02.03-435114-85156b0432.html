A2 定义与范围界定

本小类包括将PVC、PE、PP、PC、ASA、ABS、改性塑料、发泡材料、增强材料、密封件、五金配件和表面膜等投入，通过配混、挤出、共挤、发泡、压延、热成型、裁切、焊接、组装、覆膜、贴合和检验形成建筑用途塑料制品的活动。

典型产品包括塑料门窗型材、塑料装饰板、建筑用塑料管槽、采光板、屋面或墙面塑料构件、排水防水部件、踢脚线、线槽、护角、地板或墙面塑料构件以及与建筑系统配套的塑料组件。

本小类区别于通用板片管制造的核心在于建筑使用场景和构配件属性。产品需要与建筑围护、安装连接、耐候、尺寸稳定、阻燃、排水、密封、装饰和施工适配结合，而不只是作为一般塑料坯料销售。

A3 边界说明、相邻小类区分点和排除项

相邻活动容易混淆的原因主要区分依据本卡处理原则
14.02.01 塑料板片管壳建筑塑料常以板、管、型材形态出现是否按建筑构配件和施工用途设计生产建筑用途明确、配套安装或系统属性明显的归入本卡。
14.02.02 塑料包装产品部分建筑材料用塑料膜或袋包装最终产品是否为包装物包装膜袋不纳入本卡。
金属门窗和建筑金属构件功能相似，均用于建筑围护主材和主导加工过程塑料型材挤出及焊接组装归入本卡；铝合金、钢制门窗另行识别。
建筑施工安装活动建筑塑料产品需现场安装是否制造建筑塑料制品本体工厂制造归入本卡；现场安装施工不纳入本卡。
橡胶密封件制造塑料门窗和建筑构件常使用密封胶条密封件主材和制造过程单独制造橡胶密封条归入 14.01.02。
建材化学品和涂料塑料建筑制品可能使用胶粘剂和涂层最终交付物是否为塑料建筑构件胶粘剂、涂料、防水涂料不纳入本卡。

明确排除项：

  • 建筑现场施工、安装、门窗安装和装饰装修服务。
  • 金属门窗、铝型材、钢结构和建筑金属构件制造。
  • 水泥、玻璃、陶瓷、木材和石膏类建筑材料制造。
  • 通用塑料板片管坯料且未按建筑用途生产的产品。
  • 橡胶密封件、建筑涂料、胶粘剂和防水化学材料制造。

维度本小类特征上层分组调用提示

主要技术基础热塑挤出、型材截面设计、耐候改性、阻燃、发泡控制、建筑装配、热胀冷缩和连接密封普通板管挤出知识不能完全覆盖门窗型材和建筑构件组装知识。

分组敏感边界门窗组装既像制造又像施工配套工厂加工成门窗产品归入本卡；现场安装另行识别。

B3 关键技术概念说明

建筑用塑料制品的技术核心不是单纯“塑料成型”，而是塑料构件与建筑系统接口的适配。截面、连接、排水、密封、热胀冷缩和耐候共同决定其客观使用状态。

塑料门窗型材是本小类中最具代表性的复杂产品之一。其型材腔体、壁厚、共挤层、焊角、钢衬或增强件、玻璃压条和密封条共同构成系统，而不是单一挤出条材。

建筑塑料产品常暴露在日照、温湿度变化、安装应力和长期载荷下，因此耐候、尺寸稳定、阻燃、连接和施工适配是本小类与普通塑料板片管的重要差异。

C2 主要功能和性能维度

本小类产品的性能维度包括截面尺寸、壁厚、直线度、方正度、焊角强度、抗冲击、耐候、颜色保持、热尺寸变化、阻燃、隔热、气密或水密、排水、连接强度、表面装饰、耐污染、安装适配和长期使用变形。

门窗型材和成品更强调腔体、焊角、五金配套、密封、玻璃装配和排水；装饰板和线槽更强调外观、阻燃和扣合；采光板更强调透明、耐冲击和耐候；木塑和发泡产品更强调密度、翘曲和连接。

建筑塑料制品的性能往往受安装方式影响。基础卡只记录制造端产品和接口事实，现场施工质量、建筑设计和使用维护属于后续应用边界。

D. 过程与技术

D1 主要工艺或过程流程

建筑塑料型材典型流程为：树脂和助剂接收 -> 配方计量和混合 -> 挤出塑化 -> 模具成型 -> 真空定型 -> 冷却牵引 -> 在线或离线切割 -> 共挤层或覆膜确认 -> 尺寸外观检验 -> 包装入库。

塑料门窗成品典型流程为：型材接收或自制 -> 下料 -> 钢衬或增强件装配 -> 焊角或机械连接 -> 清角 -> 五金安装 -> 玻璃或压条装配 -> 密封条安装 -> 尺寸、启闭和外观检查 -> 包装。

装饰板、采光板和防水排水构件典型流程因材料而异，可包括挤出、压延、发泡、共挤、热成型、冲切、覆膜、开孔和组件装配。其共同点是需要与建筑安装接口匹配。

D5 常见工艺路线差异

路线或企业类型典型特征过程差异知识卡记录重点
PVC门窗型材路线混料、挤出、真空定型和定尺切割腔体和壁厚突出建筑塑料代表路线。
门窗成品组装路线型材下料、焊角、五金和密封装配建筑系统接口突出需与型材生产区分。
共挤耐候路线主体层和表面层同步成型层厚和界面突出户外型材和板材常见。
发泡装饰板路线挤出或压延并形成泡孔密度和翘曲突出室内装饰板常见。
采光板挤出路线透明板材连续成型透明、内应力和耐候突出屋面和温室应用常见。

边界事项常见形态识别依据记录方式

现场安装门窗和构件需在建筑现场安装施工合同和交付边界不纳入制造过程。

D7 本小类技术链条深化说明

本小类的技术链条可以概括为“塑料材料 -> 建筑截面 -> 构件装配 -> 建筑接口 -> 长期使用环境”。其特异性在于制造过程必须预先考虑安装、连接、排水、密封和耐候。

门窗型材和门窗成品是最能体现本小类边界的对象。型材阶段关注腔体和共挤层，成品阶段关注焊角、五金、玻璃和密封。两者都属于制造链，但能力抓手不同。

链条节点投入或状态技术转换输出或结果本小类特异性
材料配混PVC或改性树脂、填料、稳定剂和色母高速混合和冷却可挤出干混料热稳定和耐候助剂是建筑特异点。
截面形成塑化熔体和型材模具挤出、真空定型和冷却建筑型材腔体、壁厚和直线度决定建筑接口。
表面功能主体材料和共挤层或覆膜共挤、贴膜或表面处理耐候或装饰表面户外暴露使表层重要。
构件加工型材、板材或管槽下料、焊接、冲孔、折弯建筑构件孔位和连接决定安装适配。
系统装配五金、玻璃、密封条和连接件装配和调试门窗或系统产品建筑功能来自多部件配合。
排水密封排水孔、胶条、压条和缝隙结构布置和装配防水和密封路径建筑使用环境特异节点。
储运保护长条型材和成品门窗垫块、捆扎、立放和保护膜安装前状态长条塑料构件易变形。
施工接口产品与洞口、墙体或支架安装尺寸和连接信息传递可安装状态制造端只记录接口事实。

D8 常见异常和过程补救方式

异常类型常见表现通常处理方式底层记录边界
型材壁厚不足局部腔体薄弱或截面偏差调整模具、真空和牵引建筑型材异常。
焊角强度不足角部开裂或方正度偏差调整焊接温度、压力和清角门窗成品异常。
共挤层不均表面层薄厚变化或露底调整共挤量和模头温度户外表层异常。
发泡密度波动板材轻重不均或泡孔粗大调整发泡剂、温度和冷却发泡制品异常。
储运弯曲长条型材弯曲变形调整堆放、支撑和温度建筑长构件敏感点。

产业链边界上，型材厂、门窗加工厂、装饰构件厂和施工安装方可能分工明显。基础卡应记录制造端的型材、构件和成品交付事实，现场施工和建筑设计不纳入本卡。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

维度本小类客观特征表现形式
技术复杂度中到高塑料加工与建筑接口共同作用。
自动化程度型材挤出较高，门窗组装中等切割、焊角和装配仍有人工。
人工依赖中等组装、调试、外观和配套件安装依赖操作。
耐候敏感明显户外日照和温湿变化影响长期状态。
应用边界敏感高制造端和现场安装端容易混淆。

组织类型典型特征过程能力形态
型材挤出企业产品系列多、模具多材料配混和截面稳定突出。
门窗加工企业采购型材组装成品下料、焊角和五金密封装配突出。

H3 客观存在的易出问题环节和技术敏感点

敏感点客观表现客观影响链底层记录边界
PVC热稳定不足型材变色、分解或表面异常热稳定不足 -> 加工降解 -> 外观和物性变化客观链条。
型材腔体偏差壁厚、筋位或截面不稳定模具和定型变化 -> 截面偏差 -> 装配和刚度变化记录事实。
焊角虚焊角部强度不足或开裂焊接参数异常 -> 熔接不足 -> 框体连接弱化门窗特异敏感点。
共挤层过薄户外表层覆盖不足层厚不足 -> 基材暴露 -> 表面老化速度变化不作体系解释。
排水孔遗漏门窗积水或排水路径不畅孔位缺失 -> 积水停留 -> 构件状态变化建筑接口事实。
五金孔位偏差启闭卡滞或装配困难加工位置偏差 -> 五金配合变化 -> 使用状态改变客观链。
板材翘曲装饰板或采光板弯曲冷却或储运变化 -> 内应力释放 -> 平整度变化行业事实。
阻燃材料错用线槽或板材燃烧表现变化材料体系变化 -> 燃烧状态变化 -> 使用表现改变只记录事实。
储运划伤和变形型材表面划痕、长件弯曲堆放和保护不足 -> 外观或尺寸变化储运敏感点。
施工接口误判制造缺陷和现场安装问题混杂接口信息不清 -> 责任边界不清 -> 后续追溯困难仅作为边界敏感点。
