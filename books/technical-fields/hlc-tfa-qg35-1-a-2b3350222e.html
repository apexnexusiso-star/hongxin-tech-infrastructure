  • 文件定位说明

本文件用于质量管理体系认证中 QG35-1 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦 专业服务、管理支持、办公支持、客户联络、资金信用及受托包装等服务 在 QMS 轴下的质量形成链、客户要求转化、服务过程控制、输出验证、记录追溯、投诉反馈和改进闭环。本文件不承担行业百科说明功能，基础行业事实由对应专业小类基础卡承载。

本组采用“统一领域包 + 专业服务分支 + 办公与客户支持分支 + 资金信用分支 + 受托包装边界控制 + 条件扩展”的使用口径。组内小类可以共享通用服务质量管理判断方法，但不得把某一分支经历等同于另一分支完整能力；对专业责任强、客户损失后果高、现场活动复杂或外部合规接口明显的情形，应在授权和项目匹配阶段追加分支确认。

  • 技术领域包构成
小类编码小类名称纳入本包的活动范围主要内部路线特殊边界
35.01.00法律活动法律咨询、代理、法律文件准备、公司事务、知识产权相关法律服务和案件管理。诉讼代理、非诉专项、法律顾问、文件起草、尽职调查。执业资格、利益冲突、客户授权、保密和法律文书责任边界应专项确认。
35.02.00会计、簿记及审计活动，税务咨询记账、财务账目准备、账目检查、税务申报准备、税务咨询和客户代理。代理记账、财务外包、审计鉴证支持、税务咨询、申报代理。法定审计、注册执业责任、税务代理权限和客户财务数据安全应作为边界控制。
35.03.00公司总部的活动对关联单位实施战略、组织规划、运营控制、共享职能和日常管理。集团总部、区域总部、共享服务中心、子公司管理处。总部是否承担产品或服务实现过程，应按其实际控制范围确认。
35.04.01公共关系和交流活动对外沟通、公共关系策略、议题管理、危机沟通、传播口径和利益相关方沟通服务。品牌公关、危机公关、媒体关系、政府或社区沟通、内部沟通。舆情、危机信息和公众承诺的准确性、审批链和客户授权需专项关注。
35.04.02商业和其他管理咨询活动战略、组织、流程、人力资源、成本、营销和管理改进咨询。战略咨询、流程咨询、人力资源咨询、财务管理咨询、运营改善。咨询结论依赖客户数据和专业方法，不能等同于法定鉴证或客户经营决策。
35.06.00市场调查及民意调查市场潜力、消费者态度、购买习惯、公众意见调查和统计分析。定量调查、定性访谈、样本库调查、线上问卷、民意调查。抽样设计、数据清洗、统计分析和个人信息处理边界应专项确认。
35.08.00笔译和口译活动文件翻译、现场口译、会议口译、技术翻译、商务翻译和本地化语言服务。笔译、审校、同声或交替传译、远程口译、本地化。专业术语、译员资质、保密、交付格式和客户复核机制需分支确认。
35.14.00调查活动调查、侦探和事实信息收集服务。商业调查、背景核验、事实查证、现场访问、公开信息核验。授权边界、信息来源合法性、证据链和隐私保护应作为高边界事项。
35.18.01综合的办公室管理服务活动接待、财务规划、记账、档案保存、人事、邮件等综合办公室支持。前台接待、行政外包、档案服务、邮件收发、综合后勤。若实际包含会计、人事或客户场所管理，应按具体服务分支确认。
35.18.02复印、文件准备及其他专业化办公室支持活动文件准备、编辑校对、文字处理、秘书服务、复印、复制、邮寄支持等。文档制作、复印装订、资料录入、信函处理、邮箱租赁、地址处理。原件控制、版本控制、保密销毁、输出规格和短版印刷边界应明确。
35.19.00呼叫中心的活动呼入客户应答、订单接收、产品信息、投诉处理、呼出销售、调查和客户服务活动。呼入客服、呼出营销、投诉中心、工单中心、质检中心。脚本、录音、坐席质检、个人信息和外呼合规边界应专项确认。
35.21.01收款代理和征信机构的活动委托款项代收、收账服务、个人或商业信用信息收集与提供。收款代理、催收服务、个人征信、商业征信、信用报告。资金、信用信息、授权、异议处理和监管接口应作为高边界事项。
35.21.02包装活动合同或收费基础上的装瓶、固体包装、药品类安全包装、标识、压印、包裹和礼品包装。手工包装、自动化包装、贴标、分拣、组合装、发运前准备。实物物料、标签、数量、卫生或药品类特殊包装要求需与普通文档服务区分。
35.21.03其他未另分类的商业支持服务活动速记记录、字幕、地址条码、募捐组织、收回服务、拍卖人、忠诚度计划等商业支持。记录转录、字幕服务、条码服务、募捐组织、收回服务、拍卖支持、会员计划管理。集合类小类内部跨度大，应按实际服务对象和输出证据限定授权。
  • 分组设立的基本逻辑

本包在 QMS 轴下的共同对象是以客户委托为起点、以专业判断或服务处理结果为输出的知识型和运营支持型服务过程。质量管理体系审核关注的核心不是服务名称是否相同，而是客户需求如何被识别和转化，服务资源如何配置，服务实施过程如何受控，服务输出如何被复核或验收，客户反馈如何形成纠正和改进。

本包可概括的共同质量形成链为：客户委托或服务订单 -> 服务范围和外部要求识别 -> 人员能力和资源配置 -> 信息、文件、数据、物料或客户请求接收 -> 服务实施与过程复核 -> 输出交付或客户确认 -> 记录归档、投诉处理和改进闭环。该链条决定了本包共享的专业能力基础，即审核员应能够围绕客户要求、人员能力、服务方案、过程记录、输出验证、交付确认和反馈闭环建立审核证据链。

组内差异主要表现为专业责任强度不同、输出形态不同和客户损失后果不同：法律、会计、调查、征信具有较强执业或合规边界；总部、管理咨询和公关更强调方案、口径和管理判断；办公室支持、呼叫中心和包装更强调批量作业、服务一致性和交付差错控制。这些差异不否定设组，但要求本包不能按无差别能力包使用，应通过分支标注、专项确认、条件扩展和抽样控制加以处理。

  • 专业小类关系类型与授权后果
关系类型含义授权后果典型控制方式
共同基础关系同属以合同、委托、项目任务或服务订单为输入的专业服务活动，均需识别客户要求、配置人员和资源、形成服务输出、保存服务证据并处理反馈。可简化通用服务过程、客户沟通、记录控制和服务评价等基础能力评价，但仍需确认目标小类或目标分支的实际经历。资料评审、案例判断、专业面谈、服务证据追溯。
并列分支关系同属本技术领域包，但服务对象、交付物、专业责任、现场条件或客户验收方式不同。应记录实际分支能力，不把同包经历理解为全分支能力。分支标注、限定使用、项目技术支持。
条件扩展关系已具备相邻分支能力，具有扩展基础，但目标分支仍存在专门知识、证据链或法规边界。完成补充培训、案例评审、专业面谈、见证审核或技术支持后方可扩展。培训考核、案例评审、见证审核、专家确认。
专项确认关系涉及强执业属性、高保密数据、高客户损失后果、特殊现场作业或复杂外包链。项目使用前应开展专项确认，必要时配置技术专家支持。专项面谈、技术专家评审、项目匹配确认。
不可直接替代关系相关服务经验不足以证明目标小类的质量形成链能力。不得作为目标能力的单独授权依据，应补充目标经历或限定项目类型。重新评价、补充经历、限定项目类型。
边界受控关系当执业资格、客户行业要求、个人信息、资金信用、现场安全、外包生产或法定接口改变服务边界时，统一包内授权应增加边界说明。授权记录应写明适用边界，项目匹配时按实际服务内容确认。授权备注、合规类别清单、技术支持。
法律、会计、调查和征信之间均依赖事实、证据、数据和专业判断，但专业规则与责任边界不同。可共享证据链和保密控制基础，不得以其中一类经历替代另一类专项能力。专项案例面谈、执业边界确认、敏感信息控制评价。
咨询、公关、市场调查和总部服务之间均面向管理决策和组织沟通，依赖需求诊断、资料分析、方案输出和客户确认。可共享项目型专业服务能力，但应标注具体服务路线。项目方案、交付报告和客户评审记录追溯。
办公室支持、呼叫中心和包装之间均强调服务订单、批量处理、过程一致性、差错预防和客户验收。可共享运营支持服务基础，实物包装和个人信息处理应分别确认。现场作业、脚本记录、标签与数量复核、质检记录抽样。
35.21.03集合类商业支持服务类型跨度大，部分路线与速记、字幕、条码、募捐、收回或会员计划相关。仅可按已确认服务路线使用，不宜按小类名称笼统扩展。按实际合同服务内容建立分支备注。
  • 本体系共同能力基础
共同能力维度本包共同基础可共享的审核判断不能共享的边界
客户要求识别均以合同、委托书、服务订单、项目任务书、脚本或客户说明作为输入。判断组织是否把客户目标、交付物、期限、保密、合规和验收要求转化为内部控制要求。法律诉讼策略、法定鉴证、征信授权、包装标签和呼叫中心脚本不能互相替代。
人员能力配置均高度依赖人员专业知识、服务经验、沟通能力、复核意识和职业操守。可共享人员资格识别、岗位职责、培训考核、复核授权和外包人员控制判断。律师、会计、调查、翻译、坐席、包装作业等岗位能力差异应分支确认。
信息和材料控制均需控制客户资料、原始记录、证据材料、财务数据、调查样本、源文、脚本、包装物料或工单。可共享资料接收、版本控制、访问权限、保密、传递和归档判断。涉及资金信用、个人信息、法律证据、财务数据和实物标签时应提高确认粒度。
服务实施与复核均需要按方案、流程、作业标准或服务脚本实施，并通过复核、质检、主管审查或客户确认降低差错。可共享过程控制、复核节点、异常处理和放行责任判断。专业判断型输出和批量作业型输出的复核证据不同，不能用同一套样本覆盖。
交付与反馈闭环均需把服务输出交付给客户或使用方，并保存确认、投诉、纠正、补救或改进记录。可共享客户满意、投诉处理、不合格服务控制和纠正措施判断。法律结果、税务申报、征信异议、包装错标和呼叫中心投诉的后果链不同。
  • 本体系核心控制要求

本组所称关键质量特性，是指服务输出中影响客户可接受性的准确性、完整性、及时性、一致性、可追溯性、响应性和交付符合性。在服务业场景中，检验和放行通常表现为主管复核、质检抽查、客户确认、验收签收、报告批准、脚本质检、现场巡检或交付前复核；审核员应把这些复核和确认活动作为服务结果进入客户使用前的质量控制证据。

QMS 审核应首先确认组织是否把客户委托转化为清晰服务要求。对专业服务，应核对委托事项、权限范围、交付成果、期限、保密要求和外部合规类别；对运营支持服务，应核对服务目录、服务级别、作业标准、数量规格、脚本口径和验收方式。客户要求不清会直接导致服务输出偏离、责任边界争议和投诉处理困难。

第二，应评价人员能力和分派控制。法律、会计、税务、翻译、调查、征信等路线强调专业资质、经验和复核；呼叫中心、办公室支持和包装路线强调岗位培训、作业熟练度、脚本执行、数量核对和现场主管复核；总部和咨询路线强调项目负责人、专家组和交付物审查。审核不宜只看培训记录，应结合实际项目追溯人员分工与输出质量。

第三，应追溯信息、文件、数据和物料的受控状态。法律证据、财务资料、市场样本、译文源文、调查资料、征信信息、客户来电记录、包装标签和原件文件均是服务质量形成的重要输入。审核员应确认接收、登记、分类、权限、版本、备份、交接、销毁和归档是否与服务风险匹配。

第四，应核查服务过程复核和输出放行。专业意见、审计底稿、税务申报资料、咨询报告、公关口径、调查报告、译文、信用报告、呼叫脚本、文件复制品和包装成品均应有复核或确认机制。复核不只是签字，应能说明复核依据、修改痕迹、放行责任和客户确认结果。

第五，应评价不合格服务和客户反馈闭环。典型情形包括文书错误、申报资料遗漏、报告结论依据不足、译文术语错误、呼叫脚本偏离、客户信息泄漏、包装错标、数量短缺、信用信息异议和办公室支持交付延误。审核应追溯问题登记、原因分析、纠正处置、客户沟通和防止再发生措施。

  • 分小类或内部路线差异分析
小类/路线与本包共同基础主要差异差异对能力授权的影响控制方式
35.01.00 法律活动共享委托、资料、专业判断、文书输出和客户沟通基础。法律适用、利益冲突、授权委托、证据链和庭审或非诉责任突出。应标注法律服务分支；复杂诉讼和专项法律事务需专项确认。抽取案件卷宗、委托协议、冲突检索、文书复核和客户沟通记录。
35.02.00 会计、簿记及审计税务咨询共享客户资料、专业复核、报告或申报输出和记录归档基础。财务数据准确性、底稿、凭证、申报口径和鉴证边界突出。应标注财税服务分支；法定鉴证边界需单独确认。抽取凭证到账簿、报表、底稿、申报资料和复核批准链。
35.03.00 公司总部活动共享管理服务、文件化决策、指标和反馈控制基础。总部可能控制子公司核心过程，服务边界取决于授权和管控范围。应按总部管控、共享服务或区域管理分支限定。抽取一项总部决策、指标下达、子公司反馈和纠偏记录。
35.04.01 公共关系和交流共享客户目标、方案、口径、输出审核和反馈基础。议题敏感性、舆情响应、外部公开口径和危机沟通突出。复杂危机公关和强公共影响项目需专项确认。抽取一项传播项目或危机响应，追溯口径审批、发布和反馈。
35.04.02 商业和管理咨询共享项目诊断、资料分析、方案报告和客户验收基础。咨询方法、数据来源、备选方案和落地辅导差异大。应标注咨询领域；跨财务、人力、战略等路线需确认。抽取一项咨询项目，从需求诊断追到报告和客户评审。
35.06.00 市场调查及民意调查共享项目方案、数据采集、分析输出和客户报告基础。样本设计、问卷、访问质量、统计分析和个人信息处理突出。从一般咨询扩展到调查服务需确认调查方法和数据处理能力。抽取一项调查，追溯样本、问卷、访问、清洗、分析和报告。
35.08.00 笔译和口译共享客户要求、人员能力、输出复核和交付确认基础。术语库、源文版本、译审校流程、现场口译即时性和保密突出。翻译与咨询、文档支持之间可条件扩展，但需语言服务案例。抽取一份译文或口译项目，追溯源文、译员、审校和客户反馈。
35.14.00 调查活动共享委托、资料收集、事实核验和报告输出基础。授权边界、信息来源、事实交叉验证和隐私保护突出。调查服务属专项确认路线，不以一般咨询经历替代。抽取调查委托、信息来源清单、核验记录、报告复核和归档。
35.18.01 综合办公室管理共享服务订单、人员派驻、作业记录、交付确认和投诉处理基础。服务内容组合多，可能含接待、档案、邮件、财务和人事支持。应按实际服务目录限定，不覆盖未确认专业服务。抽取一个办公室服务月度样本，追溯工单、巡检、交付和投诉。
35.18.02 文档及办公室支持共享文件输入、加工处理、复核、交付和保密基础。原件、版本、复制规格、排版、校对、邮寄和销毁控制突出。可与办公室管理条件扩展；含短版印刷或保密销毁需确认。抽取文档任务，追溯原件接收、制作、复核、交付和销毁。
35.19.00 呼叫中心共享客户要求、人员培训、作业脚本、记录质检和反馈闭环基础。坐席排班、脚本、录音、质检、外呼合规和投诉升级突出。应标注呼入、呼出、投诉或调查分支。抽取坐席录音、脚本版本、工单、质检和客户投诉关闭记录。
35.21.01 收款代理和征信共享客户委托、信息处理、记录保存和反馈处理基础。资金信用信息、授权、异议、催收沟通和报告准确性突出。属高边界分支，应专项确认后使用。抽取收款或征信样本，追溯授权、信息来源、沟通、异议和报告。
35.21.02 包装活动共享订单、物料、作业、复核、交付和客户验收基础。实物数量、标签、批次、错装漏装、卫生或特殊包装要求突出。不得以文档服务经历替代包装现场能力。抽取包装订单，追溯物料、标签、首件、过程巡检和发运。
35.21.03 其他商业支持共享受托服务、记录处理、输出交付和客户确认基础。内部路线跨度大，速记、字幕、条码、募捐、收回、拍卖和会员计划差异明显。应按实际服务路线限定授权。抽取实际服务合同，确认服务对象、输出物、记录和验收。
  • 分组合理性论证结论

本组可以设立的理由在于，各小类虽专业形态差异较大，但在 QMS 轴下均以客户委托、资料或任务输入为起点，以专业服务输出或受托处理结果为交付对象，均需要客户要求识别、人员能力控制、信息资料受控、过程复核、输出确认、记录追溯和反馈改进。该共同质量形成逻辑足以支撑统一领域包的基础能力评价。

因此，QG35-1 可以作为质量管理体系技术领域包使用，但其使用方式应为“统一领域包 + 专业服务分支 + 办公与客户支持分支 + 资金信用分支 + 受托包装边界控制 + 条件扩展”。审核员授权、项目匹配和能力扩展均应体现分支差异，不得把同包经历理解为跨全部小类的充分证明。

  • 培训、考核与作业指导书需求

本组应建立专业服务与运营支持服务 QMS 培训，内容包括委托服务质量形成链、专业责任边界、人员能力和复核、客户资料和个人信息控制、服务输出验证、不合格服务控制、客户投诉闭环、批量作业差错预防以及集合类小类授权限定。法律、会计、调查、征信、翻译、呼叫中心和包装路线应设置分支案例。

考核宜采用场景式题目和案例追溯题，要求审核员能够从一个真实或模拟服务订单出发，说明客户要求识别、资源配置、关键过程控制、输出复核、交付验收、投诉反馈和纠正措施之间的证据关系。作业指导书宜提供分支化抽样路径、典型记录清单、访谈问题库和授权边界提示。

  • 常见合规义务类别与标准适用提示

本组可能涉及律师执业、会计和税务代理、审计鉴证、个人信息保护、商业秘密、知识产权、广告和公共传播、统计调查、征信和收款、呼叫中心外呼、劳动用工、文件保密销毁、药品或食品相关包装、邮政寄递、拍卖、募捐和客户行业专项要求等类别。文件不列具体标准编号和年份；适用性应使用机构受控的有效清单、客户合同、服务目录、项目范围和所在地监管要求确认。上述类别用于识别外部要求如何转化为服务过程控制、人员资质确认、记录保存、客户沟通和输出复核，不替代政府许可、行政执法或客户专项验收。

  • 分组使用限制和法定边界

本组覆盖的小类跨度较大，统一领域包仅用于说明其在 QMS 轴下共享服务过程控制基础。涉及法律代理、法定审计、税务代理、征信、收款、调查、个人信息密集处理、药品类或食品类包装、募捐组织和拍卖等事项时，应确认组织实际资质、客户授权、服务范围和审核员分支能力。

管理体系审核仅用于评价组织是否在其服务范围内建立并实施质量管理控制，不替代行政许可、司法判断、法定鉴证、执业资格审查、政府监管、行政处罚、强制检测、客户专项验收或其他法定结论。涉及受监管资质、敏感数据、资金信用、现场作业和第三方外包时，应在项目匹配阶段确认审核员分支能力和必要的技术支持。

  • 分组结论与使用口径

QG35-1 可作为质量管理体系专业服务、管理支持及商业支持服务技术领域包使用。授权时应记录审核员在专业判断型服务、运营支持型服务、客户联络型服务、资金信用型服务、受托包装和集合类商业支持等分支上的实际能力。文件维护触发条件包括：服务小类边界调整、受监管服务规则变化、个人信息和信用信息处理要求变化、包装服务对象变化、组织实际服务模式发生实质变化，或上层分组使用中出现能力匹配争议。
