  • 文件定位说明

本文件用于职业健康安全管理体系（OHSMS）认证中 SG35-2 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦建筑物一般清洁、建筑专项清洗、工业清洗及其他清洁服务在本体系轴下的危险源、伤害机制、人员暴露、职业健康、化学品接触、高处和工业清洗高边界作业、应急响应，不承担行业百科说明功能，基础行业事实由对应专业小类基础卡承载。

本组采用“统一领域包 + 一般清洁分支 + 建筑专项清洗分支 + 工业清洗专项确认 + 其他清洁路线限定”的使用口径。组内小类可以共享本体系的基础判断方法，但不得把某一分支经历等同于另一分支完整能力；对现场性强、外部合规接口明显、污染源或危险源发生实质变化的情形，应在授权和项目匹配阶段追加分支确认。

  • 技术领域包构成
小类编码小类名称纳入本包的活动范围主要内部路线特殊边界
35.16.01建筑物的一般清洁办公室、住宅、商店、工厂、研究所等建筑日常清洁。日常保洁、公共区域清洁、卫生间、地面、垃圾收集。湿滑地面、清洁药剂、高处、车辆道路、消杀暴露和客户现场交叉作业应按路线确认。
35.16.02其他建筑及工业清洗活动建筑外墙、窗户、烟囱、通风管、锅炉、工业机械等专项清洗。建筑专项清洗、工业设备清洗、管道清洗和炉膛系统清洗。湿滑地面、清洁药剂、高处、车辆道路、消杀暴露和客户现场交叉作业应按路线确认。
35.16.02a工业清洗活动工业设备、管道、储罐、换热器、生产设施和特殊介质系统清洗。化学清洗、高压水射流、机械清洗、停机清洗和设备复位。工业残留介质、化学品、高压水、受限空间、能量隔离、滑跌和应急响应为重点边界。
35.16.02b其他建筑清洗活动外墙、玻璃、烟囱、通风管、炉灶、锅炉和排气装置等建筑专项清洗。外墙玻璃、烟道、通风管、屋面和立面清洗。湿滑地面、清洁药剂、高处、车辆道路、消杀暴露和客户现场交叉作业应按路线确认。
35.16.03其他清洁活动游泳池、交通工具、罐体、消毒灭杀、洗瓶、道路清扫和除雪等。交通工具清洁、消杀、罐体内部清洗、道路保洁、洗瓶和除雪。湿滑地面、清洁药剂、高处、车辆道路、消杀暴露和客户现场交叉作业应按路线确认。
  • 分组设立的基本逻辑

本包在本体系轴下的共同对象是清洁人员在建筑物、工业设备、交通工具、罐体、道路、泳池和客户现场清洁作业中的人员暴露、作业活动和异常工况。分组判断的核心不是服务名称是否相同，而是危险源、伤害机制、人员暴露、职业健康、高风险作业、应急响应和承包方控制的形成机理和控制路径是否足够接近。

本包可概括的共同证据链为：清洁对象和现场条件识别 -> 危险源、人员暴露和作业边界识别 -> 人员培训、药剂、工具设备、个人防护和作业方案控制 -> 作业实施、现场警戒、监护和应急 -> 事件、职业健康和客户反馈闭环。该链条决定了本包共享的专业能力基础，审核员应能够围绕源头识别、过程控制、记录追溯、异常处置和改进闭环建立审核证据。

一般建筑清洁以湿滑、药剂刺激、重复动作和客户区域交叉作业为主；建筑专项清洗增加高处、坠落、物体打击和粉尘油污暴露；工业清洗增加化学品、高压水、残留能量、受限空间、中毒窒息和机械伤害，是本组 OHSMS 重点路线。这些差异不否定设组，但要求本包不能按无差别能力包使用，应通过分支标注、专项确认、条件扩展和抽样控制加以处理。

  • 专业小类关系类型与授权后果
关系类型含义授权后果典型控制方式
共同基础关系均以服务场所、办公作业、客户现场、交通差旅、人员接触和外包协作为主要危险源识别基础。可简化办公型服务 OHSMS 基础评价，但仍需确认目标分支的人员暴露、现场作业和应急边界。资料评审、现场访谈、危险源清单和事件记录追溯。
并列分支关系同属本职业健康安全领域包，但伤害机制、作业场景、客户现场或人员暴露不同。应记录实际分支能力，不把同包经历理解为全分支能力。分支标注、限定使用、项目技术支持。
条件扩展关系已具备相邻服务危险源识别能力，但目标路线存在专门作业活动或职业健康暴露。完成补充培训、案例评审、专业面谈或见证审核后方可扩展。培训考核、案例评审、见证审核。
专项确认关系涉及安保冲突、夜间值守、报警安装、展会搭建、工业清洗、高处清洁、车辆道路或化学品暴露。项目使用前应专项确认，必要时配置技术专家支持。专项面谈、技术专家评审、项目匹配确认。
不可直接替代关系普通办公室审核经历不足以证明高现场性服务、安保、清洗、景观或会展现场 OHSMS 能力。不得作为目标能力的单独授权依据。补充目标案例或限定项目类型。
边界受控关系客户现场、承包方、特种作业、个人防护、事件应急和法定职业健康安全要求改变使用边界。授权记录应写明边界，项目匹配时按实际活动确认。授权备注、作业活动清单、技术支持。
一般清洁与建筑专项清洗均共享清洁作业、药剂、工具、湿滑地面和客户现场基础。可共享清洁基础能力，建筑专项应补充高处、烟道、通风管和现场警戒案例。专项项目案例、个人防护、现场交底和事件记录。
一般清洁与工业清洗仅共享清洁活动基础，危险源强度和伤害机制差异明显。不得以一般清洁经历替代工业清洗 OHSMS 能力。工业清洗专项培训、案例评审和见证审核。
35.16.03集合路线交通工具、罐体、消杀、道路和除雪等路线均属清洁服务但危险源不同。应按实际清洁对象限定授权。作业对象、现场条件、药剂、车辆道路和应急记录确认。
  • 本体系共同能力基础
共同能力维度本包共同基础可共享的审核判断不能共享的边界
危险源识别均需识别湿滑、药剂、工具设备、搬运、客户现场、车辆道路、粉尘油污和异常工况。可共享清洁作业危险源和人员暴露识别方法。工业残留介质、受限空间、高压水和高处清洗需专项确认。
人员暴露和职业健康均可能涉及皮肤和呼吸道刺激、重复动作、腰背负荷、嗓尘气味、噪声和心理压力。可共享职业健康告知、个人防护、培训和事件报告判断。消杀、工业清洗和罐体清洗暴露强度需提高确认粒度。
作业控制均需控制作业方案、药剂、工具、设备、警示、隔离、现场交底和客户接口。可共享现场控制、监护和客户确认判断。受限空间、能量隔离、临时用电、高处和交通道路需专项路线。
应急响应均需针对滑跌、化学品接触、眼部喷溅、交通事故、坠落、中毒窒息和设备伤害建立响应。可共享应急物资、联系、演练、事件调查和改进判断。工业清洗和罐体作业的救援边界需专项确认。
  • 本体系核心控制要求

OHSMS 审核应围绕危险源、伤害机制、人员暴露、职业健康、工作活动、异常工况、高风险作业、承包方和应急响应展开。服务业组织不宜仅因无制造过程而简化判断；办公室视屏作业、心理压力、差旅、客户现场、夜间值守、清洁药剂和现场交叉作业均可能形成实质风险。

第一，应从清洁对象、现场条件和作业方法识别危险源。普通地面清洁、外墙玻璃清洗、通风管清洗、工业设备清洗、罐体内部清洗、道路清扫、消杀和除雪的伤害机制并不相同。

第二，应核查药剂、工具设备和个人防护。清洁剂配比、喷洒方式、眼面部防护、手套、防滑鞋、通风、工具状态、高压设备、梯具或升降设备、道路车辆和现场警戒均应与实际作业匹配。

第三，应核查工业清洗和建筑专项清洗的高边界控制。工业清洗应关注设备隔离、残留介质、置换、气体检测、能量隔离、高压水射流、化学灼伤和应急救援；建筑专项清洗应关注高处坠落、物体打击、立面材质、烟道油污和通风管粉尘。

第四，应评价事件、职业健康和应急闭环。典型事件包括滑倒跌倒、药剂喷溅、皮肤刺激、割伤夹伤、高处坠落、车辆碰撞、罐体中毒窒息、工业设备残留介质伤害和救援不当。审核应追溯报告、调查、纠正、培训和预防措施。

  • 分小类或内部路线差异分析
小类/路线与本包共同基础主要差异差异对能力授权的影响控制方式
35.16.01 建筑物一般清洁共享清洁作业、湿滑地面、药剂接触、搬运和客户场所作业基础。以日常低强度作业为主，重点在滑跌、药剂刺激、重复动作和客户区域交叉作业。可作为清洁基础分支，不覆盖专项和工业清洗。抽取保洁区域，追溯药剂、个人防护、湿滑警示、巡检和事件记录。
35.16.02 建筑及工业清洗共享专项清洗、现场方案、工具设备、人员防护和客户验收基础。内部路线跨度大，可能涉及高处、烟道、机械设备、化学品和残留能量。应按35.16.02a或35.16.02b细化授权。抽取专项项目，确认作业方案、危险源、人员暴露和应急措施。
35.16.02a 工业清洗共享清洗作业和客户现场基础。工业残留介质、化学品、高压水射流、受限空间、能量隔离、机械伤害和中毒窒息边界突出。属 OHSMS 重点专项路线，不以一般清洁经历替代。追溯隔离置换、作业许可、个人防护、气体检测、应急和复位验收。
35.16.02b 建筑专项清洗共享清洁工具、药剂、现场作业和客户验收基础。外墙、玻璃、烟道、通风管等作业可能涉及高处、坠落、物体打击和粉尘油污暴露。建筑专项清洗需专项确认，尤其是高处和烟道通风管。抽取建筑清洗项目，追溯现场勘查、工具、个人防护、警戒和异常处理。
35.16.03 其他清洁共享清洁作业、药剂、交通工具、湿滑和客户现场基础。交通工具、罐体、消杀、道路清扫、扫雪除冰和洗瓶的伤害机制差异大。应按实际路线限定；罐体、消杀和道路车辆作业需专项确认。抽取具体路线，确认车辆道路、药剂暴露、罐体进入、寒冷天气和应急边界。
  • 分组合理性论证结论

SG35-2 可以设立为 OHSMS 清洁活动技术领域包。五个小类均以清洁作业、药剂工具、客户现场、人员暴露、现场警戒、个人防护和应急响应为共同控制基础。组内差异主要由清洁对象和作业方法决定，其中工业清洗、罐体清洗、消杀、高处建筑清洗、道路清扫和交通工具清洁应作为专项或边界受控路线。

  • 审核关键要点与抽样方法
抽样场景现场必看记录必查纵向追溯路径追问方向
一般建筑清洁保洁区域、湿滑点、药剂间、工具和警示标识。危险源清单、药剂领用、培训、个人防护、巡检、事件记录。区域 -> 药剂工具 -> 作业 -> 人员暴露 -> 事件改进。湿滑和药剂接触如何控制。
工业清洗设备、隔离点、药剂、高压设备、监护点和应急物资。作业方案、交底、许可、气体检测、能量隔离、个人防护、应急记录。对象 -> 危险源 -> 隔离防护 -> 作业 -> 应急复盘。残留介质和救援边界如何确认。
建筑专项清洗外墙、烟道、通风管、梯具、警戒区和个人防护。勘查、方案、工具检查、现场交底、监护、事件和验收。勘查 -> 作业方案 -> 现场控制 -> 验收。高处和物体打击如何控制。
消杀或泳池清洁药剂储存、投加点、通风条件、客户提示。药剂、配比、培训、防护、残留确认、异常记录。对象 -> 药剂 -> 暴露控制 -> 客户提示。吸入和皮肤暴露如何降低。
道路或交通工具清洁车辆、道路、设备、交通隔离和天气条件。路线计划、设备检查、交通警示、人员培训、事件记录。路线 -> 交通环境 -> 作业 -> 事件 -> 改进。车辆和恶劣天气如何控制。
  • 能力扩展与条件授权
起点能力目标能力可扩展依据必须补充确认授权限制
一般清洁建筑专项清洗共享清洁作业、药剂和客户现场基础。高处、烟道、通风管、梯具、现场警戒和专项防护案例。未确认前仅限一般清洁。
一般或建筑清洁工业清洗仅共享清洁活动基础。残留介质、化学品、高压水、受限空间、能量隔离、气体检测和应急案例。工业清洗应专项确认。
一般清洁消杀或泳池清洁共享药剂和客户场所基础。消杀药剂、残留、通风、客户提示和暴露控制案例。按具体对象限定。
建筑专项清洗罐体或交通工具清洁共享专项清洗方案和客户验收基础。罐体进入、车辆道路、交通隔离、残留介质和救援边界案例。按实际清洁对象限定。
  • 培训、考核与作业指导书需求

本组应建立清洁活动 OHSMS 专业培训，内容包括湿滑跌倒、药剂接触、个人防护、清洁工具设备、重复动作和搬运、客户现场交叉作业、高处清洗、通风管和烟道清洗、工业清洗残留介质、高压水、能量隔离、气体检测、受限空间、消杀、罐体、道路交通和应急救援。考核应要求审核员完成一般清洁、建筑专项、工业清洗和其他清洁路线的危险源追溯。

  • 常见合规义务类别与标准适用提示

本组可能涉及劳动用工、职业健康、个人防护、化学品使用、消毒灭杀、客户现场作业、高处作业、受限空间识别、临时用电、道路交通、承包方管理、应急管理、工伤和客户行业安全要求等类别。文件不列具体标准编号和年份；适用性应使用机构受控的有效清单、服务合同、场所边界和作业活动确认。

  • 分组使用限制和法定边界

本分组仅用于 OHSMS 认证中的技术领域包论证和审核员能力控制，不替代政府许可、安全评价、职业病危害评价、消防验收、特种作业资格审查、受限空间作业审批、工伤认定、行政执法或客户专项安全验收。涉及工业清洗、罐体内部清洗、高处建筑清洗、消杀、道路作业、化学品和高压水作业时，应进行专项能力确认。

  • 分组结论与使用口径

SG35-2 可作为职业健康安全管理体系清洁活动技术领域包使用。授权时应记录一般清洁、建筑专项清洗、工业清洗、消杀/泳池/交通工具/道路等其他清洁路线的实际能力。文件维护触发条件包括：清洁对象、作业方法、药剂、设备、高处条件、工业残留介质、客户现场规则、承包方或应急要求发生实质变化。
