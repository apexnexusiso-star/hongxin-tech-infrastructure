17.11.03 工具的制造 专业小类基础卡

A. 标识与定位

A1 小类名称、分类代码、在分类体系中的位置

字段内容

所属中类17.11 金属工具、五金及相关制品制造
本卡定位描述以碳钢、合金钢、工具钢、不锈钢、铝合金、塑料手柄、橡胶握把和表面处理材料为主要投入，制造手工工具、农园工具、装配工具、夹持工具、敲击工具、切割辅助工具和类似金属工具的行业事实。

A2 定义与范围界定

本小类是指制造主要依靠人力或简单机械配合进行夹持、拧紧、敲击、撬动、剪切、修整、量规配合、园艺和维修作业的金属工具及其金属主体部件的活动。典型产品包括扳手、钳子、锤子、螺丝刀、锉刀、凿子、剪刀类工具、管子钳、夹具、手锯架、园林剪、铁锹、镐、耙、泥瓦工具、装配工具、专用手工工具和工具组合套装。

本小类的核心在于工具工作部位、手柄或握持部位、连接部位和表面状态的形成。制造过程通常包括锻造、冲压、机加工、热处理、磨削、抛光、表面涂覆、手柄注塑或包胶、装配、功能检测和包装。

本小类不包括刃具制造、锁和铰链制造、电动工具和气动工具整机制造、机床或机械设备制造、模具制造、普通金属制品无明确工具功能的制造、单纯工具维修和贸易。若某产品以切削刃部作为机床或加工设备工作部件，应优先按刃具识别；若以电机、气动或液压动力为主，应按相应设备或电动工具识别。

B3 关键技术概念说明

工具制造的核心是让金属工作部位能够承受人工施力并稳定作用于工件。扳手需要扳口尺寸和扭矩承载，钳子需要铰接、钳口硬度和夹持状态，锤子需要锤头材料和柄部连接，园林工具需要刃口、韧性和防腐，螺丝刀需要刀杆硬度、刀尖尺寸和手柄结合。

热处理和工作面加工决定工具的使用基础。硬度不足会导致磨损和变形，硬度过高或韧性不足会形成崩裂路径。手柄和连接部位则影响施力传递、握持和使用舒适性。

C4 典型产品族专业差异补充

工具制造的底层识别重点在于“工作端如何受力、柄部如何传力、表面如何防护、套装如何防混”。同一小类中，锻造扳手、铰接钳类、锤类工具和农园工具的过程资源差异较明显，不能仅按“手工具”笼统描述。

产品族过程差异对底层识别有价值的专业信息
扳手、套筒和内六角锻造或冷挤、开口或六方成形、热处理、抛光镀覆和尺寸检具配合。开口尺寸、扭矩承载、支承面状态和套筒同轴状态是识别抓手。
钳类工具左右半体锻造、铰接孔加工、刃口热处理、铆接和柄部包胶共同形成。钳口咬合、铰接间隙、剪切刃口和握持状态需要分开描述。
螺丝刀和批头棒料成形、端部加工、热处理、磁化或表面处理、手柄注塑装配突出。刀杆硬度、端部轮廓、柄部结合和扭矩传递状态是主要信息。
锤类、冲子和凿子锻造、冲击面处理、柄孔或柄部连接、热处理和防脱结构较突出。冲击端硬度、柄部连接和飞边毛刺状态与其他工具不同。
锉刀、刮刀和修整工具齿纹或刃口形成、热处理、柄部装配和防锈包装构成主线。齿纹密度、刃口直线度和表面毛刺应与普通冲压件区分。
农园工具板材冲压、锻打、焊接、木柄或塑柄装配和涂装占比高。刃口、柄部连接、涂层和土工使用造成的磨耗接触面需识别。
汽修、管道和电工工具套装多规格零件配套、绝缘或防滑结构、包装清单和外购件协同明显。套装完整性、规格标识和专用功能接口是底层描述重点。

D. 过程与技术

D1 主要工艺/过程流程

`mermaid flowchart LR A["产品图纸/材料要求"] --> B["下料、锻造或冲压"] B --> C["机加工和工作面加工"] C --> D["热处理和校正"] D --> E["磨削、抛光和表面处理"] E --> F["手柄、铰接或附件装配"] F --> G["功能、尺寸和外观检测"] G --> H["包装、套装和交付"] `

锻造工具通常经过钢材下料、加热、模锻、切边、机加工、热处理、抛光和表面处理。钳类工具还需要铰接装配和钳口调整；扳手需要开口、环口和表面尺寸；锤类工具需要锤头与柄部可靠连接；螺丝刀和套筒工具需要刀杆、扭矩部位和手柄装配。

D1.1 扳手、套筒和螺丝刀类工具过程深度

扳手和套筒类工具的核心是扭矩传递。开口扳手、梅花扳手和两用扳手通常通过锻造或精密冲压形成毛坯，再进行开口或环口加工、热处理、抛光、表面处理和标识。开口尺寸、环口齿形、头部厚度、柄部过渡圆角和热处理状态共同决定工具与螺栓螺母的接触状态。套筒类工具还需要控制方孔、六角孔、壁厚、同轴度和表面防锈。

螺丝刀和批头类工具需要关注刀尖型式、杆部硬度、扭矩能力和手柄结合。十字、一字、梅花、内六角等刀尖轮廓必须与螺钉槽匹配；刀尖热处理过软会磨损，过脆会崩裂；手柄注塑或包胶需要与金属杆形成可靠机械锁合或粘结。

D1.2 钳类、锤类和农园工具过程深度

钳类工具由左右钳体、铰接点、钳口、刃口、手柄和弹簧或限位结构组成。制造过程需要对锻造毛坯进行钳口加工、刃口热处理、铰接孔加工、铆接或螺钉连接、开合间隙调整和手柄包胶。钳口咬合、剪切刃重合和铰接间隙会直接影响夹持、剪切和手感。

锤类工具和冲击工具强调冲击韧性和柄部连接。锤头通常经锻造、热处理、锤面加工和防锈处理，柄部可能为木柄、钢柄、玻纤柄或包胶柄。柄孔配合、楔紧、胶粘或包覆结构决定使用中是否松动。铁锹、镐、园林剪等农园工具则更关注刃口、板体韧性、表面防腐、手柄连接和土壤或植物接触后的耐蚀状态。

D1.3 套装和出口型工具的多品种管理

组合工具套装的制造难点不只在单件工具，而在规格配套和包装一致。套筒、接杆、棘轮扳手、批头、内六角和专用小件外观相近、数量多，容易出现混规格、漏件、错标和包装划伤。出口型工具还常涉及不同客户图案、语言标识、表面颜色、包装盒结构和条码管理，产品族管理比单一工具更复杂。

D6 典型工艺路线识别提示

工具制造应按受力方式和工作端形态识别路线。锻造扳手、铰接钳、螺丝刀、锤类和农园工具虽然都属于工具，但材料、热处理和装配接口差异明显。

路线类型典型识别信息与其他路线的差异
锻造扳手路线下料、加热、模锻、切边、热处理、开口加工和镀覆。扭矩承载和开口尺寸是主要识别点。
套筒和批头路线冷挤或机加工、六方孔、热处理、表面处理和分选。内孔配合、同轴和小规格防混突出。
钳类路线左右半体锻造、铰接孔、刃口、铆接、柄套和启闭。运动副、刃口和握持件共同形成产品状态。
螺丝刀路线棒料、端部成形、热处理、镀覆、手柄注塑和装配。端部轮廓和柄部传力路径突出。
锤类冲凿路线锻造、冲击面处理、柄孔或柄部连接、防脱和表面防锈。冲击面和柄部连接状态是主要差异。
农园工具路线板料或锻件、焊接、刃口、木柄或塑柄装配和涂装。大件薄板和柄部连接对成品状态影响明显。
套装工具路线多规格采购或自制、分格包装、清单核对和标识。配套完整性和规格防混是独有识别点。

E. 产业链与边界

E1 上游供应

上游包括工具钢、板棒材、塑胶粒子、橡胶、木柄、紧固件、表面处理材料、包装盒和外部热处理或涂覆资源。材料硬度、塑性、手柄材料和表面处理状态会传递到成品。

E2 下游应用/客户

下游包括工业装配、设备维修、建筑施工、家庭维修、园林农业、汽车维修、电工安装、五金流通和出口渠道。

E3 本小类在产业链中的位置

本小类位于金属材料和终端作业使用之间，是通用作业工具和专业维修工具的制造环节。产品通常既是消费品，也是工业生产和维修维护的基础工具。

E4 常见委外/外包环节

委外环节常见原因边界提示
锻造或冲压毛坯模具和设备投入较大可作为工具主体毛坯输入。
热处理炉型和硬度要求专业常作为后段接口。
表面处理电镀、发黑、喷涂专业化常由外部处理企业完成。
手柄注塑塑胶设备和模具专业化可作为工具成品装配输入。
功能检测扭矩、寿命或耐蚀设备有限可由外部检测资源完成。

E5 典型接口资料与实物流转补充

工具产品与材料、热处理、表面处理、手柄配件和渠道包装联系紧密。底层记录应把功能端与配套件的交付关系写清。

接口环节常见资料或实物识别价值
材料输入碳钢、Cr-V、Cr-Mo、不锈钢、木柄、塑胶和包材。反映强度、热处理和握持结构基础。
工作端参数开口尺寸、钳口、刃口、锤面、螺丝刀端部和套筒规格。决定工具功能和检测组合。
热处理接口淬火、回火、表面硬化、校直和硬度确认。反映工作端承载和耐磨状态。
表面处理接口电镀、发黑、喷涂、抛光、防锈油和包装防潮。反映防腐和外观形成路径。
配套装配手柄、包胶、铆钉、弹簧、套盒、内衬和说明标签。反映成品使用和套装交付状态。
下游使用工业装配、维修、建筑、园林、电工、汽修和家庭工具。反映不同工具族的使用边界。

F1 行业准入/资质/许可要求

工具制造通常按金属工具和五金制品活动管理。电工工具、绝缘工具、汽车维修工具、起重或承载工具、食品接触工具、园林剪切工具等可能涉及特定产品技术要求。热处理、表面处理、抛光、喷涂和包装材料存在通用行业门槛类别。

F2 强制性产品标准、主要国家/行业技术标准

标准类别可能覆盖内容本卡处理方式

农园工具标准刃口、柄部连接、强度和防腐具体标准号待核验。
绝缘或专用工具标准绝缘、特殊用途和安全结构仅适用于对应产品。
表面处理标准镀层、涂层、防锈和耐蚀作为表面状态来源类别。
检测方法标准硬度、扭矩、拉力、寿命、盐雾作为检测方法来源类别。

F3 通用性法律法规主体

本小类涉及产品质量、标准化、计量、消费者权益、市场监管、工业生产、合同交付和售后服务等通用类别。本卡只保留类别指针。

G. 检验、检测与计量手段

G1 行业常用检测/试验/计量方法

方法类别常用手段适用对象
尺寸检测卡尺、塞规、专用检具、样板扳口、钳口、孔位、柄部和工作面。
硬度检测HRC/HB/HV工作面、刃口和冲击部位。
强度检测扭矩、拉力、冲击、剪切试验扳手、螺丝刀、钳子和柄部连接。
表面检测膜厚、盐雾、外观、附着镀层、涂层和防锈表面。
功能检测夹持、剪切、装配试用、套装核对成品工具和组合工具。

G2 关键检测参数与对应方法

参数/项目常见方法说明
开口尺寸卡尺、塞规适用于扳手和套筒。
工作面硬度硬度计适用于钳口、刃口、锤面。
扭矩能力扭矩测试适用于扳手和螺丝刀。
柄部连接强度拉力、冲击或弯曲试验适用于锤类和园林工具。
表面耐蚀盐雾或外观检查适用于镀层和涂层工具。
套装完整性清单核对、目视适用于组合工具。

G3 典型检测组合与适用对象

工具产品的检测组合通常由功能端、受力状态、热处理状态、表面防护和包装配套共同组成。底层记录应反映不同工具的客观测试方式，而不是把所有工具都归入同一种尺寸外观检查。

适用对象常见检测组合识别意义
扳手和套筒开口尺寸、六方或十二角配合、硬度、扭矩、外观和镀层状态。反映螺纹连接工具的装配接口和承载状态。
钳类工具钳口咬合、剪切能力、铰接间隙、硬度、柄套结合和启闭手感。反映夹持剪切工具的运动副和工作端状态。
螺丝刀和批头端部轮廓、杆部硬度、扭矩、磁性或表面状态、手柄拉拔。反映旋拧工具的端部配合和传力路径。
锤类工具锤面硬度、冲击面状态、柄部连接、重量偏差和表面防锈。反映冲击工具的材料状态和连接安全边界。
锉刀和刮刀齿纹均匀性、刃口状态、硬度、平直度和柄部连接。反映修整工具的工作表面连续性。
农园工具刃口、柄部连接、弯曲或冲击、涂层、木柄含水或表面状态。反映土工和园艺场景下的承载与磨耗接触面。
组合工具套装单件尺寸功能、表面状态、规格清单、装盒位置和标识一致性。反映多规格产品的配套和防混状态。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类整体技术成熟，但产品品种多、材料和热处理差异明显。自动化程度从小型手工装配到锻造线、自动抛光、注塑包胶和套装包装线均有分布。人工经验在锻造缺陷识别、抛光外观、装配手感和包装套装核对中仍然明显。

H2 典型组织形态

组织形态典型特征常见资源配置
小型工具厂单一产品、外协多冲压、简单机加工、装配和包装。
锻造手工具企业扳手、钳子、锤类锻压、热处理、磨削、抛光和检测。
园林工具企业剪、铲、锹、镐等冲压锻造、刃口、手柄和涂装。
组合工具企业套装和出口产品多品类供应链、包装和清单管理。
专用工具企业汽修、电工、管道等专用尺寸、功能测试和标识管理。

H4 典型组织形态差异补充

工具制造企业常在锻造、机加工、热处理、表面处理、装配和包装之间形成不同资源组合。底层描述应体现企业是以单类工具为主，还是以成套配货为主。

组织形态典型表现技术识别提示
扳手套筒企业锻造、冷挤、热处理和镀覆资源较集中。尺寸、扭矩和防混信息突出。
钳类企业锻造半体、铰接、刃口和柄套装配较多。铰接间隙、刃口和握持状态突出。
螺丝刀企业端部加工、杆部热处理和手柄注塑装配突出。端部轮廓和柄部结合信息较多。
农园工具企业板料成形、焊接、柄部装配和涂装占比高。柄部连接和防锈包装是识别重点。
专用工具企业汽修、管道、电工或维修工具按用途组合。专用接口、绝缘或附件配套需要说明。
套装配货企业自制和采购并存，包装清单和规格管理突出。配套完整性和供应链接口是主要信息。

H3 客观存在的易出问题环节/技术敏感点

敏感点客观影响链
材料牌号或热处理不匹配材料和硬度状态偏差 → 工作面承载变化 → 变形、磨损或崩裂路径形成。
锻造折叠或冲压毛刺成形缺陷残留 → 工作面或握持部位异常 → 使用中划伤、裂纹或失效路径形成。
工作面尺寸偏差扳口、钳口或刀尖尺寸偏移 → 与工件配合状态变化 → 打滑、损伤或夹持不足。
手柄连接不牢铆接、压装、胶粘或包胶异常 → 施力传递中松动 → 脱落或转动路径形成。
表面处理不连续镀层或涂层薄弱 → 防锈路径中断 → 锈蚀和外观变化。
套装混装漏装多品种包装识别不足 → 工具规格与清单不一致 → 使用端配套缺失。
钳类铰接间隙异常铰接孔、销轴或铆接状态偏差 → 开合阻力和钳口对合变化 → 夹持、剪切或手感状态波动。
扭矩工具工作端轮廓磨损扳口、套筒或批头型面偏差 → 接触面积和受力位置变化 → 打滑、棱角损伤或工具变形路径形成。
锤类柄部锁合不足柄孔、楔紧、胶粘或包覆状态异常 → 冲击时相对位移增加 → 锤头松脱或柄部开裂路径形成。

H3 只记录行业中客观存在的敏感点及事实因果链，不对其在任何上层视图中的重要性作判断。
