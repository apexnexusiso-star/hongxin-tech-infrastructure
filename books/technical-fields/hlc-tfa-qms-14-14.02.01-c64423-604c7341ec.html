14.02.01 塑料板、塑料片、塑料管及塑料壳体的制造 专业小类基础卡

> 本卡为技术领域分组底层知识卡，记录不依附于特定管理体系的行业事实、过程边界、术语、产品、工艺、产业链、法规标准类别、检测计量手段和维护信息。凡涉及具体管理体系下的专业能力、抽样重点、人员授权、合格评定结论或体系风险分级的内容，应在上层分组论证文件中展开。

A. 标识与定位

A1 小类名称、分类代码、在分类体系中的位置

字段内容
专业小类代码14.02.01
专业小类名称塑料板、塑料片、塑料管及塑料壳体的制造
所属大类14 橡胶和塑料制品制造
所属中类14.02 塑料制品制造
活动属性以塑料树脂熔融、挤出、压延、定型、冷却、切割和壳体成型为核心的板片管壳类塑料制品制造。
卡片定位作为后续不同管理体系技术领域分组论证调用的底层知识原子，不直接给出人员授权结论。

A2 定义与范围界定

本小类包括将聚乙烯、聚丙烯、聚氯乙烯、聚苯乙烯、聚碳酸酯、聚酰胺、ABS、工程塑料、改性料和添加剂等投入，通过干燥、配混、挤出、压延、共挤、定径、冷却、牵引、切割、热成型、吸塑、弯折、焊接或机械加工形成塑料板材、片材、管材、壳体及类似基础形态产品的活动。

本小类的核心特征是产品形态偏基础材料或半成品构件，常作为后续包装、建筑、电子、设备外壳、广告、化工防腐或工业制造的输入。与包装、建筑专用品和其他塑料终端件相比，本小类更强调连续挤出、尺寸定型、厚度均匀、壁厚控制、材料批次和后续加工适配性。

塑料壳体在本卡中主要指以塑料板片或热塑成型方式形成的壳状、罩状、箱体状或保护性结构件；若其已经构成特定电子产品、车辆零部件、建筑门窗或包装容器的专门产品，应结合主导功能和机构分类规则另行识别。

A3 边界说明、相邻小类区分点和排除项

相邻活动容易混淆的原因主要区分依据本卡处理原则
14.02.02 塑料包装产品包装膜、片材、瓶坯和容器会使用相同树脂和挤出技术最终交付物是否以包装功能为主通用板片管壳归入本卡；袋、膜、瓶、盒、托盘等包装产品归入 14.02.02。
14.02.03 建筑用塑料制品管材、型材和板材可用于建筑是否按建筑构配件或建筑系统用途生产通用塑料管板归入本卡；门窗型材、防水板、建筑装饰部件等归入 14.02.03。
14.02.04 其他塑料制品注塑壳体、日用塑料件和工业零件可能外形接近产品是否为通用板片管壳基础形态以注塑终端零件或复杂装配件为主的归入 14.02.04。
橡胶制品制造软管、弹性片和密封壳体可能外观相似主材是否为热塑性树脂以及是否经硫化热塑性挤出或热成型归入本卡；橡胶硫化制品归入 14.01。
金属管板壳制造用途和形态相似主材和加工过程不同金属轧制、焊管、冲压和金属壳体不纳入本卡。
塑料原料和改性料制造板片管壳生产前常需配混改性最终产品是否为树脂颗粒或制品形态只生产改性塑料颗粒的活动不纳入本卡。

明确排除项：

  • 以包装用途为主的塑料袋、薄膜、瓶、盒、桶、托盘和复合包装。
  • 建筑专用塑料门窗型材、装饰板、防水材料和建筑系统构件。
  • 塑料原料、改性塑料颗粒、母粒和化学单体生产。
  • 复杂注塑装配件、日用塑料件、玩具、文具和专用工业塑料零件。
  • 金属、玻璃、纸质或橡胶板片管壳产品。

A4 分组特征摘要

维度本小类特征上层分组调用提示
主导活动类型连续热塑加工和基础形态塑料制品制造与包装和建筑塑料相比，本小类更偏板片管壳基础材料，不以终端用途定义为主。
核心过程性质树脂干燥、配混、挤出或压延、模头成型、定径冷却、牵引切割、热成型或壳体加工A4 应突出连续成型、尺寸稳定和壁厚控制，而不是泛泛写塑料加工。
主要技术基础热塑性流变、熔体温控、模头流道、真空定径、冷却结晶、牵引同步、材料改性和二次加工具备注塑终端件知识不等同于掌握连续挤出板管线。
产业链段位上接树脂、改性料、填料和母粒，下接包装、建筑、广告、化工、电子外壳和工业制造本小类常作为中间材料，上层调用应识别是否已进入特定产品小类。
典型规模跨度大型连续挤出线、中型管材厂、小型板片加工厂均存在设备线速度、模头宽度、冷却系统和在线检测能力差异明显。
内部差异提示板材、片材、管材和壳体在模头、定型、厚度和后加工方式上不同不可把四类产品全部写成同一挤出流程。
分组比较提示与 14.02.02 共享薄膜片材技术，但包装更强调热封、阻隔和印刷；与 14.02.03 共享型材管材技术，但建筑更强调构配件适配和耐候共组时应说明用途分化不会掩盖过程共性。
分组敏感边界塑料管既可为通用管材，也可为建筑给排水或工业防腐管应依据产品标准、销售用途、结构设计和客户场景判定。

A4 不是新的事实来源，而是从 C、D、E、G、H 各段提炼出的调用索引。上层文件使用本卡时，应以 A4 先形成初判，再回到 D 段过程链、G 段检测手段和 H3 客观敏感点核对证据。

B. 术语与概念

B1 专业术语和行业常用表达

术语解释本小类中的使用语境
树脂塑料制品的高分子基础材料决定材料熔融、成型和使用性能。
改性料通过填充、增强、阻燃、增韧或合金化处理的塑料材料用于满足特定性能和加工要求。
母粒含有高浓度颜料或助剂的粒料用于着色、抗老化、阻燃、抗静电等。
熔体指数表征热塑性材料流动性的指标影响挤出和成型稳定性。
挤出树脂熔融后通过模头连续成型的过程板、片、管和型材的主要方法。
模头决定熔体截面形状的成型工装板片模头、管材模头和异型材模头差异明显。
定径使塑料管材或型材冷却时保持尺寸的过程常使用真空定径套、定型台或冷却槽。
牵引控制连续制品线速度和尺寸的过程牵引速度与挤出量共同决定厚度和壁厚。
压延熔融或塑化材料经辊筒形成片材的过程PVC片材和部分软质片材常用。
共挤两种或多种材料同时挤出形成多层结构用于耐候层、阻隔层、表面层或功能层。
热成型片材加热后通过模具形成壳体或浅盘形状壳体、罩壳和托盘类制品常用。
真空吸塑利用真空将加热片材吸附到模具上的成型方式薄壁壳体和罩盖常见。
壁厚偏差管材或壳体不同位置厚度差异连续制品和热成型件的重要尺寸现象。
翘曲冷却收缩不均导致板片或壳体变形与材料结晶、冷却和内应力有关。
口模积料模头出口物料堆积或降解导致表面缺陷连续挤出常见异常。
在线测厚连续检测板片厚度的计量方式用于宽幅板片生产线。

B2 缩略语、材料代号和过程代号

缩略语或代号含义说明
PE聚乙烯常用于管材、板材、片材和防腐材料。
PP聚丙烯常用于片材、板材、壳体和耐化学材料。
PVC聚氯乙烯常用于板片、管材和型材。
ABS丙烯腈-丁二烯-苯乙烯共聚物常用于壳体和工程塑料件。
PC聚碳酸酯用于透明板材、罩壳和高强度片材。
PA聚酰胺用于耐磨、强度较高的工程塑料制品。
MFR/MFI熔体流动速率或指数热塑性材料流动性常用表达。

B3 关键技术概念说明

板、片、管和壳类塑料制品的共同技术核心是熔体从颗粒状态转变为连续几何形态，并在冷却、定径和牵引过程中保持尺寸稳定。熔体温度、模头流道、牵引速度和冷却条件会共同塑造产品截面。

本小类与包装塑料的区别不在于是否有薄膜或片材，而在于产品主导用途和交付形态。若产品已经以热封、阻隔、印刷、灌装适配等包装功能定义，通常应转入包装产品小类。

塑料壳体可能由热成型、吸塑、板材折弯焊接或注塑形成。本卡主要覆盖与板片连续生产或板片二次成型相关的壳体；复杂注塑装配件应与 14.02.04 区分。

C2 主要功能和性能维度

本小类产品的功能维度包括尺寸稳定、厚度或壁厚均匀性、表面平整度、颜色一致性、透明度、耐冲击、拉伸和弯曲性能、耐热变形、耐化学介质、耐候、阻燃、耐压、气密或水密、焊接适配性和二次加工适配性。

板材和片材重视厚度、翘曲、表面缺陷和后加工适配；管材重视外径、壁厚、椭圆度、纵向回缩、耐压和连接适配；壳体重视壁厚分布、成型深度、孔位、加强筋、装配尺寸和外观。

材料差异会显著改变工艺窗口。PE和PP更关注结晶冷却和收缩，PVC更关注热稳定和塑化，PC、PA等工程塑料更关注干燥、熔体温度和内应力。

D. 过程与技术

D1 主要工艺或过程流程

塑料板片典型流程为：树脂和助剂接收 -> 干燥或预混 -> 挤出塑化 -> 模头展布或压延 -> 三辊压光或冷却定型 -> 在线测厚 -> 牵引 -> 切边 -> 卷绕或定尺切割 -> 表面保护 -> 检验包装。

塑料管材典型流程为：原料干燥或混配 -> 挤出塑化 -> 管材模头成型 -> 真空定径 -> 喷淋或水槽冷却 -> 牵引 -> 在线外径和壁厚监测 -> 打印标识 -> 切割 -> 扩口或端面处理 -> 检验。

塑料壳体典型流程为：片材制备或外购 -> 加热软化 -> 热成型或吸塑 -> 冷却脱模 -> 修边冲孔 -> 局部焊接、粘接或装配 -> 外观尺寸检验。若为注塑壳体，则应识别是否更适合归入其他塑料制品。

D2 关键过程和特殊过程

过程环节为什么是关键或特殊过程主要控制对象客观证据形态
原料干燥和配混水分、助剂分散和材料比例影响熔体稳定干燥温度、时间、配比、混合均匀性干燥记录、配料单、批次标识。
挤出塑化树脂在料筒内熔融剪切，温度和压力决定熔体状态温区、螺杆转速、熔体压力、过滤网状态设备参数记录、熔体压力曲线。
模头成型模头流道决定截面和厚度分布模唇间隙、口模温度、流道清洁、分流状态首件截面、模头点检、厚度记录。
定径和冷却塑料冷却收缩会改变尺寸和内应力真空度、水温、冷却长度、牵引速度定径记录、尺寸巡检、冷却状态记录。
牵引和切割牵引速度与挤出量匹配影响壁厚和长度线速度、夹持力、切割长度、端面状态在线记录、长度检查、端面检查。
共挤或复合多层材料相容性和层厚难以只靠外观确认层厚比例、材料匹配、温度窗口、界面清洁层厚检测、剖面观察、材料批次记录。
热成型壳体加热、拉伸和冷却决定壁厚分布和翘曲片材温度、模具温度、真空度、成型深度首件确认、壁厚和尺寸记录。
二次焊接和加工焊缝或加工孔位影响壳体功能和装配焊接温度、压力、坡口、孔位、表面清洁图纸、焊接记录、尺寸检验。

D2 记录的是过程本身需要形成稳定输出的技术控制对象；H3 记录的是行业中客观易出问题环节及事实影响链，两者不互相替代。

D3 主要设备、设施和工装

D7 本小类技术链条深化说明

本小类的技术链条是典型的“颗粒材料 -> 熔体 -> 连续截面 -> 冷却定型 -> 定尺或壳体”的热塑转换过程。其特异性不在单个设备，而在挤出量、模头、冷却和牵引的同步关系。

板、片、管和壳体虽然同属基础形态塑料制品，但技术矛盾不同：板片关注厚度横向分布，管材关注外径壁厚和圆度，壳体关注拉伸后的壁厚、翘曲和装配孔位。

链条节点投入或状态技术转换输出或结果本小类特异性
材料准备树脂、改性料、母粒和助剂干燥、混合和计量稳定投料水分和配比直接影响熔体状态。
熔融塑化颗粒料加热、剪切和输送均匀熔体热历史过长会造成降解或色变。
模头赋形熔体通过板片、管材或异型模头连续截面模头是本小类截面形成核心。
冷却定型高温连续制品三辊、真空、水冷或风冷尺寸初步稳定冷却不均会带来内应力和翘曲。
牵引切割连续制品同步牵引和定长切割卷材、定尺板或管材速度匹配决定厚度和长度。
壳体成型片材或板材加热拉伸、吸塑、折弯或焊接壳状结构件壁厚分布和孔位是壳体特异点。
表面保护板片壳产品覆膜、隔离、包装储运状态表面划伤和变形影响后续加工。
交付适配定尺产品或卷材标识、规格、批次和文件确认下游加工输入本小类常作为中间品进入其他产业。

D8 常见异常和过程补救方式

异常类型常见表现通常处理方式底层记录边界
厚度横向波动板片两边和中间厚度不一致调整模唇、辊距、温度和牵引板片特异异常。
管材椭圆或壁厚偏心截面不圆或一侧壁厚偏薄调整模头、定径和冷却管材特异异常。
熔体破裂或表面纹表面粗糙、鲨鱼皮或流痕调整温度、速度、材料和口模连续挤出敏感点。
翘曲变形板材或壳体冷却后弯曲调整冷却、退火、材料和堆放记录尺寸稳定事实。
壳体薄弱区热成型深拉处壁厚过薄调整加热、模具和预拉伸壳体特异异常。

这种产业位置使本小类边界判断高度依赖产品主导用途。相同片材进入包装热封链条时可能属于包装产品，进入建筑门窗或防水系统时可能属于建筑用塑料制品，作为通用坯料时则仍属于本卡。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

维度本小类客观特征表现形式
技术复杂度中到高材料、模头、冷却和牵引共同决定尺寸。

组织类型典型特征过程能力形态

H3 客观存在的易出问题环节和技术敏感点

敏感点客观表现客观影响链底层记录边界
树脂水分偏高气泡、银丝、降解或表面缺陷水分进入熔体 -> 气化或水解 -> 外观和物性变化客观链条。
熔体温度失控色变、降解、流动不足或熔接不良温度异常 -> 熔体状态变化 -> 截面和物性变化不着色。
模头流道污染黑点、线痕或厚度条纹积料降解 -> 夹入制品 -> 表面缺陷连续挤出敏感点。
牵引速度不匹配厚度、壁厚或长度波动线速度变化 -> 截面拉伸变化 -> 尺寸偏差记录技术事实。
冷却不均翘曲、内应力或圆度变化温度梯度 -> 收缩差异 -> 形状变化行业本底事实。
共挤层厚偏差功能层不足或界面不均层厚变化 -> 表面或功能层状态变化 -> 使用表现改变限于事实。
热成型拉伸过度壳体边角过薄或开裂局部拉伸 -> 壁厚下降 -> 结构薄弱壳体特异敏感点。
回料比例波动颜色、气味、物性或杂质变化回料差异 -> 熔体和材料状态变化 -> 成品一致性变化不作评价。
标识规格混淆管材打印、板材标签或材料牌号错误多规格切换 -> 标识失误 -> 下游选用错误组织形态敏感点。
储运变形板材弯曲、管材椭圆、表面划伤堆放和温度作用 -> 形状和表面变化客观影响链。
