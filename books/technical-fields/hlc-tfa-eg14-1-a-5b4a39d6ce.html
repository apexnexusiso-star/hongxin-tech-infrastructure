  • 文件定位说明

本文件用于环境管理体系（EMS）认证中 EG14-1 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦橡胶和塑料制品制造在 EMS 轴下的环境因素、污染源、污染物形成环节、收集治理、监测转移、合规义务接口和环境绩效改进。

本文件不承担行业百科说明功能，基础行业事实由对应专业小类基础卡承载。本文件只调用与分组论证、能力后果和审核抽样有关的信息。本组采用“统一领域包 + 橡胶分支 + 塑料基础成型分支 + 包装分支 + 建筑塑料分支 + 其他塑料分支 + 条件扩展 + 专项边界控制”的使用口径；组内共同基础可以共享，但分支差异必须通过能力标注、条件扩展、专项确认和项目边界控制落地。

  • 技术领域包构成
小类编码小类名称纳入本包的活动范围主要内部路线特殊边界
14.01.01橡胶轮胎和内胎的制造，橡胶轮胎翻新和再造新轮胎、内胎、轮胎半成品和翻新再造轮胎制造。配料混炼、半成品成型、硫化、轮胎成型、胎体打磨修补、二次硫化。轮胎翻新、胎体打磨、硫化烟气、废胎体和重型轮胎搬运应作为边界控制。
14.01.02其他橡胶制品的制造胶管、胶带、密封件、减震件、橡胶板、型材、辊、衬里和包胶复合件制造。模压、挤出、压延、连续硫化、橡胶金属粘接、衬胶和后处理。溶剂粘接、乳胶浸渍、衬胶、胶管增强层和产品族差异应分支确认。
14.02.01塑料板、塑料片、塑料管及塑料壳体的制造塑料板片、管材、壳体和类似基础形态制品制造。挤出、压延、共挤、真空定径、热成型、板材焊接和切割。粉料混配、挤出烟气、冷却水、边角料和管材用途边界应确认。
14.02.02塑料包装产品的制造塑料袋、膜、瓶、桶、盒、托盘、泡罩、瓶盖和功能包装制造。吹膜流延、印刷复合、制袋热封、吹塑注塑、吸塑和周转包装。油墨、胶粘剂、溶剂、迁移检测、标签和内容物适配属于专项边界。
14.02.03建筑用塑料制品的制造塑料门窗型材、门窗成品、建筑装饰板、线槽、采光板、防水排水构件和木塑发泡制品。PVC 混料、型材挤出、共挤耐候层、门窗焊角、五金密封装配、发泡和切割。PVC 粉料、稳定剂、阻燃、建筑现场接口、长料搬运和门窗玻璃装配应受控。
14.02.04其他塑料制品的制造日用、工业、电子电器、车辆配套、文教、休闲、滚塑、发泡和装配类塑料制品。注塑、吹塑、滚塑、发泡、嵌件成型、焊接装配、喷涂印刷和表面处理。集合性小类内部跨度大，应按注塑、滚塑、发泡、喷涂、装配和用途分支限定。
  • 分组设立的基本逻辑

本包在 EMS 轴下的共同对象是高分子材料加工过程中形成的废气、粉尘、废水、固体废物、危险废物、噪声、资源消耗和异常泄漏等环境因素。分组判断的核心不是产品名称是否相近，而是原辅材料、助剂、溶剂、油墨、胶粘剂、粉料、回料和能源介质如何进入生产，污染源和污染物在哪些工序产生，废水、废气和固体废物如何收集、治理、监测、转移和形成合规证据。

本包可概括的共同证据链为：原辅料和化学品输入 -> 配混、混炼、加热成型、硫化、印刷复合、切割打磨或清洗 -> 废气、粉尘、废水、固体废物、危险废物和噪声产生 -> 收集治理、暂存转移、监测和台账 -> 合规接口、异常处置和改进。该链条决定了本包共享的专业能力基础，审核员应能够沿现场产线、物料流、记录台账、控制设施和监测、转移、异常处置和改进闭环建立纵向证据。

组内差异主要表现为产污节点和污染物谱不同：橡胶制品突出炼胶粉尘、炭黑和助剂粉尘、硫化废气、臭气、边角料和废胎体；塑料板管壳突出粉料混配、挤出烟气、冷却水和回料；包装突出油墨、胶粘剂、溶剂、复合熟化和清洗废物；建筑塑料突出 PVC 粉料、稳定剂、切割粉尘、共挤层和长料废料；其他塑料突出注塑、滚塑、发泡、喷涂印刷和集合性外包边界。这些差异不否定设组，但要求本包按“统一领域包 + 分支能力标注 + 条件扩展 + 边界受控”的方式使用，不得把某一产品族或工艺路线经历视为覆盖全部组内小类的充分证明。

  • 专业小类关系类型与授权后果
关系类型含义授权后果典型控制方式
共同基础关系组内小类共享高分子材料加工、配混、加热成型、边角料回用、废气收集、固体废物分类和污染源识别等基础。可简化通用环境因素和污染源基础评价，但仍需确认目标小类的实际工艺、污染物和治理设施。资料评审、污染源清单核对、现场路线追溯、排放和转移记录抽样。
并列分支关系同属本技术领域包，但橡胶硫化、塑料熔融、包装印刷复合、建筑 PVC 型材和注塑装配等路线的产污节点不同。应记录实际分支能力，不把同包经历视为全分支能力。分支标注、限定使用、项目技术支持、见证审核。
条件扩展关系已具备相邻分支能力，具有共同材料和环境因素基础，但目标分支存在专门污染源或合规接口。完成补充培训、案例评审、专业面谈、见证审核或技术支持后方可扩展。培训考核、污染源案例评价、首个项目技术支持。
专项确认关系涉及溶剂印刷复合、轮胎翻新打磨、乳胶浸渍、发泡、PVC 粉料和稳定剂、食品接触包装或建筑应用边界。项目使用前应专项确认，必要时增加产品族或工艺路线限定。专项面谈、技术专家评审、现场污染源样本评价。
不可直接替代关系相关高分子材料经历不足以证明目标分支的污染源识别、污染物控制和合规接口能力。不得作为目标能力的单独授权依据，应补充目标经历或限定项目类型。重新评价、补充经历、限定污染源和工艺路线。
边界受控关系当排污许可、危险废物、食品接触包装、溶剂使用、废胎处置、外包治理或地方监管接口改变边界时，同包授权应增加边界说明。授权记录应写明适用边界，项目匹配按实际活动确认。授权备注、合规类别清单、技术支持。
橡胶与塑料基础成型均涉及高分子材料、粉料或颗粒、加热成型、边角料和设备噪声，但橡胶硫化废气和塑料熔融烟气不同。可共享高分子加工环境基础，目标分支的废气成分和治理方式仍需确认。污染源清单、废气收集设施、监测记录和固废台账追溯。
包装分支与其他塑料均可能使用注塑、吹塑或热成型，但包装印刷复合和溶剂使用使 VOCs、废油墨、废胶和清洗废物更突出。普通塑料经历不能替代包装印刷复合 EMS 能力。油墨胶粘剂台账、废活性炭、废包装桶、排气筒和无组织控制样本。
轮胎翻新和废胎边界翻新与新胎共享硫化和橡胶废气基础，但胎体打磨粉尘、废胎体和修补材料形成专门环境因素。轮胎制造经历扩展到翻新需补充胎体和废胎流向确认。胎体接收、打磨除尘、废胎和边角料转移记录抽样。
  • 本体系共同能力基础
共同能力维度本包共同基础可共享的审核判断不能共享的边界
环境因素识别组内均需识别原料粉尘、热加工废气、VOCs、臭气、废水、固体废物、危险废物、噪声和资源消耗。可共享从工艺流程识别环境因素、确定污染源、划分正常和异常状态的审核判断。硫化废气、印刷复合 VOCs、PVC 粉料、发泡剂、废胎体和食品包装清洗边界需分支确认。
废气和无组织排放混炼、粉料投加、塑化挤出、硫化、热封、印刷、复合、喷涂和清洗均可能形成废气或无组织排放。可共享集气罩、密闭、通风、除尘、吸附、燃烧或洗涤治理设施的审核方法。橡胶硫化臭气与包装溶剂 VOCs 的污染物、治理效率和监测项目不同。
废水和循环水清洗、废气治理、乳胶浸渍、模具清洗、冷却循环和生活污水可能构成废水管理对象。可共享废水来源识别、分质收集、处理设施、排口、监测和异常溢流控制判断。多数塑料冷却水可循环，乳胶或清洗废水、喷淋吸收液和含油废水需专项确认。
固体废物和危险废物边角料、不合格品、废包装、废滤材、废活性炭、废油、废抹布、废胶、废胎体、废油墨胶粘剂和废化学品桶均可能存在。可共享分类、暂存、标识、转移、回用和台账审核方法。危险废物属性、废胎处置、包装溶剂废物和回料使用边界不能互相替代。
合规义务和监测均需把排放、转移、许可、监测、台账、突发环境事件和第三方处置等类别转化为运行控制。可共享合规义务识别、监测计划、记录保存、第三方资质核验和异常处置判断。不同地区、产品用途、溶剂用量、排口和固废属性会改变适用性。
  • 本体系核心控制要求

本组 EMS 审核的核心控制对象是环境因素和污染源。审核员应从原辅料和能源介质进入组织开始，沿配混、混炼、塑化、挤出、硫化、印刷复合、切割打磨、清洗、治理设施、暂存转移、监测和合规接口建立证据链。

第一，应确认组织是否按照产品族和工艺路线识别环境因素。橡胶混炼、硫化、翻新打磨、塑料粉料混配、挤出塑化、包装印刷复合、PVC 型材混料、注塑喷涂和发泡等环节的污染源不同，环境因素清单不能只按大类笼统列示。

第二，应审核废气和粉尘的收集治理。橡胶企业应关注炭黑和助剂粉尘、炼胶粉尘、硫化废气、臭气和溶剂挥发；塑料企业应关注粉料投加、挤出和注塑热加工烟气；包装企业应关注油墨、胶粘剂、熟化、清洗和印刷复合 VOCs；建筑塑料应关注 PVC 粉料、稳定剂和切割粉尘。

第三，应审核废水和循环水边界。多数塑料成型冷却水以循环使用为主，但清洗废水、废气喷淋液、乳胶浸渍废水、模具清洗水、地面清洗水和生活污水仍需识别。审核应核对排口、处理设施、监测记录、异常旁路和雨污分流状态。

第四，应把固体废物和危险废物作为重要证据链。边角料和不合格品可回用或外售，但废活性炭、废滤材、废油墨、废胶粘剂、废溶剂、废油、含化学品包装、废抹布和废喷淋液可能具有专门管理要求。废胎体、废胶料、PVC 粉尘和废包装物的分类、暂存、转移和去向应形成闭环。

第五，应审核监测和合规义务接口。排气筒、无组织排放、废水排口、厂界噪声、固体废物转移、危险废物贮存、化学品储存和突发环境事件应按组织实际活动建立清单。监测结果异常、治理设施停运、活性炭更换、袋式除尘清灰和第三方处置异常应能追溯到纠正措施。

第六，应关注生命周期和资源效率。橡胶和塑料制品普遍存在边角料、废品和包装材料消耗；轮胎翻新具有再制造属性，但同时带来废胎体和打磨粉尘；包装产品和建筑塑料涉及下游使用和废弃边界。EMS 审核应评价组织是否识别可控的减量、替代、回用和污染预防机会。

  • 分小类或内部路线差异分析
小类/路线与本包共同基础主要差异差异对能力授权的影响控制方式
14.01.01 轮胎和内胎制造共享高分子材料、粉尘、硫化废气、边角料、废水和噪声控制基础。轮胎半成品多、硫化强度高、废胶囊和废垫布等辅助废物多，内胎检漏和气门嘴工序较集中。应标注轮胎分支；普通橡胶件经历不能替代轮胎硫化和轮胎废物链能力。抽取轮胎批次，追溯混炼粉尘、硫化废气、边角料、废胶囊和监测记录。
14.01.01 翻新再造轮胎共享橡胶硫化和成品边角料基础。旧胎体接收、打磨粉尘、修补材料、废胎体淘汰和二次硫化形成专门环境因素。属于专项确认路线；新胎制造经历不能替代废胎和胎体打磨污染源识别。抽取翻新现场，追溯胎体来源、打磨除尘、废胎去向、修补材料和硫化废气。
14.01.02 其他橡胶制品共享橡胶混炼、成型、硫化、边角料和废气控制基础。胶管、密封件、衬胶、包胶和乳胶浸渍路线差异大，溶剂粘接、表面处理和清洗废水可能突出。应按产品族标注；跨密封、胶管、衬胶和乳胶路线扩展需补充确认。抽取目标产品族，追溯原料、硫化、粘接、废气、废水和固废。
14.02.01 板片管壳共享塑料粉料、挤出塑化、边角料、回料、冷却水和噪声基础。连续挤出、模头、定径和切割带来粉尘、热塑烟气、冷却水和长料边角料。可作为塑料基础成型分支；不能替代包装溶剂和建筑 PVC 专项边界。抽取挤出线，追溯投料粉尘、挤出废气、冷却水、边角料和回料。
14.02.02 塑料包装共享塑料成型、边角料和废气控制基础。印刷、复合、熟化、制袋清洗、油墨胶粘剂、废活性炭和包装标签边界突出。从普通塑料成型扩展到包装需专项确认溶剂和废物链。抽取印刷复合或制袋线，追溯油墨胶粘剂、VOCs、废桶、废活性炭和监测记录。
14.02.03 建筑用塑料共享塑料挤出、粉料、切割、边角料和废气控制基础。PVC 粉料、稳定剂、共挤耐候层、发泡、切割粉尘、长料废品和建筑应用边界突出。应标注建筑塑料分支；通用管板经历不能替代 PVC 型材和门窗链条。抽取型材或门窗线，追溯混料粉尘、挤出废气、切割废料、助剂和固废台账。
14.02.04 其他塑料制品共享塑料注塑、吹塑、边角料、回料和废气基础。集合性强，滚塑、发泡、喷涂、印刷、嵌件装配和电子外壳路线的污染源差异明显。应按产品族和工艺路线标注，不宜笼统按小类使用。抽取注塑、滚塑、发泡或喷涂样本，追溯废气、固废、化学品和回料边界。
  • 分组合理性论证结论

本组可以设立的理由在于，六个小类均属于高分子材料制品制造，EMS 轴下的主要环境因素集中在粉尘、废气、VOCs、废水、固体废物、危险废物、噪声、资源消耗和异常泄漏。其污染源识别、收集治理、监测、暂存转移、台账和合规义务转换方法具有共同基础。

因此，EG14-1 可以作为环境管理体系（EMS）技术领域包使用，使用口径为“统一领域包 + 橡胶分支 + 塑料基础成型分支 + 包装分支 + 建筑塑料分支 + 其他塑料分支 + 条件扩展 + 专项边界控制”。审核员授权、项目匹配、能力扩展和持续保持均应体现分支差异；当项目产品族、工艺路线或现场条件超出已确认经历时，应通过案例评价、专业面谈、见证审核或技术支持补足证据。

  • 培训、考核与作业指导书需求

本组应建立橡胶和塑料制品 EMS 专业培训，内容包括高分子材料加工环境因素识别、橡胶混炼粉尘、硫化废气和臭气、轮胎翻新打磨粉尘和废胎处置、塑料挤出和注塑热加工废气、包装印刷复合 VOCs、油墨胶粘剂和废活性炭、PVC 粉料和稳定剂、发泡和喷涂路线、废水和循环水边界、固体废物和危险废物分类、排放监测、第三方处置和异常应急。

考核宜采用场景式案例和纵向追溯题，要求审核员能够从一个真实或模拟现场出发，说明污染源识别、污染物产生、收集治理、监测转移、合规义务接口、异常处置和改进闭环之间的证据关系。作业指导书应提供分支化抽样路径、典型记录清单、访谈问题库、授权边界提示和首个项目技术支持触发条件。

本组可能涉及排污许可类别、废气和无组织排放、VOCs 治理、恶臭控制、颗粒物控制、废水排放、厂界噪声、固体废物、危险废物、化学品储存、突发环境事件、第三方处置、清洁生产、资源综合利用、再生料和废胎资源化、食品接触包装相关环境合规接口、地方排放管理和客户环境要求等类别。本文件不列具体标准编号和年份；适用性应使用机构受控的有效清单、产品目录、项目范围、客户合同、排放或职业健康检测资料、许可文件类别和所在地监管要求确认。上述类别用于识别外部要求如何转化为管理控制、运行控制、记录保存和现场验证，不替代政府许可、行政执法或专项法定结论。

  • 分组使用限制和法定边界

本组 EMS 分组不替代排污许可核发、环境影响评价审批、竣工环保验收、危险废物属性鉴别、清洁生产审核、突发环境事件备案、在线监测验收、第三方治理设施验收、政府环境执法或行政处罚判断。涉及溶剂印刷复合、轮胎翻新、乳胶浸渍、发泡、喷涂、PVC 粉料、食品接触包装和废胎处置时，应确认审核员具备对应分支能力。

环境管理体系审核仅用于评价组织是否识别并控制其环境因素和合规义务，不替代政府许可、法定监测、行政执法、环保设施验收、危险废物鉴别、污染事故调查或其他法定结论。

  • 分组结论与使用口径

EG14-1 可作为环境管理体系橡胶和塑料制品制造技术领域包使用。授权时应记录审核员在橡胶混炼硫化、轮胎翻新、塑料挤出注塑、塑料包装印刷复合、建筑塑料和其他塑料特殊路线上的实际能力。组内扩展应通过培训、案例评审、专业面谈、见证审核或项目技术支持控制。文件维护触发条件包括：原辅材料和助剂变化、溶剂或 VOCs 控制方式变化、废物属性变化、排放口和治理设施变化、产品用途边界变化、法规许可类别变化或项目匹配中出现能力争议。
