  • 文件定位说明

本文件用于环境管理体系认证中 EG29-4 技术领域包的分组论证、审核员专业能力评价、授权控制、项目匹配、能力扩展和持续保持。文件聚焦个人及家庭用品修理服务在环境管理体系轴下的维修拆解、废旧件、电子废弃物、制冷剂、油脂胶粘剂、清洁废液和外包处置，不承担行业百科说明功能；基础行业事实由对应专业小类基础卡承载。

本组采用“共同维修逻辑 + 维修对象分支限定”的使用口径。组内小类可以共享本体系轴下的基础判断方法，但不得把某一分支经历等同于另一分支完整能力。对污染源、危险源、外部合规接口、客户现场或外包链条发生实质变化的情形，应在授权和项目匹配阶段追加分支确认。

  • 分组设立的基本逻辑

本组在本体系轴下的共同对象是个人及家庭用品的接收、故障诊断、维修、更换、调试和交付服务。分组判断的核心不是小类名称是否相近，而是环境因素、污染源、污染物、废水、废气、固体废物、监测、外包处置和合规义务的形成机理、控制路径和审核证据是否足够接近。

本组可概括的共同证据链为：接修登记 -> 故障诊断 -> 报价确认 -> 拆解维修 -> 备件和材料使用 -> 功能或外观验证 -> 废旧件和废液收集 -> 交付和返修反馈。该链条决定了审核员可以共用的专业能力基础，也决定了现场抽样时应从源头识别、过程控制、记录追溯、异常处置和改进闭环几个方向建立证据。

电子产品、家电园艺设备、鞋革、家具、钟表珠宝和其他家庭用品的材料、工具、废旧件和污染物不同。这些差异不否定设组，但要求本组按条件授权和边界受控方式使用。

  • 组内关系结构与授权后果
关系类型含义授权后果典型控制方式
共同基础关系组内活动均需要识别环境因素、污染源、污染物、资源能源消耗、废水、废气、固体废物、外包处置和合规义务。可共享基础 EMS 审核能力，但应确认具体商品、服务场所和外包链条。资料评审、环境因素清单复核、现场走查、废物流向追溯。
并列分支关系同属本环境领域包，但商品属性、场所形态、储存条件、废物类别或客户现场接口不同。授权应保留分支标注，不把单一分支经历理解为全分支能力。分支面谈、样本追溯、项目匹配备注。
条件扩展关系相邻分支具备相同控制基础，但目标分支存在专门污染源、危险废物、冷链、燃料、化学品或维修废物。完成补充培训、案例评审、专业面谈或见证审核后方可扩展。培训考核、案例评审、见证审核。
专项确认关系涉及燃料、危险化学品、药品、冷库、废旧材料、制冷剂、油液、电子废弃物等高边界环境因素。项目使用前应确认实际经营内容和污染控制责任，必要时配置技术支持。专项问询、合同边界确认、外包方证据复核。
不可替代关系纯办公、纯代理或普通零售经历不能证明燃料经营、维修服务、废旧材料或化学品经营的环境控制能力。不得作为目标分支能力的单独依据。补充目标经历或限定项目类型。
边界受控关系实际业务包含仓储、运输、维修、拆解、加注、清洗、冷链或客户现场服务时，环境因素边界发生变化。授权和项目匹配应按实际活动边界使用。授权备注、现场边界确认、外包链条核验。
维修对象分支组内共享维修服务链条，但不同对象产生不同废物和环境敏感点。授权应标注电子电器、鞋革家具、钟表珠宝或其他用品分支。接修工单、拆解现场、废旧件和材料去向追溯。
  • 共同过程与专业机制分析

个人家庭用品维修的环境因素通常规模不大，但种类分散、现场细碎。电子产品维修关注废电路板、显示屏、电池和报废介质；家电维修关注制冷剂、润滑油、清洁剂和废旧零部件；鞋革和家具维修关注胶粘剂、涂料、皮革边角料、木屑和打磨粉尘；钟表珠宝维修关注小型金属件、清洗液和贵重物品保护。EMS 审核的关键是用工单把维修对象、材料消耗和废弃物去向追溯起来。

过程环节环境因素和污染源形成机制审核关注的证据
接修诊断确定维修对象、故障类型、材料和可能产生的废旧件。接修单、检测记录、客户确认。
拆解维修拆解、更换、焊接、清洁、打磨、胶粘或润滑形成废物和污染物。维修记录、材料领用、现场分区、设备点检。
废旧件处置电子废物、电池、制冷剂、废油、木屑、皮革边料、清洗液和包装物需分类去向。废物台账、回收记录、外包处置凭证。
交付返修功能验证和返修反馈可暴露维修过程控制和废物产生的重复性。交付确认、返修记录、投诉处理。
  • 本体系核心控制要求

第一，应按维修对象建立分支化环境因素识别。不能把所有家庭用品维修写成一个笼统工序，审核员应区分电子产品、家电园艺设备、鞋革、家具、钟表珠宝和其他用品的材料、工具、废物和外包处置路径。

第二，应以接修工单追溯废旧件和材料。抽样时应核对维修项目、备件领用、废旧件替换、清洁或胶粘材料使用、功能验证和交付记录，确认废物产生量与业务量相匹配。

第三，应关注电子废弃物、电池和制冷剂。消费电子和家电维修常涉及电池、线路板、显示屏、压缩机、制冷剂和旧电器部件，其回收、暂存和委托处置应形成证据链。

第四，应关注小型维修场所的现场管理。家庭用品维修常见小店、柜台、上门服务和外包维修中心并存，审核员应确认组织实际控制边界，不能只看客户服务前台资料。

  • 分组结论

EG29-4 组内小类均围绕个人及家庭用品维修形成环境因素，核心证据链为接修、诊断、拆解、材料使用、废旧件和废液处置、功能验证与客户交付。不同维修对象的污染物不同，但维修服务逻辑和废物追溯方法一致，因此可以设为同一环境管理体系技术领域包，并通过维修对象分支限定控制差异。

因此，EG29-4 可以作为环境管理体系技术领域包使用，使用方式为“共同维修逻辑 + 维修对象分支限定”。审核员授权、项目匹配和能力扩展均应体现分支差异，不得把同包经历理解为跨全部小类的充分证明。

  • 审核员共同能力评价与条件授权

本章用于界定本技术领域包可共享的共同能力，以及不同分支在授权、项目匹配和能力扩展时需要追加确认的内容。

能力要素评价内容可接受证据授权控制
环境因素识别识别服务场所、仓储、运输、维修、燃料、化学品、废弃物和外包链条形成的环境因素。环境因素清单、现场走查记录、外包合同、废物转移或处置记录。按分支标注；特殊商品需专项确认。
污染源与污染物判断判断废水、废气、固体废物、危险废物、油气、异味、粉尘、制冷剂和化学品泄漏来源。现场照片、台账、监测或检查记录、应急物资、处置凭证。燃料、化工、维修和冷链类项目需目标经历或专家支持。
合规义务转化将许可、产品经营、废物处置、排放、运输和客户要求转化为组织内部控制。合规义务清单、合同评审、供应商评价、外包方资质和内审记录。不替代行政许可判断，仅评价管理体系控制。
运行控制与应急检查泄漏预防、废物分类、外包处置、清洁消毒、冷链、维修废物和异常处置。运行规程、点检记录、培训记录、应急演练、异常整改记录。按实际活动抽样，不能用纯办公经历替代现场经营。
绩效与改进评价监测、巡检、废物去向、能资源消耗和投诉事件的趋势与改进。目标指标、统计报表、纠正措施、管理评审输入。证据应能追溯到具体场所或服务样本。

能力扩展应采用“基础经历确认、目标分支差异培训、案例评审或专业面谈、必要时见证审核、授权记录标注”的路径。对燃料、危险化学品、车辆维修、个人家庭用品维修、冷链、废旧材料和含客户现场复杂接口的项目，应在项目匹配阶段再次确认适用边界。

  • 审核关键要点与抽样路径

本组抽样应至少覆盖一个电子或电器类维修样本、一个非电子类维修样本和一个废旧件或废液处置样本；若组织开展上门维修或外包维修，应追加客户现场或外包接口证据。

  • 培训、考核与作业指导书需求

培训应覆盖个人家庭用品维修的工单追溯、电子废弃物、电池和制冷剂、胶粘剂和清洗液、木屑和皮革边角料、贵重物品交接、上门维修和外包维修边界。对只有零售经历的审核员，应通过维修案例确认其能够识别维修废物和材料使用。

考核宜采用场景题、案例追溯题和边界判断题，要求审核员能够从一个真实或模拟项目出发，说明本体系轴下的识别、评价、控制、记录、异常处置和改进之间的证据关系。作业指导书应提供分支化抽样路径、记录清单、访谈问题和授权边界提示。

  • 常见合规义务类别与标准适用提示

常见合规义务类别包括废旧电子产品和废电池回收、制冷剂和含油废物管理、化学品和清洁剂使用、固体废物分类处置、上门服务安全环保约定、客户财产保护和外包维修方控制。本文件不列入具体标准编号和年份；适用性应使用机构受控的有效清单、客户合同、服务目录、项目范围和所在地监管要求确认。上述类别用于识别外部要求如何转化为管理体系控制，不替代政府许可、法定检验、行政执法或客户专项验收。

  • 使用限制和法定边界

本组不覆盖电子电器制造、家具制造、珠宝制造、汽车维修、报废产品拆解再加工或危险废物经营。若维修组织实质开展翻新制造、拆解再销售或规模化再制造，应另行确认对应技术领域能力。

管理体系审核仅用于评价组织是否在其服务范围内建立并实施相应管理控制，不替代行政许可、法定检验、行政执法、政府监管、司法判断或强制性专项评价。涉及受监管资质、特种商品、危险化学品、燃料、药品、医疗器械、个人信息、资金信用、道路运输、客户现场和外包服务时，应在项目匹配阶段确认审核员分支能力和必要的技术支持。
