A. 标识与定位

A1 小类名称、分类代码、在分类体系中的位置

字段内容
专业小类代码19.08.00
专业小类名称磁性及光学媒体的制造
所属大类19 电气、电子和光学设备制造及相关服务
所属中类19.08 磁性及光学媒体制造
本卡定位描述用于数据、音视频或信息记录的磁性介质、光学介质和相关存储载体的行业事实，侧重产品边界、电子装联、功能形成、测试计量、版本追溯和交付资料。
与上层文件关系本卡只记录底层行业事实、技术边界、过程、设备、投入、检测手段和维护信息，不记录任何上层视图判断。

A2 定义与范围界定

本小类是指围绕用于数据、音视频或信息记录的磁性介质、光学介质和相关存储载体开展设计转化、物料准备、电子装联、结构装配、程序配置、功能测试、标识包装和交付资料形成的制造活动。

本小类通常包括磁带、磁盘、光盘、记录介质、复制介质、涂布介质、光学记录层、基片、保护层、标识包装和介质检测等制造活动。部分产品形态随技术发展变化，但分类识别仍以记录介质制造为核心。

本小类不包括硬盘整机制造、半导体存储器制造、计算机设备制造、音视频内容制作、数据服务、印刷复制服务和存储设备维修服务。

易混淆活动混淆原因区分依据本卡处理原则

19.03.00 通信设备制造通信设备也由电子板和模块构成通信设备以无线、有线、网络传输或交换功能为主导按通信功能、射频或网络接口识别。
19.04.00 消费类电子产品制造消费电子和专业电子产品外观相近消费电子以民用娱乐、音视频、个人使用或家庭场景为主按用途、渠道和产品功能识别。
19.05.01 仪器及导航装置制造仪器产品也有电子测量模块仪器以测量、检测、导航、校准或显示量值为主导按测量对象和计量链条识别。
19.07.00 光学仪器及摄影器材制造光学仪器含电子控制和传感器光学仪器以镜片、光路、成像、观察或测量光学系统为主导按光学系统是否为核心识别。
内容制作光盘或磁带可能承载内容本小类制造记录介质，内容制作属于信息或文化服务按交付对象识别。
半导体存储均为数据存储半导体存储以芯片或固态器件为主，本小类以磁性或光学记录介质为主按记录机理识别。

明确排除项包括：单纯元器件贸易、单纯软件开发、无实物制造责任的系统集成、维修服务、安装服务、普通机械加工、塑料外壳或包装材料独立制造。

A4 分组特征摘要

受控维度本小类特征摘要
主导活动类型磁性及光学媒体制造，交付对象是承载信息记录功能的磁性、光学或复合记录介质。
核心过程性质基材处理、磁性涂布或光学复制、记录层/反射层/保护层形成、分切卷绕或注塑金属化、读写特性检测、标签包装。
主要技术基础薄膜基材、磁性颗粒分散、精密涂布、光盘母盘复制、金属化、UV固化、表面缺陷控制、误码和读写状态测试。
产业链段位位于高分子基材、磁性材料、光学材料、模具母盘和包装材料之后，数据备份、音视频载体、档案存储和工业记录应用之前。
典型规模跨度覆盖磁带介质厂、光盘介质厂、备份数据介质厂、记录层涂布企业、复制介质企业和专用记录载体企业。
主要分型轴按磁性/光学/相变/复制、空白/预录、磁带/光盘/专用介质、记录层结构、读写方式和包装形态分型。
分组比较提示与计算机存储设备的边界在于本小类形成记录介质本体，不形成硬盘、固态存储或整机设备；与内容制作服务按交付对象区分。

B3 关键技术概念说明

磁性及光学媒体的制造的底层识别不能只看是否带电路板，而要看交付对象是否围绕磁性及光学媒体形成独立功能。板卡、外壳、线束、显示件、软件和包装共同构成产品状态。 电子类产品的制造过程通常具有物料小型化、批次多、版本变化快、软件和硬件耦合、检测项目密集等特征。材料、焊接、清洁度、静电防护和程序版本都会传递到成品状态。 电子制造中的测试不是单一终检概念，而是从来料、过程、板级、模块、整机到老化和出货的多层状态确认。不同企业可能承担其中一段，也可能承担完整整机制造。 本卡只描述行业事实和分类边界，不记录任何上层视图中的重要程度判断。

D. 过程与技术

D1 主要工艺/过程流程

`mermaid flowchart LR A["基材准备"] B["涂布压制或复制"] C["记录层和保护层形成"] D["固化或金属化"] E["介质检测"] F["标识包装"] A --> B B --> C C --> D D --> E E --> F `

磁性及光学媒体制造的核心不是电子装联，而是记录层结构。基材、磁性涂层、染料层、相变层、反射层和保护层共同决定读写状态。 磁带类产品要关注浆料分散、精密涂布、干燥、压光、分切、卷绕和带盒装配。厚度、颗粒、卷绕张力和表面缺陷会影响记录状态。 光学媒体要关注基片注塑、母盘复制、坑纹、金属化、保护层、印刷标签和固化状态。复制缺陷、翘曲、划伤和反射状态是关键事实。 介质测试通常关注误码、反射率、磁性参数、厚度、表面缺陷、翘曲、卷绕和包装防护。内容本身不是本卡的制造对象。

D5 常见工艺路线或服务路线差异

路线典型组织形态差异说明
专业装联路线电子装联工厂以 SMT、THT、焊接、AOI、ICT 和板级测试为主，整机装配较少。
模块制造路线功能模块企业在板卡基础上增加结构、接口、参数配置和模块测试。
整机制造路线品牌厂或代工厂包含结构装配、软件配置、整机测试、老化、包装和售后资料。
小批专用路线仪器、通信或工业电子企业批量小、版本多、配置差异大，测试和资料依赖度高。
高度自动化路线大批量消费或计算设备企业自动装联、自动测试、条码追溯和流水化包装突出。

H. 行业本底特征

H1 技术复杂度、自动化与人工依赖程度

本小类技术复杂度取决于磁性及光学媒体的功能复杂度、电子装联密度、软件配置、测试深度和供应链稳定性。大批量产品自动化程度较高，小批专业产品更依赖人工装配、调试和工程判断。产品版本变化快、元器件替代频繁、测试夹具和软件程序依赖度高，是电子类制造的共同本底特征。

H2 典型组织形态

组织形态典型特征常见资源配置

电子装联工厂以板卡和模块装配为主SMT、THT、清洗、检测和防静电资源。
品牌整机企业承担整机配置和交付装配线、测试线、老化、包装和售后资料资源。
代工制造企业按客户资料和配置生产物料管理、批量装配、测试夹具和追溯系统。
专业设备企业批量较小、功能专用工程调试、校准、专用测试和客户资料资源。

H3 客观存在的易出问题环节/技术敏感点

敏感点客观影响链
物料替代关系不清元器件型号或等级偏移 → 电路参数和热状态变化 → 产品功能状态波动。
湿敏和静电控制不足元器件受潮或静电放电路径形成 → 焊接或器件状态异常 → 早期失效路径增加。
焊接曲线偏移温度、时间或助焊状态偏移 → 焊点组织和润湿状态变化 → 连接状态波动。
程序版本混淆固件或配置文件版本错误 → 功能逻辑偏移 → 产品交付状态不一致。
测试夹具状态异常夹具磨损、接触不良或程序版本偏移 → 测试结果信息失真。
结构装配应力异常紧固、卡扣、线束或散热接触不当 → 连接、温升或外观状态波动。
老化条件不稳定负载、时间或温度条件偏移 → 早期失效信息暴露不足。
标签和序列号不一致实物、系统记录和包装标识不匹配 → 追溯链条断裂。
涂层均匀性不足厚度、颗粒或分散状态偏移 → 记录层状态变化 → 读写信息波动。
清洁度不足颗粒、划伤或污染进入介质表面 → 读取或写入状态受扰动。
